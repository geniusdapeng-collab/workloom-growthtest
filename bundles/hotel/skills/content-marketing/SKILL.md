# 内容营销套件

## 适用场景
- 每日 1-2 条内容生产；活动节点加更；好评选题库驱动选题

## 触发条件
- 每日定时 + 活动触发 + 好评资产化选题事件

## 输入数据
- 一店一档（brand_guideline/property）、好评选题库（review-asset-mining 产出）、素材库、目的地资料

## 方法
1. 选题：好评高频卖点优先；节假日/本地事件蹭点；竞对内容差异化。
2. 生成：必读「档案+阶段+目标」三要素（L3.7）；基于真实资料，不编造设施/服务。
3. 合规：品牌规范校验（tone/banned_words/image_rules）；forbidden 清单过滤。
4. 排期：小红书/抖音分平台排期；新渠道首发挂起待审。
5. 复盘：阅读/互动数据回流，迭代选题。

## 输出动作
- 内容草稿 → 店长确认 → 发布；新渠道首发 → R3 审批卡

## 对接系统
- 小红书/抖音/素材库（L3 剧本执行层）

## 围栏绑定
- R3（新渠道首发 review）；R15（直播/首发双重必审）

## 验收用例
- 正常路径：选题 → 草稿 → 店长确认 → 发布 → 数据回流
- 异常路径：素材缺失 → 标待补充不编造
- 围栏触发：新渠道首发 → R3 必审；含 forbidden 表达 → 拒绝生成

## 证据口径（无回执不算完成）

1. 内容草稿版本 + 店长确认记录（确认人/时间/版本号）
2. 新渠道首发引用 R3 审批卡；直播类引用 R15 双重必审记录
3. 发布回执（平台/时间/链接）；无回执不得宣称已发布
