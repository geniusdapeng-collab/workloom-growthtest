# 团购券运营（coupon-ops）

> 获客五环④转化环的第一转化品。「先囤后约」把决策做到极致轻量化——用户看到优惠先下手，酒店提前锁定未来入住。

## SKU 设计公式

```
券价 = 门市价 × 0.7~0.85（且 ≥ 保底价×0.85，R26 红线）
权益 = 房型 + 早餐/延迟退房等低成本高感知权益
限制 = 有效期 90-180 天 + 法定节假日不可用（保护旺季收益）+ 不约可退
```

## 与内容的联动纪律

- 推什么内容挂什么券：亲子内容挂亲子券、商旅内容挂商旅券；
- 房态联动：满房日期自动关券（防超卖投诉），淡季猛推（填谷）；
- 售罄/下架即熔断：相关内容停投、AI 接待话术切换、直播口播换品（R22）。

## 核销对账（三轮比对口径）

1. 平台核销记录 ↔ PMS 入住记录 ↔ 券库存扣减，三方一致；
2. 核销率周报复盘：<30% 预警（内容-券不匹配）/ >90% 预警（定价偏低或黄牛）；
3. 未核销到期券：自动退款 + 二次触达（「你的券快到期了」= 免费再营销）。

## 红线

- 券价 < 保底价×0.85 → 熔断（R26）；
- 券文案权益口径与一店一档一致（R25）；
- 库存=0 后任何渠道的售卖动作 → 熔断（R22）。

## 前置校验

1. 券价 = 门市价 × 0.7~0.85 且 **≥ 保底价 × 0.85**（R26 红线）
2. 券面权益口径与一店一档逐字一致（R25），不新增未确认权益
3. 库存与房态日历联动：满房日期必须自动关券；库存=0 后任何渠道售卖动作熔断（R22）


## 失败诊断（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 券价低于保底价×0.85 | R26 红线校验 | 熔断该 SKU，不发布；上报调价建议 |
| 满房日期仍在售券 | 房态日历联动检查 | 自动关券并告警；已售部分给替代方案 |
| 核销三方数据不一致 | 三轮比对（平台/PMS/库存） | 标记差异并冻结对账，不静默平账 |


## 证据口径（无回执不算完成）

1. SKU 定价与权益口径的确认记录（券价/权益/限制三项与一店一档一致）
2. 核销三方比对回执（平台核销 ↔ PMS 入住 ↔ 券库存扣减）与差异清单
3. 核销率周报与预警事件（<30% 或 >90%）；熔断动作（R22/R26）原样上报
