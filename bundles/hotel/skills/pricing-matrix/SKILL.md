# 价格日历套件

## 适用场景
- 90 天价格日历维护；节假日/展会/旺季远期定价；远期房态联动调价

## 触发条件
- 每周定时滚动维护 + 节假日锚点（提前 7 天）+ 远期预订变化事件

## 输入数据
- 一店一档 price_calendar 基线、history_curve 历史曲线、竞对远期价、本地节假日/展会日历

## 方法
1. 矩阵维护：房型×渠道×日期三维价格日历，每周滚动更新 90 天窗口。
2. 节假日锚定：提前 7 天生成节假日价格策略，店长确认后写入日历。
3. 远期联动：远期预订率超/低于阈值 → 对应日期价格带调整建议。
4. 纪律同源：任何日期调价同样受 R1（≤8%）/R2（保底价）约束，远期不放松。

## 输出动作
- 价格日历更新（写 price_calendar 对象）；节假日策略审批卡

## 对接系统
- PMS/OTA 渠道价日历

## 围栏绑定
- R1（涨幅≤8% auto）、R2（保底价 block）

## 验收用例
- 正常路径：周滚动更新 → 远期低预订日期降价 5% → auto 执行 → 日历事件留痕
- 异常路径：竞对远期价缺失 → 该日期标「未核实」不调整
- 围栏触发：节假日策略涨幅 15% → review 挂起；日历价 <¥380 → R2 block

## 证据口径（无回执不算完成）

1. 价格日历更新回执（before/after + 生效日期）与 R1/R2 判定记录
2. 节假日策略审批卡（提前 7 天生成、店长确认）与策略版本号
3. 保底价相关动作引用 R2 block 记录；越线挂起项原样上报
