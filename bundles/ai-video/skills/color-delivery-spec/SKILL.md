# 调色交付规范

## 一、交付口径（第一版）

| 项 | 口径 |
|---|---|
| 色彩空间 | Rec.709（web 交付） |
| 位深/编码 | 8-bit，H.264（交付）/ 原始母版另存 |
| 帧率 | 跟随母版，不改帧率 |
| 音频 | 原样或 AAC 192k（不重编码无损链） |
| 命名 | `<项目>-<版本>-color.<ext>`，版本号只增不覆盖 |

HDR / 10-bit / ACES 属后续能力（当前不做，遇到时按"超出交付口径"上报，不硬凑）。

## 二、平台变体派生纪律

1. 调色只做一次，落在**母版**；
2. 画幅（9:16 / 1:1 / 4:5）、时长、封面从已调色母版派生；
3. **禁止**对每个平台变体重新调色（会造成同片不同色，且成本翻倍）；
4. 平台适配只在必要时微调亮度/对比（见 `color-look-design` 的平台表），并记录为"平台微调"而非"重新调色"。

## 三、证据包（无证据不得宣称完成）

每次交付必须包含：

1. 成片路径 + sha256；
2. 应用滤镜链（可复现）+ profile/LUT 标识 + 强度；
3. before/after 指标（YMIN/YAVG/YMAX/UAVG/VAVG/SATAVG）与差值；
4. scope 三图（波形/矢量/直方图）；
5. **可见性度量**（平均像素差）：`≥4/255` 记 visible 方可作为"已调色"交付；`2–4` 记 subtle 需说明理由；`<2` 由工具直接拒绝出片（verify_failed）；
6. 选型说明（题材/场景/情绪/配方 id）与多镜残差（如有多镜）。

## 四、版本、回滚与围栏

- 原片只读（G-COL2），每次调色产出新文件，版本链可回溯；
- 品牌 look 变更必须走人审（G-COL1）后才可作为默认；
- 调色过程中禁止关闭校验（G-COL3）；
- 单租户日调色超过 30 次触发熔断（G-COL4）——批量任务请分批并说明原因。

## 五、返工判定表（先归因，再动手）

| 现象 | 归因 | 处置 | 案例 |
|---|---|---|---|
| 整体偏色 | 白平衡/矩阵 | 重做校正段（不动 look） | FC-COL-002 |
| 风格不符预期 | 选型错 | 换配方 id + 重出，记录原因 | — |
| 强度过/不足 | 参数 | 只调 intensity（0.5–0.85 区间内微调） | FC-COL-001 / FC-COL-005 |
| 肤色异常 | 校正或饱和 | 先修白平衡，再降饱和，禁止直接调色相 | — |
| 多镜跳变 | 匹配没做/参考镜错 | 重选参考并整批重跑 | FC-COL-003 |
| 关键信息丢失（爆炸/死黑） | 拍摄或渲染阶段 | **不可修复**，退回上游；不得用后期掩盖（检测：`shadow/highlightClipPct` ≥5%） | — |
| 画面发糊/焦点不实 | 拍摄或渲染阶段 | **不可修复**，退回上游（检测：`blurdetect` ≥15 判不可修复档、8–15 告警；浅景深/柔焦属创作意图时人工确认放行） | FC-COL-008 |
| 画面颗粒噪点明显 | 拍摄或渲染阶段 | **不可修复**（不做实质降噪，会涂抹细节）；差分 YAVG ≥9 判明显噪点、5–9 可用保守降噪或保留质感 | — |
| 平滑区出现色带/台阶 | 编码或上游 | **不可修复**：退回重转码/重拍（检测：直方图空洞比 ≥0.25 且行剖面平台 ≥3 且单调）；不得用风格化掩盖 | — |

## 六、不可修复与诚实上报

调色不是万能的。以下情形必须**如实标注"不可修复"**并回退上游，禁止用风格化掩饰：

- 高光/暗部已经裁切（信息不存在）——检测器：`analyze` 的 `shadow/highlightClipPct`，不可修复档 ≥5%；
- 严重欠曝+高感的噪点色块——检测器：`detectDefects` 的噪点差分 YAVG（≥9 不可修复档）；
- 压缩伪影（马赛克、色带）——检测器：`detectBanding` 的直方图空洞比 + 平台结构（holeRatio ≥0.25）；
- 焦点/运动模糊——检测器：`detectBlurLevel`（ffmpeg blurdetect，≥15 不可修复档、8–15 告警档）。

工具口径（`colorwrite.grade` / `colorread.analyze` 的 `defects` 字段，默认开启）：
`report`（默认）**如实上报 + 随证据包留痕**，产物不删；交付硬闸传 `on_unfixable=block`，
命中"不可修复"即删产物并 `verify_failed`。检测器读不到时标注"未核实"，不得当成"通过"。

诚实上报是交付纪律的一部分：宁可标"该镜不可修复"，也不要交付一个看起来"调过了"的坏镜头。
