# 配音交付规范

## 默认与显式配音

成功镜头原生声音直接进入正式后期；无音轨也不自动 ASR、TTS、克隆或重渲。只有用户明确要求配音且已有真实声音授权时执行 speak/dub，默认处理一次，不做后置 ASR、口型、声音品质评审或质量重试。

## 输出契约

| 实际交付事实 | 记录 |
|---|---|
| 文件 | 新音频/配音视频、路径、SHA 和普通时长/音轨元数据 |
| 授权 | profile-id、参考源 SHA、来源与本次用途/外发授权 |
| 引擎 | 实际 kind/model 与请求参数，不伪称调用 |
| 配音 | 段起止、生成时长、显式适配参数、实际原声策略 |
| 处理 | 请求 loudnorm/混音/视频 copy、源未改变、真实错误 |
| 品质 | 默认 null/`not-reviewed`，`qualityReviewPerformed=false` |

-16/-14 LUFS 与峰值可以是请求滤镜参数；未额外测量不宣称达标。无 ASR 诊断不伪造文本匹配或口型通过，也不把未测诊断挂起为后期审批。

## 显式诊断

`voicewrite.verify` 保留为用户明确调用的诊断，可使用 expect_text、ASR、响度、峰值或时间检查。诊断失败/未核实如实返回，strict 行为按该工具契约执行；它不自动追加配音、重渲、模型或人工，也不是成功原片进入普通后期的必需步骤。

## 不变的授权和技术边界

G-VOICE1 克隆授权与 G-VOICE6 外发授权保持；G-VOICE2 原片/参考只读、G-VOICE4 配额与 G-VOICE5 声纹隐私保持。G-VOICE3 不把 verify=false/skip_verify 视为普通后期违规。默认音轨不需要宿主 stems 密钥；显式独立源仍需真实授权与字节验证。

非法时间窗、超过显式适配边界、授权不足、非本机引擎、路径、磁盘、实际合成/ffmpeg 或输出规格错误必须失败，不能吞掉或伪报完成。用户明确反馈后修改指定音频层；历史声音意见保留，不导致成功镜头自动重做。
