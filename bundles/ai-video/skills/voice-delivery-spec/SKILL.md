# 配音交付规范

## 一、交付口径（第一版）

| 项 | 播报音频 | 成片配音 |
|---|---|---|
| 响度 | **-16 LUFS**（±1.0） | **-14 LUFS**（±1.5） |
| 真峰值 | ≤ **-1.5 dBTP** | ≤ **-1.0 dBTP** |
| 采样率 / 声道 | 24kHz 单声道（语音轨） | 24kHz 单声道语音轨混入成片；视频轨 `copy` |
| 段间气口 | 150–250ms | 按时间窗，不额外加气口 |
| 命名 | `<角色>-<用途>-<版本>.wav` | `<项目>-<版本>-dubbed.mp4` |
| 版本 | 只增不覆盖（v1/v2/…） | 只增不覆盖；原片只读 |

本地工位的产物默认落 `~/.workloom/voice-station/deliveries/`；客户素材与成品只在工位/租户素材区留存，不上行蜂群。

## 二、证据包六件（缺一不算完成）

1. 产物路径 + **sha256**（磁盘文件与回执必须对得上）；
2. **时长**与响度（LUFS / dBTP / LRA）实测值；
3. **音色档案**引用（profile-id + 参考音频 sha256 + 授权范围）；
4. **引擎与模型版本**（kind / model / 是否用了参考音频注入）；
5. 性能指标：**RTF**（渲染耗时 ÷ 音频时长）、分段数、重试次数；
6. 视频配音另附**逐段时窗表**与总时长漂移；有台词必须附有效 **ASR 回读**与顺序匹配结果。

## 三、可懂度抽检（别只听"像不像"，还要看"听不听得清"）

- `voicewrite.verify` 传 `expect_text`（CLI：`verify --expect-text "<原稿>"`）会用 ASR 回读产物，按标准化 Unicode 码点
  的最长公共子序列除以较长文本长度比对；错序、漏句和重复台词均会降分。
- 门槛：**match_ratio ≥ min_match_ratio** 才通过，默认 **0.6**；低于门槛均为 `failed`，严格模式抛 `verify_failed`。
  可转人工抽听定位问题，但不能用抽听建议自动改变失败回执。
- 缺原稿、ASR 关闭、空转写、引擎错误或超时均为 `unverified`。只有项目明确无台词并传 `speech_expected=false`
  才是 `not_applicable`；不允许用省略原稿或 `round_trip=false` 代替此声明。
- `strict=false` 只返回测量证据，失败或缺测仍为 `ok=false`、`receipt.synced=false`。
  `checked.text_match_status` 与削波等物理项分别判断；文本通过而真峰值失败时修混音，不能追加另一段配音。
- 相似度是回读检查，不是声音质量证明：语气、音色和表达是否合适仍需审听。

## 四、返工归因表（返工要能定位到环）

| 症状 | 先查 | 常见归因 |
|---|---|---|
| 音色不像 | 参考音频 | 采集环境/电平/腔调不对（回 `voice-reference-craft` 重采） |
| 发音错字 | 逐字稿 | 数字读法、专名、多音字写错（改 `ref_text` 或改写文案） |
| 中途换声 | 档案绑定 | 同任务多档混用（违反"一个角色一个档案"） |
| 时长对不上 | 分段与倍速 | 时窗太紧 / 文案过长（改文案，不是硬拉倍速） |
| 响度不合格 | 复检环节 | 漏归一 / 归一后未复检（本工位强制复检，关校验会被围栏拒） |
| 审核被拒（授权） | 授权链 | 范围没覆盖用途（补授权或降级为内部使用） |

## 五、不可修复情形（如实上报，不硬做）

1. 参考音频**削波**：削掉的波形无法恢复 → 重录；
2. 原片**没有人声轨但要保留现场声**：需先做音源分离（`bgmwrite.separate`）→ 明确告知"当前只能替换音床"；
3. 授权范围与用途**冲突且无法补授权** → 停手并升级到人；
4. 目标语言引擎**不支持**：换引擎或改交付语言，不伪造"支持"。

## 六、与围栏/管线的对应

| 环节 | 落点 |
|---|---|
| 授权与范围 | G-VOICE1 / G-VOICE6（人审） |
| 原片与参考只读 | G-VOICE2（block） |
| 强制复检 | G-VOICE3（block） |
| 单租户日配额 | G-VOICE4（block，1 小时/日） |
| 声纹不出域 | G-VOICE5（block） |
| 管线位置 | `narrative-film` 的 `voice` 步（调色之后、配乐之前，owner=voice-artist） |

## 输出契约

一次配音交付必须能回答：**谁的声音（profile-id + 授权范围）、什么引擎与模型、产物在哪（路径 + sha256）、
响度与真峰值多少、与原片是否对得上（时长漂移 + 逐段时窗表）、可懂度抽检结果如何、哪些地方是人工判断而非自动结论**。
缺少其中任何一项，只能说"已提交"，不能说"已完成"。

## 七、参数边界（越界即不合格）

1. **响度**：播报音频 -16 LUFS（±1.0）；成片配音 -14 LUFS（±1.5）。
2. **真峰值**：播报 ≤ -1.5 dBTP；成片配音 ≤ -1.0 dBTP。
3. **台词核验**：有效 ASR 回读 match_ratio ≥0.6 才通过；低于门槛为 failed，缺测为 unverified。仅明确无台词可记 not_applicable。
4. **音画同步**：总时长漂移 ≤0.25s；段起点偏差 ≤120ms；视频轨必须 `copy`（零重编码）。
5. **语速**：播报 0.95–1.05×、配音 0.9–1.15×；>1.25× 由时窗工具判 `segment_overflow`，改文案不改倍速。
6. **授权**：`scope` 未覆盖本次用途（尤其对外发布/商用）时不得出片（G-VOICE1/G-VOICE6）。
7. **配额**：单租户日配音超过 1 小时触发 G-VOICE4 熔断，需分批并说明原因。
