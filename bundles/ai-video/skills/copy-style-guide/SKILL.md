# 字幕文案：风格 × 目标 × 人设（copy-style-guide v1）

> 产品所有者口径（2026-10-11）：字幕文案要**更像人说的话**；文案跟短片风格强相关
> （vlog / 带货 / 知识分享……），文案服务于短片风格与短片目标，还要符合博主的人设。

## 1. 三个输入维度

| 维度 | 取值 | 对文案的影响 |
|---|---|---|
| 短片风格 | `vlog` 生活流 / `promo` 带货 / `knowledge` 知识 / `story` 情感 / `food` 美食探店 | 句式节奏、口语标记、禁用词表 |
| 短片目标 | 完播 / 关注 / 转化 / 收藏 / 共情 | 要不要钩子、要不要给利益点、结尾怎么收 |
| 博主的人设 | 身份 / 受众 / 自称 / 对观众的称呼 / 口头禅 / 方言词 / 人设禁用词 | 人称与用词；口头禅自然出现，宁可少不要硬塞 |

## 2. 风格预设（要点）

| 风格 | 句式 | 鼓励的口语标记 | 典型禁用 |
|---|---|---|---|
| vlog 生活流 | 短句为主、长短交替，一句一个动作或感受 | 了/呢/就/都/真/还/咱/吧 | 让我们一起、不妨、值得一试、尽享、之旅 |
| promo 带货 | 短促、信息密度高，先结论后理由 | 就/只要/真/才/直接/够/顶 | 让我们一起、众所周知、毋庸置疑、堪称 |
| knowledge 知识 | 一句一个结论，结论短、依据稍长 | 其实/就是/记住/关键/简单说 | 让我们一起、不妨、尽享、绝绝子 |
| story 情感 | 短句留白，一段只说一件事 | 了/还/就/又/才/再 | 让我们一起、治愈、美好、仪式感、氛围感 |
| food 美食探店 | 拟声/质感词 + 具体参照，每 2–3 句一个味觉信息 | 就/真/够/才/顶/嫩/香 | 让我们一起、不妨一试、味蕾的盛宴、垂涎欲滴 |

## 3. 人设档案（persona）

字段：`identity`（身份）、`audience`（说给谁听）、`selfAddress`（自称）、`audienceAddress`（对观众的称呼，克制使用）、
`verbalTics`（口头禅，≤8）、`dialectWords`（地域词）、`bannedWords`（人设禁用词，**优先于**风格默认词表）、`humor`（0–1，档案用）。

## 4. 机检口径（护栏，不通过不放行）

| 指标 | 口径 | 阈值 |
|---|---|---|
| 字数带 | `ceil(时长×2.0) ≤ 视觉字数 ≤ floor(时长×2.5)` | 100% 命中 |
| 排版 | 每句独占一行；行内无标点/空格/Emoji | 100% |
| 口语标记覆盖率 | 含（了/呢/就/都/真/还/咱…）的字幕 / 全部字幕 | ≥60% |
| 人设词覆盖率 | 含口头禅/地域词的字幕 / 全部字幕 | ≥20% |
| AI 腔 | 让我们一起 / 不妨 / 值得一试 / 尽享 / 垂涎欲滴 / 众所周知 / 非常 / 十分 / 品尝 / 位于 / 进行 / 以及 / 并且 / 然而 / 使得 / 令人… | 零硬伤 |
| 无据数字/专名 | 按 facts 清单核对 | 零出现 |

## 5. 反例 → 正例

| 说明书腔（不过） | 活人感（过） |
|---|---|
| 品尝当地的特色美食，非常值得一试 | 先来碗羊汤 热乎的 |
| 让我们一起感受美好的氛围 | 风一停 整条街都安静了 |
| 她感受到了一种幸福的氛围 | 她抬头 笑得像个孩子 |

## 6. 落地

- 写作前：先出写作简报（风格/目标/人设/禁用/镜头事实/原字幕），再落笔；
- 定稿后：跑机检（评分 ≥90、无硬伤），逐条看建议，不改事实、不补无据数字；
- 文案与字幕版式、封面文案共用同一份人设档案，避免"片里一套、封面另一套"。
