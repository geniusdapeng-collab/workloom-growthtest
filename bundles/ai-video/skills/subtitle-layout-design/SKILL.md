# 字幕版式设计

## 一、字号是算出来的，不是感觉出来的

```
字号 = 短边 × 场景基准比 × 粗细修正 × 平台字号倍率
粗细修正 = 1 + (2.5 − 字体粗细程度) × 0.04      # 细字体放大，粗字体收敛
描边 = 字号 × 0.06（复杂底可到 0.08）
安全边距 = 短边 × 0.05
```

| 场景 | 基准比 | 期望粗细 | 说明 |
|---|---|---|---|
| 标题 | 0.11 | 3~5（理想 4.5） | 冲击力优先，可高艺术气息 |
| 字幕 | 0.048 | 0.5~3（理想 1.5） | 长时阅读舒适，辨识度 > 个性 |
| 弹幕 | 0.04 | 2~4（理想 3） | 瞬时辨识，艺术气息 ≤4；滚动走顶部 1/4 轨道，1s 窗口并发 ≤8 条 |
| 贴纸 | 0.07 | 2~5 | 个性优先，配 200ms 弹入/淡入 |

**体检区间（硬口径）**：字幕字号占短边 3.8%~7.5%，标题 8.5%~16%；越界即判不达标。

## 二、平台版式（位置 × 边距 × 倍率）

| 平台 | 画幅 | 字幕位置 | 标题位置 | 字号倍率 | 封面风格 |
|---|---|---|---|---|---|
| 默认 | 16:9 | 底部居中 5% | 顶部居中 8% | 1.0 | 大标题 + 高对比描边 |
| 抖音/快手 | 9:16 | **底部上抬 18%**（避开点赞栏与文案区） | 顶部加大、避开关注按钮 | 字幕 ×1.05 / 标题 ×1.15 | 大字报粗黑体 + 主体前置 + 撞色描边 |
| B站 | 16:9 | 底部居中 6% | 顶部留弹幕区 | 1.0 | 左文右图，保留 UP 主视觉锤 |
| 小红书 | 3:4 | 底部 8% 略收 | 封面花字超大字号 | 标题 ×1.2 | 手写/可爱体 + 贴纸 + 奶油色系 |
| 视频号 | 9:16 | 上抬 16% 并放大 | 顶部居中 | 字幕 ×1.10 | 稳重粗黑/宋体，信息直给 |
| YouTube | 16:9 | 底部居中偏小 | Lower-third 左下对齐 | 0.95~1.0 | 3 词以内超大粗体 |

## 三、UI 遮挡区（字幕压上去 = 没交付）

`font_db.json#layout_policy.<平台>.occlusion_zones` 把每平台的遮挡来源落成可判定矩形，交付前用
**实测墨迹外接框**与它求交（不是估）：

| 平台 | 遮挡区 |
|---|---|
| 抖音/快手 | 右侧互动栏（x≥0.78, y 0.42~0.84）、底部文案与进度条（y≥0.88）、顶部关注/音乐（y≤0.12） |
| B站 | 顶部弹幕区（y≤0.10）、底部播放器控件（y≥0.93） |
| 小红书 | 右侧互动栏、底部文案与话题（y≥0.90） |
| 视频号 | 右侧互动栏、底部文案区（y≥0.86） |
| YouTube | 底部进度条与控件（y≥0.92） |

处置顺序：① 上抬/下移 → ② 拆行收窄 → ③ 降字号（不得低于 3.8%）→ ④ 换边（Lower-third）。
**不允许**用参数忽略遮挡区（G-SUB3 硬闸）。

## 四、描边与底衬：由实测决定

| 实测条件 | 决策 |
|---|---|
| 背景亮度 ≥ 62%（浅底） | 深墨字 + 浅色描边 |
| 背景亮度 ≤ 30%（暗底） | 浅字 + 深色描边 |
| 背景细节密度 ≥ 28%（花底） | 加半透明底衬（BorderStyle=3，BackColour 50% 黑） |
| 文字-背景对比 < 0.32 | 必须加底衬或加深描边后再交付 |

描边粗细：一般 `字号×0.06`；花底 `字号×0.08`；高端品牌片可降到 0.04 并改用渐隐带。

## 五、行宽与分行

- 单行上限：**18 个汉字 / 42 个英文字符**（竖屏），横屏可放宽到 22 字；
- 字幕最多 2 行，标题最多 2 行；超限拆行，不允许靠压缩字距硬塞；
- 中英混排按"汉字 1 字 ≈ 英文字符 2 个"折算估算后再实测确认；
- 标点不单独占行，句末标点可省略（字幕惯例）。

## 六、分层与节奏

- 标题（片头）默认 3s，允许 1.5~4s；短于 1.5s 观众读不完，长于 4s 开始挡画面；
- 标题与字幕**不同区**：标题在上（或 YouTube 左下），字幕在下；同屏不同时出现两层粗体；
- 弹幕放顶部 1/4 区滚动（分道 round-robin），不压人物面部；顶部/底部固定条各占自己的行位；
- 贴纸配 200ms 入场、停留 1.5~3s，落点必须在安全区内且与遮挡区零相交；
- 双语字幕：主语言在上、第二语言小 12% 叠在其下，两行合计不超过短边 14%（超了就拆行或降字号）。

## 七、头像/封面（与发布联动）

封面标题走"关键词前置"：`川西｜雪山倒映在草海的晨光里`；
封面字号可到短边的 16%，但必须保证缩略图尺寸下仍可读（3 词以内优先）。

## 失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 字幕压在平台 UI 上（点赞栏/文案区/进度条） | 实测墨迹外接框与 `occlusion_zones` 求交非空 | 按处置顺序：上抬/下移 → 拆行收窄 → 降字号（**不得低于 3.8%**）→ 换边；禁止用参数忽略遮挡区（G-SUB3） |
| 字号越界（太小看不清 / 太大挡画面） | 字号占短边比：字幕 3.8%–7.5%、标题 8.5%–16% | 按 `短边 × 基准比 × 粗细修正 × 平台倍率` 重算并复检 |
| 单行太长读不完 | 单行 >18 汉字 / 42 英文字符（竖屏；横屏 >22 字） | 拆行；不允许压缩字距硬塞 |
| 花底/浅底字幕看不清 | 文字-背景对比 <0.32，或背景亮度 ≥62% / 细节密度 ≥28% 未加底衬 | 加深描边或加半透明底衬（BorderStyle=3, BackColour 50% 黑）后重出 |
| 平台倍率用错（小红书没 ×1.2、抖音没上抬 18%） | 平台版式表逐项比对（位置/边距/倍率） | 按平台表重算；变体从已定版母版派生，不重新拍脑袋 |
| 标题一闪而过或久挡画面 | 标题时长 <1.5s 或 >4s | 拆成两屏或调整停留时长（默认 3s） |
| 双语字幕超出安全区 | 两行合计 >短边 14% | 拆行或降字号；主语言在上、第二语言小 12% |
