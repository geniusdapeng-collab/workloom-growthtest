# 字幕版式设计

## 默认方案

```
字号 = 短边 × 场景基准比 × 粗细修正 × 平台字号倍率
粗细修正 = 1 + (2.5 − 字体粗细程度) × 0.04
描边 = 字号 × 0.06
安全边距 = 短边 × 0.05
```

这些值用于未指定样式时的设计建议。显式字体、字号、落点、时长或样式请求优先；默认方案不抽帧测背景、墨迹、安全区或对比度，不用美感阈值挂起、删产物或重渲。

| 场景 | 基准比 | 设计建议 |
|---|---|---|
| 标题 | 0.11 | 大字、语义断行，标题与正文分层 |
| 字幕 | 0.048 | 长时阅读，约 3.8%–7.5% 短边可作参考 |
| 弹幕 | 0.04 | 顶部滚动或固定轨；完整保留请求文字与条数 |
| 贴纸 | 0.07 | 200ms 入场，停留按请求，不以 1.5–3s 否决 |

## 平台布局建议

| 平台 | 字幕位置 | 字号倍率 | 标题/封面建议 |
|---|---|---|---|
| 默认 | 底部居中，边距约 5% | 1.0 | 大标题与描边 |
| 抖音/快手 | 底部上抬约 18% | 字幕 1.05 / 标题 1.15 | 主体与大字前置 |
| B站 | 底部约 6%，顶部留弹幕区 | 1.0 | 左文右图 |
| 小红书 | 底部约 8% | 标题 1.2 | 手写、贴纸或奶油色系 |
| 视频号 | 底部上抬约 16% | 字幕 1.10 | 信息直接、可读大字 |
| YouTube | 底部或左下 | 0.95–1.0 | 简短关键词 |

平台 UI 遮挡区保存在 `font_db.json#layout_policy`。它们可帮助用户明确反馈时调整位置；默认不测像素外接框、不要求人审、不把 `ignore_safe_area` 当品质违规。字号、行宽、对比度与行数建议不会删改已请求文字。

## 描边、分行与双语

复杂背景可在设计时选择深描边或半透明底衬；浅底深字、暗底浅字可作为默认配方。用户显式请求诊断时可调用 `subtitleread.analyze`，不得把未诊断项目写成通过。

分行优先语义边界；标题和字幕分别布置。双语主语言在上，第二语言可小约 12%；卡拉 OK 缺逐字时间时均分并标注非真实发音对齐。默认保留全量文字，不按并发或字数阈值静默抽稀。

## 回执与错误

记录字体、ASS、实际时间轴、请求样式、源 SHA 与输出 SHA。字体、许可、路径、非法时间或编码错误真实失败；用户针对版式反馈时修改指定层，成功素材继续采用，不自动重渲或把质量诊断当交付审批。

## 参数边界与执行步骤

1. 必须使用请求的完整文本与有限正时间轴。缺文字、倒挂时间或非法坐标明确失败；不得按默认 20 字、8 条并发或推荐停留时间删条。
2. 字体文件、许可与摘要必须可读；字号、描边、落点按显式请求或记录的默认配方生成，不得静默回退系统字体。
3. 必须先回读生成 ASS 的条数、文字、样式与起止，再执行请求轨。显式 maxChars/maxConcurrent 才应用限制，并在回执记录 kept/trimmed；没有限制则完整保留。
4. 布局建议与 `subtitleread.analyze` 的像素诊断属于设计/反馈工具。禁止把未测安全区、墨迹、背景对比度或品质分数写成通过，禁止将诊断作为成功源的默认准入。
5. 回读输出普通元数据、字体解析日志与源/输出 SHA256；实际处理错误必须失败，用户明确反馈时只返修指定文字层。

## 失败模式（症状 → 原因 → 处置）

| 症状 | 原因/检测器 | 处置 |
|---|---|---|
| 文字被截短或弹幕少条 | 对照请求文本、ASS 条数、显式限制与 kept/trimmed | 无限制时保留全部并重新执行文字层；显式限制则如实说明请求效果 |
| 字体显示为其他字体 | 文件/许可摘要、libass 解析日志 | 停止并补齐声明字体；不以近似字体冒充完成 |
| ASS 无法解析或时间倒挂 | 有限数值、SRT/ASS 解析与请求时间轴 | 指名非法 cue 或参数，修正同一请求后再编码；不静默丢 cue |
| 画面位置不符合用户反馈 | 已记录落点、平台配方与显式反馈 | 调整指定布局层，源镜头继续采用；不抽帧投票或重渲 |
| 编码/写盘失败 | 实际退出码、stderr、输出存在性与元数据 | 返回真实处理错误并保留日志，不将无输出写成已完成 |
