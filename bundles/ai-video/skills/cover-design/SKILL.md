# 封面设计

## 一、封面是"三件套"，不是一行字

产品所有者 2026-09-25 复核滕王阁样片时点名：**默认封面只有标题**——封面职能等于没干活。
本套件把封面固化为**三件套**：

| 要素 | 要求 | 判据（机检） |
|---|---|---|
| 主视觉 | 片子最有辨识度的一镜（地标/主体清晰），取帧时刻明确 | 底图血缘：帧取自**未烧字**母版，且哈希/PSNR 与母版同帧一致 |
| 人物 | 片中有主角时必须出现（定妆照抠像层，与片中造型一致） | 人物框"有人物版 vs 无人物版"差异 < 45dB |
| 主标题 | ≤12 字、最多两行，落在上部 6%–42% 标题带 | 标题带"有字版 vs 无字版"差异 < 45dB，且底部 12% 墨迹 ≤2% |

缺任一件即判未完成。**"只有标题"的封面会被机检直接拦下**（`person-layer` 一项必挂）。

## 二、字号与位置是算出来的

```
主标题字高 = 画幅高 × 0.06–0.10      # 1080×1920 上约 115–192px
副标题字高 = 主标题字高 × 0.42–0.5
描边      = 主标题字高 × 0.06–0.08   # 复杂底再加一层半透明底衬
标题带    = 上部 6%–42%（竖屏 1080×1920 → y ∈ [115, 806]）
禁用区    = 底部 12%（y > 1690）——平台 UI（文案/点赞栏/进度条）会盖住
```

断行规则：优先在语义边界断（地点｜意象、动词｜宾语），不出现单字成行；标题与人物重叠面积必须为 0。

## 三、主视觉取帧与人物层

- 取帧时刻：人物镜取"视线进镜头、表情稳定"的那一刻（一般 0.8–1.6s）；空镜取主体最完整的那一帧；
- 人物层：定妆照是**抠像友好底**（纯色无缝背景、无投影），可键出色；键出后用 1–2px 羽化贴边，避免白边；
- 人物位置：放在标题的**对侧**（标题在左则人物在右），高度占画幅 45%–78%，脚部不留空缝；
- 主视觉处理：轻调色 + 暗角（`grade`）或上下虚化带（`blur-band`，给字留呼吸区）；**不允许把素材原样当封面成品**。

## 四、机检四项（无回执不出片）

| 检查 | 口径 | 不合格的典型原因 |
|---|---|---|
| `title-rendered` | 标题带与无字版 PSNR < 45dB | 字体缺失/坐标越界 → 字根本没画上 |
| `person-layer` | 人物框与无人物版 PSNR < 45dB | 抠像失败/人物被底图盖住 |
| `clean-source` | 底图帧与干净母版同帧一致 | 顺手拿了带字幕的成片抽帧 |
| `safe-area` | 标题带 ∈ [6%, 42%]，底部 12% 墨迹 ≤ 2% | 标题过长压到遮挡区 |

四项全过 → 交监制（LLM）看整图（rubric：能否一眼看懂地点与内容、人物是否像主角、标题是否完整可读、有无 UI 残留、调性是否与片子一致）。

## 五、参数边界（越界即回退重做）

1. 主标题 **≤12 字、最多两行**；单字成行判不合格（断行必须落在语义边界）。
2. 主标题字高 = 画幅高 × **0.06–0.10**，且必须落在**上部 6%–42%** 标题带内。
3. **底部 12% 为禁用区**（平台文案/点赞栏/进度条），该区墨迹 ≤2%。
4. 人物层与标题**重叠面积必须为 0**；人物高度占画幅 **45%–78%**，脚部不留空缝。
5. 底图必须取自**未烧字母版**同帧；用带字幕成片抽帧判 `clean-source` 失败。
6. 主视觉必须经过处理（调色 + 暗角，或上下虚化带）——**不允许把素材原样当封面成品**。

## 六、失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 封面只有标题（三件套缺件） | `person-layer` 机检必挂 | 补人物层或说明为何片中无主角；仍缺件不得交付 |
| 字没画上（字体缺失/坐标越界） | `title-rendered`（标题带 PSNR ≥45dB 判失败） | 修字体/坐标后重出；不得只改报告 |
| 人物抠像失败/被底图盖住 | `person-layer`（人物框 PSNR） | 用抠像友好定妆照重做，1–2px 羽化贴边去白边 |
| 顺手拿了带字幕成片抽帧 | `clean-source`（与干净母版同帧比对） | 回未烧字母版重新取帧 |
| 标题压到平台 UI 区 | `safe-area`（墨迹外接框 ∩ 遮挡区） | 上移/拆行/换边；不得缩小到不可读 |
| 标题过长或出现单字成行 | 字数与断行校验 | 按语义边界重写/断行（≤12 字、≤2 行） |
| 封面调性与片子不一致 | 监制 LLM 整图评审 | 调整取帧或主视觉处理；不一致不进发布队列 |
