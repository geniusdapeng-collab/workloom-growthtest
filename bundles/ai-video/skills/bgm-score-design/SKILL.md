# 配乐定调（配什么、什么调性、什么速度）

## 适用场景
- 给成片铺一条与片子调性一致的音乐床（广告/口播/纪录/剧情/促销）
- 需要"配乐风格统一"而不是"每段随手换一首"
- 需要判断"这片子到底该不该配乐"

## 一、定调四问（先答完再动手）

1. **题材**：产品广告 / 口播访谈 / 美食 / 科技 / 旅拍 / 夜景 / 美妆 / 亲子 / 汽车 / 房产 / 促销 / 纪录 / 高端品牌 / 剧情 / 悬疑 / 喜剧——决定风格族。
2. **场景与主体**：棚拍白底、室内半身、菜品特写、屏幕演示、街拍空镜……决定配器厚薄（主体越细，配器越薄）。
3. **情绪目标**：干净可信 / 可信亲和 / 诱人温暖 / 冷静精密 / 开阔通透 / 戏剧现代 / 通透可信 / 明亮有温度 / 强劲精密 / 明亮通透 / 热烈紧迫 / 真实克制 / 克制质感 / 情绪推进 / 不安张力 / 轻快明亮——决定调式（大调/小调/多利亚/弗里吉亚）与力度。
4. **发哪个平台**：抖音/小红书/视频号/B站/YouTube——决定高频是否要更亮、低频是否要更收（手机外放）。

四问答不出来的，先按 `bgmread.recipes` 的速查表取一条最接近的配方，再说明"为什么是它、被否掉了谁"。

## 二、配方库用法

```
bgmread.recipes --list                     # 全部配方（16 条）
bgmread.recipes --genre 美食 --mood 诱人温暖   # 定向检索
bgmread.recipes --id food                  # 取单条（含禁忌与备注）
```

配方字段与含义：

| 字段 | 含义 | 用法 |
|---|---|---|
| `key` / `mode` | 调性 / 调式 | 决定"明/暗"：major 明亮、aeolian 内敛、dorian 冷静、phrygian 不安 |
| `bpm` | 配方基准速度 | 只作基准；真实速度还要看剪辑节奏（见第三节） |
| `chords` | 和弦级数进行 | 4 个级数循环；一/四级明亮、六级/小四级内敛 |
| `instrumentation` | 配器 | pad（地基）/ bass（低频走向）/ pluck（推进）/ kick·hat（节拍）/ bell（点缀） |
| `musicLevelDb` | BGM 在成片里的平均电平 | 口播 -26、广告 -22、促销 -19（数值越大越"站前台"） |
| `duckingDb` | 人声出现时的让位深度 | 口播/纪录 13–14、广告/促销 10–12 |
| `avoid` | 禁忌 | 违反即回退重做（例：口播片禁打击乐） |

## 三、速度决策：配方 BPM 还是剪辑点反推

卡点对不齐，九成是速度错了。两条规则：

1. **剪辑节奏优先**：相邻剪辑点间距 ÷ 一拍 = 整拍数，反推 BPM（`bpm_strategy=cut-driven`）；
   与配方 BPM 相对差 ≤25% 时采用反推值，否则沿用配方 BPM 并说明冲突。
2. **同一项目只用一个速度**：不要"开场 128、正片 96"，那听着像两条片子拼的。

对齐验收线：剪辑点到最近拍点的误差 **≤80ms 记落拍**；达标率 ≥60% 记 partial、100% 记 aligned（工具会把这几个数写进回执）。

## 四、结构（片子多长就写多长）

| 段落 | 占比 | 配器 | 作用 |
|---|---|---|---|
| 前奏 intro | ~15% | 只留 pad + bass | 不抢开场第一句话 |
| 主体 body | ~73% | 加 pluck，必要时 kick/hat | 承担推进感 |
| 尾奏 outro | ~12% | 回落到 pad | 自然收束，不做硬切 |

**不用"裁歌"**：外部曲目短于片长时循环铺满（工位用 `-stream_loop`），不靠剪断一句旋律来对齐时长。

## 五、禁忌（违反即回退）

- 情绪与画面相反（婚礼片配悬疑底、悼念场景配促销节奏）；
- 一个项目混用多套配乐语言（调性/配器不一致）；
- 打击乐压在口播句读上（口播片默认不进 kick/hat）；
- 用配乐掩盖上游问题（对白已削波、底噪过大、单声道素材）——如实上报，不用音乐盖过去；
- 在"笑点/揭示/报价"这些关键信息前后加花抢注意力（该留白的地方留白）。

## 六、允许的结论：不配

以下情形应主动报"无需配乐"而不产出文件（`bgmwrite.best` 会给这个结论）：

- 素材疑似**已有连续配乐**（人声频段活动占比 ≥90% 且谱平坦度极低）；
- **没有安全窗口**：人声几乎铺满全片、环境底噪过高，任何电平的配乐都会压字或不可闻；
- 现场声本身就是内容（纪实、ASMR、烹饪原声），加了反而稀释。

报"不配"时要给出依据（活动占比、底噪、预估余量），不要只写一句"建议不配"。

## 输出契约

选型说明必须能回答四个问题：**什么题材、什么场景/主体、什么情绪目标、发哪个平台**，
并附：配方 id、调性/调式、BPM 及依据（配方/剪辑点反推）、配器清单、配乐电平、让位深度。
