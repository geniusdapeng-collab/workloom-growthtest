# 配乐交付规范

## 交付事实

| 项 | 要求 |
|---|---|
| 成片 | 新文件；真实视频 copy/音频处理与产物 SHA |
| 曲目 | 实际曲目/配方 id、源 SHA、许可与需附署名 |
| 来源 | 原生节目音轨或显式授权独立 stems，不能混称 |
| 处理 | 原声策略、电平、淡入淡出、有限循环、实际混音时间与滤镜 |
| 元数据 | 普通 ffprobe 的时长、采样率、声道、编码；请求输出与实际一致 |
| 回执 | 源字节未变、处理是否完成、错误码，品质项明确未测 |

默认只执行一次声明混音。-14 LUFS/-1 dBTP 可作为 loudnorm 滤镜参数，但没有额外测量时不能宣称响度达标；LUFS、LRA、真峰值、余量、可闻度、卡点与波形证据为 null/空数组。`qualityReviewPerformed=false`。

## 版本和边界

原片只读（G-BGM2），丢弃原声必须显式声明（G-BGM3），许可（G-BGM1/G-BGM5/G-BGM8）、租户配额（G-BGM4）保留。品牌或低置信标签不触发成功素材品质人审（G-BGM9）。每个风格变体可按自己的声明配方处理，回执记录是否复用或重新处理，不暗中叠加旧版音乐。

默认原生节目音轨不要求签名密钥。显式独立音轨清单必须真实授权且字节绑定；缺密钥、作用域或源字节不符立即失败，不能偷偷用原片替代。裸 `declaredProgramMix` 标志不等于授权。

## 失败与用户反馈

缺曲目、路径/许可/摘要问题、真实 ffmpeg 或导出失败停止并留错误；不自动降低 3dB、重试候选、合成兜底或交付无音乐版本。旧品质失败保留为历史，成功镜头继续默认采用。

用户明确要求换曲、电平或原声策略时修改对应音频层，保留其他素材与版本。显式 `bgmread.analyze` 可出诊断报告，诊断不触发重渲、模型或人工作品质准入。

## 知识库

`library/bgm-kb/` 保存 SCORE 设计建议与历史事故案例，可用于明确反馈后的分析，不覆盖这里的默认处理与回执口径。
