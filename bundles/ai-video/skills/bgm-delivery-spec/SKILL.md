# 配乐交付规范

## 一、交付口径（第一版）

| 项 | 口径 |
|---|---|
| 响度 | Integrated **-14 LUFS**（±1.5），两遍法 loudnorm |
| 真峰值 | **≤ -1.0 dBTP** |
| 采样率 / 声道 | 48kHz / 立体声（与成片一致，不改声道布局） |
| 成片编码 | 视频轨 **copy**（不重编码画面）；音频 AAC 192k（母版可另存 WAV） |
| 命名 | `<项目>-<版本>-bgm.<ext>`，版本号只增不覆盖 |
| 音乐时长 | 与片长对齐（短则循环铺满，长则裁尾并保尾奏） |

## 二、平台变体派生纪律

1. 配乐只做一次，落在**母版**；
2. 画幅（9:16 / 1:1 / 4:5）、时长裁剪、封面从已配乐母版派生；
3. **禁止**对每个平台变体重新混音（会造成同片不同响度/不同让位，且成本翻倍）；
4. 平台差异只允许"既有母版派生 + 必要时整片响度归一"，并记录为"平台派生"而非"重新配乐"。

## 三、证据包（无证据不得宣称完成）

每次交付必须包含：

1. 成片路径 + **sha256**（磁盘文件与回执必须对得上）；
2. 使用的 BGM：配方 id/曲目 id + 许可 + sha256（自算作曲另附调性/BPM/种子）；
3. **响度实测**：配乐前后 integrated / true peak / LRA；
4. **让位深度**（人声窗口 vs 无对白窗口的 BGM 电平差）；
5. **人声-音乐余量**（人声频段电平与同窗口 BGM 电平之差）；
6. **配乐可闻度**（无对白窗口相对原片的提升，<3dB 直接判不合格）；
7. **卡点达标率**（±80ms 落拍数/总数 + 平均误差 + 采用 BPM 与依据）；
8. 前后波形对比图（`waveform-before-after.png`）；
9. 署名文件（如使用需署名的外部曲目）。

使用外部曲目时，证据包再加两项（选段必须可复核）：

10. **选段说明**：模式（full/auto/climax/calm/显式）、片段起止秒数、用了哪一段、为什么（`section.reason`）；
11. **选段证据图**（`section-picked.png`）：上=曲目波形（红框=选中片段），下=片子波形（红框=对齐到的高潮时刻）；
    未识别到高潮点时，回执写明 `filmPeakAlign.skipped` 与原因（不许编一个"高点"）。

## 四、版本、回滚与围栏

- 原片只读（G-BGM2），每次配乐产出新文件，版本链可回溯；
- 曲库首次入片/品牌主题曲变更必须人审（G-BGM1）；
- 配乐过程中禁止关闭复检（G-BGM3）；
- 丢弃原声（`music-only`）必须显式声明，且有人声时被阻断（G-BGM3）；
- 单租户日配乐超过 40 次触发熔断（G-BGM4）——批量任务分批并说明原因；
- 版权不合规的曲目一律阻断（G-BGM5）。

## 五、返工归因表（先归因，再动手）

| 现象 | 归因 | 处置 | 案例 |
|---|---|---|---|
| 音乐压住台词 | 电平/让位 | 下调 `music_level_db` 或加深让位重出；不要靠"降整体音量"糊过去 | — |
| 音乐听不见 | 电平/底噪 | 提高电平或换配器更厚的配方；确认不是"配了跟没配一样" | FC-BGM-002 / FC-BGM-006 |
| 风格不符预期 | 选型错 | 换配方 id 重出，记录原因；不要在同一项目里混两套语言 | FC-BGM-001 |
| 卡点不齐 | 速度错 | 按剪辑点定速（`cut_points`→`cut-driven` BPM）重出 | — |
| 情绪给太满 | 结构/力度 | 前奏再留白、去掉打击、降一段配器 | — |
| 分离后声音发空 | 分离质量 | 改回让位策略，或换档位 A 引擎重做 | — |
| 对白削波/底噪大 | 拍摄或渲染阶段 | **不可修复**，退回上游；不得用配乐掩盖 | — |

## 六、诚实上报（交付纪律的一部分）

以下情形必须显式标注"未达标/不可修复"，不得写成"已优化"：

- 响度/真峰值超差（写 `loudness_ok=false` 与实测值）；
- 人声-音乐余量 3–6dB（记为告警，说明风险）；
- 卡点达标率 <60%（记为未对齐并给依据）；
- 素材本身缺陷（削波、底噪、单声道限制）。
