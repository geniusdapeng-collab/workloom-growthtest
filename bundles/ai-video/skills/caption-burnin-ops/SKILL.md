# 字幕烧录执行纪律

## 默认执行流程

已成功生成镜头直接进入正式后期。只在请求需要文字层时执行字幕、标题、弹幕、贴纸或卡拉 OK；原片只读，输出新文件。默认不抽取源/产物样本、不做可现度、边缘能量、墨迹框、对比度或版式品质评审，也不因这些意见删除成片、重渲或调用模型。

1. 读取实际素材普通元数据及输入 SHA256，解析调用方的字幕与有限时间轴。
2. 按声明平台、字体与样式生成 ASS；缺失字体、许可错误、非法 SRT 或路径越界立即报错。
3. 准备扁平字体目录，执行一次真实 libass 编码；音轨存在则 copy，不存在则保持无音轨。
4. 回读 ASS 条数/起止、字体解析日志、输出分辨率/音轨与实际文件摘要；核对原始输入字节未改变。
5. 写真实处理回执。品质字段为 `not-reviewed`/null，证据帧为空；不得把未测写成通过。

## SRT → ASS 的技术口径

| 项 | 实际口径 |
|---|---|
| 时间精度 | ASS `H:MM:SS.cc`，毫秒转换规则固定 |
| 换行 | cue 内多行写成 `\N`，保留完整请求文本 |
| PlayRes | 按实际处理画布设置 |
| ScaledBorderAndShadow | `yes` |
| 样式 | Title/Sub 与扩展轨各自有可回读样式 |
| 非法内容 | 缺时间轴、倒挂、非法数值或空文本明确失败；不静默丢条 |

字体文件必须存在且摘要与声明一致；渲染日志出现系统回落时明确失败，不用近似字体冒充请求已完成。字体许可与租户配额规则保持。

## 扩展轨

| 轨 | 默认行为 | 真正错误 |
|---|---|---|
| 弹幕 | 保留请求条数与文字，分道滚动或固定；默认不按 20 字/并发 8 条抽稀 | 非法时间、参数、字体、真实编码失败；只有显式 maxChars/maxConcurrent 请求才应用对应限制并报告 |
| 贴纸 | 执行指定落点、有限正停留时间与 200ms 入场 | 非有限坐标/时间、不存在样式或真实编码失败；1.5–3s 与 UI 位置只是设计建议 |
| 卡拉 OK | 显式逐字时间，或按字数均分并注明非真实发音对齐 | 标签或逐字时长不能与请求时间轴对应 |
| 双语 | 同源主/次字幕时间轴，第二行样式按配方 | 请求文件、时间轴、字体或实际输出失败 |

## 失败与返修

实际 ffmpeg、字体解析、磁盘、路径或时间轴错误必须返回失败和错误码。保留历史意见，已成功镜头仍默认采用；用户明确反馈后仅修改指定文字层。不自动抽帧重评、重渲、ASR/TTS、降级字体或删掉请求字幕。显式 `subtitleread.analyze` 可提供诊断，其结果不成为普通后期准入。
