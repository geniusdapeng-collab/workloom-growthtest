# 字幕烧录执行纪律

## 适用场景

- 拿到无字幕母版 + SRT（听译产出）：烧出带字幕的交付版；
- 需要片头标题/花字：与字幕分层烧录，一次成片；
- 平台变体（横屏母版 → 竖屏版）派生时的字幕重排。

## 一、SRT → ASS 的硬口径

| 项 | 口径 | 为什么 |
|---|---|---|
| 时间精度 | `H:MM:SS.cc`（厘秒） | SRT 毫秒 → ASS 厘秒，取整规则固定（截断而非四舍五入，避免漂） |
| 换行 | 同一 cue 内多行 → `\N` | ASS 硬换行；`WrapStyle: 0` 让长行自动折行 |
| PlayRes | **与实际分辨率一致** | 字号单位随分辨率解释；不一致会让"1080p 方案"在 720p 上缩水 |
| ScaledBorderAndShadow | `yes` | 保证描边随分辨率等比缩放 |
| 样式名 | `Title` / `Sub` 两个固定样式 | 分层与复检都靠样式名；不用内联覆盖 |
| `Name` 字段 | 字体 id | 让 burnt-in 的字与报告里的选型一一对应（可追溯） |

非法 SRT（时间倒挂、缺时间轴、空文本）一律**显式失败**：时间轴是交付契约，静默丢条等于改了片子。

## 二、字体必须"真的被用上"

libass 的 `fontsdir` **不递归子目录**：工位字体目录是 `cn/`、`en/` 两层时，直接把根目录交给 ffmpeg
会**静默回落系统字体**——你选了霞鹜文楷、成片里是苹方，而所有指标都"看起来正常"。

执行纪律：

1. 渲染前把工位字体目录**摊平成临时扁平目录**（硬链接优先，退化软链/复制）；
2. 渲染后解析 ffmpeg 的 `fontselect` 日志：
   - 命中工位字体 → `-> 字体名, 0, 字体名`（无路径）；
   - 回落系统字体 → `-> /System/Library/Fonts/xxx.ttc, -1, xxx`（绝对路径）→ **判失败**；
3. 字体缺失直接失败（`font_not_found`），不"尽力渲染"。

## 三、烧录命令骨架

```bash
ffmpeg -y -i 母版.mp4 -map 0:v:0 -map 0:a:0 -c:a copy \
  -vf "ass='方案.ass':fontsdir='扁平字体目录',format=yuv420p" \
  -c:v libx264 -preset fast -crf 20 -movflags +faststart 成片.mp4
```

- 音轨 **copy**（字幕不动音频）；无音轨时不加 `-map 0:a`；
- 编码器按可用性择优（libx264 → libopenh264 → mpeg4），实测写进交付报告；
- **永不覆盖原片**：输出路径等于输入路径直接拒绝（G-SUB2）；每次产出新文件与版本号。

## 四、六项复检（缺一不算交付）

| 复检 | 口径 | 失败处置 |
|---|---|---|
| 时间轴回读 | 写出的 ASS 事件与源 SRT **逐条一致**（条数 + 起止） | 失败即删产物，回查 SRT/转码 |
| 字幕可现度 | 字幕带在"加字前后"的边缘能量/亮度必须有 **Δ ≥ 0.004** 的可测增量 | 不达标 = "配了跟没配一样"，删产物（do-no-harm） |
| 版式体检 | 字号区间 / 行宽 / 安全区 / 对比度 / 墨迹外接框 | 任一不达标即失败，不允许"先发了再说" |
| 字体解析 | `fontselect` 全部命中工位字体目录 | 回落即失败（见 §二） |
| 分辨率保持 | 输出与母版宽高一致 | 不一致即失败 |
| 音轨保持 | 有/无音轨状态与母版一致 | 不一致即失败 |

## 四·五、扩展轨口径（弹幕 / 贴纸 / 卡拉OK / 双语）

| 轨 | 关键参数 | 硬口径 |
|---|---|---|
| 弹幕 | 滚动走顶部 1/4 轨道（round-robin 分道）、顶部/底部固定各占行位；透明度 0.85；单条 ≤20 字 | 1s 窗口并发 ≤8；超出按窗口抽稀并**如实报告抽掉条数**；`allow_flood`/`ignore_density` 被 G-SUB6 阻断 |
| 贴纸·花字 | 200ms 弹入（`\t(0,200,\fscx/\fscy)`，40%→100%）；五种预设（撞色/奶油/国风/科技/促销） | 停留必须落在 1.5~3s；位置必须落在安全区且与平台遮挡区零相交 |
| 卡拉OK | `\kf` 逐字扫过；高亮色可配（默认 `#FFE066`） | 逐字时长合计 = 字幕条时长（±0.05s）；缺显式时间轴时按字数均分并标注"非真实发音对齐" |
| 双语 | `srt_path_en` 触发；第二语言小 12%、下移一行叠在同侧 | 两行同属一个安全区带；主/次时间轴都要回读一致 |

渲染后复检与原六项一致（可现度按**该轨所在区域**测：弹幕测顶部 1/4 带、贴纸测落点矩形、卡拉OK/双语测字幕带）。

## 五、性能与批量

- 1080×1920 / 24s 素材：libx264 veryfast 单次约 10~20s（工位实测）；
- 批量时**同一母版只烧一次**，平台变体从已烧母版派生（改画幅/加留白，不重排字幕）；
- 需要逐条微调时用 `subtitlewrite.plan` 反复出方案（只写 ASS，零重编码成本），确认后再 burn。

## 六、失败与回退

| 症状 | 首查 | 处置 |
|---|---|---|
| 画面没字 | ASS 路径转义（冒号/空格）、时间轴是否在该帧生效 | 重新出方案；必要时抽方案样例帧核对 |
| 字是方框/缺字 | 字体是否缺该字符（生僻字/emoji） | 换支持该字集的字体；不得静默丢字 |
| 字幕位置不对 | PlayRes 与实际分辨率、平台版式键 | 重出方案并复检墨迹外接框 |
| 成片变大异常 | 编码器回落（libx264 不可用） | 记录并安装完整 ffmpeg；交付报告标注编码器 |
| 复检失败 | 见 §四 对应项 | 删除产物、如实上报、回退上游（禁止强行交付） |

## 七、证据口径（无回执不算交付）

1. 每次烧录输出：ASS 路径 + **字体解析日志**（fontselect 命中工位字体）+ 六项复检结果 + 产物 sha256。
2. 字体回落系统字体必须**判失败并留证**（记录回落的绝对路径），不静默放行、不"尽力渲染"。
3. 抽稀/降级（如弹幕并发超限）必须如实报告被抽掉的条数；"看起来正常"不构成交付证据。
4. 批量与变体：同一母版只烧一次，变体从已烧母版派生；派生链要有文件血缘可查。
