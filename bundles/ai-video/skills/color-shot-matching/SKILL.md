# 多镜色彩一致性

## 为什么这件事最重要

观众记不住单镜的漂亮，只记得**跳变**。同一支片子里两个镜头色温差 300K、肤色差一档，就会被感知为"业余"。多镜一致性的价值高于单个镜头的惊艳。

## 一、选参考镜（Reference）三条准则

1. **完整曝光**：直方图两端都不裁切，YAVG 落在 90–120；
2. **含人脸或已知中性物**：有肤色可判，或有白墙/灰卡/白纸可判白平衡；
3. **代表本片主体**：主光条件最接近全片平均值，不是最戏剧化的那一镜。

没有合格参考镜时：以**全片指标的均值**为参考（先逐镜 analyze，再取中位数），并在报告里写明这是"统计参考"而非"实拍参考"。

## 二、执行（工具：`colorwrite.match`）

```bash
color-cli match --ref hero.mp4 --in a.mp4 --in b.mp4 --in c.mp4 --out-dir matched/
```

工具会为每条目标镜派生校正（曝光 → 饱和 → 色度轴偏移），应用后再复检，输出 `residual`。

## 三、验收标准（不达标必须再迭代一轮）

| 指标 | 通过线 | 说明 |
|---|---|---|
| ΔYAVG（目标 vs 参考） | ≤ 5 | 平均亮度 |
| ΔUAVG | ≤ 3 | 蓝-黄轴 |
| ΔVAVG | ≤ 3 | 红-绿轴 |
| 肤色 hue | 落在 20–40° | 有人脸的镜头 |
| 主观跳变 | 连播无感知跳变 | 最终以连播为准，数字只是下限 |

残差超标时：**先怀疑参考镜选错**，再怀疑目标镜本身有裁切/欠曝（信息丢了就补不回来，须退回上游重渲或换镜）。

## 四、批次与断点纪律

- 逐镜处理、逐镜留痕：每镜一条事件（前后指标 + 残差 + 哈希），中断可续；
- 同一批次**不换 look**：先批量做校正与统一，最后统一叠一次 look（或对母版叠一次）；
- 生成批次不同（不同模型/不同 seed）导致的色偏差异，属**已知系统偏差**，应记录为配方备注，而不是每片临时调。

## 五、失败与回退

| 情形 | 处置 | 案例 |
|---|---|---|
| 目标镜严重欠曝/高光爆掉 | 不硬补（会出噪点/色块），退回上游重渲或在报告标"不可修复" | — |
| 参考镜被判不合格（事后发现） | 重选参考并整批重跑（工具幂等，成本可接受） | FC-COL-003 |
| 只有一个镜头 | 跳过匹配，直接按配方调；仍要出前后指标与 scope | — |
| 跨机型素材（手机+相机） | 先统一到 Rec.709，再做匹配；不要用 LUT 掩盖色彩矩阵差异 | FC-COL-004 |

## 六、输出

- 参考镜标识与选择理由（含"候选被否掉的原因"）
- 每镜：before / after / residual 三项 + 哈希
- 整片：最大残差、超标镜头清单与处置结论
