# 定妆照纪律

## 适用场景
- 角色/商品定妆照制作与确认（G5 确认门）
- 渲染脚本定妆照绑定（binding-manifest）前置

## 方法
1. 三档覆盖：主角 8 角度 / 配角 4 角度 / 道具定妆照，角度清单先行（portrait.plan）。
2. 三模式解析：studio（棚拍生成）/uploaded（用户上传）/text（文本描述），逐张 refimage.verify 核验。
3. 真实参考图纪律：商品定妆照必须基于档案评分过线的真实商品图，禁止虚构外观；与档案 confirmed 外观字段矛盾即打回重制。
4. PortraitGuard 硬闸：无定妆照绑定禁止提交渲染。
5. **背景干净度硬闸（抠像友好，2026-09-24）**：定妆照背景必须是一块**完全均匀的中性浅灰**——
   无渐变、无暗角、无光斑、无纹理、无地面线、无投影；人物边缘与背景对比清晰、可直接抠像（matting）。
   - 判定口径 `clean-background/v1`（`packages/video-studio/src/portrait-agent.ts`）：
     外圈条带亮度跨度 ≤30、外圈饱和度 ≤16、四角平均亮度极差 ≤22；实测值逐角度写进 `portrait-sets/vN.json#backgroundChecks`；
   - 不合格 → 追加加固措辞重跑；重跑仍不合格 → **该角度判失败**（记 `failedAngles`），不得当成功入库；
   - 探针不可用（缺 ffmpeg）按不合格处理，不静默放行；
   - 背景不干净的定妆照**禁止给下游出片/抠像环节使用**：拖出的灰边、暗角与影子无法在后期清除。

## 参数边界
1. 无定妆照绑定禁止提交渲染（PortraitGuard 硬闸），不得"先渲染后补图"。
2. 背景加固重跑仍不合格 → 该角度判失败并记 `failedAngles`，不得当成功入库。
3. 背景不干净的定妆照禁止给下游出片/抠像使用（灰边、暗角、影子后期无法清除）。
4. 真人肖像只走平台授权通道（方舟 `asset://`）；直传真人照片会被隐私闸拦，不得尝试绕过。
5. 角度文件解析必须支持"任意前缀-<角度>"回退匹配（历史上曾因前缀不一致导致 8 张定妆照全部"隐身"）。

## 失败模式（症状 → 检测器 → 处置）
| 症状 | 检测器 | 处置 |
|---|---|---|
| 8 张定妆照全部匹配不到（"隐身"） | `findAngleFile` 前缀回退 | 修命名或走回退匹配；回归用例锁定 |
| 角度缺失导致空路径崩溃 | 安全取字节数 + 必需角度检查 | 报缺失角度，不抛 ENOENT 中断全链 |
| 背景有灰边/暗角/影子 | `clean-background/v1` 探针 | 追加加固措辞重跑；仍不合格判失败 |
| 探针不可用仍标合格 | 探针可用性检查 | 判不合格（不静默放行） |
| 商品外观臆造 | 与档案 confirmed 字段比对 | 打回重制，禁止虚构外观 |
| 未过 G5 就绑定渲染 | binding-manifest / PortraitGuard | 阻断提交，回到 G5 确认 |

## 输出契约
- 输出：定妆照集（角度清单 + 逐张来源模式 + 核验结果 + 背景探针实测值 + 入库版本）。
- 定妆照集入库即触发 G5 确认，未确认不得绑定渲染脚本。
- 无工具回执的关键数字标「未核实」，不得宣称完成（L3.6/E3.7）。

## 边界
- 不做分镜与提示词（属导演/提示词工程师）；本技能只对定妆照资产负责。
- 不做真人肖像授权申请（走平台授权通道，由人完成）。
- 不用"看起来还行"作为通过依据：背景合格与否以探针实测值为准。
