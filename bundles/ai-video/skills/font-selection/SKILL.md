# 字体选型

## 一、先硬过滤，再打分

选型不是"挑个好看的"，而是先排除不可能，再在可能里排序：

| 顺序 | 过滤/加权 | 口径 |
|---|---|---|
| ① 场景硬过滤 | 标题 / 字幕 / 弹幕 / 贴纸 | 字体档案 `场景` 字段必须包含目标场景；草书类不得进字幕 |
| ② 语言硬过滤 | zh / en | 中文内容必须选支持中文的字体；中英混排分别选型 |
| ③ 许可白名单 | OFL-1.1 / Apache-2.0 / 厂商免费商用 | 未登记许可不得进入候选（fail-closed，G-SUB5） |
| ④ 五维加权 | 30/20/20/15/15 | 作品类型 30 · BGM节奏 20 · 粗细×场景 20 · 艺术气息×调性 15 · 气质关键词 15 |
| ⑤ 账号视觉锤 | 锁定字体优先 | 账号锁定字体直接置顶（品牌识别高于单条内容的偏好） |

## 二、五维怎么判（每一维都要能说出理由）

1. **作品类型（30）**：`生活vlog / 产品介绍 / 宣传片 / 知识科普 / 国风 / 综艺剪辑 …` 命中记满，部分命中记 60%。
2. **BGM 节奏（20）**：慢 / 中 / 快。快节奏片子用粗黑或倾斜体，慢节奏用细体或楷体。
3. **粗细×场景（20）**：字幕宜细（0.5~3，理想 1.5）、标题宜粗（3~5，理想 4.5）、弹幕中等（2~4）、贴纸 2~5。
4. **艺术气息×调性（15）**：庄重/商务/新闻/知识 → 1~3；科技/产品 → 2~4；生活/旅行/美食 → 3~5；活泼/可爱/综艺/二次元/文艺 → 4~5。
   账号调性配置里的「艺术气息区间」优先于内容调性推断（单条内容不偏离账号长期风格）。
5. **气质关键词（15）**：简报显式关键词 + **上游文生视频提示词全文命中**（字体气质词直接出现在提示词里算强命中）。

## 三、中英混排搭配

气质一致优先，不同源则分开选两套并说明搭配理由：

| 中文 | 英文搭配 | 气质 |
|---|---|---|
| 霞鹜文楷 | Dancing Script | 温润手写 |
| 思源黑体CN | Inter / Roboto | 中性现代 |
| 得意黑 | Montserrat / Oswald | 倾斜、都市感 |
| 思源宋体CN | Playfair Display | 书卷、高级感 |
| 站酷快乐体 | Pacifico | 轻松可爱 |

## 四、否决项（高于任何得分）

- 草书/狂草/辨识度极低的艺术体做**字幕** → 直接否决（可用于标题/贴纸）；
- 只在标题好看的展示体（如仅大写的 Bebas Neue）用于中文正文 → 否决；
- 艺术气息超过内容调性上限太多（如严肃科普用爆炸贴体）→ 降级或否决；
- 许可不在白名单 → 否决（G-SUB5 会硬闸）。

## 五、允许的结论：没有合适字体

候选全部不合格时，如实报「无合适字体」并说明缺什么（如"缺一款细体中文衬线"），
不要用一款明显不搭的字体凑数；也不要用未安装的字体出方案——**必须先用 `subtitleread.health`
确认工位字体在位**（`kit/install-fonts.sh` 安装并逐文件校验 sha256）。

## 六、输出形态

每次选型必须给出：Top-N（含得分）+ 每条的**可解释理由**（哪一维命中/未命中）+ 字号建议（含推导式）+
许可与文件 sha256；被否掉的候选与原因一并留痕，便于返工追溯。

## 七、工艺判据（过滤顺序 → 口径 → 判定 → 来源）

| 判据 | 口径 | 判定 | 来源 |
|---|---|---|---|
| 场景硬过滤 | 字体档案「场景」字段必须包含目标场景 | 不含即出局（草书不进字幕） | KB:`font_db.json#scenes` |
| 语言硬过滤 | zh / en 分别选型 | 中文内容缺中文字形即出局 | KB:本套件 §一 |
| 许可白名单 | OFL-1.1 / Apache-2.0 / 厂商免费商用 | 未登记许可 fail-closed 出局 | KB:`G-SUB5` |
| 五维加权 | 作品类型 30 · BGM 节奏 20 · 粗细×场景 20 · 艺术气息×调性 15 · 气质关键词 15 | 总分排序取 Top-N | KB:本套件 §二 |
| 粗细区间 | 字幕 0.5~3（理想 1.5）· 标题 3~5（理想 4.5）· 弹幕 2~4 · 贴纸 2~5 | 越界降分或否决 | KB:本套件 §二·3 |
| 账号视觉锤 | 锁定字体优先置顶 | 单条内容不偏离账号长期风格 | KB:本套件 §一·⑤ |
| 字体在位 | `subtitleread.health` + sha256 校验 | 未安装字体不得出方案 | KB:本套件 §五 |

## 八、失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 草书/狂草被用在字幕上 | 否决项检查（场景字段） | 直接否决；只允许用于标题/贴纸 |
| 选了未安装的字体 | `subtitleread.health` 字体在位检查 | 先装字体（`kit/install-fonts.sh` + sha256 校验）再出方案 |
| 未授权字体进入候选 | 许可白名单 | 剔除候选；不得"先用后补" |
| 艺术气息远超内容调性（严肃科普用爆炸贴体） | 调性上限比对 | 降级或否决，换候选 |
| 只在大写可读的展示体用于中文正文 | 语言/字形覆盖检查 | 否决，改选支持中文的字体 |
| 候选全不合格却硬凑一款 | 结论校验 | 如实报「无合适字体」并说明缺什么（如"缺一款细体中文衬线"） |
| 中英混排气质不搭 | 搭配表比对 | 分别选型并说明搭配理由 |
