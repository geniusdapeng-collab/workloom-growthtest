# 配乐分层与混音

## 一、先回答那个最容易做错的问题：原声怎么办？

成片从上游（合成/渲染/剪辑）出来时**已经带音轨**：对白、现场声、环境底噪，可能还有上一版音乐。
配乐不是"三选一的粗暴动作"，而是**先分层再决定**：

| 做法 | 什么时候可用 | 代价 |
|---|---|---|
| 原声全保留 + BGM 让位（`keep-dialogue`，**默认**） | 有对白/口播/访谈/带货 | 无明显代价；BGM 需让位 |
| 原声全保留 + BGM 更轻（`keep-all`） | 纪实/现场感强的片子 | 音乐存在感弱 |
| 先分离人声、替换环境声（`replace-bed`） | 环境声脏/穿帮/要换氛围 | 分离质量决定成败；单声道素材做不了近似分离 |
| 原声全丢 + 只铺音乐（`music-only`） | 纯卡点片、无人声素材 | **有人声时禁止**（G-BGM3）；需显式声明 `allow_discard_original=true` |

三条硬纪律：

1. **不许把"声音全去掉再盖音乐"当默认流程**——那会连同对白与现场信息一起丢掉，且不可恢复；
2. **不许把"直接把新音乐盖上去"当配乐**——不做让位的 BGM 必然和口播抢字；
3. **能不让位解决的，才考虑分离**：多数片子的正确解是"让位"，不是"分轨"。

## 二、让位（ducking）怎么做，参数怎么算

实现：`sidechaincompress`，侧链键取**人声频段（200–4000Hz 带通）**，人声出现时 BGM 自动下压。

参数换算（工位内 `deriveDuckParams`）：

```
衰减量 ≈ (侧链电平 − 阈值) × (1 − 1/ratio)
阈值 = 人声电平 − 目标让位深度 / (1 − 1/ratio)      # ratio 固定 8
```

目标值（配方库口径）：

| 内容类型 | 让位深度 | BGM 平均电平 |
|---|---|---|
| 口播 / 访谈 / 纪录 | 13–14 dB | -26 ~ -27 dBFS |
| 广告 / 旅拍 / 夜景 | 11–12 dB | -21 ~ -24 dBFS |
| 促销 / 汽车 | 10 dB | -19 ~ -20 dBFS |

其他参数：attack 20ms（快落）、release 400ms（慢起，避免抽气）、`link=maximum`（立体声一致，避免声像跳动）。

## 三、卡点（对齐剪辑点）

1. 用 scene 检测取**剪辑点**（工位一次扫描 + 自适应分级；低分候选按分值加权参与对齐）；
2. 在 [0, 一拍) 内搜索偏移，使剪辑点加权落拍误差最小；
3. 验收：**±80ms 记落拍**；把达标数量/总数、平均误差、采用 BPM 与依据一起写进回执。

无剪辑点（单镜到底/纯音频）时如实标注"退回节拍网格"，不要假装对齐过。

## 三·二、选段铺设（外部曲目：裁哪一段、从哪起播）

### 三·一·〇、取到曲子之前：三级取曲链

配乐师的取曲顺序（工位已实现，回执里逐级留痕）：

```
① 在线曲源（bgmwrite.fetch：Jamendo / Freesound / Mubert / 客户自建索引）
      ↓ 未配置 / 超时 / 无合规候选 / 下载失败
② 本地曲库（客户曲库 → 随仓精选 12 首 → 工位本地 50–70 首）
      ↓ 仍然没有匹配
③ 自算作曲（bgmwrite.compose：按配方 + 片长合成，永远可用、零权利风险）
```

**在线优先不等于必须联网**：任何一级成功都能出片，但"用了哪一级、为什么降级"必须写进回执
（`sourceResolution.attempts`），降级不能静默。

外部曲目（曲库曲目或客户给的音乐文件）通常比片子长，混音前必须先决定"用哪一段"：

| 参数 | 行为 |
|---|---|
| `section: "full"` | 整曲循环（默认关闭选段时的行为） |
| `section: "auto"` | 按片子是否有高潮点自动决策（有→高潮段+峰值对齐；没有→代表段+从片头铺） |
| `section: "climax"` / `"calm"` | 强制取高潮段 / 铺垫段 |
| `section_start_sec` + `section_end_sec` | 人工指定片段（越界即拒） |

铺设口径（工具已实现，写进回执）：

- 片段先按**选中边界**裁出（边界吸结构/节拍，两端各 120ms 微淡防爆音）；
- 片段短于片子 → **循环铺满**（与整曲循环同一条链路，不额外拼接）；
- 峰值对齐：把片段内的能量峰值窗对到片子高潮时刻；若片子高潮更早，则向前裁掉片头（回执写明裁掉多少）；
- 选段后**重新量片段电平**再定增益——避免"整曲的 -22dB 口径"因为换段而失真。

## 四、淡入淡出与"句间不抢"

- 淡入 1.0–1.5s（前奏本来就只有 pad，别硬起）；
- 淡出 1.5–2.0s（尾奏自然收，不做硬切）；
- 口播片在句与句之间不要把音乐推起来：让位由侧链自动完成，不人为"补音量"；
- 平台变体（9:16/时长裁剪）从**已配乐母版**派生，不重新混音。

## 五、响度交付口径（EBU R128）

| 指标 | 目标 | 说明 |
|---|---|---|
| Integrated | **-14 LUFS**（±1.5） | 短视频/流媒体通用交付口径 |
| True Peak | **≤ -1.0 dBTP** | 编码后仍要留 headroom |
| LRA | 6–14 | 对话类偏窄，剧情类可宽 |

实现用**两遍法 loudnorm**：先测（integrated/TP/LRA/threshold）再套参数应用，避免单遍法的动态漂移。

## 六、复检线（无回执不算完成）

交付前必须实测并写进回执：

| 指标 | 目标 | 不达标怎么办 |
|---|---|---|
| 配乐可闻度（无对白窗口相对原片的提升） | ≥3 dB | <3dB → 工具 **`verify_failed`**（配了跟没配一样，删除产物） |
| 人声-音乐余量 | ≥6 dB（<3dB 直接失败） | 下调 `music_level_db` 或加深让位 |
| 让位深度 | ≤ -6 dB | 检查侧链频段与阈值换算 |
| 响度 / 真峰值 | 见第五节 | 超差记 `loudness_ok=false`，不得宣称达标 |
| 卡点达标率 | ≥60% | 换配方或按剪辑点定速（见 `bgm-score-design`） |

## 七、失败纪律

- 桥不可达/超时 → 软失败（`receipt.synced=false`），挂起转人工，不伪造成功回执；
- ffmpeg 缺失 / 路径越界 / 磁盘不足 → 直接拒绝（见连接器错误码表）；
- 素材问题（对白削波、底噪过大、单声道不适用于近似分离）→ 如实标注，不用配乐掩盖；
- 重试 ≤3 次，仍失败转人工。

历史事故案例：FC-BGM-002（峰值对齐致前段 25.7s 静音，preroll 旋转修复）、FC-BGM-006（可闻度测不到写成 null dB 假比较）——见 `library/bgm-kb/failure-cases/`。
