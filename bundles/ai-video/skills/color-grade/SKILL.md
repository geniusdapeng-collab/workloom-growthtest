# 调色执行纪律

## 适用场景
- 成片母版统一影调、多镜之间匹配到同一基准
- 品牌 look / LUT 落地与风格化
- 交付前对成片做一次量化质检（曝光/白平衡/裁切/饱和/肤色）

## 方法（五步，禁止跳步）

1. **probe**：先读规格。确认分辨率/帧率/时长/色彩空间与是否 log（`color_transfer=arib-std-b67` 或动态范围明显偏平 = 疑似 log/HLG/PQ）。
   - log 素材**必须先做转换**（本仓自算 `slog3-to-rec709` LUT 或等效曲线），**禁止**在 log 上直接叠加创意 LUT。
2. **analyze**：抽 4 帧（首段/前中/后中/尾段）量化诊断；有人物时补一帧人脸；有灰卡/白墙时用 `neutral_patch` 精确取白平衡。
3. **correct**：先做校正（白平衡 → 曝光 → 裁切 → 饱和），**一次只改一个变量**，改完复检；工具的 `auto` 只给保守校正量，人/岗位永远可以压在自动之上。
   - **校正恒为 100% 生效**，不受 `intensity` 稀释（否则"欠曝修一半"，画面看不出变化）。
4. **look**：按内容类型选 profile（见下表），强度从 0.6–0.8 起；一个项目**只用一套 look**。
   - **只有 look 按 `intensity` 混合**：校正与创作两段分离，是本技能与工具的共同纪律。
5. **match & verify**：多镜以参考镜为基准做匹配（残差目标：|ΔYAVG| ≤ 5、|ΔUAVG| / |ΔVAVG| ≤ 3），最后用 scope + 目标值表复核。

### 0. **择优（`colorwrite.best`）：先比效果，再决定动不动**

**默认入口是 `colorwrite.best`，不是 `colorwrite.grade`。** 原理是"候选生成 → 客观打分 → 择优"，并且**允许结论是"不调"**：

1. 抽 4 张静帧（look dev，不整片渲染）；
2. 候选池：`原片不动` / `仅自动校正` / `各 look × [0.5, 0.8]`（~18 个）；
3. 用画质分打分（基准 100 = 原片），打分规则见下；
4. 最高分若**没超过阈值（默认 +2 分）→ 判定"无需调色"，不产出任何文件**；
5. 确有更优候选 → 整片只渲染一次，并对成片复测。

#### 画质分怎么算（为什么"更艳"不等于"更好"）

| 维度 | 规则 | 权重 |
|---|---|---|
| 对比度（RMS） | 朝健康区间 22–45 移动**加分**（封顶 +8）；偏离扣分（封顶 −15） | 高 |
| 清晰度（拉普拉斯能量） | 只能不掉；下降按比例扣（封顶 −25），提升最多 +5 | 中 |
| 饱和度（均值） | 朝健康区间 0.22–0.48 移动**加分**（封顶 +6）；偏离扣分（封顶 −12） | 中 |
| **裁切（暗/高光）** | **每增加 1 个百分点扣 2.5 分**（信息丢了找不回来） | 最高 |
| 过饱和像素占比 | 增加部分扣分 | 中 |
| 亮度漂移 | 每漂移 1 级扣 0.15；原片曝光健康却被拉出区间再扣 10 | 中 |

> 2026-09-21 事故复盘：早期只把"统计量塞进目标区间"，结果对一支已调好的成片做出 **亮度 +33.6 / 饱和 +46% / 高光裁切 1.6%** 的"调色"——用户原话"还没有原片好"。**根因是没有画质目标，只有统计目标**。现在：对比度/清晰度下降重罚、裁切零容忍、亮度漂移受罚，且**允许机器说"不用调"**。

## 目标值表（Rec.709 / 8-bit 交付口径）

| 指标 | 目标 | 说明 |
|---|---|---|
| YMIN | 0–16 | 黑位 |
| YAVG | 80–140 | 平均亮度（随场景，夜景可按下限放宽并留痕） |
| YMAX | 235–255 | 峰值白 |
| UAVG / VAVG | ≈128（±6） | 中性色度（蓝-黄 / 红-绿轴） |
| SATAVG | 40–80 | 适度饱和 |
| 肤色 | hue 20–40°、sat ≤60 | 有人脸必须复检 |

## profile 选型（内容类型 → look → 建议强度）

| 内容类型 | profile | 强度 | 说明 |
|---|---|---|---|
| 叙事片 / 情感向 | `warm-film` | 0.7–0.85 | 暖调、轻提黑位，肤色友好 |
| 科普 / 教学 / 产品说明 | `clean-bright` 或 `natural` | 0.6–0.8 | 准确优先，避免风格压过信息 |
| 技术 / 暗场界面 | `cool-technical` | 0.6–0.75 | 冷调，与深色 UI 协调 |
| 严肃题材 / 悬疑 | `moody-dark` | 0.5–0.7 | 压黑去饱和，力度过大人脸发灰 |
| 社媒 / 投流 | `high-contrast-social` | 0.7–0.85 | 移动端小屏要更"打眼" |
| 复古 / 怀旧 | `vintage-fade` | 0.6–0.75 | 抬黑去饱和，别做成滤镜糊 |
| 品牌统一 | `teal-orange` | 0.6–0.8 | 商业片常用；注意肤色别推到橙 |

## 硬红线（违反即回退重做）

- 原片只读：任何调色产出新文件 + 版本链，**禁止覆盖原片**（围栏 G-COL2 一票否决）。
- 不得关闭校验（围栏 G-COL3）：每次调色必须带指标复检与 sha256 回执。
- 只处理像素：不改叙事、不改字幕文案、不改画面事实（与剪辑师同口径）。
- 有人物镜头饱和度 ≤1.2；肤色跑偏先修白平衡，不要靠降饱和硬压。
- 平台变体（画幅/时长派生）与二剪钩子变体从**已调色母版**派生，**不重复调色**。
- **必须真的看得见**：调用方要了 look（profile/LUT）却几乎没改画面 = 交付失败。工具按平均像素差判定：
  `≥4/255` 记 visible、`2–4` 记 subtle（回执带提醒）、`<2` 记 negligible 并**直接拒绝出片**（`verify_failed`，删除产物）。
  2026-09-21 事故复盘：早期 look 参数只有 ±0.04 量级，成品与调色前平均像素差仅 1.5%，用户"看不出任何区别"——参数已重标定，并用可见性校验兜住这一类问题。

## 输出契约

每次调色必须产出并可核验：
- 成片路径 + 实际滤镜链 + 强度 + profile/LUT 标识；
- 前后指标（YMIN/YAVG/YMAX/UAVG/VAVG/SATAVG）与差值；
- scope 图（波形/矢量/直方图）与前后对比帧；
- 产物 sha256。

无回执=未核实：缺少上述任一项时**不得宣称完成**（L3.6/E3.7），失败必须留痕不静默。

## 失败纪律

- 桥不可达/超时 → 软失败（`receipt.synced=false`），挂起转人工，不伪造成功回执；
- ffmpeg 缺失 / LUT 非法 / 路径越界 / 磁盘不足 → 直接拒绝（见连接器错误码表），不得用近似方案顶替；
- 执行失败重试 ≤3 次，仍失败转人工。
