# 配音对齐与混音（让声音落在画面该落的地方）

## 适用场景
- 给已剪好的成片配旁白/口播（原声保留或替换）；
- 给成片做多语种配音（转录→改写→配音）；
- 成片有原声但需要"人声让位"（旁白压在原声上）。

## 一、先规划分段：`segments` 还是按文本均分

两种输入方式，优先第一种：

1. **显式时间窗**（`segments: [{start, end, text}]`）：从字幕/转录拿时间轴，最准；
2. **纯文本均分**（只给 `text`）：按句长比例把全片时长切分——**只适合原片没解说的空镜/纯音乐片**，解说片一律走第 1 种。

分段三原则：
- 一段一个意思（不要跨剪辑点）；
- 一段**不超过 8–10 秒**（长段合成误差会累积）；
- 每段留 0.2–0.4s 尾巴，不要顶到下一段。

## 二、时窗适配：语速是最后手段

```
需要倍速 = 语音时长 / 时窗时长
  ≤ 1.00  → 原速（可加 0.1–0.3s 前置静音对齐）
  ≤ 1.25  → atempo 微调（限幅内，听感基本不变）
  > 1.25  → 报 segment_overflow，回上游改文案
```

- **改文案 > 调语速**：多出来的字应删（"为进一步提升" → "提升"），硬拉 1.4× 会明显失真；
- 反向（语音远短于时窗）不要靠拉长语速，用前置静音/段尾留白；
- 同一次交付里 atempo 尽量统一（不同段忽快忽慢最容易被听出来）。

## 三、原声怎么留：四策略

| policy | 声音床 | 适用 | 纪律 |
|---|---|---|---|
| `keep-dialogue`（默认） | 原声全保留，旁白让位 | 口播/访谈/带货加解说 | 侧链让位 8–12dB，attack 20ms / release 400ms |
| `keep-all` | 原声全保留，让位更浅 | 纪录片/现场感 | 让位 3–6dB，旁白电平略降 |
| `replace-bed` | 原声丢弃，只留配音 | 外语配音/素材原声脏 | 必须声明；需要保留背景音时应先做分离（bgm 工位的 `bgmwrite.separate`） |
| `music-only` | 原声全丢 | 纯音乐卡点片 | 必须显式 `allow_discard_original=true`，否则工具与围栏都会拒绝 |

## 四、音画同步：可量化的三条线

1. **总时长漂移** ≤ 0.25s（成片与原片时长差；工具默认按此判定 `verify_failed`）；
2. **段起点偏差** ≤ 120ms（听感阈值：低于 100ms 基本不可察觉，超过 200ms 明显"嘴型不对"）；
3. **视频轨零重编码**：`-c:v copy`，只换音轨——避免二次压缩损失与体积膨胀。

## 五、响度与让位口径（与 BGM 一致）

| 交付形态 | 响度 | 真峰值 |
|---|---|---|
| 成片（含配音） | **-14 LUFS**（±1.5） | ≤ -1.0 dBTP |
| 纯播报音频 | **-16 LUFS**（±1.0） | ≤ -1.5 dBTP |

配音与配乐的先后：**先配音、后配乐**（配乐要按人声让位）。同一条片子里，人声-音乐余量仍按 ≥6dB 执行（见 `bgm-audio-layering`）。

## 六、常见翻车

| 现象 | 根因 | 处置 |
|---|---|---|
| 配音比画面"早半拍收" | 段落时窗按字幕切得太紧 | 段尾留 0.2–0.4s，或把结尾语气词写进文案 |
| 旁白压住原声 | 没做侧链让位 / 让位太浅 | 提高让位深度到 8–12dB，复核人声-旁白余量 |
| 同一段忽快忽慢 | 多段 atempo 不一致 | 统一倍速策略，优先改文案 |
| 成片时长变长 | 忘记 `-shortest` 或音轨长于视频 | 用 `-shortest` + 复核总时长漂移 |
| 画面变糊 | 重编码了视频轨 | 改回 `-c:v copy` |

## 输出契约

配音交付必须附：逐段时窗表（start/end/时窗秒数/语音秒数/倍速）、原声策略与让位深度、
总时长漂移、响度与真峰值、产物 sha256，以及"哪些段超窗/如何处置"的记录。
