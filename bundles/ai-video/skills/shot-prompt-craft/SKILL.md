# 镜头提示词工艺（25/30 字段）

## 适用场景
- 逐镜提示词融合与三阶段精炼（G6 审核前置）
- 字段质检/修复迭代的规范基准

## 方法
1. 字段工艺：内容镜头 25 字段、片头 30 字段（+5 专属），schema 硬编码，字段标准化以 FieldStandardizer 为唯一真源。
2. 三阶段：融合（上游设计逐字段落位）→ 语义精炼（表达专业化）→ 字段内容精炼（去冗余保信息密度）。
3. 字符口径：理想 2470-3000，硬上限 3000，精炼后 ≥1200；规范值一律从 vendor 真源读取，不手写字面值。
4. 交付前必过 PromptDeliveryGuard：单镜校验 + 作品级 verifyPackage（片头在场/时长带/±15% 容差）。
   时长带以**供应商能力为上限**（媒体目录 `durationSec`；Seedance 2.5 真机实测 4–30s，2026-09-23），
   运行期由 `packages/video-studio/src/duration-rules.ts` 的口径清单统一校验（不允许只改一处）。
5. **镜头内音频纪律**（产品口径 2026-09-23）：生成的镜头只允许 ①台词人声 ②旁白 ③环境音效/动作音效；
   **禁止镜头外加的 BGM/配乐**（配乐统一在后期环节加）；**画面内实况声源不算配乐**——
   街头评弹、三弦/琵琶、店内音响等「画面里真实存在的声源」允许保留（产品所有者 2026-09-23 听检确认）。
   提示词必须带【音频纪律】子句 + `no background music` 负面词，且 `audio` 字段里的「背景音乐/配乐/音乐风格」
   指令会被清洗（否定式「无配乐」与实况音乐词保留）；缺标记 = 交付闸不合格。后期配乐由 BGM 配乐师岗位负责。

## 输出契约
- 每镜输出：25/30 字段 JSON + 字符数校验快照 + 引用来源（场景卡/剧本/定妆照条目）。
- 台词字段与剧本蓝图逐字一致；商品外观只引用定妆照与档案 confirmed 字段。
- 音频字段只描述台词/旁白/环境与动作音效（含画内实况声源）；不得把"音乐风格/配乐段落/铺底音乐"写进镜头音频（那是后期职责）。
- 无工具回执的关键数字标「未核实」，不得宣称完成（L3.6/E3.7）。
