# 字幕交付规范

## 一、交付物四件

| 交付物 | 内容 | 形态 |
|---|---|---|
| 成片 | 新文件（永不覆盖原片），带 sha256 | `成片-<版本>.mp4` |
| 字幕方案 | 字体与字号、描边与边距、平台版式、ASS 样式与事件、版式体检明细 | `subtitle-plan.json` + `subtitle-plan.ass` |
| 字幕报告 | 选型理由、六项复检结果、编码器、证据帧清单、时间轴回读 | `subtitle_report`（业务事件） |
| 证据帧 | 标题帧 + 首条字幕帧 + 末条字幕帧（PNG，带 sha256） | `evidence-<成片名>-<时间>.png` |
| 扩展轨报告（用到时） | 弹幕密度/抽稀条数、贴纸停留与落点、卡拉OK 逐字误差与口径（显式/均分）、双语两行版式 | `subtitle_report.mode = danmaku|sticker|karaoke` |

> 证据帧按**产物名**打前缀：同一批次里 burn 与 best 各自出片时证据不互相覆盖，
> 每张证据都能对回它证明的那支成片。

## 二、交付指标（不达标不算完成）

| 指标 | 阈值 | 数据来源 |
|---|---|---|
| 字幕字号占短边 | 3.8% ~ 7.5% | 方案推导 + 墨迹外接框实测 |
| 标题字号占短边 | 8.5% ~ 16% | 同上 |
| 单行汉字数 | ≤ 18（竖屏）/ ≤ 22（横屏） | SRT 逐条校验 |
| 安全区 | 左/右留白 ≥ 短边 2.5%；与平台遮挡区**零相交** | 实测墨迹外接框 × `occlusion_zones` |
| 文字-背景对比 | ≥ 0.32 | 抽帧实测文字带亮度 |
| 字幕可现度 | 加字前后 Δ ≥ 0.004 | 抽帧实测（边缘能量/亮度增量） |
| 时间轴回读 | 100% 一致（条数 + 起止） | ASS 回读 × 源 SRT |
| 字体解析 | 100% 命中随包字体目录 | `fontselect` 日志 |
| 弹幕密度 | 1s 窗口并发 ≤8（超出抽稀并如实报告） | `subtitle_report.density` |
| 贴纸停留 | 1.5~3s（越界拒绝） | `subtitle_report.placements[].holdSec` |
| 卡拉OK 逐字时长 | 合计 = 字幕条时长 ±0.05s | `subtitle_report.timing[].sumErrorSec` |
| 分辨率 / 音轨 | 与母版一致（音轨 copy） | ffprobe 前后对比 |

## 三、命名与版本链

- `<项目>-<版本>-<平台>.<ext>`：版本号**只增不覆盖**（v1 → v2），改动原因写进报告；
- 母版只烧一次；平台变体从**已烧母版**派生（画幅/留白/音量），不重新排字；
- 返工必须带归因：`选型错 / 版式参数错 / SRT 时间轴错 / 上游素材问题`。

## 四、返工归因表

| 症状 | 归因 | 处置 |
|---|---|---|
| 字看不清 | 描边/底衬不足 或 背景过曝 | 重跑 `subtitleread.analyze` → 调 decision → 重出方案 |
| 字挡 UI | 版式参数（边距比/对齐） | 上抬或换边；行宽超标则拆行 |
| 字太小/太大 | 字号推导链上有覆盖值 | 回归推导式（短边×基准比×修正×倍率） |
| 字体和片子气质不搭 | 选型错 | 回 `subtitleread.fonts`，把否掉的候选理由重看一遍 |
| 字幕出现时间错 | SRT 时间轴错（上游听译） | 退回上游重出 SRT；不要在本岗位手改时间轴 |
| 中英混排断行难看 | 缺中英搭配 | 分别选型并说明搭配理由 |

## 五、不可修复情形（如实上报，别硬盖）

1. **素材底部已被压满信息**（已有硬字幕、贴片字幕）：再叠字幕必然重影 → 退回上游拿无字幕母版；
2. **画面过曝/纯白背景且无安全边距**：宁可加底衬也要如实标注"观感下降"，或建议改版式；
3. **生僻字/特殊符号缺字**：字体缺字导致方框 → 换字体或如实上报缺字，不得静默丢字；
4. **母版本身抖动/分辨率过低**：字幕清晰不能掩盖画面问题 → 记入报告回退上游。

## 六、与上下游的接口

| 对手方 | 字幕师接收/交付什么 | 冲突裁决 |
|---|---|---|
| 剪辑师 | 接收无字幕母版 + SRT（听译/转写产物） | 剪辑定节奏，字幕只做文字层 |
| 调色师 | 接收已调色母版（字幕在调色之后烧，避免字幕被 LUT 改色） | 画面先定色，文字后上 |
| BGM 配乐师 | 交付已烧字幕成片（音频轨 copy 不动） | 音画互不阻塞，管线顺序字幕 → 配乐 |
| 发布运营 | 交付已烧字幕成片 + 封面标题建议 + 平台变体 | 变体不重排字幕 |
| 合规 | 字体许可与品牌视觉锤变更记录 | 合规优先 |

## 七、质量指标（用于绩效与考试院）

| 指标 | 目标 | 数据来源 |
|---|---|---|
| 一次通过率 | ≥ 85% 首次人审通过 | G-SUB1 审批记录 |
| 版式体检一次通过率 | ≥ 90% | `subtitle_report.layoutChecks` |
| 可读性投诉率 | ≤ 2% | 发布后反馈/评论 |
| 时间轴回读一致率 | 100% | `subtitle_report.timeline.ok` |
| 字体解析命中率 | 100% | `subtitle_report.fontResolution.allFromFontsDir` |
| 许可合规率 | 100% | `G-SUB5` + 报告许可字段 |
| 返工归因准确率 | 100% | 返工表 |

**考试院题目方向（建议）**：① 竖屏 1080×1920 下 22 字长句怎么处理；
② 浅色雪地背景上白字看不见该怎么改；③ 抖音字幕为什么必须上抬 18%；
④ 客户指定方正字体但拿不出授权；⑤ 母版已带硬字幕要求"再加一层中英双语"的处置。
