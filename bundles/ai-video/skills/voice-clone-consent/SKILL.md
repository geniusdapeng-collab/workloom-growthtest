# 声音授权与克隆合规（先问清楚"这是谁的声音"）

## 适用场景
- 要给某个角色（数字员工、口播人、客户指定声线）做声音克隆；
- 要用克隆音色做**对外发布**（客户交付、平台外发、公开投放）；
- 有人拿着"别人的声音样本"来要求配音。

## 一、克隆前必须问清的七件事（问不齐就别落笔）

| # | 问题 | 为什么必须问 | 落到哪个字段 |
|---|---|---|---|
| 1 | 这是**谁**的声音？ | 声音是人格权的一部分，不是普通素材 | `speaker_label` / `speaker_type` |
| 2 | 是**本人**、**已授权的第三方**，还是**合成声线**？ | 三类声源的合规路径不同 | `speaker_type` = self / authorized-third-party / synthetic |
| 3 | 授权**范围**到哪一步？ | 内部播报与商业发布是两件事 | `scope` = internal / external-publish / commercial |
| 4 | 谁**声明**的？ | 责任要落到人，不能落到"系统" | `declared_by` |
| 5 | **证据**是什么？（口头同意 / 合同 / 邮件 / 录音） | 事后追责靠证据不靠记忆 | `evidence` |
| 6 | 授权**到什么时候**？ | 到期必须停用，不能"忘了" | `expires_at` |
| 7 | 这次的用途**是否超出**授权？ | 超范围使用是最常见的踩线方式 | 与 `params.publish_external` 对齐 |

## 二、三类声源的处理路径

### 本人声线（最常见，门槛最低）
- 可自采自用；内部播报（`scope=internal`）自动放行；
- 一旦用于对外发布，仍要把 `scope` 提到 `external-publish`（围栏 G-VOICE6 会拦）；
- 离职/合作结束后是否继续可用，要按合同写清，不要默认"永久"。

### 已授权第三方（客户声线、主播声线）
- 必须有**书面授权**（合同/授权书/邮件确认）并留 `evidence` 摘要与存放位置；
- 商用（`commercial`）一律走人审（G-VOICE1），把审批号写进音色档案；
- **不得转授权**：拿 A 客户的声线去给 B 客户配音，是典型超范围使用。

### 合成声线（引擎自有音色 / 设计声线）
- 不涉及自然人，但仍要记录**来源引擎与许可**（例：mlx-audio MIT / VoiceStudio AGPL-3.0 / Fish Audio 研究许可不得商用于闭源分发）；
- 用合成声线冒充真人（"这是某某本人的发言"）依然属于欺骗性使用，禁止。

## 三、拒绝清单（直接拒绝，不留"商量空间"）

1. **伪造他人表态**：用克隆音色生成某人没说过的观点、道歉、承诺、背书；
2. **伪造证言/证据**：生成用于纠纷、仲裁、投诉、举报的"当事人陈述"；
3. **误导性金融/医疗/法律发言**：让克隆声线给出投资建议、诊断、法律意见；
4. **弱势群体不当使用**：未经监护授权的未成年人声音；
5. **规避人审**：试图用 `upload_voiceprint`、`allow_nonlocal_engine` 这类参数把声纹挪出工位（G-VOICE5 一票否决）。

拒绝时要**留痕**：说明拒绝理由、请求内容、时间与请求方，而不是简单回一句"不行"。

## 四、落盘口径（voicewrite.consent）

```json
{
  "profile_id": "zh-xiaozhi",
  "declared": true,
  "speaker_type": "self",
  "scope": "internal",
  "declared_by": "产品所有者",
  "evidence": "2026-09-23 会话内明确指令（本条即证据）",
  "expires_at": null,
  "recorded_at": "2026-09-23T01:30:00.000Z"
}
```

- `consent.json` 与 `profile.json` 同目录、同生命周期；
- 范围变更 = **重新声明**（覆盖写 + 新时间戳），不做"静默扩权"；
- 到期或撤回：把 `expires_at` 提前或 `declared=false`，并停止一切合成调用。

## 五、与围栏的对应

| 纪律 | 落点 |
|---|---|
| 没声明授权不得建档案 | G-VOICE1（review 挂起） |
| 商用/对外发布授权必须复核 | G-VOICE1 + G-VOICE6 |
| 声纹与参考音频不出域 | G-VOICE5（block） |
| 原片与参考音频只读 | G-VOICE2（block） |
| 交付必须带复检回执 | G-VOICE3（block） |

## 输出契约

克隆前置说明必须能回答：**谁的声音、什么授权、什么范围、谁声明的、证据在哪、到什么时候**，
并给出这次使用的授权判定结论（放行 / 挂人审 / 拒绝）与依据条款。

## 六、工艺判据（声源类型 × 用途 → 判定）

| 声源类型 | 用途范围 | 判定 | 依据 | 来源 |
|---|---|---|---|---|
| 本人声线（self） | 内部播报（internal） | 放行（自动） | 自采自用 | KB:围栏 G-VOICE1 |
| 本人声线（self） | 对外发布（external-publish） | 挂人审 | 需把 `scope` 提到 external-publish | KB:围栏 G-VOICE6 |
| 已授权第三方（authorized-third-party） | 商用（commercial） | 挂人审 + 书面授权 | 审批号写入音色档案；**不得转授权**给其他客户 | KB:围栏 G-VOICE1 |
| 合成声线（synthetic） | 任意商用 | 放行但须登记来源与许可 | 记录引擎与许可（如 MIT/AGPL/研究许可）；冒充真人仍禁止 | KB:本套件 §二·合成声线 |
| 任一类型 | 声纹/参考音频出域 | **一票否决** | `upload_voiceprint` / `allow_nonlocal_engine` 等参数被拒 | KB:围栏 G-VOICE5（block） |
| 任一类型 | 授权缺失/过期/超范围 | 拒绝（fail-closed） | 停用档案并留痕；补授权前不得出新片 | KB:本套件 §一/§四 |
