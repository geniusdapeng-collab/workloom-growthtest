# 允许不配乐（No-Score Judgment）领域知识库

> **用途**：AI 视频生成系统的配乐知识库。供数字员工 / Agent（BGM 配乐师）在判断"这片子该不该配乐"时检索调用。
> **主题编号**：SCORE-006　**版本**：v1.0　**更新日期**：2026-09-27
> **使用方式**：Agent 在 `bgmwrite.best` 打分阶段前后、或读到"要不要配乐 / 背景音乐会不会多余 / 保持原声"类创作意图时检索本主题，将"不配"从消极的"没做成"升级为有据可查的专业结论。**注意：判不配不等于什么都不做**——不配乐的片子仍要走环境声、音效与响度口径（见第四章）。

---

## 一、核心概念

### 1.1 配乐的首要职责是服务叙事，不是填满频谱

音乐在片子里只有一个合法身份：**为叙事服务**。当沉默、环境声、纯人声本身就能承担叙事功能时，加音乐是从叙事里"抽走"注意力，不是"增加"质感。判断配的反面不是"失败"，而是另一种一等的专业结论：

> **配乐是选择题，不是必答题。好配乐师的第一件作品，往往是"这条片子我没配"。**

- **沉默**（silence）→ 庄严、真实、压迫感，严肃新闻与悼念场景的标准答案
- **环境声**（room tone / ambience）→ 空间感与现场感，纪实与高端品牌的质感来源
- **纯人声**（voice only）→ 信任与亲近，证言、口播、访谈的核心资产

配方库总原则（`library/bgm-recipes/recipes.json` 的 `principle` 字段原文）写得很清楚：

> "配乐先服从片子的调性：题材定风格、场景定配器、情绪定调式与力度；同一个项目只用一套配乐语言，平台变体从母版派生、不重新配乐。**允许的结论包含「这片子不需要配乐」。**"

"允许"二字是纲领级的：不配不是兜底措辞，而是被配方库显式授权的合法产出。

### 1.2 三判据（SKILL 原文，逐条展开）

`bgm-score-design` SKILL 第六节"允许的结论：不配"给出三条判据，命中任一即应主动报"无需配乐"而不产出文件：

| 判据 | SKILL 原文 | 机器信号 | 典型题材 |
|---|---|---|---|
| **① 已有连续配乐** | 素材疑似已有连续配乐（人声频段活动占比 ≥90% 且谱平坦度极低） | `activeRatio ≥ 0.9` 且 `spectral flatness < 0.02` | 二剪素材、客户给的已成片 |
| **② 没有安全窗口** | 人声几乎铺满全片、环境底噪过高，任何电平的配乐都会压字或不可闻 | 最佳候选预估分 < `minScore`（默认 92） | 密集口播、嘈杂街拍、带货直播切片 |
| **③ 现场声即内容** | 现场声本身就是内容（纪实、ASMR、烹饪原声），加了反而稀释 | 题材词 + 简报判定 | 纪实、ASMR、烹饪/手工原声、testimonials |

另有一条**最高优先级的 do-no-harm 通道**（先于三判据）：提示词/brief 明确"不要背景音乐"（`brief.noMusic`）→ 直接判不配，连素材分析都跳过。客户的明确意图永远压过机器判据。

> **已落地（T-23，2026-09-27）·前置提示**：brief 阶段（`analyzePromptBrief`）按三判据中**纯文本可预判**的部分（判据③：ASMR/烹饪原声/环境声记录/严肃公告悼念/证言，及"保留现场声"策略词）做预判，命中时在 `brief.noScoreHint` 给出"建议评估不配乐"提示与依据（只提示不判定、不写 SKIP 字样；最终判定仍在 `bgmwrite.best` 三处出口，行为不变）。判据①②依赖素材分析信号，brief 阶段不猜。

### 1.3 "不配"必须给依据，不许只写一句"建议不配"

SKILL 原话："报'不配'时要给出依据（活动占比、底噪、预估余量），不要只写一句'建议不配'。"判不配和配乐一样要交证据：命中了哪条判据、量化的源素材指标是什么、被否掉的候选方案是谁——这些都会落进回执（见第四章第 3 条），缺证据的"不配"按没判处理。

## 二、分类速查

| 不配的类型 | 触发条件 | 机制位置 | 产物 | 后续动作 |
|---|---|---|---|---|
| **指令型不配** | brief / 提示词明确"不要背景音乐" | `best()` 开头查 `brief.noMusic` | 无文件，`verdict=no_bgm_needed` | 走纯原声交付口径 |
| **素材型不配** | 素材已有连续配乐（activeRatio≥0.9 且 flatness<0.02） | `best()` 人声频段分析后 | 无文件，不重复铺音乐 | 提醒上游素材已带音乐 |
| **窗口型不配** | 最佳候选预估分 < minScore（默认 92）：人声太满 / 底噪太高 / 配了不可闻 | `best()` 候选池打分排序后 | 无文件，附全部候选预估分 | 如实上报，不用音乐硬盖 |
| **艺术型不配** | 现场声/沉默本身是内容（纪实、ASMR、证言、悬念留白） | 四问 + 三判据第③条 | 无文件；或转**降配** | 只铺环境声床，见第四章 |
| **降配（不是不配）** | 题材允许但情绪需要克制 | 配方选型（如 documentary/premium-brand） | 有文件，只留 pad + bass 薄垫 | 正常复检线 |

> 速记：**"不配"有四种来路，降配是第五条路**——别把"只铺环境声"错报成 no_bgm_needed，它有产物、要走完整复检。

## 三、分场景实战

### 3.1 严肃新闻 / 公告 / 悼念

- **判不配**。音乐的任何情绪倾向都是对事实的立场，沉默才是中立。片头片尾可用极短的标识音（sting），正片保持无配乐。
- 验收口径：响度达标（-14 LUFS±1.5）、人声清晰，不要求"可闻度"指标（无音乐可闻）。

### 3.2 Testimonials / 用户证言 / 访谈

- **默认降配，倾向不配**。证言的说服力来自"像真人说话"，音乐一进场就像广告。recipe `interview` 的口径已经是极限值（musicLevelDb -26、duckingDb 14、禁打击乐）——比这更轻，就是不配。
- 判据对照：人声铺满全片时命中判据②（没有安全窗口），机器会自动判不配，这是特性不是缺陷。

### 3.3 悬念 / 恐怖 / 揭示前留白

- **无配乐段落是悬念的核心技法**：观众习惯了音乐提示情绪，突然的静默本身就是"有什么要发生"的信号。recipe `suspense` 的 notes 原文："揭示前留半拍静默，比加音量更有效。"
- 实操：不是全片不配，而是**揭示点前后抽掉音乐**——这属于选段与结构问题（见 SCORE-002），不是 no_bgm_needed；全片无配乐的纯氛围恐怖片才走判据③。

### 3.4 ASMR / 烹饪原声 / 手工记录

- **判不配**（判据③原文点名）。咀嚼声、锅气、刀具碰砧板就是内容本体，铺任何音乐都是稀释。
- 替代动作：降噪清理底噪、统一空间混响（见第四章第 2 条），让原声"干净地在场"。

### 3.5 高端品牌广告 / 材质特写

- **声音留白 = 奢侈品语法**。高端品牌的"贵"靠克制：环境底噪 + 极稀疏的 bell/混响尾音，大面积安静。recipe `premium-brand` notes 原文："留白就是质感：宁少不多。"
- 多数情况走降配（pad + bass + bell，-26dB）；当客户 brief 强调"真实材质声"（皮革摩擦、机械开合）时，这些 SFX 即内容，可判不配转音效设计主导。

### 3.6 对话戏 / 剧情片的呼吸感

- 对话的句读、停顿、气口本身就是节奏，音乐铺满会把"呼吸感"抹平。recipe `drama-story` 的口径是"铺垫段只留 pad，转折处才让人声之外有第二层信息"——**戏剧张力靠进出，不靠常开**。

## 四、视频特有规则

1. **不配 ≠ 什么都不做**。判不配后声音工位仍有四件事：环境声床（ambient / room tone 补齐空间连续性）、音效设计（SFX，材质声与动作声）、空间混响统一（不同机位/段落混响口径一致，避免"贴出来的安静"）、响度交付（EBU R128，-14 LUFS±1.5 / TP ≤ -1.0 dBTP）。"不配乐的成片"和"没做声音的成片"观众一秒听出区别。
2. **与 voice 工位的原声策略配合**。判不配的本质是把分层策略推到极端：比 `keep-all`（原声全保留 + BGM 更轻）再退一步——原声全保留 + 无 BGM。纪律同源：**不许把"声音全去掉再盖音乐"当默认流程**（`music-only` 有人声时禁止）；判不配的片子更不允许动原声，环境声床只能"补"不能"换"，除非走显式的 `replace-bed` 并声明理由。
3. **判定机制（机制对齐，勿凭空发明）**。`no_bgm_needed` 只在 `bgmwrite.best` 内产生，共三处出口，按执行顺序：
   - **第一出口（do-no-harm）**：`brief.noMusic` 命中 → 直接判不配，reason 写"提示词明确要求不加配乐（no music）→ 按 do-no-harm 判定，不产出文件"；
   - **第二出口（素材判定）**：人声频段分析后，`activeRatio ≥ 0.9` 且谱平坦度 `< 0.02` → 判"素材疑似已有连续配乐"；
   - **第三出口（打分类判定）**：候选池（配方 × 让位深度）预估打分，扣分项含人声余量 <6dB（每差 1dB 扣 5 分）、可闻度预估 <3dB（每差 1dB 扣 6 分）、电平偏高、让位过深、卡点误差；**最佳候选得分 < `minScore`（默认 92）→ 判不配**，reason 写明"没有安全的配乐窗口（人声太满 / 环境底噪太高 / 配乐会不可闻）"。
4. **证据落盘：用现有字段，不新增字段**。判不配的回执结构与判配完全一致：`verdict`（`no_bgm_needed`）、`reason`（判定依据全文）、`source`（`speechLevelDb` / `roomToneDb` / `activeRatio`，do-no-harm 出口为 null）、`candidates`（第三出口保留全部候选预估分，前两个出口为空数组）、`sha256`（原片哈希，证明"审过这条片子"）；receipt 的 `snapshot_uri` 形如 `bgm://best/no-change?sha256=...`，与正常产物 `bgm://best/<file>` 区分。下游凭 `verdict` 分支即可，**不需要也不允许新增报告字段**。
5. **客户明确要求配乐时，机器判据让位**。brief 写了"要配乐/要 BGM"，即使素材条件触边（人声偏满），也不得直接报不配——按降配处理：取让位最深的配方、压低 `musicLevelDb`、如实写明"人声余量偏紧"的 warning 交人审。三判据是"不劣化优先"的护栏，不是对抗客户意图的武器。
6. **判不配后的复检：可闻度判据不适用，换替代验收**。`music_audible`（配乐可闻度 ≥3dB）对无配乐产物无意义，复检换四项：响度/真峰值达标（loudnorm 两遍法口径）、人声清晰度无劣化（对照原片人声频段电平）、原声完整性（`sha256` 链路确认未动原片，或环境声补齐段拼接无爆音）、环境声床电平低于人声余量 ≥6dB（若补了 ambient）。**复检标准换了，"要复检"这件事没换。**

## 五、常见误区

| 误区 | 纠正 |
|---|---|
| "不配 = 这单没做成，是失败" | 恰恰相反。配方库 principle 显式授权"允许的结论包含「这片子不需要配乐」"，有据的不配是一等专业结论 |
| "判不配就是交付静音" | 不配乐的片子仍要做环境声床、SFX、混响统一与响度（见第四章第 1 条）；观众要的是"没有音乐"，不是"没有声音" |
| "机器判不配就不用写依据" | SKILL 明令：报不配要给活动占比、底噪、预估余量。回执 `reason` 写不满等于没判 |
| "客户要配乐，但人声太满，直接报不配" | 违反第四章第 5 条。客户明确意图优先，转降配 + warning 交人审 |
| "verify_failed 删了产物 = 这片子不用配乐" | 混淆两种机制（见下节辨析）。verify_failed 是"配了但质量不达标"的质量护栏，不携带任何"该/不该配"的判断 |
| "悬念片就全片别配" | 悬念靠的是音乐的进出与揭示前的静默（选段/结构问题），全片不配只适用于纯氛围恐怖；别把艺术型不配用成偷懒 |
| "有环境声就算配过了" | 环境声床是"不配"的替代动作，不是配乐；有 ambient 产物要走响度复检，但不要套用可闻度 ≥3dB 的音乐判据 |

### 附：no_bgm_needed 与 verify_failed 的辨析（最常混淆的一对）

| 维度 | `no_bgm_needed`（判不配） | `verify_failed`（软失败/质量护栏） |
|---|---|---|
| 性质 | **主动专业结论**：这片子不该配 | **被动质量拦截**：配了但不可闻（<3dB）或压了人声（余量 <3dB） |
| 时机 | `best()` 打分阶段，产出文件**之前** | `mix` 复检线，产出文件**之后** |
| 产物 | 从未产出（candidates 留证） | 已产出但**立即删除**，不得交付 |
| 回执语义 | `verdict=no_bgm_needed`，synced=true | 抛错 `verify_failed`，带不可重试标注 |
| 后续 | 走替代验收口径，正常交付 | 调参重跑或转人工，**不能**改口报"无需配乐" |

一句话：**不配是判断，verify_failed 是刹车**——踩了刹车不许把"没配成"包装成"判不配"。

## 六、意图→参数映射表

> 规则：brief/提示词里的抽象意图按本表翻译成判定动作或参数；判不配时"英文关键词/参数"列即回执 `reason` 与机制字段的引用口径。

| 创作意图/场景 | 中文写法 | 英文关键词/参数 |
|---|---|---|
| 客户明说不要音乐 | 提示词明确"不要背景音乐"，按 do-no-harm 判不配 | `brief.noMusic` → `verdict=no_bgm_needed` |
| 素材已经带音乐（二剪/已成片） | 素材疑似已有连续配乐，不重复铺底 | `activeRatio ≥ 0.9 && flatness < 0.02` |
| 口播铺满全片、没地方放音乐 | 没有安全的配乐窗口，任何电平都会压字或不可闻 | `winner.score < minScore`（默认 92），margin < 6dB |
| 底噪太脏、配了也听不见 | 环境底噪过高，配乐可闻度预估不达标 | `musicPresenceDb < 3dB`，`roomToneDb` 偏高 |
| 纪实/ASMR/烹饪原声即内容 | 现场声本身就是内容，加配乐反而稀释 | 判据③：ambient/voice 即 content，no score |
| 证言要真实感、不要广告感 | 纯人声交付，保留气口与停顿 | voice-only, keep natural pauses |
| 严肃新闻/公告保持中立 | 正片无配乐，沉默即立场 | no underscore, neutral silence |
| 悬念揭示前留白 | 揭示点前后抽掉音乐，留半拍静默 | strip music before reveal, half-beat silence |
| 高端品牌要克制质感 | 声音留白，环境声 + 稀疏点缀 | sound留白：room tone + sparse bell, premium restraint |
| 不配但要空间感（降配路径） | 只铺环境声床，混响统一 | ambience bed only, unified reverb, no music |
| 配了但复检不可闻（质量护栏，非判不配） | 配了跟没配一样，删除产物不交付 | `verify_failed`, `musicPresenceDb < 3dB`, artifact removed |

## 七、模板

### 模板 A：判不配回执文案（reason 字段口径）

```
verdict: no_bgm_needed
reason: [命中判据] + [量化依据] + [被否掉的方案]
source: { speechLevelDb: <人声电平>, roomToneDb: <底噪电平>, activeRatio: <人声频段活动占比> }
sha256: <原片哈希>
```

示例（窗口型不配）：
> verdict: no_bgm_needed。reason: 最佳候选「人物访谈 · 可信亲和（84BPM / 让位 16dB）」预估分 78（阈值 92）：人声频段活动占比 96%，人声余量预估 2.1dB（目标 ≥6dB），没有安全的配乐窗口，按「不劣化优先」判定无需配乐。建议：纯原声交付，走响度复检口径。

示例（艺术型不配，需人工确认后走同一字段）：
> 题材=烹饪记录，现场声（锅气、翻炒、装盘）即内容主体，命中判据③「现场声本身就是内容」。建议不配乐，替代动作：环境声床补齐 + 底噪清理 + 响度统一至 -14 LUFS。

### 模板 B：降配说明（不是 no_bgm_needed，有产物）

```
verdict: scored（降配）
recipe: documentary / premium-brand 级（只留 pad + bass，禁用 pluck/kick/hat/bell）
musicLevelDb: -27 ~ -30（贴近配方库下限 -30）
duckingDb: 14（取上限）
说明：情绪需要克制但题材允许音乐，走"薄垫降配"，不走判不配。
```

### 模板 C：不配片子的复检清单（替代可闻度判据）

```
□ Integrated 响度 -14 LUFS ±1.5，True Peak ≤ -1.0 dBTP
□ 人声频段（200–4000Hz）电平与原片一致，无劣化
□ 原片 sha256 链路完整（或仅环境声段有声明式改动）
□ 若补环境声床：ambient 电平 ≤ 人声 − 6dB，段落拼接无爆音
□ 回执 verdict / reason / source / sha256 四件齐全
```

## 八、决策树

```
brief / 提示词输入（render_scripts.md / prompt_package / 一句话 brief）
  │
  ├─ ① 客户/brief 明说"不要背景音乐"？
  │     └─ 是 → 判不配（do-no-harm 通道，verdict=no_bgm_needed）
  │           → 验收：替代复检清单（模板 C）
  │
  ├─ ② 客户/brief 明说"要配乐"？
  │     └─ 是 → 禁止判不配：正常四问 → 配乐
  │           （素材条件触边 → 降配 + warning 交人审）
  │
  └─ ③ 未明说 → 定调四问（题材 / 场景与主体 / 情绪目标 / 平台）
        │
        ├─ 素材检测：activeRatio ≥0.9 且 flatness <0.02？
        │     └─ 是 → 判不配（已有连续配乐，不重复铺底）
        │
        ├─ 题材命中判据③（纪实/ASMR/烹饪/证言/严肃新闻）？
        │     ├─ 现场声即内容 → 判不配 → 环境声床 + SFX + 混响统一
        │     └─ 情绪需克制但允许音乐 → 降配（只铺环境声级薄垫，
        │           pad+bass，-27~-30dB）→ 正常复检线
        │
        └─ 其余 → best 候选池打分
              ├─ 最佳候选 ≥ minScore(92) → 配乐 → 复检线
              │     （可闻度 ≥3dB / 人声余量 ≥6dB / 响度达标）
              └─ 最佳候选 < minScore → 判不配（无安全窗口）
                    → 验收：替代复检清单（模板 C）
                    → 复检重点：响度、人声无劣化、原声完整性、ambient 余量
```

## 九、关联知识

- **SCORE-001 配乐电平与让位**：判不配的第三出口打分类判定直接引用其口径——人声余量 ≥6dB、可闻度 ≥3dB、`musicLevelDb` 区间 -30~-16、让位深度 8~14dB；降配路径的电平取值亦以此为准。
- **SCORE-002 风格决策与配方选型**：四问答完后的配方选择、降配选哪条配方（documentary / premium-brand / interview）、以及"揭示前静默"这类选段与结构问题，均属该主题；本主题只回答"配/不配/降配"的总开关。
- **bgm-score-design SKILL**：三判据与"允许的结论：不配"的权威出处（第六节）；定调四问、禁忌清单与失败模式表配合使用。
- **bgm-audio-layering SKILL**：软失败纪律（`verify_failed` 删产物）、四种原声分层策略（`keep-dialogue` / `keep-all` / `replace-bed` / `music-only`）、复检线与响度交付口径——判不配后的替代验收以其第五、六节为基准。
- **bgm-recipes/recipes.json**：`principle` 字段（"允许的结论包含「这片子不需要配乐」"）与 `targets` 复检目标值的机读出处。
