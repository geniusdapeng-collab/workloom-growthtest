# PLAT-005 B站横版封面规范

> 版本 v1.0 · 2026-09-27 · 适用链路：视频封面设计（cover-designer 岗位）

## 一、核心概念

B站封面是 16:9 横版缩略图，出现在首页推荐流、搜索结果、UP 主空间与相关视频列表——在信息流中占比很小（单列卡片中的横条），用户是「扫标题 + 扫封面」并行决策。横版带来与竖屏平台完全不同的设计逻辑：纵向空间宽裕（标题带可达 6%–55%），但缩略图整体小，因此「主体必须居中放大、标题靠左做大字」。B站是社区文化最深的平台：允许梗化表达、设计感贴图、描边字、表情包元素，封面可以「会玩」；但硬广口吻会被弹幕文化反噬（「恰饭」需坦荡，装则挨骂）。另一关键机制是系列化：B站用户有追更习惯，系列视频的封面模板一致性直接决定老观众「一眼认出更新了」的效率。

## 二、分类速查

| 类型 | 特征 | 适用账号 | CTR 表现 |
|---|---|---|---|
| 左字右图式 | 标题大字靠左，主体（人脸/产品/角色）居右 | 知识、测评、游戏、影视 | 高（平台主流） |
| 人物表情式 | UP 主夸张表情特写 + 短标题 | 生活、搞笑、挑战 | 高（个人 IP 型） |
| 对比碰撞式 | 双方对峙构图（A vs B、新旧、真假） | 测评、影视、游戏 | 高 |
| 梗图融梗式 | 融入热梗元素/表情包贴图，社区黑话标题 | 鬼畜、游戏、动漫 | 中高（圈内自嗨） |
| 信息密集式 | 多元素拼贴 + 大字标题，密度高但有序 | 盘点、教程、科技 | 中高 |
| 系列模板式 | 固定版式 + 期数编号 + 统一色板 | 连载、系列课程、周更栏目 | 高（追更驱动） |

## 三、分场景实战

**场景 1：知识/科普类（B站强势分区）**
做法：左字右图——左侧 1/2 放大标题（≤16 字，可 2 行）+ 右侧放讲者抠图或核心视觉（实验装置/天体/文物），配色走「高知感撞色」（深底 + 荧光点缀）。为什么：知识区用户为「认知升级」点进，标题的信息密度和锋利度即钩子；B站知识区封面已形成「杂志感」审美范式，太素会被认为不用心。

**场景 2：游戏类（最大分区之一）**
做法：游戏画面高光帧打底 + UP 主表情贴图（抠图描边）+ 大字短标题，可用游戏内元素（血条/装备图标）做装饰。为什么：游戏封面的决策链是「这局有看点」——高光帧证明素材质量，表情包传达情绪，图标元素是圈内身份暗号；描边贴图风是游戏区成熟方言。

**场景 3：影视解说/盘点类**
做法：多角色拼贴（3–5 个角色/名场面）+ 顶部或左侧大字标题，角色抠图加白色描边分层。为什么：解说类卖的是「信息压缩」，拼贴密度 = 内容含量承诺；描边分层让多角色在缩略图状态仍可辨认。

**场景 4：测评/数码类**
做法：产品居中放大 + 大标题 + 数据角标（「跑分 XX」「续航 12h」），背景用产品色系的渐变或工作台实拍。为什么：数码用户为「参数结论」点进，封面直接给关键数据 = 价值预览；产品图必须精修（反光/质感），数码区用户对产品图精度最挑剔。

**场景 5：系列连载类（课程/周更栏目）**
做法：固定模板——统一色板、统一字位、固定位置放期数编号（「EP.12」），每期只换主视觉和标题。为什么：B站追更文化下，模板一致性 = 老观众的识别效率；期数编号还制造「系列资产感」，提升收藏率。

## 四、平台参数速查（核心调用区）

| 参数 | 口径 |
|---|---|
| 画幅 | 16:9 横版 |
| 画布尺寸 | 1920×1080 px |
| 顶部安全区 | 画面上方 6%（约 65px），禁放关键元素 |
| 底部遮挡区 | 画面下方 9%（约 90px），被进度条/信息条遮挡，禁放关键元素 |
| 右侧栏 | 无右侧栏（横版信息流形态） |
| 标题带 | 画面上部 6%–55%（约 65px–595px），横版纵向空间宽裕，为各平台最宽 |
| 标题字数上限 | 主标题 ≤16 视觉字（各平台最宽上限，可利用但勿滥用） |
| 文案调性 | 社区语境、信息密度高、允许梗化、忌硬广口吻 |
| 钩子风格 | 疑问式 / 价值预览 / 数据冲击式 |
| 特殊机制 | 横版缩略图在信息流中占比小 → 主体居中放大、标题靠左大字；系列视频模板一致性；允许设计感贴图/描边/表情包元素 |

## 五、常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 竖屏思维做横版（主体小、字居中堆叠） | 缩略图状态主体消失、标题糊成一团 | 主体居中放大，标题靠左大字，左右分区 |
| 标题文字超过 16 字 | 信息流里读不完，重点失焦 | ≤16 字，信息分层：主标 + 副标 + 角标 |
| 关键元素放底部 9% | 被进度条遮挡（尤其时长信息） | 底部 90px 只放背景延伸，不放任何信息 |
| 硬广口吻（「必买」「史上最值」） | 弹幕反噬「恰饭可耻」，社区信任受损 | 坦荡标注合作，标题用体验向表达（「用了 30 天，说真话」） |
| 抠图不描边直接拼贴 | 多元素糊成一片，缩略图不可辨 | 抠图统一加 4–8px 白色/彩色描边分层（建议） |
| 每期封面版式乱跳 | 老观众认不出更新，追更链断裂 | 系列视频锁定模板：色板/字位/期数位置固定 |
| 梗元素堆砌过度 | 圈外用户看不懂，信息噪音 | 一条封面最多一个梗，梗不压主体 |
| 用平台外竖版封面裁切凑数 | 16:9 裁切后主体残缺、字被切 | 横版单独设计，不复用竖版素材裁切 |

## 六、意图→设计映射表（核心调用区）

| 用户意图/题材 | 设计动作（版式/构图/字级/配色/钩子） | 判据 |
|---|---|---|
| 涨知识（科普/人文/科技） | 版式：左字右图；构图：左侧 1/2 标题，右侧讲者抠图或核心视觉；字级：主标高约 140–180px（建议），可 2 行；配色：深底 #1A1A2E + 荧光点缀 #00F5D4（建议）；钩子：疑问式「XX 为什么是 XX」 | 缩略图状态（约 300px 宽）标题可读、主体可辨 |
| 看这局（游戏实况/攻略） | 版式：高光帧打底 + 表情贴图 + 大字；构图：游戏画面满版，UP 主表情贴图放右上；字级：主标高约 150px（建议）+ 8px 描边；配色：游戏原色 + 高对比字色；钩子：冲突/疑问式「这波操作，封神」 | 圈内元素（装备/角色/地图）一眼可认 |
| 补番/看片（影视解说/盘点） | 版式：多角色拼贴 + 顶部大字；构图：3–5 个角色抠图描边分层；字级：主标高约 140px（建议）；配色：底色统一压暗，角色原色跳出；钩子：价值预览式「一口气看完 XX 全季」 | 每个角色在缩略图状态可辨认 |
| 买前参考（数码/测评） | 版式：产品居中 + 标题 + 数据角标；构图：产品精修图占 50%+；字级：主标高约 140px，数据角标约 60px（建议）；配色：产品色系渐变底；钩子：数据冲击式「续航 12h，我测了」 | 关键参数（跑分/续航/价格）直接上封面 |
| 追更（系列课程/周更栏目） | 版式：固定模板；构图：固定字位 + 期数编号固定位置；字级：主标高约 140px（建议）；配色：系列统一色板，每期仅换强调色；钩子：价值预览式「零基础 Python｜EP.08」 | 与系列前作并排时一眼认出同系列 |
| 图一乐（搞笑/鬼畜/生活挑战） | 版式：表情特写 + 短大字；构图：夸张表情占 60%+；字级：主标高约 160px、单行（建议）；配色：高饱和撞色（黄黑/粉蓝）；钩子：疑问式「挑战 24 小时只吃 XX」 | 表情帧本身有笑点/槽点，字只加一层悬念 |
| 听故事（案件/历史/纪实解说） | 版式：氛围图 + 悬念标题；构图：关键物证/场景居中压暗；字级：主标高约 140px（建议）；配色：暗色底 + 血红/惨白点缀；钩子：疑问式「消失的 XX，真相只有一个」 | 悬念感成立但不泄露结局，无血腥惊悚违规元素 |
| 学手艺（教程/软件教学/手工） | 版式：成果展示 + 步骤暗示；构图：成品居中 + 工具元素环绕；字级：主标高约 130px（建议）；配色：清爽底 + 主色突出成品；钩子：价值预览式「10 分钟做出 XX」 | 成品质量在缩略图状态可判断 |
| 同好狂欢（动漫/二创/cos） | 版式：角色主体 + 梗化标题；构图：角色占主体，允许贴图/对话框元素；字级：主标高约 140px（建议）；配色：角色应援色/作品原色系；钩子：圈内梗式「全体起立，XX 回归」 | 圈内人 0.5 秒 get 梗，画面还原度被认可 |

## 七、设计模板

**模板 A：左字右图知识款（科普/人文/财经）**
- 布局：左侧 0–50% 放标题（主标 2 行 + 一行副标），右侧 50%–100% 放讲者抠图（8px 白色描边）或核心视觉；顶部 6%、底部 9% 留空。
- 字体：思源黑体 Heavy / 阿里妈妈数黑体（建议）；主标字高约 150px（建议）。
- 配色：底 #16161E（深墨），主标 #FFFFFF，关键词 #FFD60A（亮黄），副标 #8E8E93，点缀线 #00F5D4。
- 标题示例：「人民币升值，你的钱包会怎样？」——「钱包」亮黄高亮。

**模板 B：游戏高光款（游戏/电竞）**
- 布局：游戏高光帧满版打底（压暗 15%），UP 主表情抠图贴右上（描边 + 投影），左侧放大字标题 + 游戏元素角标（装备/段位图标）。
- 字体：站酷高端黑 / 思源黑体 Heavy + 8–10px 描边（建议）。
- 配色：字 #FFFFFF 描边 #000000，冲突词 #FF4757，图标保留游戏原色。
- 标题示例：「落后 1 万经济，这波翻盘了」。

**模板 C：系列模板款（课程/连载栏目）**
- 布局：固定结构——左上放栏目标签 + 期数（「EP.12」），左下放主标，右侧放本期主视觉；色板、字位、标签样式全系列锁死。
- 字体：思源黑体 Bold（建议），期数用等宽数字。
- 配色：系列主色（示例：#2E5BFF 蓝）+ 每期强调色轮换；标签白底黑字固定。
- 标题示例：「零基础学剪辑｜EP.12 蒙版的 3 个神操作」。

## 八、决策树

```
题材是什么？
├─ 知识/科普/财经 → 模板 A（左字右图），疑问钩子
├─ 游戏/电竞 → 模板 B（高光帧 + 表情贴图），圈内元素必须准确
├─ 影视解说/盘点 → 多角色拼贴 + 描边分层，价值预览钩子
├─ 数码/测评 → 产品居中精修 + 数据角标，忌硬广口吻
├─ 搞笑/挑战/鬼畜 → 表情特写 + 短大字，最多一个梗
├─ 教程/手工/软件 → 成品居中 + 价值预览钩子
└─ 系列/连载 → 模板 C（锁定模板），期数编号固定位置
再判断：是系列内容吗？
├─ 是 → 无论题材，模板一致性 > 单期创意，套系列模板
└─ 否 → 按题材模板走
发布前再校验：
① 主标 ≤16 字，信息分层（主标/副标/角标）？
② 顶 6% / 底 9%（90px 进度条区）无关键元素？
③ 缩略图状态（信息流小横条）主体与标题可辨？
④ 抠图元素是否都加描边分层？
⑤ 无硬广口吻（合作内容坦荡标注）？
```
