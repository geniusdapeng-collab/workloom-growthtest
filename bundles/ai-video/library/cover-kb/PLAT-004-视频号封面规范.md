# PLAT-004 视频号封面规范

> 版本 v1.0 · 2026-09-27 · 适用链路：视频封面设计（cover-designer 岗位）

## 一、核心概念

视频号的分发底座是微信社交链：「朋友点赞」推荐让内容流入熟人信息流，用户点开视频的决策发生在「我朋友在看的」语境里——封面因此带有社交成本。标题党、夸张惊悚、低俗擦边的封面在抖音可能只是被划走，在视频号会让点赞的朋友「替你尴尬」，直接抑制社交传播。同时视频号用户年龄层显著偏高（中老年用户占比高），带来两条硬约束：字级必须取上限、字体必须粗壮清晰，细瘦字体和花屏配色直接出局。调性总纲是「熟人社交语境、真实分享感、克制不硬广」——像在朋友圈转发时敢署自己名字的东西，才配当视频号封面。

## 二、分类速查

| 类型 | 特征 | 适用账号 | CTR 表现 |
|---|---|---|---|
| 人物口播式 | 人脸半身 + 双行价值标题，稳重配色 | 知识、资讯、情感、健康 | 高（主流形态） |
| 真实记录式 | 生活/工作场景帧 + 短句，轻加工 | 三农、手艺、日常 | 高 |
| 新闻资讯式 | 事件画面 + 大字标题（克制版新闻风） | 媒体号、本地资讯 | 中高 |
| 金句卡式 | 纯色/意境底 + 一行金句大字 | 情感、读书、鸡汤 | 中高（转发友好） |
| 价值清单式 | 「3 个方法」类数字标题 + 人物/场景 | 健康、养生、教育 | 中 |
| 夸张标题党式 | 惊悚/悬念过度/擦边 | 全类型 | 低（熟人语境反噬，禁用） |

## 三、分场景实战

**场景 1：健康/养生类（中老年基本盘题材）**
做法：讲者正装或白大褂半身像放下 1/2，标题带放双行大字（主标 ≤12 字），配色沉稳（藏蓝/墨绿/深红），字级取建议上限（主标约画面宽 1/5–1/4）。为什么：健康题材的信任来自「专业形象 + 可读性」；中老年用户对字号极敏感，字小 = 直接划走。

**场景 2：情感/家庭类（转发主力军）**
做法：金句卡式——意境底图（夕阳/茶/书房）+ 一行金句大字居中偏上，字体用粗宋体或粗黑体，字数 ≤12。为什么：中老年用户转发的是「这句话说到我心里」，金句卡在微信生态里转发零社交成本；花哨排版反而稀释金句力量。

**场景 3：新闻/本地资讯类**
做法：事件现场帧 + 标题带大字（新闻风但克制，不用感叹号轰炸），时间地点信息可入副标。为什么：资讯类靠「与我有关」点进，本地地名/时间是最强钩子；克制的新闻风在朋友圈语境里有公信力，标题党则社死。

**场景 4：知识/教育类**
做法：讲者人像 + 价值预览标题（「退休前必懂的 3 件事」），数字高亮，背景用书房/讲台等场景强化专业感。为什么：「价值预览 + 数字锚点」在熟人语境里仍有效，因为它承诺的是获得感而非悬念；配上专业场景，朋友点赞也拿得出手。

**场景 5：三农/手艺/生活记录类**
做法：真实场景帧 + 口语化短句（参考快手逻辑但更克制），标题放标题带上段。为什么：视频号的真实感逻辑与快手相通，但少了「老铁文化」的外放，多一分朋友圈式的体面——真实但不粗粝。

## 四、平台参数速查（核心调用区）

| 参数 | 口径 |
|---|---|
| 画幅 | 9:16 竖屏 |
| 画布尺寸 | 1080×1920 px |
| 顶部安全区 | 画面上方 6%（约 115px），禁放关键元素 |
| 底部遮挡区 | 画面下方 16%（约 300px），平台 UI 遮挡，禁放关键元素 |
| 右侧栏 | 右侧约 11% 宽（约 120px）操作栏，关键元素左移避让 |
| 标题带 | 画面上部 6%–42%（约 115px–810px）为标题安全放置区 |
| 标题字数上限 | 主标题 ≤12 视觉字，≤2 行 |
| 文案调性 | 熟人社交语境、真实分享感、克制不硬广 |
| 钩子风格 | 疑问式 / 价值预览 / 冲突式（克制使用） |
| 特殊机制 | 社交推荐链路（朋友点赞），标题党有社交成本；中老年用户占比高 → 字级取上限、避免细瘦字体 |

## 五、常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 搬运抖音夸张标题党 | 熟人语境社交成本，朋友不点赞 = 断推荐 | 钩子克制化：价值预览替代悬念惊悚 |
| 用细瘦/文艺字体 | 中老年用户看不清，直接划走 | 粗黑体/粗宋体，笔画粗壮（建议字重 ≥Bold） |
| 字级按年轻平台标准做 | 可读性不及格 | 字级取上限（建议主标约画面宽 1/5–1/4） |
| 配色高饱和撞色轰炸 | 观感廉价，与微信生态气质冲突 | 沉稳色系：藏蓝/墨绿/深红/米白 |
| 关键信息放底部 16% | 被 UI 遮挡（300px 遮挡带） | 底部 300px 只放背景，核心信息进标题带 |
| 封面像广告海报（促销感） | 朋友圈语境里没人愿意点赞广告 | 分享感 > 推销感，软价值表达 |
| 惊悚/擦边/卖惨帧 | 举报风险 + 社交反噬，账号受损 | 情绪表达克制，用价值而非刺激驱动 |
| 忽视「转发」场景 | 只做点击钩子，丢了视频号独有的转发杠杆 | 金句类内容封面即「转发宣言」，排版留白大气 |

| 孩子教育（育儿/升学） | 版式：人物（家长/教师）+ 价值标题；构图：人物亲切近景；字级：主标约 1/5 宽（建议）；配色：暖而不跳（暖米/浅棕 + 深棕字）；钩子：疑问式「孩子磨蹭，问题出在哪」 | 家长身份代入感，无制造焦虑的恐吓式表达 |
| 缅怀/节日（节气/传统节日/家国情怀） | 版式：意境大图 + 短句；构图：节日意象主体（月/灯/雪）；字级：主标约 1/5 宽（建议）；配色：节日正色（中国红/月白/黛青）；钩子：共鸣式「今日重阳，记得打个电话」 | 情绪浓度高而表达克制，转发零压力 |
| 商机/副业（中老年创业/副业） | 版式：人物 + 结果数字标题；构图：讲者 + 真实经营场景；字级：主标约 1/5 宽，数字高亮（建议）；配色：稳重底色 + 金色数字；钩子：价值预览式「摆摊第 90 天，说句实在话」 | 数字真实可信（忌夸张收益承诺，合规红线） |

## 七、设计模板

**模板 A：稳重口播款（健康/知识/资讯讲者）**
- 布局：讲者半身像放下 1/2（深色正装/白大褂），标题带 6%–28% 放主标双行，28%–40% 放一行副标或留空；底部 16% 留空。
- 字体：思源黑体 Bold / 思源宋体 Heavy（建议），忌细瘦体；主标字高约 200–260px（建议，全平台最大值）。
- 配色：底 #1F3251（藏蓝），主标 #FFFFFF，关键词 #E8B84B（哑光金），副标 #C9D4E5。
- 标题示例：「医生提醒：这 2 种早餐，趁早撤下餐桌」——「2 种早餐」金色高亮。

**模板 B：金句卡款（情感/读书/感悟）**
- 布局：意境底图（茶/夕阳/书房，压暗 20%–30%），金句居中偏上（画面 20%–45% 区间）单行大字；底部可放极小出处行。
- 字体：思源宋体 Heavy / 方正粗宋（建议），衬线体增强「书面感、分量感」。
- 配色：底图压暗 + 字 #F5F0E6（米白），或米白底 #F5F0E6 + 字 #3E3229（深棕）。
- 标题示例：「人这一辈子，健康是 1，其余是 0」。

**模板 C：本地资讯款（媒体号/本地号）**
- 布局：事件现场帧满版，标题带 6%–30% 放白字黑边双行标题，副标带地名/时间；右下角避开 11% 操作栏。
- 字体：思源黑体 Bold + 4–6px 黑色描边（建议）。
- 配色：字 #FFFFFF，描边 #000000，关键词（地名/数字）#FFD23F。
- 标题示例：「郑州这条地铁，下月通车」——「下月通车」黄色高亮。

## 八、决策树

```
题材是什么？
├─ 健康/养生/医疗科普 → 模板 A（讲者 + 双行大字），字级取上限
├─ 情感/人生感悟/读书 → 模板 B（金句卡），单行 ≤12 字，衬线体优先
├─ 新闻/本地资讯 → 模板 C（现场帧 + 新闻式标题），地名时间入副标
├─ 知识/教育/政策科普 ── 讲者出镜吗？
│   ├─ 是 → 模板 A 变体（人像 + 数字清单标题）
│   └─ 否 → 稳重底大字报（政务色系），关键词金色高亮
├─ 三农/生活记录 → 场景帧 + 口语短句（真实但克制，不粗粝）
└─ 节日/节气/情怀 → 意境大图 + 短句，节日正色
发布前再校验（视频号独有「社交成本三问」）：
① 这条封面，用户的朋友看了会觉得 TA「品位在线」吗？
② 有无任何标题党/惊悚/擦边元素？
③ 40cm 距离（中老年老花场景）主标可读？
技术校验：
④ 主标 ≤12 字、≤2 行，字重 ≥Bold？
⑤ 底部 16%（300px）、顶部 6%、右侧 11% 无关键元素？
```
