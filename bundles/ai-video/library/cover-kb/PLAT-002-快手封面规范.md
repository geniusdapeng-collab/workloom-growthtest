# PLAT-002 快手封面规范

> 版本 v1.0 · 2026-09-27 · 适用链路：视频封面设计（cover-designer 岗位）

## 一、核心概念

快手的流量结构与抖音不同：双列点选流（发现页为双列瀑布流）占比高，用户先看封面缩略图、再决定点不点——封面是点进决策的主战场，而不是「首帧顺带露脸」。这决定了快手封面的第一判据是「缩略图状态下的点进欲」。同时快手社区文化是「老铁经济」：真实、接地气、熟人信任是社区货币，用户相信「跟我一样的普通人」。因此快手封面有两条铁律：其一，双列缩略图里必须一眼看清主体和标题；其二，真实感 > 精致感——过度修图、过度广告感的封面在快手 CTR 反而低，因为触发了老铁的「这是广告/这是装的」防御心理。

## 二、分类速查

| 类型 | 特征 | 适用账号 | CTR 表现 |
|---|---|---|---|
| 真实场景式 | 原生场景帧（田间/车间/店铺/厨房），轻加工 | 三农、手艺、个体户 | 高（快手基本盘） |
| 老铁口播式 | 人脸半身 + 口语化标题，素色或场景底 | 知识、情感、本地服务 | 高 |
| 对比反差式 | 前后对比（货品/手艺/改造），对比真实不摆拍 | 手艺、改造、测评 | 高 |
| 大字标题式 | 场景底 + 大字压顶，字口语化（「咋整」「嘎嘎香」） | 美食、三农、搞笑 | 中高 |
| 信任背书式 | 身份/资质/销量数字入封面（「20 年老店」） | 带货、本地商家 | 中高（信任驱动） |
| 精致海报式 | 精修图、大片感排版 | 全类型 | 低（快手慎用，广告感劝退） |

## 三、分场景实战

**场景 1：三农/手艺类（快手基本盘题材）**
做法：直接用劳动现场帧（抓鱼、打铁、收割），人物在画面中真实劳作，标题口语化短句放标题带上段（如「这网下去，爆了」）。为什么：三农内容的核心资产是「真实生产过程」，任何摆拍痕迹都会被老铁识破；场景帧本身就是最强钩子，文字只做点睛。

**场景 2：美食类（探店/做菜）**
做法：成品特写占画面中心 50%+，蒸汽/油光/拉丝等「食欲细节」必须保留，标题带放口语钩子（「嘎嘎香」「10 块钱管饱」）。为什么：快手美食的决策链是「看着香 → 便宜/实在 → 点进」，食欲细节是真实感信号，过度滤镜磨皮反而显得假。

**场景 3：带货/个体商家类**
做法：人脸 + 产品同框（店主手持货品），标题放信任背书数字（「卖了 8 年」「回头客 3000+」），配色朴实不刺眼。为什么：快手带货靠信任而非冲击，老铁买的是「这个人靠谱」；背书数字是最短信任路径，比价格冲击更有效。

**场景 4：情感/民生口播类**
做法：人脸半身占下 1/2，标题带放双行口语化标题（「这事儿，我憋不住要说」），字级取大（建议主标约画面宽 1/6）。为什么：情感号靠「自己人」人设，口语化标题 = 语音消息般的亲近感；快手用户年龄层偏高，字必须够大。

**场景 5：双列流抢点击（发现页分发为主的账号）**
做法：刻意在双列缩略图尺寸（约半屏宽）下自检——主体放大、标题≤2 行、对比度拉高；与同类内容比「更亮一点、更大一点、更清楚一点」。为什么：双列流是「相邻封面赛马」，你的对手是同一屏里另外 3 个封面，可辨性胜出即 CTR 胜出。

## 四、平台参数速查（核心调用区）

| 参数 | 口径 |
|---|---|
| 画幅 | 9:16 竖屏 |
| 画布尺寸 | 1080×1920 px |
| 顶部安全区 | 画面上方 6%（约 115px），禁放关键元素 |
| 底部遮挡区 | 画面下方 17%（约 320px），平台 UI 遮挡明显重于抖音，禁放关键元素 |
| 右侧栏 | 右侧约 11% 宽（约 120px）操作栏，关键元素左移避让 |
| 标题带 | 画面上部 6%–42%（约 115px–810px）为标题安全放置区 |
| 标题字数上限 | 主标题 ≤12 视觉字，≤2 行 |
| 文案调性 | 老铁式真实口语、强信任背书、忌精致过度 |
| 钩子风格 | 疑问式 / 冲突式 / 数据冲击式 |
| 特殊机制 | 双列点选流占比高，封面 = 点进决策主战场；真实感 > 精致感，过度广告感 CTR 反降 |

## 五、常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 套用抖音精致海报风 | 老铁识别为「广告/装的」，CTR 反降 | 保留场景原生感，轻加工，字朴实 |
| 过度磨皮滤镜 | 假面感，信任崩塌 | 保留皮肤/食材/场景真实质感 |
| 关键信息放底部 17% | 快手底部遮挡重（320px），信息全丢 | 核心信息集中标题带 6%–42%，底部大段留白 |
| 标题用书面语/文艺腔 | 与社区语境违和，完播差 | 口语化：「咋整」「管饱」「憋不住」 |
| 字级按抖音下限做 | 快手用户年龄层偏高，看不清 | 字级取大（建议主标 ≥ 画面宽 1/6） |
| 只堆价格冲击没有信任元素 | 带货转化低，被判硬广 | 信任背书数字入封面（年限/销量/身份） |
| 双列缩略图状态不自检 | 发现页赛马输给相邻封面 | 半屏宽缩略图下主体可辨、标题可读 |
| 摆拍「假装真实」 | 被评论区识破，账号人设崩 | 用真实生产过程帧，构图可以设计、内容不能演 |

## 六、意图→设计映射表（核心调用区）

| 用户意图/题材 | 设计动作（版式/构图/字级/配色/钩子） | 判据 |
|---|---|---|
| 看真实生产（三农/手艺） | 版式：场景帧为主 + 顶部短句；构图：人物劳作瞬间居中；字级：主标约 1/6–1/7 宽（建议）；配色：保留场景原色，字色白/黄 + 黑描边；钩子：冲突/数据式「这一网，值了」 | 画面一眼认出「真现场」，无摆拍痕迹 |
| 解馋（美食/探店） | 版式：成品特写 + 口语短标；构图：食物占中心 50%+，保留蒸汽/油光；字级：主标约 1/6 宽（建议）；配色：暖黄暖橙食欲色；钩子：口语数据式「10 块钱管饱」 | 缩略图状态能唤起食欲，价格/分量信息可见 |
| 找靠谱商家（带货/本地服务） | 版式：人脸 + 产品同框 + 背书数字；构图：店主手持货品下 1/2；字级：背书词约 1/6 宽（建议）；配色：朴实大地色系，忌荧光撞色；钩子：数据冲击式「卖了 8 年的老手艺」 | 封面含至少一个可验证的信任数字 |
| 听人说事（情感/民生口播） | 版式：人脸半身 + 双行口语标题；构图：人脸下 1/2，视线朝向镜头；字级：主标约 1/6 宽（建议）；配色：深色底 + 白/黄字；钩子：冲突/疑问式「这事儿我憋不住」 | 标题读感像语音消息，不像新闻标题 |
| 看手艺反差（改造/修复/测评） | 版式：前后对比分屏；构图：before 左、after 右，均为实拍；字级：主标约 1/7 宽置顶（建议）；配色：对比侧一旧一新（色温区分）；钩子：冲突式「废品站捡的，修完值这个数」 | 不看字也能识别「变新/变好」，且两侧都真实 |
| 学手艺（教程/农技） | 版式：步骤场景帧 + 结果前置标题；构图：操作手部特写；字级：主标约 1/6 宽（建议）；配色：场景原色 + 黄字黑边；钩子：疑问式「嫁接成活率低？差这一步」 | 标题点出具体痛点，而非泛泛「教程」 |
| 图个乐（搞笑/段子） | 版式：表情高潮帧 + 短字角标；构图：人物表情特写居中；字级：主标约 1/7 宽（建议）；配色：明快黄/橙；钩子：冲突式「媳妇查岗，我急中生智」 | 表情帧本身有喜感，文字不解释笑点只设悬念 |
| 买便宜好货（促销/清仓） | 版式：货品堆头实拍 + 价格大字；构图：货品堆叠占下 2/3；字级：价格词约 1/5 宽（建议）；配色：红/黄促销色但控制饱和度不过曝；钩子：数据冲击式「工厂清仓，全场个位数」 | 价格一眼可见，画面保留「仓库/工厂」真实感 |
| 认老乡/本地（同城/方言内容） | 版式：地标/方言元素 + 人物同框；构图：人物 + 本地标志场景；字级：主标约 1/6 宽（建议）；配色：接地气暖色；钩子：疑问式「咱 XX 人都懂这一口」 | 本地用户一眼识别「这是我们这儿的」 |

## 七、设计模板

**模板 A：老铁口播款（情感/知识/本地服务）**
- 布局：人脸半身放下 1/2（视线朝镜头），标题带 6%–30% 放双行口语标题，30%–42% 留空或放一行小字背书；底部 17% 全留空。
- 字体：思源黑体 Bold / 阿里巴巴普惠体 Bold（建议）；主标字高约 170–200px（建议），笔画粗忌细瘦。
- 配色：底用场景原色或 #26313F（深灰蓝），主标 #FFFFFF，关键词 #FFC300，描边 #000000。
- 标题示例：「干了 15 年装修，这 3 个坑我必须说」——「3 个坑」黄色高亮。

**模板 B：三农现场款（三农/手艺/美食）**
- 布局：满版真实场景帧（劳作/出锅瞬间），顶部 6%–25% 放一行口语短句 + 黑描边；不加任何贴图、边框、花字。
- 字体：思源黑体 Bold + 4–6px 黑色描边（建议）。
- 配色：字 #FFFFFF 描边 #000000，强调词 #FFDD33。
- 标题示例：「凌晨四点出海，就等这一网」。

**模板 C：信任带货款（个体商家/工厂号）**
- 布局：人物手持产品居中（人 + 货同框），标题带 6%–22% 放背书数字（「8 年老厂」），22%–40% 放价格/承诺；底部 17% 留空。
- 字体：阿里巴巴普惠体 Heavy（建议）。
- 配色：底 #F5EFE6（米白），背书词 #8B5A2B（暖棕），价格 #C0392B（暗红，不用荧光红）。
- 标题示例：「8 年老厂直发」+「一双也是批发价」。

## 八、决策树

```
题材是什么？
├─ 三农/手艺/美食现场 ── 有真实过程帧吗？
│   ├─ 有 → 模板 B（场景帧 + 口语短句），不加装饰元素
│   └─ 没有 → 回去补拍，快手封面不接受摆拍式「假装真实」
├─ 口播/情感/知识 ── 人设是「自己人」吗？
│   ├─ 是 → 模板 A（人脸 + 口语双行标）
│   └─ 否（专家/权威人设）→ 人脸 + 背书数字（年限/资质）
├─ 带货/商家号 ── 核心武器是什么？
│   ├─ 信任（老店/回头客）→ 模板 C（背书数字最大）
│   └─ 价格（清仓/源头货）→ 价格词最大 + 仓库/工厂场景帧
├─ 改造/修复/对比 → 前后分屏，before/after 都必须是实拍
└─ 搞笑/段子 → 表情高潮帧 + 短字角标，不解释笑点
发布前再校验：
① 主标 ≤12 字、≤2 行、口语化？
② 底部 17%（320px）无关键元素？
③ 半屏宽缩略图状态主体可辨？
④ 画面有「真实感信号」（原场景/原质感/无过度磨皮）？
```
