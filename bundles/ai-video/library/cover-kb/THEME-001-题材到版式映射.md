# THEME-001 题材到版式映射
> 版本 v1.0 · 2026-09-27 · 适用链路：视频封面设计（cover-designer 岗位）

## 一、核心概念

题材决定版式（archetype）。封面链路只有两种版式：
- **person-led**：人物为主，人物占画面高 ≥55%，背景只作点缀；
- **subject-led**：非人主体（物体/场景/图表/食物/动物）满幅，画面禁止出现人物小卡。

禁止第三种版式——"人物小图贴地标"（人物占比不足，缩在角落贴在地标/产品图上），它在两种链路里都判非法。选版式的判据只有一条：这个题材里，用户为谁点击——为"人"（脸、表情、人设），还是为"物"（信息、食欲、风景、产品）。

## 二、分类速查

| 题材 | 默认 archetype | 用户点击动机 |
|---|---|---|
| 知识科普 | subject-led（图表）或 person-led（讲师） | 为信息/为讲师权威 |
| 美食 | subject-led | 为食欲 |
| 旅行风光 | subject-led（有人设账号才 person-led） | 为风景/为旅者人设 |
| 剧情/短剧 | person-led | 为表情冲突 |
| 带货/种草 | subject-led（或手持产品 person-led） | 为产品与利益 |
| Vlog 日常 | person-led | 为人设陪伴感 |
| 测评/对比 | subject-led | 为结论与数据 |
| 母婴/宠物 | subject-led（萌宠）或 person-led（亲子同框） | 为治愈 |

## 三、分场景实战

### 1. 知识科普
- archetype：图表/关键帧满幅（subject-led）优先；讲师型账号用 person-led 讲师半身（≥55%）。
- 取帧：信息密度最高帧（核心图表/公式/结论页）；讲师号取"手势打开、眼神看镜头"帧。
- 构图：图表居中放大至画面 70%+；讲师半身置左 1/3，右侧留白放标题。
- 字级：主标题 0.07–0.10（疑问式 ≤12 字），副标题 0.025–0.04。
- 典型钩子：疑问式（"为什么……""……到底是什么"）。
- 平台备注：B站标题可至 16 字并加副标题；YouTube 需 120px 宽度下可读。

### 2. 美食
- archetype：subject-led，食物特写满幅；人或手只作点缀（手持/夹起动作），禁止人物占比过半变成吃播人像。
- 取帧：食欲峰值帧（拉丝/流心/冒热气/咬开截面）。
- 构图：主体占画面 60–80%，45° 俯拍或平视特写；暖色调。
- 字级：主标题 0.05–0.08，店名/菜名优先；价格利益点进副标题。
- 典型钩子：食欲词+利益（"一口爆汁""人均 30 吃到撑"）。
- 平台备注：小红书忌过度饱和的滤镜感；快手可加大字号、降低精致度。

### 3. 旅行风光
- archetype：subject-led 地标/风光满幅为默认；仅当账号是人设型旅拍（visual_hammer 锁定 person-led）才用人物 ≥55% 的旅人主体。严禁"人物小图贴地标"。
- 取帧：光线戏剧化帧（黄金时刻/蓝调时刻/云海）。
- 构图：地标置上 2/3 或三分线交点，底部留 scrim 区放标题。
- 字级：主标题 0.045–0.07（风光图留白多，字不宜过大压景）。
- 典型钩子：地名+稀缺感（"99% 人不知道的机位"）。
- 平台备注：IG 中央 1:1 安全区收地标主体；小红书 3:4 竖构图优先。

### 4. 剧情/短剧
- archetype：person-led，表情冲突帧（惊讶/愤怒/哭泣/对峙）。
- 取帧：情绪峰值帧，双眼必须清晰；双人冲突可双人同框（合计 ≥55%）。
- 构图：面部置上 1/3，视线方向留白放标题。
- 字级：主标题 0.08–0.12（可顶格大号），冲突式 ≤12 字。
- 典型钩子：冲突式（"丈夫手机里的秘密""她被开除那天"）。
- 平台备注：抖快主战场；标题禁止剧透结局。

### 5. 带货/种草
- archetype：subject-led 产品满幅（白底/场景底）为默认；手持产品的 person-led（手+产品合计 ≥55%，人脸可不出）亦可。禁止"人像小卡+产品小图"双拼贴。
- 取帧：产品 hero 帧（使用前后效果/质地特写）。
- 构图：产品居中放大 50–70%，利益点用色块条承载。
- 字级：主标题 0.06–0.10；数字钩子（"3 天见效""立省 200"）放大至强调层级。
- 典型钩子：利益/数据式。
- 平台备注：小红书重"测评感"忌硬广字；抖音可更直白。

### 6. Vlog 日常
- archetype：person-led，生活感瞬间（大笑/回眸/做饭手忙脚乱）。
- 取帧："非摆拍感"帧，宁可糊一点不要硬凹。
- 构图：人物偏中心，环境保留生活痕迹（厨房/街道）。
- 字级：主标题 0.045–0.07，轻钩子忌硬（不喊口号）。
- 典型钩子：轻悬念（"周三的一件小事"）。
- 平台备注：小红书/B站友好；B站标题可到 16 字讲故事感。

### 7. 测评/对比
- archetype：subject-led 双物对比构图。
- **关键工艺约束**：底图必须是单张连续画面（两物同框实拍）。对比感通过设计层实现——"前后分屏字幕条"、分割线、VS 角标等叠加元素；禁止把两张独立底图拼接成一张底图。
- 取帧：两物同框并列帧，或单物+数据表同框。
- 构图：左右对称并列，中间留 2–4% 缝放 VS/分割线元素。
- 字级：主标题 0.06–0.09，数字结论（"贵 3 倍值不值"）为钩子核心。
- 平台备注：B站/YouTube 测评浓度高，标题结论化。

### 8. 母婴/宠物
- archetype：subject-led 萌宠满幅，或 person-led 亲子同框（人物+孩子合计 ≥55%）。
- 取帧：萌宠取"歪头/揣手/瞳孔圆"帧；亲子取互动帧（对视/牵手）。
- 构图：主体居中偏下，上方留白放标题；治愈系配色（详见 THEME-002）。
- 字级：主标题 0.05–0.08，圆润字体气质优先。
- 典型钩子：治愈/轻悬念（"它等了我一整天"）。
- 平台备注：小红书宠物赛道拥挤，靠色板一致性突围。

## 五、常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 人物小图贴地标/产品 | 双链路判非法：人物看不清、主体也不突出 | 二选一：人物 ≥55% 走 person-led，或物满幅走 subject-led |
| 美食封面人物占半 | 食欲被稀释，CTR 下降 | 食物满幅，手只作点缀 |
| 测评拼两张独立底图 | 底图被判拼接，工艺校验失败 | 单张连续画面，对比靠分屏字幕条等设计层元素 |
| 剧情封面用唯美微笑帧 | 无冲突感，点击率低 | 取情绪峰值帧（惊讶/对峙/哭泣） |
| 知识封面标题塞 20 字 | 超 ≤12 字硬口径，缩略图不可读 | 砍到 ≤12 字（小红书 14 / B站 16），疑问式优先 |
| 风光封面字过大压景 | 风景卖点被遮 | 字高比压到 0.045–0.07，标题带 scrim 承载 |
| 种草封面产品+人像双拼 | 主体不明，判非法 | 产品满幅或手持 ≥55% 二选一 |
| Vlog 用硬广式大标题 | 人设崩塌，社区反感 | 轻钩子+小字级（0.045–0.07） |

## 七、设计模板

### 模板 1：知识科普标准版
- archetype：subject-led；底图=核心图表帧放大 ≥70%
- 字体：source-han-heavy；主标题字高 0.08（≤12 字疑问式）
- 结构：底部 25% scrim 压暗带 + 主标题 + 副标题（期数/栏目）
- 角标：「干货第N期」左上

### 模板 2：剧情冲突版
- archetype：person-led；底图=情绪峰值帧，面部上 1/3
- 字体：smiley-sans；主标题字高 0.10–0.12（冲突式 ≤12 字）
- 结构：视线方向留白放标题 + 关键词 accent 描边
- 角标：「第N集」右上

### 模板 3：测评对比版
- archetype：subject-led；底图=双物同框单张连续画面
- 设计层：中缝 VS 圆标 + 前后分屏字幕条（左"之前"右"之后"）
- 字体：source-han-heavy；主标题字高 0.07–0.09（数字结论）
- 判据：底图无拼接；分屏元素全部位于设计层

## 八、决策树

```
拿到题材
├─ 用户为"人"点击还是为"物"点击？
│  ├─ 为物 → subject-led：主体满幅，禁止人物小卡
│  │        ├─ 图表/信息 → 知识科普模板（图表 ≥70%）
│  │        ├─ 食物 → 美食模板（60–80% 暖调）
│  │        ├─ 风光 → 地标下 2/3 + 标题带 scrim
│  │        ├─ 产品 → 种草模板（50–70% + 利益钩子）
│  │        ├─ 双物 → 测评模板（单张连续画面+设计层分屏）
│  │        └─ 萌宠 → 居中偏下 + 上留白标题
│  └─ 为人 → person-led：人物占画面高 ≥55%
│           ├─ 讲师 → 左 1/3 + 右侧标题
│           ├─ 剧情 → 面部上 1/3 + 冲突标题
│           ├─ Vlog → 居中生活帧 + 轻钩子
│           ├─ 手持产品 → 手+产品 ≥55%（脸可不出）
│           └─ 亲子 → 合计 ≥55% + 治愈配色
├─ 校验人物占比：不足 55% 且贴了地标/产品？→ 判非法，重选链路
├─ 查账号档案：题材默认 archetype 与 visual_hammer.archetype_bias 冲突？
│  └─ 以账号锤为准（如人设旅行号可 person-led）；strict=true 时禁止偏离
├─ 字级落位：主标题 0.045–0.12 区间内按题材取值；副标题 0.022–0.06
└─ 字数校验：≤12 字（小红书 14 / B站 16）
```
