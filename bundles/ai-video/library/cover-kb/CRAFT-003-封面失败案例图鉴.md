# CRAFT-003 封面失败案例图鉴

> 版本 v1.0 · 2026-09-27 · 适用链路：视频封面设计（cover-designer 岗位）

## 一、核心概念

本篇是事故复盘库，收录封面链路真实事故。每个案例四段式：**症状描述 → 根因 → 检测口径（机检/监制如何拦住）→ 正确做法**。事故的价值不在追责，在于把「出过一次的错」转化为「永远不再过的检」。所有检测口径分两级：机检（规则可自动化拦截）与监制（人工终审看真机缩略图）。机检拦硬口径，监制拦观感与调性，两级都过才可出厂。

## 二、分类速查（事故分类表）

| 事故类别 | 案例编号 | 拦截级别 | 一句话特征 |
|---|---|---|---|
| 职能缺失 | 案例 1 | 监制 | 封面没参与设计，只是截图打字 |
| archetype 混乱 | 案例 2 | 监制 | 人与物两种主视觉打架 |
| 底图违规 | 案例 3/4/7 | 监制（案例 7 另有底图血缘机检） | 拼接、抠像、带字幕水印 |
| 口径不符 | 案例 5 | 机检 | 标题时长与成片不一致 |
| 安全区越界 | 案例 6 | 机检 | 文字进平台 UI 遮挡区 |
| 工艺粗糙 | 案例 8/10 | 监制 + 清晰度机检 | scrim 硬接缝、模糊闭眼帧 |

| 诚信违规 | 案例 11 | 监制+算法 | 钩子骗点击，完播率崩塌 |

## 三、分场景实战（案例图鉴）

### 案例 1 ·「只有一行标题」
- **症状**：封面 = 随手取一帧 + 烧一行字，无副标题、无角标、无构图设计。点击率在账号均值的一半徘徊。
- **根因**：封面职能未参与——把封面当「视频的截图」而非「广告位」，三件套（主标题/副标题/底图设计）只做了一件。
- **检测口径**：监制终审核对三件套清单，缺任一件即打回；机检可拦「主标题存在但副标题与角标均空」的裸奔稿。
- **正确做法**：三件套硬要求——主标题承载钩子，副标题补信息增量（≤24 字），底图按 archetype 重新构图取帧。

### 案例 2 ·「人物小图贴地标」
- **症状**：旅行封面把人物小图贴在地标建筑照片一角，人物与建筑互相抢焦点，真机被打回三次。
- **根因**：两种主视觉（人/物）在同一画面打架，archetype 未二分——到底这条片子卖的是「人」还是「景」没想清楚。
- **检测口径**：监制用 240px 小图测试，说不出「第一眼看人还是看景」即打回。
- **正确做法**：archetype 二分——person-led 则人物 ≥55% 画面高、地标退为虚化背景；subject-led 则地标 ≥35% 占主导、人物不出镜。

### 案例 3 · 横向拼接两个镜头
- **症状**：左右拼接两个镜头画面表现「前后对比」，中间一道贯穿全宽的硬接缝，小图下像两张图拼贴。
- **根因**：违反「底图必须单张连续画面」硬口径；对比诉求错用画面拼接表达。
- **检测口径**：提示词硬约束（禁止拼接）+ 监制在 240px 小图上找"贯穿全宽的纵向亮线"。专项接缝机检（纵向高对比直线扫描）**尚未实现**，登记在模板 A 的"建议增强"里。
- **正确做法**：底图单张连续画面；对比/反差别靠文案表达（「装修前 vs 入住一年后」），或选本身含对比信息的单帧。

### 案例 4 · 定妆照抠像贴图
- **症状**：把人物定妆照抠出贴在视频场景帧上，边缘掉脸、残留光晕，肤色与场景光线两个世界。
- **根因**：违反「人物用片子自己的镜头帧」硬口径；抠像素材与底图光影来源不同，物理上不可能融合自然。
- **检测口径**：工艺上**从源头杜绝**——管线的人物层恒取本片镜头帧、四边柔化软嵌入（不做抠像贴图，就没有毛边与光晕）；监制复核光影一致性。抠像毛边专项机检尚未实现（不抠像即无此类事故）。
- **正确做法**：从本片镜头里选人物峰值帧，软嵌入封面底图（同场景、同光源、羽化过渡）。

### 案例 5 · 标题写「48 秒」成片其实 51 秒
- **症状**：主标题「48 秒学会系领带」，成片实际 51 秒，上线前被打回。
- **根因**：文案先写、剪辑后改，数字口径没回写封面。
- **检测口径**：机检比对标题时长数字与成片元数据，±2s 之外即拦（51-48=3s，超差）。
- **正确做法**：时长类数字以成片元数据为唯一来源反写封面；剪辑定版后才锁定标题数字。

### 案例 6 · 标题落进平台 UI 遮挡区被裁
- **症状**：副标题放在画面最底部，发布后被平台标题栏/进度条盖掉一半。
- **根因**：设计稿按满画布排版，没扣平台 UI 遮挡区。
- **检测口径**：机检套各平台安全区模板，文字像素落入遮挡区即拦。
- **正确做法**：底部遮挡区零文字；竖版标题带控制在顶部 6%–42% 口径内，关键信息全部进安全区。

### 案例 7 · 底图自带字幕/水印
- **症状**：取的镜头帧底部带正片字幕，与封面主标题两行字打架，左右还有平台水印。
- **根因**：用了「已烧字幕的成片帧」而非 clean source；双重文字信息流用户无法扫读。
- **检测口径**：机检做**底图血缘校验**——封面底图帧必须与"未烧字幕的干净母版"同帧一致（哈希 + PSNR 双验），不一致即拦。底图 OCR / 水印模板匹配为**建议增强**（尚未实现）。
- **正确做法**：取帧走 clean-source（未烧字幕的原始素材）；封面文字是画面上唯一文字层。

### 案例 8 · 两层厚压暗带留下硬接缝
- **症状**：为压亮底图叠了两层 60% 黑带，色带交界处一道明显亮线，像贴了块膏药。
- **根因**：单层透明度过高、层数过少、无羽化，违反渐变 scrim 工艺口径。
- **检测口径**：监制看色带边缘有无硬接缝。管线实现已是多层薄带渐变（上带 14 条、下带 28 条，单条 ≤0.40；下带用两端渐隐的三角剖面——2026-09-27 真机反馈"下带底缘可见一条硬边"后修正）；压暗区边缘亮度梯度突变检测为**建议增强**（尚未实现）。
- **正确做法**：多层薄带渐变——2–3 层、单层 20%–35% 透明度、边缘羽化，过渡区 ≥ 标题带高的 1/3。

### 案例 9 · 冷雾滤镜把暖调夜景改成另一种天气
- **症状**：原片是暖黄灯光的夜市烟火气，封面套冷蓝滤镜「显高级」，点进正片色调完全两样，评论区吐槽「照骗」。
- **根因**：封面滤镜凌驾原片光线气质，调性不一致构成软性货不对板。
- **检测口径**：监制对比封面与正片首帧色温/氛围，肉眼可辨差异即打回。
- **正确做法**：底图保持原光线气质，只允许亮度/对比度微调（±15% 内），禁止改色温方向的滤镜。

### 案例 10 · 取帧模糊/闭眼帧
- **症状**：人物帧是运动中间态——脸糊、眼半闭，小图上像「没睡醒」。
- **根因**：随手截帧，未过清晰度与表情筛选。
- **检测口径**：机检**边缘能量阈值**（`background-sharpness` 硬闸：白天 5.5 / 夜景 2.8 / 人物镜 2.6，低于标定值判模糊）+ 取帧候选先过清晰度筛再选表情峰值。人脸关键点闭眼检出为**建议增强**（尚未实现）。
- **正确做法**：清晰度标定先行（边缘能量过筛），再在清晰帧里选表情峰值（睁眼/情绪最高点），见 CRAFT-001 取帧策略。

### 案例 11 · 封面与正片货不对板
- **症状**：封面写「月入十万的副业」，正片是泛泛而谈的鸡汤，点击率高但 5 秒跳出率 80%，完播率崩塌，算法降权。
- **根因**：钩子骗点击——封面承诺正片不兑现，违反「勾而不骗」原则。
- **检测口径**：监制核对封面承诺与正片前 3 秒内容；算法侧完播率/跳出率异常是后置信号，出事后流量已损。
- **正确做法**：封面承诺必须在视频前 3 秒兑现——前 3 秒口播/画面直接回应钩子；兑现不了就换钩子，不换内容。

### 案例 12 · 系列封面各自为政
- **症状**：同一系列 12 条视频，12 种字体 7 种配色，主页点进去像杂货铺，粉丝认不出是自己关注的号。
- **根因**：每条封面单独「发挥」，无视觉锤一致性约束。
- **检测口径**：监制看主页九宫格截图，相邻封面找不出 ≥2 个一致元素（字体/色板/版式/角标）即打回。
- **正确做法**：系列定视觉锤四件套（固定版式/字体/色板/角标位），单条允许微调不允许换体系，见 ACCT-001/002。

## 四、参数速查（核心调用区）

| 检测项 | 口径 | 级别 | 关联案例 |
|---|---|---|---|

## 五、常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 「机检过了就能发」 | 调性类事故（9/11/12）全漏 | 机检+监制两级都过才出厂 |
| 「拼接对比更直观」 | 硬接缝废稿（案例 3） | 单张连续画面，对比靠文案 |
| 「定妆照更清晰」 | 抠像光晕废稿（案例 4） | 本片帧软嵌入 |
| 「滤镜统一点好看」 | 改天气照骗（案例 9） | 只调亮度对比，不动色温方向 |
| 「先定标题再剪片」 | 时长口径对不上（案例 5） | 剪辑定版后反写数字 |
| 「每条封面重新设计有新鲜感」 | 主页杂货铺（案例 12） | 视觉锤四件套锁死 |

## 六、意图→设计映射表（核心调用区）

（事故信号 → 检测与修复动作 → 判据）

| 事故信号 | 检测与修复动作 | 判据 |
|---|---|---|
| 只有主标题一行字 | 监制查三件套清单 | 主/副/底图三件齐全 |
| 人与物同屏抢焦点 | 240px 小图问「第一眼看什么」 | 唯一答案，archetype 二分 |
| 底图有纵向亮线 | 监制在 240px 小图上看（专项机检未实现） | 零命中 |
| 人物边缘有光晕 | 不抠像（恒用本片帧软嵌入）+ 监制看光影 | 无毛边，光源方向一致 |
| 标题含时长数字 | 比对成片元数据 | 差值 ≤2s |
| 文字贴画面底部 | 套平台安全区模板 | 遮挡区零文字像素 |
| 底图有两层文字 | 底图血缘校验（与干净母版同帧）+ 监制复核 | 仅封面设计文字一层 |
| 压暗带边缘一条亮线 | 监制看边缘（梯度检测未实现） | 无梯度突变，多层薄带 |
| 封面与正片色调两样 | 对比正片首帧色温 | 色温方向一致 |
| 人物帧模糊/闭眼 | 机检边缘能量（闭眼交给监制） | 过阈值且睁眼 |
| 高点击高跳出 | 核对承诺与前 3 秒内容 | 前 3 秒直接兑现钩子 |
| 主页缩略图风格杂乱 | 看九宫格截图 | 相邻 ≥2 个一致元素 |

## 七、设计模板

**模板 A · 出厂前机检清单（自动化，与链路实现一一对应）**
```
□ 产物规格正确：画幅 = 平台规格（cover-platforms.ts）、字节数 > 120KB
□ 标题真的画上去了：标题带 vs"无字版"PSNR 显著下降（案例 1）
□ 人物层真的合成进去了：人物框 vs"无人物版"PSNR 显著下降（案例 4 相关，物体版式跳过该项）
□ 底图血缘：取自未烧字幕的干净母版（案例 7）
□ 安全区：标题带落位达标（按平台）+ 底部遮挡区墨迹 ≤2%（案例 6）
□ 时长数字与成片 ±2s（案例 5）
□ 底图边缘能量过阈值：白天 5.5 / 夜景 2.8 / 人物镜 2.6（案例 10）
```
七项全绿 → 进监制终审；任一红 → 自动打回并附案例编号。

**建议增强（尚未实现的机检项，进提案池；实现前一律由监制人工拦）**
```
□ 拼接接缝检测（纵向高对比直线扫描，案例 3）
□ 底图 OCR / 水印模板匹配（案例 7）
□ 人脸关键点闭眼检测（案例 10）
□ scrim 边缘亮度梯度突变检测（案例 8）
```

**模板 B · 监制终审五问（人工）**
1. 三件套齐吗？（案例 1）
2. 240px 小图第一眼看什么？答案唯一吗？（案例 2）
3. 封面气质和正片首帧是同一个世界吗？（案例 9/11）
4. 主页九宫格里它和老封面是一家人吗？（案例 12）
5. 封面承诺，正片前 3 秒兑现吗？（案例 11）
五问全过 → 出厂。

**模板 C · 事故复盘记录格式**
```
事故编号 / 平台 / 症状截图 / 根因归类（本篇章节）
检测缺口：机检 why 漏 / 监制 why 漏
新增检测口径（写入第四章表格）
```

## 八、决策树

```
出厂流程：
├─ 机检五项（模板 A）
│   ├─ 任一红 → 按案例编号修复 → 重跑机检
│   └─ 全绿 → 进监制
├─ 监制五问（模板 B）
│   ├─ 任一不过 → 打回标注案例编号
│   └─ 全过 → 出厂
└─ 上线后 48h 数据回看：
    ├─ 完播率/跳出率异常 → 排查案例 11 类软性事故
    └─ 新事故 → 按模板 C 记录，评审后补入本篇
```
