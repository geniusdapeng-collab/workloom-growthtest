# PLAT-001 抖音封面规范

> 版本 v1.0 · 2026-09-27 · 适用链路：视频封面设计（cover-designer 岗位）

## 一、核心概念

抖音是全屏沉浸式单列信息流：用户上下滑动切换视频，「3 秒划走」是第一定律——系统考核的是前 3 秒留存，封面（首帧）承担的是「让用户停下手指」的职责。推荐流中封面即首帧（创作者上传封面会替换系统截取的首帧）；在关注流、搜索结果页、个人主页，封面则以缩略图形态直接参与点进决策。因此抖音封面的本质不是「美观」，而是「停驻钩子」：用户扫过的 0.5 秒内，必须能 get 到「这条视频跟我有关 / 对我有用 / 让我好奇」三者之一。设计准则由此推导：字要大、钩子要狠、信息要前置——任何需要「想一想」才能理解的设计都会被划走。

## 二、分类速查

| 类型 | 特征 | 适用账号 | CTR 表现 |
|---|---|---|---|
| 大字报式 | 超大标题占标题带 60% 以上，纯色/撞色底，弱化画面 | 口播、知识、资讯 | 高（信息类首选） |
| 人物表情式 | 人脸特写 + 情绪夸张（惊讶/愤怒/大笑），配短标题 | 剧情、带货、测评 | 高（情绪驱动） |
| 场景悬念式 | 高潮帧画面 + 疑问句标题，字级中等 | 剧情、影视剪辑 | 中高 |
| 对比反差式 | 左右/上下分屏（before-after、预期-现实） | 美妆、改造、测评、健身 | 高 |
| 清单标签式 | 数字清单（「3 个方法」）+ 标签贴纸元素 | 教程、干货、合集 | 中 |
| 纯画面式 | 无标题，靠画面本身冲击（高颜值/奇观/萌宠） | 颜值、旅行、宠物 | 不稳定，赌内容质量 |

## 三、分场景实战

**场景 1：口播知识类（露脸讲干货）**
做法：人脸放下 1/3 至 1/2 建立信任，标题放 6%–30% 标题带上段，两行大字（主标 ≤12 字 + 副标补充），关键词用撞色高亮；30%–42% 区间放副标或留空，避免压脸。为什么：知识类用户为「获得感」点进，脸 = 信任背书，大字 = 价值承诺，两者分区不重叠才能同时生效。

**场景 2：剧情/段子类（有反转）**
做法：截取情绪最高点帧（瞪眼、对峙、摔东西），标题用疑问/冲突句式且不剧透结局，如「她最后那句话，全场安静了」。为什么：悬念缺口（curiosity gap）驱动点进，冲突帧 + 冲突文案是双重钩子，3 秒内制造「必须看完」感；剧透则完播率直接腰斩。

**场景 3：测评/带货类**
做法：产品主体居中放大（占画面 40%+），人脸侧置，标题数据化（「9.9 元」「月销 10w+」），配色走暖色高饱和。为什么：带货决策链是「产品吸引 → 价格锚点 → 信任下单」，数据冲击是最短路径；暖色（红/橙）刺激购买冲动，这是电商设计的共识结论。

**场景 4：教程类（做菜、手工、软件操作）**
做法：用成品/结果帧当封面（不是过程帧），标题结果前置（「3 分钟学会」「一次成功」），角落加步骤数标签（如「仅 4 步」）。为什么：用户为结果点进，过程帧没有吸引力；结果前置 + 低门槛数字（步骤少）能同时降低决策成本。

**场景 5：vlog/日常类**
做法：当天最戏剧性的一帧 + 口语化短标题，字级可略降（建议主标不低于画面宽 1/8）。为什么：vlog 靠人设留存，封面只负责「今天发生了什么」的轻悬念，过度包装反而与老粉预期违和。

## 四、平台参数速查（核心调用区）

| 参数 | 口径 |
|---|---|
| 画幅 | 9:16 竖屏 |
| 画布尺寸 | 1080×1920 px |
| 顶部安全区 | 画面上方 6%（约 115px），禁放关键元素 |
| 底部遮挡区 | 画面下方 12%（约 230px），被平台 UI（标题栏/进度条）遮挡，禁放关键元素 |
| 右侧栏 | 右侧约 11% 宽（约 120px）为操作栏（赞/评/转/头像），关键元素左移避让 |
| 标题带 | 画面上部 6%–42%（约 115px–810px）为标题安全放置区 |
| 标题字数上限 | 主标题 ≤12 视觉字，≤2 行 |
| 文案调性 | 大字强钩子、节奏快信息密 |
| 钩子风格 | 疑问式 / 冲突式 / 数据冲击式 / 反差式 |
| 特殊机制 | 推荐流「首帧即封面」场景多；关注流/搜索/主页以封面缩略图呈现 |

## 五、常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 标题写满 3 行以上 | 信息流里看不清，0.5 秒被划走 | 主标 ≤12 字、≤2 行，一眼读完 |
| 标题压在人脸上 | 人脸与文字互相干扰，两个钩子都失效 | 脸放下 1/3，字放 6%–42% 标题带，分区不重叠 |
| 关键信息放底部 12% 或右侧 11% | 被平台 UI 遮挡，等于白做 | 顶 6% / 底 12% / 右 11% 三区禁放关键元素 |
| 字级过小（主标 < 画面宽 1/10） | 搜索/主页缩略图状态不可辨 | 建议主标字级 ≥ 画面宽 1/6（约 180px 字高，建议值） |
| 封面剧透结局 | 悬念消失，完播率下跌 | 封面只制造缺口，答案给一半 |
| 全篇文字没有视觉主体 | 像传单，信任感低、被判营销号 | 至少一个视觉主体（人脸/产品/场景），文字服务主体 |
| 每条封面风格乱跳 | 主页九宫格无辨识度，关注转化低 | 固定字色/字位/字体，系列化（见 ACCT-002） |
| 为抓眼用廉价素材拼贴 | 被判低质营销，限流风险 | 主体清晰、构图干净，强钩子靠文案不靠脏乱 |

## 六、意图→设计映射表（核心调用区）

| 用户意图/题材 | 设计动作（版式/构图/字级/配色/钩子） | 判据 |
|---|---|---|
| 获取干货（教程/知识） | 版式：上字下人；构图：人脸下 1/3，标题放 6%–30%；字级：主标约为画面宽 1/6–1/5（建议）；配色：深蓝/深灰底 + 亮黄关键词高亮；钩子：结果前置式「3 分钟学会 XX」 | 缩略图状态（约 1/4 屏宽）能读出核心价值承诺 |
| 看热闹（剧情/冲突） | 版式：满版画面 + 顶部双行字；构图：情绪帧居中；字级：主标约 1/6 宽（建议）；配色：黑底白字 + 红色冲突词；钩子：疑问/冲突式「他居然当场翻脸」 | 标题读完产生「必须看下去」的缺口感，且未剧透 |
| 占便宜（促销/带货） | 版式：产品居中 + 大字压顶；构图：产品占 40%+；字级：价格词最大（约 1/4 宽，建议）；配色：红橙暖色高饱和；钩子：数据冲击式「9.9 元抢完即止」 | 价格/折扣信息 0.5 秒内可识别 |
| 求共鸣（情感/扎心） | 版式：暗调画面 + 居中短句；构图：人物侧影或特写；字级：主标约 1/7 宽、单行（建议）；配色：低饱和灰蓝 + 白字；钩子：扎心疑问式「你是不是也这样」 | 目标人群第一反应是「说的是我」 |
| 看反差（改造/变装/减肥） | 版式：左右或上下分屏对比；构图：before 左/上、after 右/下；字级：主标约 1/7 宽置顶（建议）；配色：对比侧一冷一暖；钩子：反差式「同一个人，差 30 斤」 | 不看文案也能一眼看出「变了」 |
| 追热点（资讯/时事） | 版式：大字报式满幅标题；构图：弱化画面，标题占标题带 60%+；字级：主标约 1/5 宽（建议）；配色：红黑/蓝白新闻感撞色；钩子：数据冲击式「刚刚，XX 官宣」 | 12 字内说清「事件 + 看点」 |
| 找答案（搜索场景） | 版式：问题当标题 + 答案预告；构图：人脸与问题对象同框；字级：主标约 1/6 宽（建议）；配色：浅底深字（搜索结果页为浅色列表，深底封面会被视觉跳过）；钩子：疑问式「XX 到底怎么选」 | 标题与目标搜索词字面重合度 ≥70% |
| 消磨时间（搞笑/宠物/萌娃） | 版式：画面为主 + 角标短字；构图：高潮瞬间帧；字级：主标约 1/8 宽置标题带上段（建议）；配色：明黄/亮粉活泼色；钩子：反差式「没想到结局是这样」 | 不看字也想点，字只负责再加一层悬念 |
| 信任决策（医疗/财经/法律） | 版式：正装半身人像 + 双行字；构图：人物居中下 1/2；字级：主标约 1/6 宽（建议）；配色：藏蓝/墨绿沉稳色 + 金/白点缀；钩子：价值预览式「律师教你三句话」 | 整体观感「专业可信」，禁用夸张表情包元素 |
| 种草好物（开箱/测评） | 版式：产品特写 + 顶部长句；构图：产品占画面中心 50%；字级：主标约 1/6 宽（建议）；配色：产品色系取互补色做字色；钩子：反差/数据式「百元内没对手」 | 产品辨识度优先，遮挡产品的元素一律移除 |

## 七、设计模板

**模板 A：大字报知识款（口播/知识号首选）**
- 布局：纯色或微渐变底；标题带 6%–30% 放主标（≤2 行），30%–42% 放副标或留空；下 1/3 放人物半身抠图（去背）。
- 字体：思源黑体 Heavy / 站酷高端黑（建议）；主标字高约 180–220px（建议）。
- 配色：底 #1B2A4A（藏蓝），主标 #FFFFFF，关键词 #FFD700（亮金），副标 #A8B8D0。
- 标题示例：「工资不高的女生，一定要做这 3 件事」——主标「一定要做这 3 件事」，其中「3 件事」用金色高亮。

**模板 B：剧情悬念款（剧情/段子/影视剪辑）**
- 布局：满版剧情帧（情绪最高点），顶部 6%–25% 放两行白字黑描边标题；右侧 11%、底部 12% 留空避让 UI。
- 字体：思源黑体 Bold + 4–6px 黑色描边（建议），保证复杂画面上可读。
- 配色：字 #FFFFFF，描边 #000000，冲突词 #FF3B30。
- 标题示例：「婚礼当天，婆婆拿出了那份协议」。

**模板 C：带货冲击款（直播切片/短视频挂车）**
- 布局：产品图居中放大（40%+），标题带 6%–28% 放价格锚点大字，28%–40% 放一句话卖点；底部 12% 禁放。
- 字体：阿里妈妈数黑体 / 思源黑体 Heavy（建议）。
- 配色：底 #FFF3E0（暖米），价格 #E60012，卖点 #333333，点缀 #FF8F00。
- 标题示例：主标「9.9 元 3 支」+ 副标「超市一支的钱买三支」。

## 八、决策树

```
题材是什么？
├─ 知识/教程/资讯 ── 真人出镜吗？
│   ├─ 是 → 模板 A（上字下人）＋ 结果前置钩子
│   └─ 否 → 大字报式满幅标题 ＋ 数据冲击钩子
├─ 剧情/段子/情感 ── 有反转吗？
│   ├─ 有 → 模板 B（情绪帧 + 悬念句），禁止剧透
│   └─ 无 → 扎心短句 + 暗调特写（共鸣钩子）
├─ 带货/测评 ── 核心卖点是价格吗？
│   ├─ 是 → 模板 C（价格词最大字级）
│   └─ 否（卖点是功能/效果）→ 对比式分屏 + 效果帧
├─ 改造/变装/减肥 → 分屏对比式，before/after 分冷暖
└─ vlog/日常/宠物 → 高潮帧 + 角标短字，字级可降至 1/8 宽（建议）
发布前再校验：
① 主标 ≤12 字、≤2 行？
② 顶 6% / 底 12% / 右 11% 三区无关键元素？
③ 缩略图状态（约 1/4 屏宽）一眼可读？
④ 与主页已有封面风格一致？
```
