# CRAFT-001 封面构图与视觉层次

> 版本 v1.0 · 2026-09-27 · 适用链路：视频封面设计（cover-designer 岗位）

## 一、核心概念

封面构图的本质是「在小图状态下管理用户视线的落点顺序」。信息流里封面只占 1/4–1/2 屏宽，用户以缩略图状态扫过，构图的成败不在设计软件里的大画布，而在手机实机的小图上。视觉层次三问：第一眼看到什么（主体）、第二眼看到什么（标题）、有没有第三眼的信息（副标题/角标）。层次错乱的典型症状是「三件套同时在喊」，用户 0.3 秒内抓不到重点，直接滑走。

构图的链路硬约束：版式只有 person-led / subject-led 两种；底图必须单张连续画面，禁止拼接；人物必须用片子自己的镜头帧软嵌入，禁止抠像贴图；竖屏标题带默认占画面高 6%–42%（**平台不同：小红书 7%–45%、B站 6%–55%**，机检口径以 `packages/video-studio/src/cover-platforms.ts` 为准），底部遮挡区不放字。

## 二、分类速查

| 维度 | 可选方案 | 适用判据 |
|---|---|---|
| 浏览动线 | Z 型 / F 型 | 横版 Z 型、竖版 F 型 |
| archetype | person-led / subject-led | 有无可信人物出镜 |
| 构图法则 | 三分法 / 居中对称 / 对角线 | 三分法为默认，居中仅对称题材 |
| 字图关系 | 压留白 / scrim 压暗带 | 底图亮度与纹理复杂度 |
| 取帧 | 信息量峰值帧 | 表情/动作/光线峰值 |
| 画幅 | 竖版 9:16·3:4 / 横版 16:9 | 平台决定，见 PLAT 篇 |

## 三、分场景实战

### 视觉动线
- **Z 型（横版 16:9，B站/YouTube）**：视线从左上 → 右上 → 左下 → 右下。标题放左侧纵列，主体偏右，视线终点落在主体表情上。
- **F 型（竖版 9:16/3:4，抖音/小红书）**：视线先横扫顶部，再沿左侧纵向扫。主标题在顶部 6%–30% 区，主体在中下部。
- **3 米外可辨原则**：把封面缩到手机屏 1/4 宽看，3 米等效距离下必须能认出「是什么主体 + 标题讲了什么类别」，细节字（副标题）允许不可辨。
- **小图可辨性自检**：导出 240px 宽的预览图检查，主标题每字笔画仍清晰、主体轮廓不糊成一团即过。

### 字图关系
- **标题压留白区**：底图本身有大面积低纹理区（天空、墙面、桌面）时首选，文字直接压上，不加任何底板。
- **scrim 压暗带**：底图纹理复杂或亮度高时使用；用「渐变」而非单层厚色块——设计口径是 2–3 段渐变（20%–35% 透明度），链路实现把它铺成多条薄带近似（上带 14 条、下带 28 条，单条 ≤0.40），两端渐隐、杜绝硬接缝。**只写"渐变"意图，不要指定实现层数**。
- **不压人脸/不压主体**：主标题任何一字不得遮挡人物面部与核心主体轮廓；人物视线方向朝向标题所在区（视线引导），人物看左标题放左、看右放右。
- **底部遮挡区**：平台 UI（进度条/互动按钮/标题栏）覆盖区，任何文字与关键主体部位不进该区，机检安全区口径见各 PLAT 篇。

### 构图法则与主体占比
- **三分法**：默认法则。主体落交叉点，标题沿对侧三分线排布。
- **主体占比硬指标**：subject-led 主体占画面高 ≥35%；person-led 人物占画面高 ≥55%（半身或胸上特写）。占比不足 = 小图主体失踪。
- **居中对称**：仅适用于本身对称的题材（建筑正面、圆桌美食俯拍、产品正装照），配 value-preview 类中性钩子；强钩题材不用居中，张力不足。

### 取帧策略
- **信息量峰值帧**：选帧优先级 = 表情最强 > 动作最高点 > 光线最好。三者冲突时保表情（person-led）或保光线（subject-led）。
- **兜底逻辑**：候选帧先过清晰度筛（边缘能量阈值，剔除运动模糊/失焦帧），再过表情筛（剔除闭眼/半张嘴的过渡帧），最后在剩余帧里选光线最干净的。
- **红线**：人物帧必须来自本片镜头，软嵌入封面底图（同场景光影融合）；禁止定妆照/他片素材抠像贴图（掉脸、光晕、调性割裂，见 CRAFT-003 案例 4）。

### 横版构图（B站/YouTube）
- 主体偏右、标题靠左为默认（适配 Z 型动线与平台 UI 右下角的时长标）；也可镜像反转，但必须整系列统一方向。
- 纵向空间宽裕 → 字级可比竖版大 20%–30%，YouTube 封面字高建议 ≥10% 画面高。
- 注意右下角默认被时长标遮挡，关键信息避开右下 1/8 区。

### 主页网格裁切
- **IG 中心 1:1**：封面中心正方形区必须独立成立（主体与核心标题都在中心 1:1 内），主页网格只显示这一块。
- **抖音主页三列**：封面按 3 列网格缩略显示，主标题缩到网格态仍可读是硬判据；系列三连封面可跨格排版，见 ACCT-002。

## 五、常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 大画布好看就定稿 | 小图缩略后字糊主体失踪 | 240px 预览为定稿判据 |
| 标题压在人脸上 | 表情被切，点击率腰斩 | 人脸留白，标题让位 |
| 单层厚黑带压底 | 硬接缝显眼，像贴了块膏药 | 2–3 层薄带渐变羽化 |
| 人物视线朝向屏幕外 | 视线把用户引离标题 | 翻转底图或换帧，视线指向标题 |
| 居中构图配强钩 | 画面死板，撑不起冲突感 | 强钩用三分法，居中留给对称题材 |
| 横版标题塞右下角 | 被时长标盖掉 | 右下 1/8 区为禁放区 |
| 取帧随手一截 | 闭眼/模糊帧出厂 | 边缘能量过筛后再选表情峰值 |

## 六、意图→设计映射表（核心调用区）

| 场景/意图 | 构图动作 | 判据 |
|---|---|---|
| 人物出镜口播 | person-led，胸上特写，视线朝标题 | 人物 ≥55% 高，标题不压脸 |
| 产品/场景为主 | subject-led，主体落三分点 | 主体 ≥35% 高 |
| 底图纹理复杂 | scrim 多层薄带渐变 | 2–3 层、单层 ≤35%、无硬接缝 |
| 底图有大留白 | 标题直压留白，不加底板 | 压字区纹理均匀低对比 |
| 情绪向强钩 | 三分法 + 表情峰值帧 | 表情为第一优先级 |
| 对称题材（建筑/俯拍餐） | 居中对称 + 中性钩子 | 题材本身对称才启用 |
| B站/YouTube 横版 | 主体偏右标题靠左 | 系列内方向统一，右下无关键信息 |
| IG Reels | 中心 1:1 自成立 | 裁切后主体+主标题完整 |
| 抖音主页三列 | 主标题大字，网格态可读 | 三列缩略下主标题可辨 |
| 取帧模糊时 | 边缘能量筛 → 表情筛 → 光线筛 | 过清晰度阈值再谈美感 |
| 竖版两行标题 | 第一行顶部 6%–30%，第二行 ≤42% | 底部遮挡区零文字 |

## 七、设计模板

**模板 A · 竖版 person-led 三分法（抖音/快手）**
- 人物胸上特写占画面高 60%，脸落右下三分点，视线朝左上。
- 主标题一行压顶部 6%–25% 区，左对齐；副标题在其下。
- 底图为原镜头帧；若背景杂乱，顶部加 2 层 25% 黑渐变带。

**模板 B · 竖版 subject-led 俯拍（小红书美食/好物）**
- 主体俯拍居中偏上，占画面高 40%，桌面纹理作天然留白。
- 主标题压底部上方 1/3 处（避开底部遮挡区），花字版式可选。
- 副标题 ≤24 字补清单信息，角标 ≤10 字放系列名。

**模板 C · 横版 Z 型（B站/YouTube）**
- 主体偏右占宽 45%，表情峰值帧；标题靠左纵列，字高 ≥10%。
- 右下角留空给时长标；系列封面统一此方向形成主页识别。

## 八、决策树

```
开始：有无真人出镜？
├─ 有 → person-led
│   ├─ 人物 ≥55% 高？否 → 换更近的镜头帧/裁切
│   ├─ 视线朝向标题？否 → 水平翻转或换帧
│   └─ 表情是否峰值？否 → 清晰度筛后换帧
└─ 无 → subject-led
    ├─ 主体 ≥35% 高？否 → 推近构图
    └─ 题材本身对称？是 → 居中对称；否 → 三分法
统一检查：
├─ 底图单张连续画面？拼接 → 重做
├─ 底部遮挡区无字？有 → 上移
├─ scrim 无硬接缝？有 → 多层薄带
└─ 240px 小图可辨？否 → 加字级/减信息
```
