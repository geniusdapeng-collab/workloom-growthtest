# ACCT-002 系列化与主页拼图
> 版本 v1.0 · 2026-09-27 · 适用链路：视频封面设计（cover-designer 岗位）

## 一、核心概念

封面不是单张图，是"主页网格里的一个格子"。用户路径是：信息流刷到单条 → 感兴趣点进主页 → 扫一眼前 6–9 格 → 决定关注/继续看/离开。因此：

1. **系列封面纪律**：同系列 = 同模板 + 同字体 + 同色板，只换主视觉（底图）与标题文案。系列识别交给角标（badge_series ≤10 字）承担，不靠版式差异。
2. **主页即店面**：网格的整体观感本身是转化工具。色彩有节奏、系列有分组、置顶有门面的主页，关注转化率显著高于随机排布。
3. **单图成立 + 拼图加分**：任何封面必须在信息流里单独成立（用户 90% 场景只见单图）；三连拼图是进阶玩法，绝不能牺牲单图可读性。

## 二、分类速查

| 主页形态 | 特征 | 设计重点 |
|---|---|---|
| 单条独立型 | 每条题材不同，无连载 | 靠视觉锤四件套统一；色彩轮换避免连排同色 |
| 系列连载型 | 固定栏目，期数递增 | 系列模板锁死，角标带期号，主页形成"色块分组" |
| 栏目矩阵型 | 账号 2–4 个栏目并行 | 每栏目一套子模板（同字体、不同 accent），主页呈栏目色带 |

## 三、分场景实战

### 场景 A：抖音/快手——三列网格
- 网格一行 3 张，竖版 9:16 封面按发布顺序从左上排起。
- **三连玩法一：一条片切成三张**（长图切片式）
  - 适用电影解说、风光大片：一张 3:1 横幅素材切成三张 9:16。
  - 接缝纪律：① 关键元素（人脸、主体产品、标题文字）禁止跨缝，必须完整落在单张内；② 允许色块、线条、天空/地面等连续背景跨缝；③ 三张各自配独立可读的标题或期号（上/中/下），保证单图在信息流单独成立。
- **三连玩法二：三条片讲一个故事**（系列三连）
  - 三条同系列视频连续发布，同模板同构图，仅底图动作/期号不同。
  - 三张标题递进（起因/经过/结果），角标统一系列名。
- 发布顺序 = 网格从左到右，注意三连的"第一张"须在最左。

### 场景 B：小红书——双列网格
- 一行 2 张，3:4 与 1:1 混排；同账号建议固定一种为主（推荐 3:4 为主、1:1 点缀）。
- **置顶三条 = 门面管理**：① 账号介绍条（我是谁+提供什么价值）；② 数据最好的代表作；③ 最新系列的第一期。三条置顶封面色彩不得互相撞色（相邻明度/色相错开）。
- 双列相邻两张避免同色块连排；系列更新一次发 2 条（占满一行）观感最佳。

### 场景 C：Instagram——中心 1:1 裁切
- 主页网格按 1:1 中心裁切显示。核心信息（人脸/主体/标题）必须收进中央 1:1 安全区，四边允许被裁。
- 横竖版原图均可发，但中央 1:1 必须独立成立：上传前用 1:1 遮罩自查一次。

### 场景 D：YouTube——频道页横版节奏
- 频道页/播放列表按横版 16:9 缩略图成行排列。
- **颜色交替**：相邻两条缩略图主色调错开（蓝→橙→蓝），避免整行同色糊成一片。
- **系列分组**：同系列同角标+同色系，在播放列表内形成视觉分组；播放列表封面单独设计（系列代表帧+系列名）。

### 场景 E：主页色彩规划
- **色板轮换法**：账号 2–3 套子色板（对应不同栏目/题材）按行轮换，形成"一行暖一行冷"的节奏。
- **禁同色块连排**：九宫格内同一 accent 连续出现 ≤3 次；超过则插入一张中性色（黑/白/灰底）封面打断。
- 每发 6 条截一次主页九宫格自查。

## 四、参数速查（核心调用区）

| 字段 | 类型 | 说明 | 校验 |
|---|---|---|---|
| series_id | string | 系列唯一标识 | 同 series_id 强制同模板同字体同色板 |
| episode_no | int | 期号 | 写入角标（如「第N期」），角标总长 ≤10 字 |
| badge_series | string | 系列角标文案 | ≤10 字，同系列零改动 |
| grid_ratio | enum | 9:16（抖快）/ 3:4 或 1:1（小红书）/ 1:1-safe（IG）/ 16:9（YouTube） | 按平台出图 |
| seam_group_id | string | 三连切图组标识 | 同组三张：标题不跨缝、关键元素不跨缝 |
| pinned_ids | list | 置顶位封面清单（≤3） | 三条互不同色 |
| color_rotation | list | 账号轮换色板队列 | 九宫格同 accent 连排 ≤3 |
| single_view_pass | bool | 单图成立自检 | false 判非法（拼图不得牺牲单图） |

## 五、常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 三连封面把人脸/标题跨缝切 | 信息流里单张残疾，CTR 暴跌 | 关键元素完整落单张，只让背景跨缝 |
| 系列每期换模板求新鲜 | 系列识别崩坏，追更率下降 | 只换底图与标题，模板零改动 |
| 主页九张同色块连排 | 网格糊成一片，无重点 | 色板轮换，同 accent 连排 ≤3 次 |
| 置顶位长期不更新 | 门面过时，新访客流失 | 每月审查置顶三条：介绍/代表作/新系列 |
| IG 原图直接发不看中央裁切 | 主页里标题被切一半 | 核心信息收进中央 1:1 安全区 |
| 小红书 3:4 与 1:1 随机混排 | 网格高低错位杂乱 | 固定 3:4 为主，1:1 仅点缀 |
| 为拼图牺牲单图可读性 | 90% 信息流场景失效 | single_view_pass=true 才允许做三连 |
| 系列角标越写越长 | 角标压标题、字小到不可读 | badge_series ≤10 字，超出砍栏目名 |

## 六、意图→设计映射表（核心调用区）

| 意图/系列场景 | 设计动作 | 判据 |
|---|---|---|
| 抖音电影解说三连 | seam_group_id 建组；3:1 素材切三张 9:16；「上/中/下」置于各自标题带 scrim 区 | 三张单图各自标题完整可读；无跨缝人脸 |
| 抖音系列连载（如职场36计） | 同模板同字体；角标「职场36计·N」；底图换当期案例帧 | 主页相邻三期呈同色系分组 |
| 快手老铁连续剧 | 三条连续发布；同构图（人物对峙位）；标题递进（悬念→冲突→结局） | 三张标题连读成一句话 |
| 小红书新系列首发 | 一次发 2 条占满双列一行；两张色板一冷一暖错开 | 行内不撞色；3:4 优先 |
| 小红书置顶门面 | 置顶=介绍条+代表作+新系列首期；三色错开 | 相邻明度差 ≥20% |
| IG 日常更新 | 核心元素收中央 1:1；上传前 1:1 遮罩自查 | 中央裁切后标题零缺失 |
| YouTube 教程系列 | 播放列表内同角标同色系；列表间颜色交替（蓝→橙） | 频道页一行内相邻不同主色 |
| YouTube 混合内容频道 | 栏目 A 用 accent #FF3B30、栏目 B 用 #FFD60A；按行轮换 | 九宫格同 accent 连排 ≤3 |
| B站合集连载 | 合集封面单独设计（系列代表帧+系列名 ≤16 字）；单期带合集角标 | 合集页内风格统一 |
| 本地探店周更栏目 | 每周固定发布日；角标「每周N店」；暖色板统一 | 连续 4 期主页呈色带分组 |
| 大促/节点特辑（系列外） | 四件套不变，仅 accent 临时换节点色（如春节红 #E60012） | 节点结束立即换回，不超 7 天 |

## 七、设计模板

### 模板 1：系列连载标准模板（抖快）
- 版式：沿用账号 archetype_bias；角标位固定左上「系列名·第N期」（≤10 字）
- 主标题：当期差异化信息 ≤12 字，置标题带 scrim 区
- 色彩：系列专属 accent，期与期零改动
- 发布：连载期内固定时段，保持网格连续分组

### 模板 2：三连封面切图模板
- 素材：3:1 高清横幅（或三张同场景连续帧）
- 切分：三张 9:16；面部/标题/主体各自完整落单张
- 标题：三张底部分别「上集钩子/中集钩子/下集钩子」，各 ≤8 字
- 自查：single_view_pass=true（遮住另外两张，每张独立成立）

### 模板 3：小红书门面置顶模板
- 置顶① 介绍条：个人形象或主体满幅 +「我是谁｜你能得到什么」≤14 字
- 置顶② 代表作：历史 CTR 最高封面的复刻版（同模板换最新帧）
- 置顶③ 新系列首期：系列模板+角标「新系列」
- 色彩纪律：三条 accent 互不相同，并与下方网格首行错开

## 八、决策树

```
收到设计需求
├─ 属于某个系列？（series_id 存在）
│  ├─ 是 → 强制继承系列模板/字体/色板，只换底图+标题+期号
│  │        └─ 角标与往期完全一致？否 → 打回
│  └─ 否 → 走账号视觉锤四件套（ACCT-001）
├─ 是否三连/拼图需求？
│  ├─ 是 → 建 seam_group_id
│  │        ├─ 三张各自单图成立？否 → 重切或放弃三连
│  │        └─ 关键元素跨缝？是 → 调整切线
│  └─ 否 → 单图流程
├─ 平台网格适配
│  ├─ 抖快 9:16 → 检查与上两条的网格色彩关系
│  ├─ 小红书 3:4 → 双列相邻不撞色；系列首发一次配 2 条
│  ├─ IG → 中央 1:1 遮罩自查
│  └─ YouTube 16:9 → 与频道页相邻条颜色交替
├─ 主页色彩自查
│  └─ 预览九宫格：同 accent 连排 >3？是 → 换色板队列下一条
└─ 归档：写入 series_id / episode_no / color_rotation 记录
```
