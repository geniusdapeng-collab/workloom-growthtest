# HOOK-001 封面钩子公式库

> 版本 v1.0 · 2026-09-27 · 适用链路：视频封面设计（cover-designer 岗位）

## 一、核心概念

钩子是封面上「逼用户停下滑动」的那句话。信息流里用户给一张封面的注意力约 0.3 秒，钩子的唯一使命是制造「不点开就亏了」的心理缺口。钩子不是文案修辞，是一套可复用的结构公式：同一公式换变量即可批量产出，且每个公式都有明确的适配平台与强度边界。

钩子与链路硬口径的关系：钩子的字数必须服从主标题 ≤12 视觉字（小红书 ≤14、B站 ≤16、英文平台 ≤5 词）、最多 2 行的总约束——钩子再强，超字数即废稿。钩子强度分三级（强/中/弱），强度选择由账号阶段与平台政策共同决定，不是越强越好。

## 二、分类速查

| 公式 ID | 名称 | 心理机制 | 强度 | 一句话特征 |
|---|---|---|---|---|
| question | 疑问式 | 求知缺口 | 中 | 把用户心里的问题喊出来 |
| conflict | 冲突式 | 站队冲动 | 强 | 立场对立，招评论 |
| data-shock | 数据冲击式 | 数字锚点 | 强 | 用反直觉数字砸停滑动 |
| contrast | 反差式 | 对比认知 | 强 | A vs B，落差即张力 |
| value-preview | 价值预览式 | 获得预期 | 中 | 明牌告诉你能拿走什么 |
| curiosity-gap | 悬念缺口式 | 完形冲动 | 强 | 说一半藏一半 |
| pattern-interrupt | 模式打断式 | 预期违背 | 强 | 反常识断言，否定开场 |

## 三、分场景实战

### 1. question 疑问式
- **公式结构**：疑问词 + 具体对象 +（可选）限定条件。
- **文案模板**：
  - 「为什么你的视频没人看？」（11 字）
  - 「这个价格到底值不值？」（10 字）
  - 「小户型还能这样装？」（9 字）
- **适配平台**：小红书（疑问 + 审美底图是搜索流量入口）、B站（疑问引发弹幕讨论）、视频号（熟人语境疑问不冒犯）。
- **适配题材**：知识科普、测评、家居、职场。
- **强度评级**：中。疑问本身不招处罚，但疑问的对象必须真实存在于正片。

### 2. conflict 冲突式
- **公式结构**：否定指令 / 争议断言 + 具体对象。
- **文案模板**：
  - 「我劝你别买这款锅」（9 字）
  - 「这套方案被骂惨了」（9 字）
  - 「别再信平替这个词」（9 字）
- **适配平台**：抖音、快手（强钩子容忍度高）；小红书慎用「我劝你」体，易被判营销号。
- **适配题材**：测评、带货、剧情、观点输出。
- **强度评级**：强。评论区吵架是流量，但立场必须与正片结论一致，否则成标题党。

### 3. data-shock 数据冲击式
- **公式结构**：数字 + 时间/范围 + 反常识结果。
- **文案模板**：
  - 「3 天涨粉 1 万，我只改了标题」（12 字，两行断）
  - 「99% 的人洗脸洗错了」（10 字）
  - 「月存 5 千，我靠这三张表」（11 字）
- **适配平台**：全平台；抖音/B站效果最稳，数字自带可信度。
- **适配题材**：知识科普、财经、成长记录、运营复盘。
- **强度评级**：强。数字必须真实可查，「3 天涨粉 1 万」若正片拿不出后台截图即为虚假承诺。

### 4. contrast 反差式
- **公式结构**：A 状态 vs B 状态 + 同一对象。
- **文案模板**：
  - 「月薪 3 千 vs 3 万的简历」（12 字）
  - 「装修前 vs 入住一年后」（10 字）
  - 「同一件裙子，胖瘦上身」（10 字）
- **适配平台**：小红书（前后对比是种草母语）、抖音、快手。
- **适配题材**：美妆穿搭、家居改造、职场、健身。
- **强度评级**：强。注意底图仍需单张连续画面——反差靠文案表达，禁止拼接对比图。

### 5. value-preview 价值预览式
- **公式结构**：范围限定词（一篇/一条/三步）+ 干货承诺。
- **文案模板**：
  - 「一篇讲透全屋净水」（9 字）
  - 「新手化妆保姆级教程」（10 字）
  - 「三步搞定周末早餐」（9 字）
- **适配平台**：小红书（搜索场景首选）、B站（教程区标配）、视频号。
- **适配题材**：知识科普、教程、美食、母婴。
- **强度评级**：中。最安全的公式，「讲透/保姆级」要求正片信息密度真的够。

### 6. curiosity-gap 悬念缺口式
- **公式结构**：过程/结论 + 关键信息留白（最后一步/第 X 个/关键是）。
- **文案模板**：
  - 「最后一步 90% 的人做错」（12 字）
  - 「第三种方法没人告诉你」（11 字）
  - 「关键在关火前 10 秒」（9 字）
- **适配平台**：抖音、快手、B站；小红书慎用（用户更吃明牌价值）。
- **适配题材**：教程、美食、剧情、科普。
- **强度评级**：强。缺口必须在正片前 30 秒内揭晓，拖太久完播率反噬。

### 7. pattern-interrupt 模式打断式
- **公式结构**：反常识断言 / 否定句开场 + 具体对象。
- **文案模板**：
  - 「多喝水反而伤肾？」（8 字）
  - 「贵的防晒霜没必要」（9 字）
  - 「早起毁一天，真的」（8 字）
- **适配平台**：抖音、B站；医学健康类注意资质与表述红线。
- **适配题材**：科普辟谣、测评、观点输出。
- **强度评级**：强。断言必须与正片结论一致，「震惊体」换皮会被平台限流。

### 英文钩子（TikTok / YouTube）
- **纪律**：≤5 词，可全大写；动词开头或数字开头 CTR 最高。
- **模板**：
  - 「I Tried X So You Don't Have To」→ 封面缩写「I TRIED IT」（2 词）+ 表情帧
  - 「X vs Y」→ 「$3 vs $300」（3 词）
  - 「STOP Doing This」（3 词）
  - 「3 Mistakes Beginners Make」→ 封面「3 MISTAKES」（2 词）
- **适配**：YouTube 横版封面文案 ≤3 词效果最佳，剩余信息交给画面表情与标题文字区。

## 四、参数速查（核心调用区）

| 公式 ID（对应 hookStyles） | 结构 | 字数预算（视觉字） | 适配平台 | 强度 |
|---|---|---|---|---|
| question | 疑问词+对象 | ≤10 | 小红书/B站/视频号 | 中 |
| conflict | 否定/争议+对象 | ≤10 | 抖音/快手 | 强 |
| data-shock | 数字+时间+结果 | ≤12 | 全平台 | 强 |
| contrast | A vs B+对象 | ≤12 | 小红书/抖音/快手 | 强 |
| value-preview | 限定词+干货承诺 | ≤11 | 小红书/B站/视频号 | 中 |
| curiosity-gap | 过程+关键留白 | ≤12 | 抖音/快手/B站 | 强 |
| pattern-interrupt | 反常识断言 | ≤9 | 抖音/B站 | 强 |

> 上表 7 个 ID 是**跨语言公式**（也是 `account-profile.hook_bias` 与 `cover-platforms.hookStyles` 的取值集合）；
> 英文平台不新增公式 ID，而是同一公式的**语言变体**：动词/数字开头、≤5 词、可全大写（YouTube 封面 ≤3 词更佳）。

字数预算与硬口径对照：主标题 ≤12 视觉字为总上限，上表是各公式实测过审且不折行的安全线；小红书放宽至 14、B站 16、英文 ≤5 词（英文按**词数**计，中文按视觉字数计，见 `cover-platforms.ts`）。时长类钩子（「48 秒看完」）数字必须与成片一致，±2s 校验。

## 五、常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 钩子字数顶满 12 字还加修饰 | 折成 3 行或字号被迫缩小，小图不可辨 | 先删副词，再删限定语，保核心冲突 |
| 一个封面叠两个公式 | 信息互相稀释，0.3 秒读不完 | 一封面一钩子，副标题才补信息 |
| 全账号清一色强钩子 | 老粉疲劳，调性崩塌，被贴营销号标签 | 成熟号强弱钩按 3:7 配比轮换 |
| 悬念缺口拖到视频结尾才揭 | 完播率崩塌，算法降权 | 缺口在前 30 秒内给阶段性答案 |
| 数字钩子无凭据 | 虚假承诺判罚，限流或下架 | 数字必须能在正片或后台数据自证 |
| 英文钩子直译中文长句 | 超 5 词，横版缩略图糊成一团 | 砍到动词+名词核心，≤5 词 |

## 六、意图→设计映射表（核心调用区）

| 意图 | 设计/文案动作 | 判据 |
|---|---|---|
| 「想让人点进来学东西」 | value-preview：限定词+干货承诺 | 含「一篇/三步/讲透」之一，≤11 字 |
| 「想让人站队评论」 | conflict：否定指令或争议断言 | 含「别/劝/被骂」之一，立场与正片一致 |
| 「想用成绩背书」 | data-shock：真实数字前置 | 数字阿拉伯写法，可自证，≤12 字 |
| 「想展示变化」 | contrast：A vs B 文案，单画面底图 | 含「vs/前后」，底图无拼接 |
| 「想让人追到底」 | curiosity-gap：关键信息留白 | 缺口前 30 秒揭晓，≤12 字 |
| 「想破除误区」 | pattern-interrupt：反常识断言 | 断言与正片结论一致，≤9 字 |
| 「新号冷启动起量」 | 强钩三连发（conflict/data-shock/curiosity-gap 轮换） | 连续 3 条不重复公式 |
| 「成熟号护调性」 | 强弱钩 3:7 轮换，疑问/价值预览为主 | 近 10 条强钩 ≤3 条 |
| 「做 TikTok/YouTube」 | en-short：动词或数字开头 | ≤5 词，YouTube 封面 ≤3 词 |
| 「小红书搜索流量」 | question/value-preview + 关键词前置 | 前 5 字含搜索词，≤14 字 |
| 「标题含时长卖点」 | data-shock 时长变体 | 与成片 ±2s 一致 |
| 「平台政策敏感期」 | 降一级强度，禁用绝对化词 | 无「最/第一/100%」 |

## 七、设计模板

**模板 A · 抖音强钩（新号起量）**
- 主标题：「我劝你别买这款锅」（conflict，9 字，一行）
- 副标题：「用了三个月，说说真实体验」（13 字，补信任）
- 底图：person-led，人物手持锅具皱眉帧；标题带压顶部 6%–30% 区。
- 强度：强；配套前 3 秒口播必须直接回应「为什么别买」。

**模板 B · 小红书价值预览（搜索流量）**
- 主标题：「一篇讲透全屋净水」（value-preview，9 字）
- 副标题：「前置/软水/直饮怎么选，附清单」（15 字）
- 底图：subject-led，净水设备干净陈列，花字版式；主标题前 5 字含「全屋净水」搜索词。
- 强度：中；关键词前置是搜索收录判据。

**模板 C · YouTube 横版悬念（英文）**
- 主标题：「3 MISTAKES」（data-shock 缩写，2 词，全大写）
- 底图：人物夸张表情偏右，标题靠左大字；横向 16:9。
- 强度：强；表情帧承载 50% 的点击动机，文字只做锚点。

## 八、决策树

```
开始：这条封面的第一目标是什么？
├─ 涨点击（新号/冷启动）
│   ├─ 正片有真实数字？→ data-shock（数字可自证才用）
│   ├─ 正片有明确对立立场？→ conflict
│   └─ 正片有过程悬念？→ curiosity-gap
├─ 涨搜索（小红书/B站教程）
│   ├─ 教程/清单类 → value-preview（关键词前置）
│   └─ 答疑类 → question（用户原话式提问）
├─ 护调性（成熟号）
│   └─ question / value-preview 为主，强钩占比 ≤3/10
└─ 海外平台
    └─ en-short ≤5 词（YouTube ≤3 词），表情帧补情绪
所有分支终审：封面承诺能否在视频前 3 秒兑现？否 → 换钩子或改选题。
```
