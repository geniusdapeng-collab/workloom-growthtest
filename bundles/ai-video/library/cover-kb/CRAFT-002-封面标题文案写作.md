# CRAFT-002 封面标题文案写作

> 版本 v1.0 · 2026-09-27 · 适用链路：视频封面设计（cover-designer 岗位）

## 一、核心概念

封面标题是「用最少字数通过 0.3 秒扫读测试」的写作。用户对封面文字的处理方式是扫读不是阅读：视线在标题上停留约 0.3 秒，能吸收的有效信息约 6–10 个视觉字。因此主标题 ≤12 视觉字（小红书 ≤14、B站 ≤16、英文平台 ≤5 词）、最多 2 行不是审美偏好，而是扫读生理极限的硬口径；副标题 ≤24 字、角标 ≤10 字同理。

写作纪律排序：先过字数，再过口语，最后过平台政策。顺序不能反——一句合规但 18 字的标题是废稿，一句 12 字但书面语的标题点击率减半。

## 二、分类速查

| 文案位 | 字数上限 | 职能 | 禁忌 |
|---|---|---|---|
| 主标题 | ≤12 视觉字（小红书 14/B站 16/英文 5 词） | 钩子本体，一眼定生死 | 超两行、单字成行 |
| 副标题 | ≤24 字 | 补信息增量，不重复主标题 | 复述主标题、塞第二钩子 |
| 角标 | ≤10 字 | 只放地点/系列名 | 放卖点、放日期 |
| 数字 | 阿拉伯优先 | 扫读锚点 | 「三天」式汉字数字 |
| 花字 | 小红书专用 | 情绪与审美 | 满屏贴纸、遮主体 |

## 三、分场景实战

### 字数纪律与断行
- **≤12 字的底层逻辑**：0.3 秒扫读 + 小图字级下限（字级不能无限小）。超过 12 字只有两条路：砍字或进副标题，不存在第三条。
- **断行原则**：两行时必须语义完整切分，每行 ≥4 字，杜绝单字成行与虚词结尾行（「的/了/在」不落行尾）。
  - 好：「3 天涨粉 1 万 / 我只改了标题」（5+7，因果分段）
  - 坏：「3 天涨粉 / 1 万我只改了标题」（数字被劈开）
- **长短行美学**：两行时上短下长或上长下短均可，行长差 ≥2 字才有节奏感；两行等长显呆，仅对称构图题材可用。
- **视觉字口径**：阿拉伯数字与半角标点按 0.5 个视觉字计，「vs」按 1 字计。

### 数字的使用
- **阿拉伯数字优先**：「3 天」优于「三天」——阿拉伯数字在扫读中是视觉锚点，识别速度快约一倍。
- **时长数字与成片一致**：标题写「48 秒」「1 分钟」，成片时长必须落在 ±2s 内，机检以成片元数据为准，超出即打回（见 CRAFT-003 案例 5）。
- **数字的位置**：尽量前置（前 4 字内），「3 天涨粉 1 万」优于「涨粉 1 万只用 3 天」。

### 口语化
- **说人话测试**：把标题读出声，像对朋友说话就过，像念说明书就重写。
  - 书面：「关于小户型收纳的若干方法论」→ 口语：「小户型还能这样收？」
  - 书面：「本视频将阐述三大误区」→ 口语：「这三个坑别再踩了」
- **去术语**：行业黑话一律翻译成人话（「GMV」→「卖货额」，「疗愈」→「解压」），除非术语本身是搜索关键词（小红书场景保留）。
- **第二人称**：「你/你的」制造代入感，question 与 conflict 公式默认带人称呼应；但一句话只喊一次，「你你你」是喊麦。

### 平台文案政策
- **抖音/快手**：允许强钩子（conflict/curiosity-gap），但处罚夸大与虚假承诺——「最」「第一」「100% 有效」类绝对化词触发机审，用「我测过的里最好用」式限定表达替代。
- **小红书**：忌硬广词与营销腔，「最便宜」「代购」「甩卖」类限流词概念；文案调性是「闺蜜分享」不是「柜台推销」，价值预览与疑问式最安全。
- **视频号**：熟人社交语境，标题克制——强冲突文案在朋友圈转发场景会「社死」，用疑问式与价值预览式，避免「震惊」「不看后悔」。
- **B站**：允许梗与黑话（「前方高能」「yyds」式社区语言），但梗必须是当期活梗，过气老梗掉价；≤16 字的宽容留给双句梗。
- **英文平台**：全大写纪律——YouTube 封面词全大写提升小图可辨性；≤5 词，介词能省则省；禁用 clickbait 判罚词（「GONE WRONG」类已被算法降权）。

### 副标题与角标的分工
- **副标题 = 信息增量**：主标题说「是什么/为什么」，副标题补「有多少/给谁看/包含什么」。
  - 主：「一篇讲透全屋净水」副：「前置/软水/直饮怎么选，附清单」——互补。
  - 反例：副标题「全屋净水选购指南」——与主标题同义重复，浪费 24 字额度。
- **角标 = 定位标签**：只放地点（「上海探店」）、系列名（「装修日记 Vol.12」），≤10 字；角标放卖点是与主标题打架。

### 花字与特殊排版（小红书）
- **适用边界**：审美先行题材（穿搭/美妆/家居/旅行）可用花字（描边/圆角底/手写字），知识科普与剧情类用标准粗黑字，花字会稀释可信度。
- **克制原则**：一张封面花字样式 ≤2 种，颜色 ≤3 色，贴纸 ≤2 个且不遮主体；花字是调味，满屏花字 = 美图秀秀风，判据见 THEME-002 色板口径。

## 四、参数速查（核心调用区）

| 项目 | 口径 | 校验方式 |
|---|---|---|
| 主标题字数 | ≤12 视觉字（小红书 14/B站 16/英文 ≤5 词） | 视觉字计数（数字/半角符号 0.5） |
| 行数 | ≤2 行 | 渲染行数机检 |
| 单行最短 | ≥4 字 | 断行检查 |
| 行尾禁忌 | 虚词（的/了/在/和）不落行尾 | 断行检查 |
| 副标题 | ≤24 字，与主标题零重复词 ≥60% | 语义去重 |
| 角标 | ≤10 字，仅地点/系列名 | 词性检查 |
| 时长数字 | 与成片 ±2s | 成片元数据比对 |
| 绝对化词 | 「最/第一/100%」禁用（抖快/小红书） | 敏感词表 |
| 英文全大写 | YouTube 封面词全大写 | 字符检查 |

## 五、常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 舍不得砍字硬塞 15 字 | 折三行或缩字号，小图报废 | 砍到 12 字内，余量进副标题 |
| 副标题复述主标题 | 双倍字数传达单倍信息 | 副标题只补增量：数量/人群/清单 |
| 「三天见效」汉字数字 | 扫读无锚点，点击折损 | 阿拉伯数字前置：「3 天见效」 |
| 标题带「最便宜」冲小红书 | 限流词触发，推荐量腰斩 | 换闺蜜口吻：「这个价位真香」 |
| 视频号用「不看后悔」 | 熟人转发场景社死 | 克制疑问式：「这样收纳合理吗」 |
| 断行劈开语义 | 「3 天涨粉 / 1 万…」读不通 | 按语义块断行，数字不拆 |
| 花字叠 4 种样式 | 美图秀秀风，可信度崩塌 | ≤2 样式 ≤3 色，科普类不用花字 |
| 标题写「48 秒」成片 51 秒 | ±2s 校验打回 | 以成片元数据为准反写数字 |

## 七、设计模板

**模板 A · 强钩两行版（抖音知识号）**
- 主标题：「3 天涨粉 1 万 / 我只改了标题」（5+7 字，上短下长）
- 副标题：「标题公式在视频里，直接抄」（13 字）
- 角标：「运营日记」（系列名，4 字）

**模板 B · 小红书克制版（种草）**
- 主标题：「这个价位的面霜真香」（10 字，规避「最便宜」）
- 副标题：「干皮秋冬实测，成分表扒给你看」（15 字）
- 花字：单样式描边字，2 色内。

**模板 C · 视频号熟人版（生活经验）**
- 主标题：「这样收纳合理吗」（8 字，克制疑问）
- 副标题：「住了三年总结的厨房动线」（12 字）
- 无角标，无强情绪词，适配朋友圈转发语境。

## 八、决策树

```
开始：写完标题初稿
├─ 视觉字 ≤12（平台放宽值）？
│   └─ 否 → 删副词 → 删限定语 → 仍超 → 拆一半进副标题
├─ 需两行？→ 按语义块断行，每行 ≥4 字，虚词不落行尾
├─ 含数字？→ 阿拉伯化并前置；含时长 → 对成片 ±2s
├─ 含绝对化词/限流词？→ 按平台词表替换（「最」→「真香/我测过」）
├─ 读出声像说话？→ 不像 → 书面语改写
├─ 副标题与主标题重复？→ 重写副标题只补增量
└─ 小红书且审美题材？→ 可启用花字（≤2 样式 ≤3 色）
终审：主标题 240px 小图扫读一遍能懂 → 过稿
```
