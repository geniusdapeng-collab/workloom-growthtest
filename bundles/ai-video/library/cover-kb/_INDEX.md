# 视频封面设计知识库 · 总索引

> **用途**：本目录是「视频封面制作链路」的行业 know-how 知识库，供封面设计师岗位（cover-designer）通过 cover-kb-bridge 检索调用，注入设计稿 prompt。
> **版本**：v1.0　**更新日期**：2026-09-27　**主题数**：14
> **统一结构**：每篇均为九章式——核心概念 → 分类速查 → 分场景实战 → 平台参数速查 → 常见误区 → **意图→设计映射表（核心调用区）** → 设计模板 → 决策树 → 关联知识。
> **检索总则**：平台参数类数字（画幅/安全区/标题带）以 `packages/video-studio/src/cover-platforms.ts` 为最终口径，本库是经验与判据的载体；冲突时以代码规格为准。
> **治理**：内容缺口走提案评审（仿 proposals/kb-gap-round4 格式），只增不改。

## Agent 调用建议

1. **出任何平台封面** → 先 `profile <平台ID>` 取对应 PLAT 篇第四章参数速查。
2. **指定题材** → `recipe <平台> <题材>` 组合：PLAT 参数 + THEME-001 版式 + HOOK-001 短名单。
3. **有账号档案** → ACCT-001 视觉锤约束优先进 prompt；字体色板冲突时档案 > 题材默认。
4. **高频组合**：小红书种草 = PLAT-003 + THEME-001（种草/测评行）+ HOOK-001（价值预览式）；抖音知识号 = PLAT-001 + THEME-002（知识科普行）+ ACCT-001。
