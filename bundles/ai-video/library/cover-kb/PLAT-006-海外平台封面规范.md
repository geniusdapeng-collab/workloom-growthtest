# PLAT-006 海外平台封面规范（TikTok / YouTube / Instagram Reels）

> 版本 v1.0 · 2026-09-27 · 适用链路：视频封面设计（cover-designer 岗位）

## 一、核心概念

海外三平台分属两种封面逻辑：**TikTok / IG Reels 是竖屏全屏沉浸流**（首帧即封面，封面负责「停住拇指」），**YouTube 是横版缩略图点选流**（缩略图 + 标题组合决策，封面负责「赢得点击」）。YouTube 是海外封面方法论的发源地：以 MrBeast 为代表的创作者把缩略图当作增长实验品——一条视频常备 3–5 版缩略图做 A/B 测试（YouTube 官方已内建 Test & Compare），CTR 以 4%–10% 为健康区间，封面与标题必须「互补不重复」。三平台共同铁律是**小尺寸可辨性优先**：YouTube 手机端缩略图仅约 120px 高，竖屏平台在搜索/网格页同样缩得很小——所有设计必须在邮票大小下依然成立。英文标题全部按「词数」纪律：≤4–5 个词，全大写 + 高对比描边是主流处理。

## 二、分类速查

| 平台 | 主流封面流派 | 特征 | CTR 表现 |
|---|---|---|---|
| TikTok | 文字横幅式 | 首帧画面 + 全大写文字条（text banner），钩子前置 | 高（钩子驱动） |
| TikTok | 表情/动作高潮帧 | 夸张表情或动作瞬间帧 + 短词 | 高 |
| YouTube | Face-closeup 式 | 人脸表情特写（震惊/狂喜）占 30%+，情绪即钩子 | 高（MrBeast 范式） |
| YouTube | Curiosity-gap 式 | 画面制造信息缺口（遮挡/对比/未完成的动作） | 高 |
| YouTube | Before-After 对比式 | 左右分屏，结果可视化 | 高（改造/测评类） |
| IG Reels | Aesthetic 首帧式 | 色调统一的高审美帧，字极少或无字 | 中高（美学驱动） |
| IG Reels | 模板字卡式 | 品牌色底 + 短词大字，与 feed 网格统一 | 中高（账号资产型） |

## 三、分场景实战

**场景 1：TikTok 带货/种草（TikTok Shop 生态）**
做法：产品高光帧 + 顶部全大写文字条（≤5 词，如 "THIS $10 FIND BLEW UP"），文字条用高对比底色 + 白字描边。为什么：TikTok 带货决策链极短，pattern-interrupt（打破滑动惯性）靠「价格 + 惊叹」组合；全大写英文在快速滑动中辨识度最高。

**场景 2：YouTube 挑战/实验类（MrBeast 范式）**
做法：人脸表情特写（震惊/用力）占画面 30%+，背景交代挑战场景（百万美金/荒岛/百人），文字 ≤5 词且与标题互补——标题说 "I Survived 50 Hours"，缩略图只说 "DAY 3"。为什么：该品类的公式是「表情 = 情绪强度，场景 = 赌注规模，文字 = 进度钩子」；MrBeast 团队公开的做法是先设计缩略图再拍视频，封面即内容企划书。

**场景 3：YouTube 教程/知识类**
做法：左文右图或上文下图，结果预览（成品/数据曲线）+ ≤5 词价值承诺（"RANK #1 ON GOOGLE"），配色 2–3 色高对比。为什么：教程搜索流量占比高，缩略图与标题要在搜索结果列表里与 10 个竞品赛马；结果可视化（before 数据 → after 数据）是最强点击理由。

**场景 4：IG Reels 美学账号（生活方式/时尚/家居）**
做法：首帧选色调统一的高审美帧，文字 ≤4 词用品牌衬线体小字居中，或干脆无字；同时检查主页网格——中心 1:1 裁切区必须独立成立。为什么：IG 的封面双重职责（信息流 + 主页网格），网格观感的连续性直接影响关注转化；aesthetic 一致性是 IG 账号的核心资产。

**场景 5：跨平台分发（一条素材发三平台）**
做法：竖屏素材拍 9:16 时把核心主体保持在画面中轴 2/3 内（兼容 TikTok/Reels），YouTube Shorts 同理；如需 YouTube 横版长视频则横屏单独拍，封面单独设计。为什么：三平台安全区数值不同（见第四章），同一封面直接复用必然在某平台被遮挡；行业惯例是「素材可复用，封面不跨平台复用」。

## 四、平台参数速查（核心调用区）

| 参数 | TikTok | YouTube | Instagram Reels |
|---|---|---|---|
| 画幅 | 9:16 竖屏 | 16:9 横版缩略图 | 9:16 竖屏 |
| 画布尺寸 | 1080×1920 px | 1920×1080 px | 1080×1920 px |
| 顶部安全区 | 上方 6% | 上方 5% | 上方 6% |
| 底部遮挡区 | 下方 17% | 下方 8% | 下方 15% |
| 右侧栏 | 右侧约 11% 宽 | 无 | 右侧约 11% 宽 |
| 标题带 | 上部 6%–42% | 上部 5%–60% | 上部 6%–42% |
| 标题字数上限 | 英文 ≤5 词 | 英文 ≤5 词 | 英文 ≤4 词 |
| 文案调性 | 全大写 + 高对比描边主流，钩子直接 | CTR 驱动、curiosity gap、与标题互补 | aesthetic 首帧美学，字极少 |
| 钩子风格 | pattern-interrupt / question / data-shock / contrast | curiosity gap / 高对比 / face-closeup | 美学吸引 / 轻量价值预览 |
| 特殊机制 | 首帧即封面 | 右下角时长角标区（约 12%×8%）禁放关键元素；手机端缩略图仅约 120px 高，小尺寸可辨性优先；缩略图与标题互补不重复；官方 Test & Compare A/B 测试 | 封面同时用于主页网格，中心 1:1 裁切区必须独立成立 |

## 五、常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 中英混排或中文标题直出海外 | 目标用户不读，CTR 崩 | 全英文，≤4–5 词，按词数纪律 |
| 英文小写长句 | 滑动中辨识度低 | 全大写 + 粗体 + 高对比描边 |
| YouTube 关键元素放右下 | 被时长角标（约 12%×8% 区域）遮挡 | 右下角区域只放背景，主体和文字避开 |
| 缩略图文字与标题重复 | 浪费一次信息传递机会（YouTube 大忌） | 互补分工：标题说 What，缩略图说 Why/How/情绪 |
| 按桌面端预览效果设计 | 手机端约 120px 高下文字糊成色块 | 以 120px 高预览为准做可读性验收 |
| IG 封面只考虑信息流 | 主页网格裁切后主体腰斩，账号门面受损 | 中心 1:1 裁切区单独验收，独立成立 |
| 同一封面三平台直发 | 各平台安全区不同，必然有遮挡 | 素材可复用，封面按平台分别适配 |
| 表情特写不够夸张（YouTube） | 情绪信号弱，竞争不过同列竞品 | face-closeup 表情强度拉满（震惊/狂喜/崩溃），占画面 30%+ |
| 一版封面用到底不测试 | 无法逼近 CTR 上限 | YouTube 用 Test & Compare 跑 3 版以上，数据定稿 |

## 七、设计模板

**模板 A：TikTok 文字条钩子款**
- 布局：首帧画面满版，顶部 6%–22% 放文字条（全大写 ≤5 词，黑底白字或黄底黑字）；右侧 11%、底部 17% 留空。
- 字体：Montserrat ExtraBold / Poppins Bold（建议），全大写 + 2–4px 描边（建议）。
- 配色：文字条 #000000 + 字 #FFFFFF，强调词 #FFE600；或黄底 #FFE600 + 黑字 #111111。
- 标题示例："THIS $10 FIND BLEW UP" / "POV: YOUR FIRST CLIENT PAYS $5K"。

**模板 B：YouTube Face-closeup 款（MrBeast 范式）**
- 布局：人脸表情特写占左侧 30%–40%，右侧放场景/赌注元素（钱/车/百人阵列），文字 ≤5 词放顶部或左下（避开右下 12%×8% 时长角标区）。
- 字体：Bebas Neue / Anton / Montserrat Black（建议），全大写。
- 配色：高饱和撞色——底 #1B9CFC 系 + 字 #FFFFFF + 强调 #FFD32A；人脸肤色调亮 10%–15% 增强跳出（建议）。
- 标题示例：缩略图文字 "LAST TO LEAVE" + 视频标题 "Wins $500,000"（互补不重复）。

**模板 C：IG Reels 美学网格款**
- 布局：色调统一的首帧（主体居中偏上，保中心 1:1 区），文字 ≤4 词用账号固定字体放画面上 1/4；或品牌色底字卡与实拍封面交替排布。
- 字体：Playfair Display（优雅衬线）/ DM Sans（现代无衬线）（建议），全账号锁定一款。
- 配色：示例米白 #F5EFE6 + 陶土 #C0865E + 墨黑 #2B2622；整套账号色板 ≤4 色。
- 标题示例："Slow mornings" / "Desk setup tour"。
