# PLAT-003 小红书封面规范

> 版本 v1.0 · 2026-09-27 · 适用链路：视频封面设计（cover-designer 岗位）

## 一、核心概念

小红书是双列信息流社区：发现页以双列瀑布流呈现笔记封面，视频封面在流内只占约 1/4 屏宽（半列宽 × 3:4 高）——这是所有平台里单封面展示面积最小的场景之一，因此「字必须更大、更聚焦，信息必须做减法」。小红书用户决策链是「审美吸引 → 价值判断 → 点进」：封面审美即内容质量信号，用户默认「封面做得糙 = 内容也糙」。社区语境排斥硬广：广告感强的封面会被直接划过甚至点「不感兴趣」。由此得出小红书封面的三重身份：它是门面（审美即质量）、是摘要（价值预览）、是筛选器（帮对的用户认出「这是给我的」）。「封面 = 门面」是小红书运营的第一共识。

## 二、分类速查

| 类型 | 特征 | 适用账号 | CTR 表现 |
|---|---|---|---|
| 花字标题式 | 高审美底图 + 设计感花字（描边/阴影/贴纸字） | 美妆、穿搭、生活方式 | 高（平台主流） |
| 拼图合集式 | 2–4 宫格拼图（多产品/多造型/多场景） | 合集、测评、穿搭 | 高（信息密度信号） |
| 前后对比式 | 左右分屏 before-after，对比强烈 | 美妆、护肤、改造、减肥 | 高 |
| 清单体封面 | 数字清单（「6 家宝藏店铺」）+ 标签元素 | 探店、攻略、干货 | 中高 |
| 氛围感纯图式 | 无字或极小字，靠色调/构图美学 | 旅行、家居、摄影、穿搭 | 中高（赌审美） |
| 干货便签式 | 便签/手账风排版，文字信息为主 | 学习、职场、干货 | 中（实用向用户吃这套） |

## 三、分场景实战

**场景 1：美妆/护肤类**
做法：特写妆效/质地帧，花字标题放标题带上段（≤14 字），配色跟妆面色系走（同色系或补色），关键词用色块托底。为什么：美妆用户为「效果」点进，特写即证据；花字是平台原生语言，不用花字反而显得「不像小红书笔记」，融入感即点击率。

**场景 2：穿搭类**
做法：全身/半身穿搭图占画面主体，标题放角落做「标签式」处理（小字 + 色块），或走氛围感无字路线；色系控制全图 ≤3 色。为什么：穿搭的封面主角是「衣服本身」，字是配角；1/4 屏宽下大字压图会毁掉穿搭的完整呈现，标签式小字既给信息又不抢戏。

**场景 3：探店/攻略类**
做法：拼图（门头 + 招牌菜 + 环境 2–3 格）或清单体封面，标题数字前置（「3 家」「人均 50」），加定位标签元素。为什么：攻略类用户为「信息量」点进，拼图 = 密度承诺，数字 = 决策锚点；清单体与小红书搜索场景（「北京  brunch 推荐」）天然匹配。

**场景 4：干货/学习类**
做法：便签/手账风排版，标题占视觉中心，正文要点做成封面上的「预览列表」（3–4 行短句），配色清爽（白底/奶油底 + 深色字）。为什么：干货用户为「可收藏」点进，封面直接展示内容骨架 = 收藏价值可视化；手账风是小红书干货区的成熟视觉方言。

**场景 5：改造/家居/减肥类（强对比题材）**
做法：左右分屏 before-after，分割线清晰，两侧色温/亮度拉开差距，标题放顶部小字（对比本身即钩子）。为什么：强对比题材的钩子已经由画面承担，文字只需点题；1/4 屏宽下对比必须在缩略图状态就肉眼可辨，否则等于没做。

## 四、平台参数速查（核心调用区）

| 参数 | 口径 |
|---|---|
| 画幅 | 3:4 竖屏 |
| 画布尺寸 | 1080×1440 px |
| 顶部安全区 | 画面上方 7%（约 100px），禁放关键元素 |
| 底部遮挡区 | 画面下方 17%（约 240px），被标题/互动条遮挡，禁放关键元素 |
| 右侧栏 | 无右侧栏（双列流形态，无竖屏操作栏遮挡） |
| 标题带 | 画面上部 7%–45%（约 100px–650px）为标题安全放置区 |
| 标题字数上限 | 主标题 ≤14 视觉字（平台各场景中上限最宽，但仍须克制） |
| 文案调性 | 审美先行、价值预览、弱化硬广 |
| 钩子风格 | 美学吸引 / 价值预览 / 对比 |
| 特殊机制 | 双列信息流封面仅占约 1/4 屏宽 → 字必须更大更聚焦；流行花字、拼图、前后对比、清单体；封面审美 = 内容质量信号 |

## 五、常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 按抖音大字报思路做 | 1/4 屏宽下大字 + 满信息 = 脏乱，被划走 | 信息做减法：一个主体 + 一行核心字 |
| 字多且小（要点写满封面） | 缩略图状态全糊成色块 | 封面只放「钩子句」，要点留给正文/视频 |
| 硬广感（价格弹窗/促销贴纸堆砌） | 社区排斥，被点「不感兴趣」，限流 | 价值预览替代促销叫卖，软种草口吻 |
| 用无审美实拍原图直出 | 用户默认「封面糙 = 内容糙」 | 调色/构图/字体至少一项精修，门面必须立住 |
| 对比图差距不明显 | 核心钩子失效 | 两侧色温/亮度/状态差距拉大，缩略图可辨 |
| 花字字体与内容气质不符 | 违和感，专业度受损 | 字体跟题材走（美妆用圆润体、干货用黑体，见 THEME-002） |
| 忽略底部 17% 遮挡 | 关键信息被标题栏盖住 | 底部 240px 只放背景，不放字和产品 |
| 封面与笔记内容不符（标题党） | 收藏/关注转化低，社区举报风险 | 钩子必须有兑现，小红书重「长效搜索流量」，失信封面毁掉笔记生命周期 |

## 六、意图→设计映射表（核心调用区）

| 用户意图/题材 | 设计动作（版式/构图/字级/配色/钩子） | 判据 |
|---|---|---|
| 变美参考（美妆/护肤） | 版式：特写图 + 顶部花字；构图：妆效/质地特写占 60%+；字级：主标约为画面宽 1/5–1/4（建议，1/4 屏宽下仍可读）；配色：跟妆面同色系 + 色块托字；钩子：价值预览式「黄皮显白的 3 支口红」 | 1/4 屏宽缩略图下，效果与标题均可辨 |
| 抄作业（穿搭/搭配） | 版式：全身图为主 + 角落标签字；构图：人物居中完整呈现；字级：标签字约 1/8–1/10 宽（建议），小而精；配色：全图 ≤3 色；钩子：价值预览式「158cm 通勤穿搭」 | 穿搭完整可见，字不压衣服 |
| 找去处（探店/旅行攻略） | 版式：2–3 宫格拼图 + 数字标题；构图：门头/招牌/环境分格；字级：主标约 1/5 宽（建议）；配色：拼图格间留白 8–12px，字色统一；钩子：清单体「上海 3 家宝藏 brunch」 | 数字与地名在缩略图状态可读 |
| 学干货（学习/职场/工具） | 版式：便签手账风 + 要点预览；构图：文字信息为主体，留白充足；字级：主标约 1/5 宽、要点行约 1/12 宽（建议）；配色：奶油底 #FFF8EE 类 + 深棕/深灰字；钩子：价值预览式「Notion 模板｜效率翻倍」 | 封面能直接看出「收藏这篇能得到什么」 |
| 看变化（改造/减肥/家居） | 版式：左右分屏对比；构图：before 左 after 右，分割线居中；字级：顶部点题字约 1/8 宽（建议）；配色：两侧色温拉开（冷 vs 暖）；钩子：对比式「出租屋改造，月租 800」 | 缩略图状态不看字也能识别「变了」 |
| 找同款（好物/开箱） | 版式：产品平铺/手持 + 花字；构图：产品居中占 50%，背景干净；字级：主标约 1/5 宽（建议）；配色：产品色取补色做字色；钩子：美学吸引式「被问爆的奶油色小家电」 | 产品辨识度第一，任何元素不得遮挡产品 |
| 情绪共鸣（生活方式/独居/vlog） | 版式：氛围感大图 + 极小字或无字；构图：光影/色调优先；字级：点缀字约 1/12 宽（建议）；配色：低饱和莫兰迪或胶片暖调；钩子：美学吸引（无文字钩子，画面即钩子） | 封面气质与目标用户「向往的生活」对味 |
| 决策避坑（测评/避雷） | 版式：红黑榜式分区或单图 + 「避雷」关键词；构图：产品阵列或翻车证据帧；字级：主标约 1/5 宽，「避雷/别买」等词最大（建议）；配色：警示红 #E74C3C 点缀，整体仍保审美；钩子：对比式「8 款防晒，只有 2 款能打」 | 「帮你省钱/避坑」的信号一眼可辨 |
| 节日应景（节日/季节内容） | 版式：节日元素 + 氛围图 + 花字；构图：主体居中，节日元素做边框/角落；字级：主标约 1/5 宽（建议）；配色：节日色（圣诞红绿/春节金红/樱花粉）；钩子：价值预览式「圣诞氛围感布置清单」 | 节日信号 0.5 秒可辨，但不土味堆砌 |

## 七、设计模板

**模板 A：花字美妆款（美妆/护肤/好物）**
- 布局：特写图满版；标题带 7%–30% 放主标（≤14 字），关键词用圆角色块托底；底部 17% 留空。
- 字体：站酷快乐体 / 阿里巴巴普惠体 Rounded（建议，圆润亲和）；可加 2–3px 白色描边 + 轻微投影（建议）。
- 配色：字 #FFFFFF，托底色块 #FF8FAB（粉）或跟妆面同色系，底色文字 #5D4037（深棕）。
- 标题示例：「黄皮天菜！这 3 支素颜口红绝了」——「黄皮天菜」粉色色块托底。

**模板 B：清单攻略款（探店/合集/攻略）**
- 布局：顶部 7%–25% 放数字主标；下方 2×2 或 1×3 拼图（格间距 8–12px）；每格可带极小标签字。
- 字体：思源黑体 Bold（建议），数字用 Heavy 字重突出。
- 配色：底 #FFFFFF，主标 #2D2D2D，数字 #E63946，格间留白 #FFFFFF。
- 标题示例：「广州 4 家老字号糖水铺」——「4 家」红色放大。

**模板 C：前后对比款（改造/减肥/家居）**
- 布局：左右分屏（before 左 / after 右，分割线 4px 白色），顶部 7%–18% 放一行点题小字；两侧图色温一冷一暖。
- 字体：思源黑体 Medium（建议），字小不抢戏。
- 配色：点题字 #FFFFFF + 黑描边，或 #333333 + 白描边（随底图明暗选）。
- 标题示例：「月供 800 的出租屋，改成了理想家」。

## 八、决策树

```
题材是什么？
├─ 美妆/护肤/好物 ── 效果可特写吗？
│   ├─ 可 → 模板 A（特写 + 花字）
│   └─ 否（产品是主角）→ 产品平铺/手持 + 花字，背景干净
├─ 穿搭 → 全身图为主 + 角落标签字；色系 ≤3 色
├─ 探店/攻略/合集 ── 素材 ≥3 张吗？
│   ├─ 是 → 模板 B（拼图 + 数字清单）
│   └─ 否 → 单图氛围款 + 清单体标题
├─ 改造/减肥/对比 → 模板 C（左右分屏），缩略图状态对比必须可辨
├─ 干货/学习 → 便签手账风，封面直接放要点预览
└─ 生活方式/vlog → 氛围感纯图，极小字或无字，色调定生死
发布前再校验：
① 1/4 屏宽缩略图下主体与主标可辨？
② 主标 ≤14 字且只做「一个钩子」？
③ 底部 17%（240px）无关键元素？
④ 无硬广感元素（促销贴纸/价格弹窗/叫卖词）？
⑤ 封面审美能代表内容质量（调色/字体/构图至少一项精修）？
```
