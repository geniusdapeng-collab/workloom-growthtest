# AI 视频生成提示词知识库 · 总索引

> **用途**：本目录是「AI 视频生成」系统的提示词知识库，供数字员工 / Agent 检索调用。
> **版本**：v1.0　**更新日期**：2026-09-24　**主题数**：19
> **统一结构**：每个主题均为九章式——核心概念 → 分类速查 → 分场景实战 → 视频特有规则 → 常见误区 → **意图→提示词映射表（中英文双语，核心调用区）** → 提示词模板 → 决策树 → 关联知识。
> **检索总则**：视频生成模型不认技术参数（F 值、ISO、快门数值），只认视觉效果描述。所有主题的价值都在把"参数意图"翻译成"画面语言"。
