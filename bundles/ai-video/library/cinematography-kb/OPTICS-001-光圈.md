# 光圈（Aperture）领域知识库

> **用途**：AI 视频生成系统的提示词知识库。供数字员工 / Agent 在生成视频提示词时检索调用。
> **主题编号**：OPTICS-001　**版本**：v1.0　**更新日期**：2026-09-24
> **使用方式**：Agent 接收到涉及"背景虚化、景深、清晰范围、星芒、通透感"等创作意图时，检索本主题，将 F 值换算为对应的视觉描述语言写入提示词。**注意：AI 视频模型不理解 F 值本身，必须把光圈意图翻译成画面效果描述**（见第六章映射表）。

## 一、核心概念

### 1.1 光圈是什么

光圈是镜头内部控制进光孔径大小的机械结构，用 **F 值（f-number）**表示：

> **F 值 = 镜头焦距 ÷ 进光孔直径**

- **F 值越小**（如 f/1.4）→ 孔径越大 → 进光越多 → **景深越浅**（清晰范围小，背景虚化强）
- **F 值越大**（如 f/16）→ 孔径越小 → 进光越少 → **景深越深**（前后都清晰）

记忆口诀：**"数字越小，光圈越大；数字越大，光圈越小"**（与直觉相反，Agent 生成内容时最常搞反的一点）。

### 1.2 光圈的三大作用

| 作用 | 小光圈值（f/1.4–f/2.8） | 大光圈值（f/8–f/16） |
|---|---|---|
| **景深** | 浅景深，主体清晰背景糊 | 深景深，全景清晰 |
| **进光** | 进光多，暗光友好 | 进光少，需要充足光线或降低快门/提高感光 |
| **特殊效果** | 焦外光斑（bokeh）、氛围感 | 星芒（starburst）、边缘锐度 |

### 1.3 景深的三个决定因素（Agent 生成提示词时的完整公式）

光圈不是景深的唯一变量。同等 F 值下：

1. **焦距越长** → 景深越浅（85mm 比 35mm 更容易出虚化）
2. **拍摄距离越近** → 景深越浅（怼近拍，f/4 也能虚化）
3. **主体与背景距离越远** → 背景虚化越明显

> 提示词组合技巧：想要强虚化时，不要只写光圈，组合"长焦 + 近摄 + 远背景"的描述，效果更稳定。

## 二、光圈档位全表（核心速查）

| F 值 | 景深 | 典型用途 | 画面效果关键词 |
|---|---|---|---|
| **f/1.2–f/1.4** | 极浅 | 夜景人像、情绪特写、拯救杂乱背景 | 奶油般虚化、梦幻光斑、主体悬浮感 |
| **f/1.8–f/2.0** | 很浅 | 单人写真、室内人像、美食特写 | 柔和虚化、主体突出、电影感 |
| **f/2.8** | 浅 | 环境人像、双人镜头、产品视频 | 主体清晰+背景有层次、专业感 |
| **f/4** | 中浅 | 环境人像、活动记录、日常 Vlog | 主体与场景兼顾、自然过渡 |
| **f/5.6** | 中等 | 旅游打卡、街拍、多人合影 | 人景皆清、所见即所得 |
| **f/8** | 较深 | 风光、建筑、大场景叙事 | 全画面锐利、细节丰富 |
| **f/11** | 深 | 风光、建筑内景、产品全景 | 前后景全清、质感扎实 |
| **f/16** | 很深 | 星芒特效、强光光源、大景深风光 | 太阳/路灯星芒、光线放射状 |
| **f/22** | 极深 | 微距、特殊风光（慎用） | 全景深但画质下降（衍射） |

### 原始口诀扩展解读（保留原口诀骨架）

> 原口诀：F16 出星芒 → F8 拍风景 → F5.6 打卡照 → F2.8 出层次 → F1.4 救杂乱背景。

- **f/16 —— 星芒制造机**：点光源（太阳、路灯、车灯）在极小光圈下会呈现放射状星芒。星芒尖角数 = 光圈叶片数（偶数叶片 = 同数尖角，奇数叶片 = 双倍尖角）。注意：f/16 进光量极小，只适合明亮场景；超过 f/16 画质开始衍射劣化。
- **f/8 —— 风光甜点位**：绝大多数镜头的最佳锐度区间（俗称"镜头甜点"在最大光圈收缩 2–3 档处，多在 f/5.6–f/11），f/8 拍风景中心到边缘都扎实，是无脑安全牌。
- **f/5.6 —— 人景兼顾**：旅游打卡照的核心是"既要人清楚、也要看得出身后是什么地方"。f/5.6 让人和地标都清晰，又不至于像 f/11 那样把背景拍成"说明书插图"。
- **f/2.8 —— 层次感起点**：主体清晰、背景可辨认但已柔和分离，画面出现"前后分层"的专业感。大三元变焦镜头（16-35 / 24-70 / 70-200 f/2.8）的恒定光圈就是这个值，是视频工作的主力档。
- **f/1.4 —— 杂乱背景橡皮擦**：背景再乱（人流、杂物、电线），大光圈一虚全成柔色块。同时是弱光救星。代价：景深极浅，眼部合焦稍有偏差整张废掉，视频运镜时焦点呼吸要格外小心。

## 三、分题材实战指南

### 3.1 人像

| 场景 | 推荐光圈 | 原因 |
|---|---|---|
| 单人特写 / 半身 | f/1.4–f/2.0 | 眼部合焦，背景全虚，情绪集中 |
| 环境人像（要带场景） | f/2.8–f/4 | 人清楚，场景可辨但不抢戏 |
| 双人 / 小合影 | f/2.8–f/4 | 保证两人都在景深内 |
| 多人合影 / 团体 | f/5.6–f/8 | 前后排都清晰，避免边缘人脸虚 |
| 夜景人像 | f/1.4–f/1.8 | 保进光量 + 背景灯点变梦幻光斑 |

### 3.2 风景 / 城市

- 大场景风光：**f/8–f/11**，锐度与景深平衡。
- 要带太阳 / 路灯星芒：**f/16**（注意三脚架或提高快门）。
- 前景虚化构图（花、草、树叶作画框）：**f/2.8–f/4** 对远处主体对焦，前景自然柔化。

### 3.3 旅游 / Vlog / 街拍

- 打卡照：**f/5.6**（人景皆清）。
- 边走边拍的 Vlog：**f/4–f/5.6**，给对焦系统留容错，防止人物出景深。
- 街拍叙事感：**f/8** 超焦距思路，抬手就拍，整街清晰。

### 3.4 产品 / 美食 / 静物

- 单品特写（香水、咖啡杯）：**f/2.0–f/2.8**，聚光灯式聚焦。
- 产品全貌（包装、摆盘全景）：**f/8–f/11**，每个细节都清楚，显得"贵"。
- 美食蒸汽 / 拉丝瞬间：**f/2.8**，虚化背景餐桌杂物，突出动态。

### 3.5 夜景 / 弱光

- 手持夜景：**能开多大开多大**（f/1.4–f/2.8），用光圈换快门速度。
- 夜景车轨 / 星芒长曝：**f/8–f/16**，小光圈延长曝光且点光源出星芒。
- 星空银河：**用镜头最大光圈**（f/1.4–f/2.8），此时求的是进光量而非景深。

### 3.6 微距

- 微距景深天然极浅，**f/8–f/16** 起步才能保证主体大部分清晰；f/22 慎用（衍射）。
- 提示词侧：微距视频常需要"浅景深聚焦局部 + 缓慢移焦"的描述。

## 四、视频拍摄的特有规则（与拍照不同，Agent 必须知道）

1. **180° 快门规则**：视频快门速度 ≈ 帧率 × 2 的倒数（25fps → 1/50s）。快门被锁死后，**光圈成了控制曝光的主变量**——白天想开大光圈拍浅景深，必须配 ND 减光镜。
2. **光圈优先于变焦**：拍视频尽量避免镜头呼吸（对焦时画面大小轻微变化）。定焦镜头呼吸效应小，更适合大光圈特写。
3. **恒定光圈变焦镜头**：拍视频选镜头时优先 f/2.8 恒定光圈变焦（24-70 f/2.8 等），变焦过程中曝光不跳变。
4. **跟焦容错**：浅景深视频（f/1.4–f/2.0）人物走动极易脱焦，Agent 生成提示词时如涉及运镜+浅景深，建议描述"缓慢、小幅度运镜"。
5. **光圈环无级调节**：视频拍摄收放光圈要平滑（无级光圈/无极调整），AI 视频中的"曝光渐变"效果可描述为 exposure ramp。

## 五、常见误区（生成提示词时的纠错规则）

| 误区 | 纠正 |
|---|---|
| "光圈越大 F 值越大" | 反了。F 值越小光圈越大 |
| "虚化全靠光圈" | 焦距、摄距、背景距离同样决定虚化 |
| "F 值写进提示词模型就懂" | 多数视频模型只认视觉效果描述，要翻译（见第六章） |
| "f/22 画面最清晰" | 超过 f/16 衍射让画质变软，f/8–f/11 才是锐度甜点 |
| "浅景深一定高级" | 产品全貌、合影、风光恰恰需要深景深；景深是叙事工具不是档次 |
| "拍视频和拍照片用光逻辑一样" | 视频快门被 180° 规则锁死，光圈承担主要曝光职责 |

## 六、创作意图 → 提示词关键词映射表（Agent 核心调用区）

> 规则：**提示词里不要直接写 f 值**（多数视频模型无效），按本表翻译成视觉语言。中英文都给，英文关键词对国际模型更有效。

### 6.1 浅景深方向（模拟 f/1.2–f/2.8）

| 创作意图 | 中文提示词写法 | 英文关键词 |
|---|---|---|
| 背景全虚、主体突出 | 浅景深，背景柔和虚化，主体锐利清晰 | shallow depth of field, blurred background, sharp subject |
| 梦幻光斑（夜景灯点） | 背景灯光化作圆形散景光斑 | creamy bokeh, circular bokeh balls, defocused city lights |
| 杂乱背景消失 | 背景完全虚化成柔和色块 | background melted into soft blur, heavily defocused |
| 电影感分离 | 电影级浅景深，主体从背景中分离 | cinematic shallow DOF, subject isolation |
| 焦点转移叙事 | 焦点从前景缓慢转移到远处主体 | rack focus, focus pull from foreground to subject |

### 6.2 深景深方向（模拟 f/8–f/16）

| 创作意图 | 中文提示词写法 | 英文关键词 |
|---|---|---|
| 全画面清晰 | 深景深，前景到远景全部清晰锐利 | deep depth of field, everything in focus, edge-to-edge sharpness |
| 风光大片 | 全景深风光，细节丰富通透 | deep focus landscape, crisp details throughout |
| 人景皆清（打卡） | 人物与背景地标都清晰 | subject and background both in focus, moderate depth of field |
| 星芒 | 太阳呈放射状星芒，光线刺目光斑 | starburst sun, sun star effect, radiating light rays |
| 建筑质感 | 建筑线条横平竖直全画面锐利 | architectural sharpness, deep focus cityscape |

### 6.3 氛围叠加词（与光圈效果配合使用）

- 大光圈氛围：柔焦 glow、朦胧 hazy、梦幻 dreamy、胶片感 film look
- 小光圈氛围：通透 clear、锐利 tack-sharp、 HDR 质感、纹理丰富 textured

## 七、提示词模板（Agent 直接填空调用）

### 模板 A：人像特写视频

```
[主体描述]，[动作/表情]，浅景深，背景[场景]完全虚化为柔和色块与圆形光斑，
主体眼部锐利合焦，[光线描述]，电影感，缓慢[运镜方式]。
Shallow depth of field, creamy bokeh, sharp focus on eyes, cinematic.
```

示例：
> 一位穿红色长裙的女子回眸微笑，浅景深，背景夜市灯光完全虚化为暖色圆形光斑，主体眼部锐利合焦，轮廓光勾勒发丝，电影感，镜头缓慢环绕。Shallow depth of field, creamy bokeh, rim light, cinematic, slow orbit shot.

### 模板 B：风光大场景视频

```
[场景描述]，深景深，前景[前景元素]到远处[远景元素]全部清晰锐利，
[时间/光线]，太阳呈放射状星芒，画面通透细节丰富。
Deep depth of field, edge-to-edge sharpness, starburst sun.
```

示例：
> 雪山脚下的湖泊倒影，深景深，前景野花到远处雪峰全部清晰锐利，清晨低角度阳光，太阳从山脊后升起呈放射状星芒，画面通透。Deep focus, starburst sun, golden hour, drone shot slowly rising.

### 模板 C：产品 / 美食视频

```
[产品描述]，浅景深聚焦[产品局部]，背景[环境]柔和虚化，
[材质/动态细节]清晰可见，[光线]，镜头缓慢推进。
Shallow DOF, sharp focus on [detail], soft blurred background, slow push-in.
```

### 模板 D：旅游打卡 / Vlog

```
[人物]在[地标场景]前[动作]，中等景深，人物与背景地标都清晰，
自然光，生活气息，手持镜头轻微晃动感。
Moderate depth of field, both subject and landmark in focus, handheld feel.
```

### 模板 E：焦点叙事（进阶）

```
前景[前景物体]虚化遮挡，焦点从前景缓慢转移到[主体]，
rack focus，[主体]逐渐清晰，背景保持柔焦，电影叙事感。
Rack focus from foreground to subject, cinematic focus pull.
```

## 八、意图 → 光圈 → 提示词 决策流程（Agent 推理链）

```
用户意图
  │
  ├─ "突出人/物，背景不重要或很乱" → 浅景深（f/1.4–f/2.8 效果）
  │     → 提示词：shallow depth of field + bokeh + subject isolation
  │
  ├─ "人和场景都要看清（打卡/合影）" → 中景深（f/4–f/5.6 效果）
  │     → 提示词：moderate depth of field + both in focus
  │
  ├─ "风景/建筑/产品全貌，全都要清楚" → 深景深（f/8–f/11 效果）
  │     → 提示词：deep focus + edge-to-edge sharpness
  │
  ├─ "要太阳/灯光的星芒效果" → 极小光圈（f/16 效果）
  │     → 提示词：starburst sun / radiating light rays
  │
  ├─ "夜晚/暗光手持" → 最大光圈效果（f/1.4–f/2.8）
  │     → 提示词：浅景深 + 高感氛围 + 背景光斑
  │
  └─ "运镜叙事/焦点转移" → 浅景深 + rack focus
        → 提示词：focus pull / rack focus + cinematic
```
