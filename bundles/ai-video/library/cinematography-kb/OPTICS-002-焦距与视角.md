> **用途**：AI 视频生成系统的提示词知识库。供数字员工 / Agent 在生成视频提示词时检索调用。
> **主题编号**：OPTICS-002　**版本**：v1.0　**更新日期**：2026-09-24
> **使用方式**：Agent 接收到涉及"大场景、拉近背景、人脸显瘦、空间压缩、夸张透视"等创作意图时，检索本主题，将焦距档位换算为对应的画面语言写入提示词。**注意：AI 视频模型不理解毫米数本身，必须把焦距意图翻译成透视关系与画面效果描述**（见第六章映射表）。

## 一、核心概念

### 1.1 焦距是什么

焦距是镜头光学中心到成像平面的距离，用**毫米（mm）**表示。它决定的核心是**视角宽窄**和**空间透视关系**：

- **焦距越短**（如 14mm）→ 视角越宽 → 容纳的场景越大 → **近大远小的透视被夸张**，纵深拉长
- **焦距越长**（如 200mm）→ 视角越窄 → 只截取局部 → **远近物体的体积差被抹平**，空间被压缩

关键纠偏：**焦距不是"放大倍数"**。长焦"拉近"物体的本质，是改变了相机与被摄体的相对位置关系——用长焦拍，人会站得更远，前景和背景在画面中的大小比例随之改变。这就是为什么 200mm 能把远山"压"到人物身后，而 14mm 能让一条走廊显得深不见底。

记忆口诀：**"短焦拉纵深，长焦压空间；数字越小装得多，数字越大看得窄"**。

### 1.2 焦距的三大画面语言

| 作用 | 短焦距（14–35mm） | 长焦距（85–300mm+） |
|---|---|---|
| **视角** | 宽，一镜装下大场景 | 窄，只取局部特写 |
| **透视** | 夸张近大远小，纵深感强 | 压缩远近距离，前后景"贴在一起" |
| **变形** | 边缘拉伸畸变，近摄人脸变形 | 面部扁平化，五官更"端正" |

### 1.3 等效焦距与裁切系数（一句话带过）

不同画幅的相机，同一支镜头的实际视角不同，需乘以裁切系数换算为"全画幅等效焦距"（如 APS-C ×1.5、M43 ×2）。**本知识库所有焦距数值均指全画幅等效值**，Agent 无需换算，直接按档位调用即可。

### 1.4 虚化三要素（与 OPTICS-001 联动）

景深不只由光圈决定，完整公式是：

> **虚化强度 = 大光圈 + 长焦距 + 近摄距 + 远背景**

- 同样 f/2.8，85mm 比 35mm 虚化强得多
- 200mm 即使 f/5.6，也能拍出奶油般的背景
- 提示词组合技巧：想要强虚化时，写"长焦镜头 + 大光圈 + 主体远离背景"，比单写光圈效果更稳定（详见 OPTICS-001 第 1.3 节）。

## 二、焦距档位全表（核心速查）

| 焦距段 | 视角特征 | 典型题材 | 画面语言关键词 | 易翻车点 |
|---|---|---|---|---|
| **14–24mm 超广角** | 极宽，边缘拉伸，纵深夸张 | 建筑、室内、大场景风光、沉浸 Vlog | 夸张透视、宏伟、视觉冲击力 | 人脸放边缘立刻变形；地平线歪斜即废片 |
| **35mm 人文视角** | 略宽，带环境叙事 | 街拍、纪实、环境人像 | 临场感、故事感、所见即所得 | 视角"平庸"，构图能力要求高 |
| **50mm 标准视角** | 接近人眼单眼视角 | 日常记录、访谈、叙事视频 | 自然、真实、无畸变 | 容易拍得"白开水"，需要内容本身撑 |
| **85mm 人像甜点** | 窄，面部比例最舒服 | 人像特写、半身像 | 柔和压缩、背景分离、显瘦 | 室内施展不开，需退很远 |
| **135–200mm 长焦** | 很窄，空间压缩明显 | 舞台、街拍"偷拍感"、风光局部 | 背景拉近、层次压缩、主体悬浮 | 抖动放大，手持视频基本不可行 |
| **300mm+ 超长焦** | 极窄，压缩奇观 | 打鸟、月亮悬日、体育 | 日月巨大化、远景贴脸 | 需三脚架/增稳，空气质量影响画质 |

### 原始口诀扩展解读（保留原口诀骨架）

> 原口诀：超广出气势 → 35 讲故事 → 50 最真实 → 85 拍人像 → 长焦压空间 → 300 打月亮。

- **超广角 14–24mm —— 气势制造机**：把镜头怼近前景（一块石头、一朵花），前景巨大、远景渺小，画面张力瞬间拉满。拍建筑和室内空间显大显气派。代价：边缘拉伸畸变，人脸放画面边缘会变成"外星人"，拍人必须把脸放中心。
- **35mm —— 讲故事的视角**：比人眼稍宽，能带进人物周围的环境信息，"他在哪、在干什么"一镜说清，是纪实和人文视频的主力。缺点是不突出任何人——构图、光线、瞬间全靠功力。
- **50mm —— 最接近人眼**：透视关系与人眼习惯一致，观众看这类画面时"无感"，注意力全在内容上。访谈、叙事、日常记录的安全牌。风险是平淡——没有广角的气势也没有长焦的压缩，画面好不好看全看拍什么。
- **85mm —— 人像甜点位**：站距适中，面部五官比例自然不畸变，配合大光圈背景柔和分离，"糖水片"标配。视频访谈、情绪特写几乎无脑选它。室内小空间慎用——退无可退时只能拍到一颗头。
- **135–200mm —— 空间压缩机**：背景被"拉"到主体身后，一条普通的街能拍出人流贴脸的密度感。缺点：轻微手抖在画面里都是地震，视频必须上稳定器或三脚架。
- **300mm+ —— 奇观档**：让落日、月亮变得巨大悬在人物/建筑身后，是社交平台爆款画面的来源。门槛：三脚架、好天气、长距离无遮挡，缺一不可。

## 三、广角变形 vs 长焦压缩（正确与错误用法）

### 3.1 广角近摄变形

**原理**：广角镜头近大远小的透视被放大，离镜头近的物体（鼻子、手）异常大，远的（耳朵、身体）异常小。

| 用法 | 场景 | 效果 |
|---|---|---|
| ✅ 正确 | 人脸放画面中心、保持平视距离 | 视角开阔带环境，人脸正常 |
| ✅ 正确 | 怼近前景拍风光/建筑 | 前景巨大、纵深夸张，视觉冲击 |
| ✅ 正确 | 低角度拍宠物/儿童 | 夸张可爱感，萌系视频常用 |
| ❌ 错误 | 人脸贴近画面边缘 | 边缘拉伸，脸变宽变形 |
| ❌ 错误 | 近距离俯拍人脸 | 大鼻子小耳朵，"车底视角" |
| ❌ 错误 | 竖拍全身且机位过低 | 腿长逆天但比例诡异 |

### 3.2 长焦空间压缩

**原理**：长焦拍摄时相机离主体远，主体与背景的距离在画面中被"折叠"，远景显得又大又近。

| 用法 | 场景 | 效果 |
|---|---|---|
| ✅ 正确 | 人物 + 远处建筑/山/落日 | 背景巨大贴近，史诗感 |
| ✅ 正确 | 街道纵深方向拍人流车流 | 密度感，城市脉搏 |
| ✅ 正确 | 舞台/运动抓拍 | 主体从环境中"抠"出来 |
| ❌ 错误 | 狭窄室内硬上长焦 | 只能拍到局部，构图局促 |
| ❌ 错误 | 手持长焦拍运镜视频 | 抖动灾难，观众眩晕 |
| ❌ 错误 | 压缩 + 大光圈 + 移动主体 | 景深极浅，一移动就脱焦 |

## 四、视频拍摄的特有规则（与拍照不同，Agent 必须知道）

1. **焦距越长，抖动越放大**：24mm 下手持微晃可以接受，200mm 下同样的抖动是灾难。经验法则——手持视频的安全焦距上限约 **35mm**，50mm 需要稳定身体或倚靠，**85mm 以上务必稳定器/三脚架**。
2. **广角是手持和运镜之友**：超广角 + 小幅移动（行走跟拍、低角度横移）容错极高，画面天然带稳定感。Vlog、第一视角、穿越机感镜头首选 14–24mm。
3. **长焦运镜要"慢"**：长焦下任何快速摇移都会产生画面眩晕感（strobing），提示词如涉及 135mm+ 运镜，建议描述"极缓慢平移"或"固定机位"。
4. **长焦浅景深叠加效应**：虚化 = 光圈 + 焦距 + 摄距（见第 1.4 节）。135mm f/2.8 的景深比 35mm f/1.4 还浅，**长焦视频中主体移动极易脱焦**，生成提示词时建议主体相对静止或缓慢移动。
5. **焦距决定运镜语言**：广角推近 = 冲击力；长焦平移 = 观察感/窥视感；标准焦距手持 = 纪实临场感。生成提示词时焦距与运镜要成套描述（详见 CINE-001 运镜语言）。
6. **变焦镜头 vs 定焦**：AI 视频模型不理解变焦过程（zoom），"镜头从 24mm 变到 200mm"要翻译成 dolly zoom（滑动变焦/希区柯克变焦）或干脆描述为两个镜头。

## 五、常见误区（生成提示词时的纠错规则）

| 误区 | 纠正 |
|---|---|
| "长焦拍得远就是好镜头" | 焦距是视角选择不是性能指标，各档位服务不同题材 |
| "广角显脸小" | 广角边缘拉伸会拉宽脸；显瘦要靠 85mm 的柔和压缩 |
| "焦距就是放大倍数" | 焦距改变的是透视关系（近大远小的比例），不只是大小 |
| "虚化全靠光圈" | 长焦同样强虚化，200mm f/5.6 胜过 35mm f/1.8（联动 OPTICS-001） |
| "长焦画质更好" | 长焦吃光线、吃稳定、吃空气质量，手持出片率反而低 |
| "毫米数写进提示词模型就懂" | 多数视频模型只认画面效果描述，要翻译（见第六章） |
| "拍视频和拍照片选焦距逻辑一样" | 视频有抖动放大问题，焦距上限受稳定条件约束 |

## 六、创作意图 → 提示词关键词映射表（Agent 核心调用区）

### 6.4 氛围叠加词（与焦距效果配合使用）

- 广角氛围：宏伟 epic、沉浸 immersive、冲击 dramatic、辽阔 sweeping
- 长焦氛围：史诗感 monumental、静谧 serene、梦幻压缩 dreamy compression、孤立 isolation
