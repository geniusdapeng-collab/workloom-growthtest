# 科技数码/产品测评短视频默认背景要求规范

> **适用范围**：本规范作为短视频生成系统的**默认约束**，当内容主题为"科技数码/产品测评"（T4）时自动生效。覆盖：手机/数码产品测评、科技新品开箱、软件/APP 演示、智能硬件种草、科技资讯解读。
> **核心目标**：科技内容的观众默认"**场景的专业度 = 测评的可信度**"。一个极客感的工作台是免费的专业背书，一个杂乱的桌面会让所有参数解读都打个问号。产品本体的质感呈现永远是第一位。

---

## 一、背景与定位

科技测评的观看心理是"帮我做购买决策"，观众要的是**专业、客观、有细节**。画面的任务是营造"这个人很懂、这个设备很强"的双重信任。

**默认人物设定**：懂产品的极客/编辑/工程师人设，表达理性有逻辑，偶尔有真诚的惊喜感。
**核心调性关键词**：科技感、理性、极简、冷调、未来感、精密、专业。

**本主题的色调特权**：科技测评是少数**允许暗调**的主题（例外于通用明亮底线），但必须"暗而高级"——暗是氛围，亮是产品，产品本体永远打亮打透。

---

## 二、镜头与画面内容规范

### 2.1 画面丰富度
- 产品是绝对主角：**外观 360°、材质工艺、接口按键、屏幕显示、上手手感**，一个维度都不能缺。
- 功能演示必须"眼见为实"：跑分、实拍样张、游戏帧率、充电计时——**演示画面 > 口头宣称**。

### 2.2 镜头类型配比（每个成片默认约束）
| 镜头类型 | 占比要求 | 用途 |
|---|---|---|
| 产品特写（材质/细节/工艺） | ≥ 40% | 科技片的核心资产 |
| 功能演示镜头（屏幕/操作/实测） | ≥ 25% | 可信度的直接来源 |
| 人物讲解镜头 | 20%–30% | 观点输出与信任建立 |
| 环境氛围镜头 | ≤ 10% | 定调极客感，点到为止 |
| 运动镜头 | ≥ 30% | 环绕产品、微距推进、滑轨平移 |

### 2.3 产品镜头要求
- **环绕镜头必备**：产品 360° 缓慢旋转（转盘或滑轨环绕），完整呈现工业设计。
- **微距特写**：CNC 切边、镜头模组、纹理质感、Logo 蚀刻——工业精密度靠微距说话。
- **屏幕内容必须真实**：屏摄画面清晰无摩尔纹，UI 界面与所讲述功能严格对应。
- 拆箱镜头：保留开箱仪式感（撕膜、阻尼开盒），但节奏要快，不拖泥带水。

---

## 三、色调与视觉风格规范

### 3.1 总体色调
- 默认**冷调科技感**：深灰、藏蓝、黑色基底 + 品牌色/灯效点缀。
- 极简浅色路线（适合苹果系/生活方式科技）：白、浅灰、原木色 + 大面积留白。
- 两条路线二选一，**禁止冷暖混搭的"四不像"桌面**。

### 3.2 光线要求
- **暗调场景的光比控制**：环境暗、产品亮——轮廓光勾勒产品边缘，产品本体无死黑。
- 允许 RGB 灯带/屏幕光效点缀背景，但**色光不可污染产品本色**（产品色彩必须真实）。
- 屏幕拍摄：必须避免频闪条纹、摩尔纹、反光——屏摄质量是科技片的硬指标。
- 人物面部：即使在暗调场景中，面部主光依然充足柔和。

### 3.3 空间质感（默认基准）
| 场景类型 | 适用内容 | 关键质感元素 |
|---|---|---|
| 极简测评桌面 | 开箱、测评、对比 | 深色岩板/浅色木纹桌面、显示器、机械键盘、一盏屏幕挂灯 |
| 科技感工作台 | 深度评测、拆机 | 多屏工作站、灯带、工程设备、工具墙（整洁有序版） |
| 纯色棚拍 | 产品特写、官方感内容 | 无缝背景（黑/白/渐变）、倒影板、精准布光 |
| 实景使用场景 | 体验类内容 | 通勤、办公、户外（按产品定位匹配，画面需干净） |

## 四、口播与表达规范

### 4.1 表达形式（默认白名单）
- **桌面讲解式**：人物 + 工作台场景，手持产品讲解（主流形式）
- **纯产品演示式**：无人出镜，产品特写 + 字幕 + 音乐（官方感/高质感路线）
- **数据实测式**：屏幕录制/仪器画面 + 画外音解读（硬核内容）

### 4.2 表达调性
- 风格：**理性、有依据、结论明确**。参数必须准确（芯片型号、规格数据说错 = 人设崩塌）。
- 优缺点都讲 = 可信度来源；全程无缺点 = 一眼恰饭，信任破产。
- 禁止：夸张震惊体（"颠覆！革命！"）、参数口嗨无实测支撑、拉踩竞品的引战话术（合规风险）。

---

## 五、人物与服化道规范

- **服装**：简约质感休闲（纯色 T 恤/卫衣/衬衫），黑灰白藏青为主；禁止花哨图案、大 logo。
- **手部**：产品上手镜头极多——指甲干净、无夸张饰品，手表可加分（极客人设道具）。
- **状态**：语速偏快但吐字清晰，有"我对这东西很熟"的松弛专业感。
- **道具**：桌面设备是人物背景板的一部分——显示器、键盘、音箱需质感统一，禁止杂牌拼凑感。

---

## 六、场景黑名单（AI 默认禁止生成）

1. **杂乱桌面**：线缆缠绕、零食饮料、杂物堆叠——科技测评第一大减分项
2. **生活化背景**：卧室床铺、沙发茶几的居家感场景（生活方式科技品类除外，需精致版）
3. **廉价道具**：塑料感背景布、杂牌外设、起皮的旧桌子、昏暗台灯
4. **屏摄事故**：摩尔纹、频闪条纹、屏幕反光、模糊截屏感画面
5. **光线翻车**：彩色灯光污染产品本色、产品死黑无细节、环境亮产品暗（喧宾夺主）
6. **过度特效**：廉价的赛博朋克滤镜、乱飞的全息 HUD 特效、抖音风闪光转场
7. **手持晃动**：测评镜头手持抖动的"随手拍"感（vlog 类除外，但仍需稳定底线）

## 七、生成前自检清单（系统默认校验项）

- [ ] 已确定冷调科技或极简浅色路线，桌面/场景统一？
- [ ] 产品特写占比是否 ≥40%，是否有 360° 环绕镜头？
- [ ] 产品本体是否打亮打透，色彩还原真实？
- [ ] 屏摄画面是否无摩尔纹、频闪、反光？
- [ ] 功能演示是否"眼见为实"（实测画面支撑结论）？
- [ ] 人物手部、桌面设备质感是否过关？
- [ ] 暗调场景是否"暗而高级"（环境暗、产品亮、人脸亮）？
- [ ] 参数与屏幕内容是否准确对应，无口嗨风险？

任何一项不达标，必须重新生成对应镜头的场景方案。

## 八、一句话总结

> 科技测评的画面里，**专业感是可以被看见的**——用微距下的工艺细节、真实无纹的屏幕画面和一张干净的极客桌面，让观众还没听到结论就先信了三分。
