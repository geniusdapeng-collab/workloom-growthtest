# 美妆时尚/穿搭短视频默认背景要求规范

> **适用范围**：本规范作为短视频生成系统的**默认约束**，当内容主题为"美妆时尚/穿搭"（T7）时自动生效。覆盖：美妆教程、妆容展示、穿搭分享、时尚品牌内容、饰品/箱包种草、形象改造类内容。
> **核心目标**：美妆时尚赛道的观众对审美**极度敏感且挑剔**——场景即品位宣言，场景的审美水位线就是观众对博主/品牌的品位判断。宁可空，不可滥；宁可简，不可俗。

---

## 一、背景与定位

美妆时尚内容的本质是**贩卖审美**。观众用 3 秒判断"这个人的审美值不值得我参考"，而判断依据一半是妆容穿搭本身，另一半是画面里的一切——背景、光线、色调、道具。

**核心调性关键词**：时尚、精致、高级、氛围感、杂志感、干净、有呼吸感。

**审美分级默认**：
- 高奢/大牌内容 → 对标时尚杂志大片与品牌广告
- 日常美妆/穿搭 → 对标精品买手店与生活方式杂志
- 平价种草 → 至少达到"干净明亮的精致感"，底线参照 T5 电商规范

## 二、镜头与画面内容规范

### 2.1 画面丰富度
- 妆容类必须有**特写级呈现**：眼妆、唇妆、底妆质感、上妆手法，一个都不能少。
- 穿搭类必须有**全身 + 半身 + 细节**三级镜头：整体造型、搭配逻辑、面料配饰细节。

### 2.2 镜头类型配比（每个成片默认约束）
| 镜头类型 | 占比要求 | 用途 |
|---|---|---|
| 妆容/产品特写 | ≥ 30%（美妆类） | 妆效质感是内容本体 |
| 全身/造型镜头 | ≥ 25%（穿搭类） | 整体效果与比例 |
| 细节特写（面料/配饰/手法） | ≥ 20% | 精致感的直接证据 |
| 中景人物镜头 | ≥ 20% | 人物气质与场景氛围 |
| 运动镜头 | 20%–35% | 缓慢环绕、跟随转身、细节推进；禁止快切晃镜 |

### 2.3 关键镜头要求
- 妆容特写必须**皮肤质感真实**：保留皮肤纹理的高级感，禁止磨皮磨成"硅胶脸"。
- 穿搭必须有**动态镜头**：行走、转身、回眸——衣服的垂坠感和动态美只有动起来才有。
- 变装/改造类：Before 画面也要整洁有光，**反差靠妆容造型，不靠丑化前期**。

## 三、色调与视觉风格规范

### 3.1 总体色调
- 允许**低饱和高级灰调、莫兰迪色系、奶油色调**——这是本主题的风格特权。
- 但"高级灰"≠"脏灰"：灰调必须干净通透，有明度层次，禁止灰蒙蒙一片的雾霾感。
- 妆品色彩还原必须**绝对真实**：口红、眼影色号失真 = 种草变拔草 + 退货。

### 3.2 光线要求
- **柔光是本主题的生命线**：大面积柔光（环形灯/柔光箱/窗边自然光），皮肤通透有光泽。
- 面部无硬阴影、无油光、无鼻影黑洞；眼神光必备（眼睛里的光点 = 灵动感）。
- 允许氛围感暗调（夜景、霓虹、烛光），但必须"暗而精致"：面部主光永远充足。
- 禁止：强黄光（显肤色蜡黄）、彩色灯光污染肤色、顶光（显法令纹与眼袋）。

### 3.3 空间质感（默认基准）
| 场景类型 | 适用内容 | 关键质感元素 |
|---|---|---|
| 杂志感纯色空间 | 高奢、妆容特写 | 无缝背景、高级灰/米色/莫兰迪色、一盏设计感灯 |
| 精品店氛围 | 穿搭、品牌内容 | 拱门、艺术墙、落地镜、衣架陈列（克制版） |
| 精致梳妆区 | 美妆教程 | 整洁化妆台、带灯化妆镜、化妆品有序陈列 |
| 生活方式空间 | 日常穿搭、vlog 感 | 设计感客厅一角、窗边、质感床品（卧室仅限"精致床角"） |
| 街拍场景 | 穿搭、时尚大片 | 有设计感的建筑立面、干净的街道、咖啡馆外摆（避开杂乱街景） |

## 四、口播与表达规范

### 4.1 表达形式（默认白名单）
- **教程讲解式**：边化边讲/边搭边讲，语气像"品味好的闺蜜"
- **展示式**：无人声，纯画面 + 音乐 + 字幕（高奢内容优先，音乐品位要求极高）
- **分享式**：对镜讲述好物与心得，真诚松弛

### 4.2 表达调性
- 语气：**自信、松弛、有审美主张**——"我觉得这样更美"优于"这样肯定好看"。
- 禁止：叫卖式催单、夸大妆效（"一抹换头"）、拉踩其他品牌的引战话术。
- 专业术语（色号、质地、工艺）必须准确——时尚观众会逐帧纠错。

---

## 五、人物与服化道规范

- **皮肤呈现**：保留真实纹理与光泽，磨皮 ≤30% 感知度；禁止"硅胶脸""假白脸"。
- **发型**：整洁有光泽，碎发需打理（除非是精心设计的慵懒感）。
- **指甲**：手部特写前必须检查——美甲完整或素甲干净，禁止斑驳掉漆。
- **配饰**：少而精，一件亮点配饰 > 全身堆砌。
- **服装状态**：熨烫平整、无线头、无褶皱（慵懒风褶皱需是"设计好的褶皱"）。
- **镜前检查项**：口红无粘牙、眼妆无晕染、粉底无卡粉——特写镜头会放大一切。

## 六、场景黑名单（AI 默认禁止生成）

1. **出租屋感**：老旧家具、昏暗日光灯、杂乱电线、廉价塑料收纳
2. **杂乱化妆台**：化妆品东倒西歪、棉签纸巾散落、脏污的粉扑刷子入镜
3. **廉价网红风堆砌**：劣质 ins 风道具（掉漆字母灯、艳俗假花、起球地毯）、土味闪片背景布
4. **光线灾难**：强黄光、顶光、彩色灯污染肤色、频闪条纹
5. **过度滤镜**：磨皮成硅胶、美白成假人、口红变色、画面糊成"柔光雾"
6. **背景穿帮**：晾衣架、外卖盒、垃圾桶、无关路人、凌乱床铺
7. **自拍杆/镜子污渍**：对镜拍摄时镜面指纹水渍、手机壳廉价感入镜

## 七、生成前自检清单（系统默认校验项）

- [ ] 场景审美是否达到"杂志感/精品店感"水位线？宁空勿滥？
- [ ] 皮肤质感是否真实（保留纹理、无硅胶感）？
- [ ] 妆品/服装色彩还原是否绝对真实？
- [ ] 面部光线是否柔和均匀，有无黄光/顶光/油光问题？是否有眼神光？
- [ ] 妆容特写、细节特写、动态镜头是否齐备？
- [ ] 指甲、服装褶皱、镜面等细节是否经得起特写放大？
- [ ] 灰调/暗调风格是否"暗而精致"而非"脏灰雾蒙"？
- [ ] 道具是否克制，有无廉价网红风堆砌？

任何一项不达标，必须重新生成对应镜头的场景方案。
