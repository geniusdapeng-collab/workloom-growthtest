# 获客增长 C 前台原子能力

`../agent-capabilities.json` 声明了四个能力：查询本人工单、预览合作需求、提交合作需求、核对工单进度。查询与核对沿用 C 网关的通用工单接口，可能返回咨询以外的类型；每次查询最多返回最近 100 条。PC、员工移动端和客户 H5 仍使用现有服务。命令入口当前可读工单及本地预览，提交入口保持关闭。服务端决定工作区、身份、归口和事件回执；活动行业包不可用时，当前工单链会使用通用部门兜底。

## 会话与数据状态

`c-service` 入口必须从 `WORKLOOM_C_TOKEN` 读取当前 C 会话令牌，按 `Authorization: Bearer <c-token>` 请求同源 `/c/...`。没有令牌时失败关闭。令牌通过独立的 `POST /c/session` 获取；正式 H5 入口需要受信方签发的短期 `entryToken` 与匹配的 `workspaceKey`。开发态显式启用 `SERVICE_C_DEMO_AUTH=true` 时，可用 `channel=h5` 与临时 `openid` 建演示会话。令牌不放入命令参数、仓库文件或日志。

预览函数只校验调用方提供的 JSON，与服务端实际授权或落库结果无关。当前通用 C 工单接口可在活动行业适配器不可用时使用通用部门兜底；本地选择 `geo-growth` 能力目录不能证明 C 令牌所属工作区正在运行该行业包。提交能力在公共 C 工单幂等跨用户隔离修复、服务端活动 `geo-growth` 行业包绑定及受控同步回归前保持 `enabled:false`。当前 C 网关可将工单真实写入数据库与事件账本，但回执中的 `demo:true` 和通知 `delivery.state=demo` 表示外部通知未真实送达；能力声明使用 `dataMode:simulated`，不能把该回执当作外部同步完成。

`execute` 输入必须有至少 8 字符的 `idempotencyKey`；预览中若提供该字段，也按同一长度门槛校验。同一键重试只能对应同一 C 用户和同一请求内容；服务端修复与回归验证完成后才可启用。`receipt` 以工单编号查本人时间线，不能据此推断服务顾问已完成处理。
