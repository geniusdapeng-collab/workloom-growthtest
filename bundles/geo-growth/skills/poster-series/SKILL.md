# 系列海报（Poster Series）

## 适用场景
- 24 节气问候、节日营销、上新倒计时、周年庆、月度主题等需要「一眼成套」的排产

## 方法
1. 先定「系列三件套」：主视觉规则（构图/色板/字体）+ 版式骨架 + 变量表（日期/节气名/主题句）；
2. 用同一 recipe 模板批量出图；变量表一行一张，命名带序号与日期；
3. 系列内保持同一角标/边框/落款位置，形成识别度；
4. 排产节奏：按月一次排完，交给发布岗位按日分发；
5. 每张出图后过 `brand-guard` 抽检（≥30% 抽检率，首月全检）。

## 输出契约
- 系列成品 + 变量表 + recipe + 回执；变量表可复用为下一年度模板。

## 边界
- 节日文案不得编造习俗/数据；使用传统纹样素材需确认授权；
- 系列不改事实性内容，仅做表达与版式变化。

| 条件 | 做法 | 判据 | 来源 |

| 批量出图 | 同一 recipe；变量表一行一张 | 命名带序号与日期，可回溯 | KB:本套件 §方法 2 |
| 系列识别度 | 同一角标/边框/落款位置 | 系列内保持一致 | KB:本套件 §方法 3 |

| 抽检 | `brand-guard` 抽检 **≥30%**（首月全检） | 抽检不合格批次全量复查 | KB:本套件 §方法 5 |

## 参数边界

1. 系列**抽检率 ≥30%**；首月**全检**。不合格批次必须全量复查。
2. 系列内角标/边框/落款位置必须一致；单张偏离即重排。
3. 变量表必须**一行一张**且命名含序号与日期，缺项不得排产。
4. 节日文案不得编造习俗/数据；传统纹样需授权。
5. 系列只做表达与版式变化，**不改事实性内容**。

## 失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 系列里某张风格游离 | 系列一致性检查（角标/边框/落款） | 用同 recipe 重出该张 |
| 日期/节气名写错 | 变量表与成图对账 | 更正变量表并重出；错版撤回 |
| 抽检不合格但已批量分发 | 抽检记录与发布记录对比 | 停止发布、全量复查、已发内容按需替换 |
| 编造习俗/数据 | 事实核查（与权威来源比对） | 改写为可核实表述；无法核实则删 |
| 使用未授权纹样 | 授权证据检查 | 换素材；已发内容撤回 |
| 变量表缺项导致漏排 | 变量表完整性检查 | 补齐后重排，不得"漏几张算完" |
