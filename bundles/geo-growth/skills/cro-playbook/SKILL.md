# 承接转化 CRO

## 适用场景
- "询盘接住了但转化不动"的摩擦诊断与改法设计；
- 落地页/表单/话术/券包装的变体实验。

## 触发条件
- 某一段转化率持续低于基线、流量结构变化、竞对 offer 变化。

## 输入数据
- 各段转化率与停留/跳出、表单字段完成率、话术与券包装版本、客户反馈与退款原因。

## 方法
1. **逐段诊断**：访问→留资→询盘→报价→成交，每段算"摩擦率"，先修最大漏点。
2. **变体设计**：一次只改一个主要变量（结构/字段/话术/包装），变量与假设写进实验卡。
3. **可理解性**：30 秒看懂值不值；价格与权益表述与大仓口径一致，不夸大、不承诺。
4. **A/B 纪律**：交增长实验官登记与判定，未显著不上线；上线可回滚。
5. **负反馈闭环**：驳回原因、退款原因、投诉关键词回流到下一轮变体设计。

## 边界（什么不做）
- 价格/折扣/绑定承诺一律 L4（G-GROW2）；
- 不做内容生产与发布执行；不私自上线变体；
- 事实表述与品牌实体卡逐字一致（G-GEO2 前置校验）。

## 决策原则（含阈值与失败关闭）
1. **一次只改一个主要变量**：结构/字段/话术/包装四类不同时改；变量与假设进实验卡。
2. **30 秒可理解**：价格与权益表述与大仓口径一致；夸大与承诺一票否决（G-GROW2）。
3. **A/B 纪律**：未显著不上线；上线必须可回滚；变体交实验官登记。
4. **负反馈闭环**：驳回/退款/投诉关键词必须回流下一轮变体设计，未回流视为无效迭代。

## 打法库（场景 → 动作序列 → 判据）
- **主线·逐段摩擦诊断**：访问→留资→询盘→报价→成交逐段算摩擦率 → 先修最大漏点（判据：漏点修复后段落转化提升）。
- **分支·表单优化**：字段数/顺序/校验文案变体（判据：完成率显著提升）。
- **分支·券与报价包装**：可理解性重构（30 秒看懂值不值）→ 价格类走 L4（判据：G-GROW2 审批通过）。

## SOP（每步带触发/回执/失败路径）
1. 触发（某段转化低于基线/流量结构变化）→ 诊断 → 回执：摩擦与漏点报告；失败：数据不足标不可判定。
2. 变体设计与登记 → 实验官判定 → 回执：实验卡与结果；失败：未登记不得上线。
3. 上线与回流 → 负反馈收集 → 回执：迭代记录；失败：投诉未处理即冻结该变体。

## 关键指标（含基准与护栏）
| 指标 | 口径 | 基准/阈值 | 类型 |
|---|---|---|---|
| 段落转化率 | 各段转化 | 环比提升 | 滞后 |
| 表单完成率 | 完成/开始 | 环比提升 | 领先 |
| 变体胜率 | 显著胜/上线实验 | ≥30% | 质量 |
| 承诺类驳回 | 驳回数 | 0 值得上线的承诺稿 | 护栏 |

## 失败模式（症状 → 检测器 → 处置）
| 症状 | 检测器 | 处置 |
|---|---|---|
| 多变量同改 | 实验卡变量审计 | 拆分实验重跑 |
| 夸大表述 | G-GROW2/G-GEO2 拦截 | 驳回 + 文案校准 |
| 未登记上线 | 上线审计 | 回滚 + 补登记 |
