# 短视频封面（Video Cover）

## 适用场景
- 抖音/视频号/TikTok/YouTube Shorts 的竖版封面（9:16）与主页三连封面（统一版式、不同钩子）
- 与脚本成套包联动：标题即前 3 秒钩子，封面文字与口播一致

## 输入
- 脚本成套包（标题/钩子/卖点）；成片抽帧或 AI 生成主视觉；平台规格（1080×1920）。

## 方法
1. 钩子分级：疑问式 / 冲突式 / 利益式，各出一版（同主体不同文案）；
2. 主标题 ≤ 9 字/行、最多两行，字号 ≥ 96px（1080 宽画布）；底部 320px 为平台 UI 遮挡区，不放大字；
3. 主体居中偏上，人脸/产品不被文字压住；必要时用调整层压暗背景提高对比；
4. 三连封面用同一模板、同一字体与色板，仅换钩子与序号；
5. `visualwrite.compose` 渲染 → `visualread.verify` 校验。

## 输出契约
- 每版：PNG + recipe + sha256；三连封面成套交付（3 张同版式变体）；
- 封面文案与脚本标题逐字一致，不改写事实。

## 边界
- 不做「标题与内容不符」的钩子党；极限词、医疗金融承诺禁入（G-VIS2）；
- 不在封面堆叠超过 3 层文字；不使用未授权字体。

## 参数边界

1. 主标题 **≤9 字/行、≤2 行**；字号 **≥96px**（1080 宽画布）。
2. 底部 **320px 平台 UI 区**不得放文字；墨迹与遮挡区零相交。
3. 文字层**不超过 3 层**；超层即重排。
4. 封面文案与脚本标题**逐字一致**；禁止"标题党"式改写。
5. 极限词/医疗金融承诺禁入（G-VIS2）；不使用未授权字体（G-SUB5）。

## 失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 文字被平台 UI 盖住 | 遮挡区相交检查（底部 320px） | 上移或缩行；不得靠"平台可能不显示"赌运气 |
| 缩略图看不清标题 | 缩略图可读性检查（字号/对比） | 提高字号或压暗背景，重出 |
| 封面与内容不符（钩子党） | 与脚本标题逐字比对 | 改回与内容一致；严重不符判不合格 |
| 三连封面风格不统一 | 模板/字体/色板一致性检查 | 用同一模板重排三张 |
| 人脸/产品被文字压住 | 主体与文字层重叠检查 | 重排主体或文字位置 |
| 字体未授权 | 字体白名单检查（G-SUB5） | 换授权字体后重出 |
