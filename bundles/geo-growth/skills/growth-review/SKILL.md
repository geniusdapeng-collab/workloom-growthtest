# 增长复盘

## 适用场景
- 周增长会、月度预算与实验组合复审、给公司 CEO/董事长的增长报告。

## 触发条件
- 每周一固定节拍；月度；CAC/ROI/转化率触发阈值时即时复盘。

## 输入数据
- 五环漏斗（曝光→互动→询盘→留资→成交→复购）、预算账本、实验账本（expected vs actual）、护栏指标。

## 方法
1. **三账合并**：结果账（归因成交额/CAC/ROI）、预算账（分配到哪、花了多少、增量多少）、实验账（胜/负/不确定、胜率、假阳性）。
2. **先说结论**：本周最重要的一个变化 + 原因 + 下周一个动作；数据放后面。
3. **漏环定位**：五环里最漏的一环 + 证据 + 修复方案（含需要的实验）。
4. **决策清单**：需要董事长/公司 CEO 拍板的事项不超过配额，每件给建议与依据。
5. **回测诚实**：命中就是命中，未命中写明"预期 vs 实际差在哪"。

## 边界（什么不做）
- 不做流水账式数据堆砌；不隐藏未命中的决策；
- 未归因到钱的结论标"推测"；不对外承诺未验证的效果。

## 决策原则（含阈值与失败关闭）
1. **三账合并**：结果账/预算账/实验账缺一不完整；只报结果不报预算与实验的复盘视为无效。
2. **先说结论后数据**：每次复盘第一句必须是"最重要的一个变化+原因+下周一个动作"。
3. **回测诚实**：命中就是命中，未命中写明预期 vs 实际差异；隐藏未命中即判缺陷。
4. **决策清单限配额**：需董事长/公司 CEO 拍板的事项不超配额，且每件带建议与依据。

## 打法库（场景 → 动作序列 → 判据）
- **主线·周增长会五件套**：五环漏斗/实验组合/预算执行/下周打法/待拍板（判据：全稿齐 + 结论前置）。
- **分支·漏环定位**：找最漏一环 → 证据 → 修复方案 + 实验需求（判据：修复项进 backlog）。
- **分支·月度单位经济**：社媒询盘/AI 搜索询盘/广告产出分列 + 单条内容成本/单询盘成本（判据：分列呈现不合并）。

## SOP（每步带触发/回执/失败路径）
1. 触发（周一 09:00 / 月 1 日 / 阈值告警）→ 三账取数 → 回执：数据快照；失败：缺账即标"未核实"并列出缺口。
2. 生成全稿 → 结论前置 + 漏环 + 决策清单 → 回执：报告版本；失败：超配额事项合并同类项或降级。
3. 会后跟踪 → 决策执行状态 → 回执：闭环台账；失败：未执行项进入下期"最重要变化"。

## 关键指标（含基准与护栏）
| 指标 | 口径 | 基准/阈值 | 类型 |
|---|---|---|---|
| 报告按时率 | 按时/应出 | 100% | 护栏 |
| 未命中披露率 | 披露/未命中 | 100% | 治理 |
| 漏环定位命中 | 次月验证命中/定位数 | ≥70% | 质量 |
| 决策闭环率 | 已执行/拍板事项 | ≥90% | 滞后 |

## 失败模式（症状 → 检测器 → 处置）
| 症状 | 检测器 | 处置 |
|---|---|---|
| 流水账式报告 | 结构审计（结论前置缺失） | 打回重写 |
| 隐藏未命中 | 与回测账本交叉比对 | 记录治理事件并通报 |
| 行动缺失 | 决策清单为空检测 | 强制补"下周一个动作" |
