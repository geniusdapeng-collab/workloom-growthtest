# 艺术指导（Art Direction）

## 触发
brief 确认后、动手排版前。

## 方法
1. **概念方向（2-3 个）**：每个方向一句话定位 + 情绪关键词 + 构图骨架 + 代表参考图（`visualwrite.fetch_stock` 拉取正版图库，或客户素材），说明适用与风险；
2. **选定方向**：由客户/运营选 1（或 AI 推荐 1 + 备选 1），记录选择理由；
3. **视觉规范**：色板（主/辅/强调/背景/文字，含对比度要求）、字体（中文衬线/黑体分工、字重层级、最小字号）、网格与留白规则、图文关系（全出血/分栏/卡片）；
4. **素材策略**：
   - 客户实拍/视频抽帧（首选，授权明确）；
   - 正版图库（Unsplash/Pexels CDN，经 `fetch_stock` 落库并写 license sidecar）；
   - AI 生图（`visualwrite.generate`，需配置模型与 key；生成图必须带 AI 标识）；
5. **反模式清单**：程序化矢量冒充产品摄影、文字压主体高光、促销色滥用、每张图超过 3 个信息块、同一画面双主语。

## 输出契约
- `art-direction.md`：方向、色板、字体、网格、素材清单与授权；
- 参考图落 `assets/`，附 license.json；AI 生图附 prompt 与模型版本。

## 边界
- 不选未授权素材；不承诺平台规格（以平台规格注册表为准，未核对条目只做内部预览）。

## 工艺判据（条件 → 做法 → 判据 → 来源）

| 条件 | 做法 | 判据 | 来源 |
|---|---|---|---|
| 开工前（brief 已确认） | 出 2–3 个概念方向（定位 + 情绪词 + 构图骨架 + 参考图） | 方向数 ≥2；每个方向必须写明"适用与风险" | KB:本套件 §方法 1 |
| 素材来源选择 | 客户实拍 > 正版图库 > AI 生图 | 越级使用须写明理由；AI 生图必须带 AI 标识 | KB:本套件 §方法 4 |
| 正版图库素材 | `visualwrite.fetch_stock` 落库 + license sidecar | 无 `.license.json` 的素材不得进配方 | KB:本套件 §输出契约 |
| 视觉规范落地 | 色板（主/辅/强调/背景/文字）+ 字体分工 + 网格留白 + 图文关系 | 色板含对比度要求；字体含最小字号 | KB:本套件 §方法 3 |
| 含人像/第三方素材 | 先走合规审 | G-VIS1 = review | KB:`fences/geo-growth-visual.yml#G-VIS1` |
| 反模式自检 | 程序化矢量冒充产品摄影 / 文字压主体高光 / 促销色滥用 / >3 信息块 / 双主语 | 命中任一即回炉重做 | KB:本套件 §方法 5 |

## 参数边界

1. 单张画面**信息块 ≤3**；同一画面**不得出现双主语**。
2. 文字**不得压在主体高光或关键细节**上（压暗/渐变垫底是允许手段，直接压字不允许）。
3. 素材优先级不得倒置：有客户实拍却用图库/AI 图，必须写明理由并经确认。
4. AI 生图必须带**可读 AI 标识**；未标识不得进入交付与发布。
5. 平台规格以 `templates/platform-specs.json` 为准；**未核对条目只做内部预览**，不得对外承诺。

## 失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 方向只有一个，客户无从选择 | 方向数检查（<2） | 补齐 2–3 个方向及风险说明后再进入选型 |
| 用了无授权的图库/AI 素材 | license sidecar 校验（缺 `.license.json`） | 阻断进配方；补授权或换素材 |
| 促销色/装饰堆满导致主体失焦 | 反模式清单比对 + `design-critique` 评审 | 按评审 top3 问题整改后复评 |
| AI 生图无标识 | 交付物清单校验（`ai_label`） | 补标识后再交付；无标识不得外发 |
| 平台规格未核对就对外承诺 | 规格表核对（未核对条目） | 撤回对外承诺，改内部预览或先核规格 |
| 文字压住主体高光 | 版面质检（文字层与主体层重叠） | 加底衬/换位/改文案长度后重排 |
