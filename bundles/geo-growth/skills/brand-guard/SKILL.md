# 品牌与合规质检（Brand Guard）

## 适用场景
- 批量出图后的统一质检；客户投诉/平台驳回后的复盘；新客户品牌包建包

## 检查清单（每批必过）
1. **品牌锚点**：品牌名/LOGO/主色/字体与品牌包一致；LOGO 清晰区 ≥ 0.5× 字号；
2. **事实一致**：价格、参数、活动规则与实体卡/确认单逐字一致；
3. **素材授权**：肖像（G-VIS1）、字体商用授权、第三方素材来源；
4. **文案合规**：极限词/绝对化/医疗金融承诺（G-VIS2 词表）；
5. **AI 标识**：AI 生成或辅助生成的画面含可读标识；
6. **技术质量**：尺寸/分辨率/透明底/文字不溢出安全区；`visualread.verify` 通过；
7. **回执齐全**：每张成品有 sha256 与工程文件。

## 输出契约
- 质检报告（逐项 pass/fail + 证据）+ 驳回清单（原因枚举 + 修复建议）；
- 质检结论写回一客一档；不合格不得进入发布队列（G-VIS5）。

## 边界
- 质检不做「美化式放行」；与事实/授权冲突时一票否决并升级人审。

## 参数边界

1. LOGO 清晰区 **≥0.5× 字号**；低于该值判锚点不合格。
2. 价格/参数/活动规则必须与实体卡**逐字一致**（含单位、口径、有效期）。
3. 极限词/绝对化/医疗金融承诺**零容忍**（命中即 block），不接受"改一点点"。
4. AI 生成或辅助生成的画面**必须有可读 AI 标识**。
5. 质检**不做美化式放行**；与事实/授权冲突时一票否决并升级人审。

## 失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 价格/参数与实体卡不一致 | 逐字比对 | 一票否决：改回实体卡口径，重出并复检 |
| 极限词漏检导致平台驳回 | 词表比对（G-VIS2） | 阻断并修文案；把该词补进客户禁区清单 |
| 未授权字体/素材进成品 | 授权证据检查 | 撤回成品，换授权素材后重出 |
| AI 图缺标识 | AI 标识检查 | 补标识；补不了则换非 AI 素材 |
| 文字溢出安全区 | `visualread.verify` + 安全区检查 | 重排（缩字号/换行/换边）后复检 |
| 无回执就进发布队列 | G-VIS5 回执检查 | 阻断外发，补 sha256/工程文件 |
| 质检记录缺证据无法复盘 | 报告证据链检查 | 补证据；无证据的"通过"视为未质检 |
