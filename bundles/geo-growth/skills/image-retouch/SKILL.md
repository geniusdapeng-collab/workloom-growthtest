# 商品图精修（Image Retouch）

## 适用场景
- 客户实拍图/视频抽帧的商用级处理：去背换底、色调统一、背景虚化、锐度与尺寸规范

## 方法
1. 去背：`remove_background: true`（Vision 前景蒙版）；毛发/透明材质失败时改走人工或用蒙版微调；
2. 边缘：用 `mask` 图层做 1–2px 收缩，避免白边；
3. 色调：调整层组合——曝光（±0.5 档）→ 色阶（黑白点）→ 曲线（S 形微对比）→ 渐变映射（品牌色调统一）；
4. 背景：纯色/渐变垫底 + 轻投影；需要氛围时用 `blur` 虚化原始背景作为底图；
5. 校验：主体像素完整、无锯齿、导出尺寸符合平台（`visualread.verify`）。

## 输出契约
- 去背 PNG（透明底）+ 成品图 + recipe + 回执；
- 保留原始素材引用与处理参数，保证可复现。

## 边界
- 不做虚假修饰（改变产品外观/材质/尺寸比例）；不得用 AI 补出不存在的产品结构；
- 含人像素材必须过 G-VIS1。

## 工艺判据（条件 → 做法 → 判据 → 来源）

| 条件 | 做法 | 判据 | 来源 |
|---|---|---|---|
| 去背 | `remove_background: true`（Vision 前景蒙版） | 主体像素完整、无锯齿、无白边 | KB:本套件 §方法 1/5 |
| 毛发/透明材质去背失败 | 改人工或蒙版微调 | 不得直接交付带缺口的蒙版 | KB:本套件 §方法 1 |
| 边缘 | `mask` 图层收缩 1–2px | 白边可见即判不合格 | KB:本套件 §方法 2 |
| 色调统一 | 曝光（±0.5 档）→ 色阶 → 曲线（S 形微对比）→ 渐变映射 | 四步顺序不可跳；不做磨皮式过度处理 | KB:本套件 §方法 3 |
| 背景 | 纯色/渐变垫底 + 轻投影；氛围需要时用原背景虚化 | 背景不得与主体争夺注意力 | KB:本套件 §方法 4 |
| 尺寸与格式 | 导出符合平台规格（`visualread.verify`） | 尺寸/字节数/sha256 逐项核对 | KB:本套件 §方法 5 |
| 含人像 | 先走合规审 | G-VIS1 = review | KB:`fences/geo-growth-visual.yml#G-VIS1` |

## 参数边界

1. 边缘收缩 **1–2px**；低于 1px 白边残留，高于 2px 会啃主体。
2. 曝光调整 **≤±0.5 档**；超出即可能改变产品本色，须回到素材/拍摄解决。
3. **不做虚假修饰**：不得改变产品外观、材质、尺寸比例；不得用 AI 补出不存在的结构。
4. 处理必须**可复现**：保留原始素材引用 + 处理参数 + recipe。
5. 含人像素材未过 G-VIS1 不得进入交付。

## 失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 去背后主体缺角/锯齿 | 主体像素完整性检查 | 改人工蒙版或补拍；不得交付破损主体 |
| 白边/灰边残留 | 边缘检查（1–2px 收缩是否执行） | 重做边缘收缩并复检 |
| 产品颜色被调偏（与实体卡不符） | 与实体卡/原图色值比对 | 回退该调整；必要时回到原素材重做 |
| 用 AI 补出不存在的结构 | 与原始素材逐处比对 | 判不合格：撤回成品，回上游重拍/换素材 |
| 导出尺寸不符合平台 | `visualread.verify` 宽高比对 | 按规格重出后交付 |
| 处理参数未留档，无法复现 | 工程与参数留痕检查 | 补留痕；无留痕不得宣称交付完成 |
