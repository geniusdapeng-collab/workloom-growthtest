# 促销活动图（Promo Banner）

## 适用场景
- 大促（618/双 11）、节日（春节/中秋）、上新与直播预热的活动主图与落地页头图

## 方法
1. 信息优先级：活动名 > 利益点（立减/赠品/免邮）> 时间 > 门槛说明；
2. 价格锚点：原价划线/到手价对比必须来自客户确认的价格逻辑，不自行编造折扣；
3. 倒计时/名额位：预留独立文本层，便于按天批量换数；
4. 批量变体：同一 recipe 换 `copy` 变量生成多规格（横版/竖版/方形），一次出 3 规格；
5. 渲染后用 `visualread.verify` 对每规格做尺寸校验。

## 输出契约
- 多规格成品 + recipe + 回执；活动规则原文留档（一客一档）；
- 价格与权益与客户确认单一致。

## 边界
- 不使用「史上最低/全网最低」等无法举证的绝对化表述（G-VIS2/G-VIS1）；
- 抽奖/返现类活动须标注规则链接位，不承诺必得。

## 参数边界

1. 信息层级固定四层（活动名 > 利益点 > 时间 > 门槛）；第一眼不是活动名即重排。
2. 价格锚点**必须来自客户确认的价格逻辑**；自造折扣一票否决。
3. 倒计时/名额必须是**独立文本层**，可换数而不动版式。
4. 一次交付 **3 规格**（16:9 / 3:4 / 1:1 或同结构）；缺规格视为未完成。
5. 抽奖/返现类必须带规则链接位；不使用"史上最低/全网最低"等不可举证表述。

## 失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 自造折扣/到手价 | 与客户确认单逐字比对 | 一票否决：改回确认口径重出 |
| 出现"史上最低/全网最低" | G-VIS2 词表 | 阻断并改写；该词入客户禁区清单 |
| 倒计时写死在图片里 | 文本层结构检查 | 改为独立文本层，便于批量换数 |
| 三规格风格不一致 | 模板/字体/色板一致性检查 | 用同 recipe 重出三规格 |
| 抽奖规则链接缺失 | 规则位检查 | 补规则位；补不了不得发布 |
| 尺寸不符合平台 | `visualread.verify` | 按规格重出后交付 |
