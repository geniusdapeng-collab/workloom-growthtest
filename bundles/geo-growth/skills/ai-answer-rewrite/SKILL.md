# AI 答案版改写（六段式）

## 适用场景
- 脚本人审通过后的 GEO 内容改写（自动触发，零边际成本）
- 问答式/清单式/对比式三种结构按 query 词类匹配

## 方法
1. 六段式结构铁律（附录 B）：
   ① 问题前置（标题即用户原问）
   ② 直接给答案（首段 100 字内）
   ③ 参数/对比表格
   ④ 选购/操作建议（清单式）
   ⑤ 品牌实体信息锚点（与实体卡逐字一致）
   ⑥ 信源引用（数据来源标注）
2. 结构匹配：品牌词→问答式；品类词→清单式；竞品对比词→对比式；场景词→问答式+清单式混合。
3. 实体锚点校验：第⑤段与品牌实体卡 confirmed 字段逐字段比对，一个数字都不能改。
4. 双审制：社媒审传播力（已过）+ GEO 审事实与结构（G-GEO1/G-GEO2），都过才进信源分发队列。

## 输出契约
- 输出：AI 答案版全文（六段齐全）+ 实体锚点比对报告 + 目标信源平台建议。
- 禁机器味：不堆砌关键词、不伪造多源、不生成模板腔（驳回样本回流校准）。
- 涉人设/品牌表态段落标 G20 待审标记。
- 无工具回执的事实点标「未核实」，不得宣称完成。

## 决策原则（含阈值与失败关闭）
1. **六段缺一不可**：问题前置/直接答案（首段 ≤100 字）/参数表/清单建议/实体锚点/信源引用；缺段即拒。
2. **实体锚点逐字一致**：与品牌实体卡 confirmed 字段逐字段比对，任何数字、资质、型号偏差一票否决（G-GEO2）。
3. **事实来源限定**：只使用实体卡 confirmed 字段与已核验数据；未确认参数不得进正文。
4. **人设/表态走 G20**：涉人设或品牌表态段落必须打 G20 待审标记，不得默认通过。

## 打法库（场景 → 动作序列 → 判据）
- **主线·词类匹配**：品牌词→问答式；品类词→清单式；竞对对比→对比式；场景词→问答+清单混合（判据：结构与原问法一致性抽查）。
- **分支·竞对对比稿**：中性对比框架 → 己方优势与证据；禁止贬损性表述（判据：合规词表扫描 0 命中）。
- **分支·异常**：实体卡字段缺失 → 退回实体巡检补卡，不得用近义表述顶上（判据：锚点比对报告）。

## SOP（每步带触发/回执/失败路径）
1. 脚本人审通过自动触发改写 → 结构匹配 + 六段生成 → 回执：AI 答案版全文；失败：结构不匹配退回重写并记录原因。
2. 实体锚点校验 → 逐字段比对 → 回执：比对报告；失败：任一偏差即阻断并升级实体巡检。
3. 双审（G-GEO1 外发审 + G-GEO2 事实审）→ 进信源分发队列 → 回执：双审记录；失败：任一未过即回退修改。

## 关键指标（含基准与护栏）
| 指标 | 口径 | 基准/阈值 | 类型 |
|---|---|---|---|
| 双审一次通过率 | 一次通过/总提交 | ≥80% | 领先 |
| 实体逐字一致率 | 一致字段/比对字段 | 100% | 护栏 |
| G-GEO2 阻断率 | 阻断数/提交数 | 趋势下降 | 质量 |
| 机器味驳回率 | `style.off_brand` 等驳回占比 | <10% | 质量 |

## 失败模式（症状 → 检测器 → 处置）
| 症状 | 检测器 | 处置 |
|---|---|---|
| 机器味/模板腔 | 驳回码聚类 | 驳回样本回流校准提示词 |
| 关键词堆砌 | 平台合规预检 + 抽检 | 重写并记录边界案例 |
| 锚点漂移 | 逐字比对报告 | 一票否决 + 实体卡复核 |
