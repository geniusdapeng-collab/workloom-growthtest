# 直播卖券操盘

## 适用场景
- 酒店/门店场景的团购券、预售券直播销售；
- 需要把"内容生产—直播—核销—归因"串成一场战役。

## 触发条件
- 淡季/节日/新品节点；房态或券库存条件具备；高表现内容适合直播化。

## 输入数据
- 房态与价格日历、券 SKU 与库存、历史直播数据、账号与流量基线、合规话术库。

## 方法
1. **排期联动**：满房不推、淡季加推；场次与流量高峰、券库存、客服承接容量对齐。
2. **脚本节奏**：开场引流→福利款→主推款→逼单→切片复用；每段话术有明确目标与合规口径。
3. **库存熔断**：售罄/下架即停止相关推广并切换话术（G-GROW4 留痕），防止超卖投诉。
4. **切片复用**：高表现片段出切片需求单交视频生产线剪辑，二次分发延长战役生命周期。
5. **战报归因**：GMV/核销/归因成交额/获客成本/切片表现进增长账本；未核销不计成交。

## 边界（什么不做）
- 价格/优惠/绑定承诺一律 L4（G-GROW2）；不夸大、不制造虚假稀缺；
- 拍摄/剪辑/渲染归 ai-video 生产线；券与房态归酒店包；
- 公网发布与加投走 G9/G12 审批。

## 决策原则（含阈值与失败关闭）
1. **满房不推、售罄即停**：房态/库存不满足不排场；售罄/下架触发 G-GROW4 熔断并切换话术。
2. **未核销不计成交**：战报成交口径以核销为准；未核销不得计入归因成交额。
3. **价格与承诺 L4**：价格/优惠/绑定承诺一律人审（G-GROW2）；不得制造虚假稀缺。
4. **产能对齐**：场次与客服承接容量、渲染产能对齐；超产能不承诺交付时点。

## 打法库（场景 → 动作序列 → 判据）
- **主线·五段节奏**：开场引流→福利款→主推款→逼单→切片复用（判据：每段有目标与合规口径）。
- **分支·库存熔断**：售罄/下架 → 停投 + 话术切换 + 快照留痕（判据：超卖投诉 0）。
- **分支·切片复用**：高光片段出需求单交视频线 → 二次分发延长战役（判据：切片复用率与二次转化）。

## SOP（每步带触发/回执/失败路径）
1. 触发（节点/淡季/新品）→ 排期与主题（联动房态与券库存）→ 回执：排期单；失败：库存不足即取消场次。
2. 直播执行 → 节奏与话术（价格口径走 L4）→ 回执：过程记录；失败：异常即停播并快照。
3. 战报与复用 → GMV/核销/归因 → 回执：战报 + 切片需求单；失败：核销数据缺失标未核实。

## 关键指标（含基准与护栏）
| 指标 | 口径 | 基准/阈值 | 类型 |
|---|---|---|---|
| 核销率 | 核销/售出 | 高于品类基线 | 滞后 |
| 归因成交额 | 核销口径 | 月度上升 | 滞后 |
| 切片复用率 | 复用切片/高光片段 | ≥50% | 领先 |
| 超卖投诉 | 投诉数 | 0 | 护栏 |

## 失败模式（症状 → 检测器 → 处置）
| 症状 | 检测器 | 处置 |
|---|---|---|
| 售罄后继续推 | G-GROW4 触发记录 | 自动停投并复盘排期 |
| 未核销当成交 | 战报口径审计 | 修正口径并回溯战报 |
| 话术夸大 | 合规预检 + 抽检 | 立即替换话术并记录 |
