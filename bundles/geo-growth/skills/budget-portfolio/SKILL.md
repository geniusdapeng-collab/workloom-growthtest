# 预算组合经营

## 适用场景
- 总预算在内容/社媒/信源/投放/承接之间的分配与周度再平衡；
- 需要回答"下一块钱投到哪里边际回报最高"。

## 触发条件
- 月度预算下达、周增长会、渠道 ROI 显著变化、实验结论放量/回滚。

## 输入数据
- 各渠道历史与增量 ROI、边际成本曲线、在跑实验敞口、业务季节性、房态/库存类约束。

## 方法
1. **口径统一**：预算 = 投放 + 内容生产可归因成本 + 券/激励成本；任何一项不许漏。
2. **增量排序**：按增量 ROI（不是平均 ROI）排序；无法度量的渠道先做对照实验再上量。
3. **组合再平衡**：给出下周分配、预期增量、最坏损失；单实验 ≤5%、月内再分配 ≤20%、在跑实验敞口 ≤15%。
4. **护栏**：CAC、退款率、投诉数、现金流四条护栏；击穿即回滚并进熔断留痕。
5. **透明度**：每次分配都带数据快照与假设，供回测账本对账。

## 边界（什么不做）
- 超带不自行决定（G-GROW1 → L4）；
- 不做单条广告的盘内出价调优（归 ads-optimizer）；
- 不用"平均 ROI"掩盖渠道间差异。

## 决策原则（含阈值与失败关闭）
1. **三条硬带**：单实验 ≤5% 月预算、月内再分配 ≤20%、在跑实验风险敞口 ≤15%；任一超带转 L4（G-GROW1）。
2. **只认增量 ROI**：无法度量增量的渠道先做对照实验再上量；平均 ROI 不得作为分配依据。
3. **四护栏**：CAC、退款率、投诉数、现金流任一击穿即回滚并熔断留痕（G18）。
4. **台账完整**：预算=投放+内容可归因成本+券/激励成本，任一漏项视为台账不符。

## 打法库（场景 → 动作序列 → 判据）
- **主线·再平衡**：增量排序 → 下周分配与预期增量 → 最坏损失评估 → 带内执行（判据：预算执行率与增量 ROI）。
- **分支·新渠道**：先小流量对照实验 → 显著为正再逐步放量（判据：实验卡 + 显著性判定）。
- **分支·季节性/容量约束**：旺季提价与满房约束下重排投放（判据：护栏无击穿、库存联动正确）。

## SOP（每步带触发/回执/失败路径）
1. 触发（月度下达/周会/ROI 异动）→ 取增量证据与敞口 → 出分配方案 → 回执：方案+数据快照；失败：证据不足维持原配比。
2. 带内执行 → 周度监视 → 回执：执行与偏差点；失败：超带即停并升级 L4。
3. 月末对账 → 回测账本 → 回执：对账报告；失败：台账不符即冻结下月自动再分配。

## 关键指标（含基准与护栏）
| 指标 | 口径 | 基准/阈值 | 类型 |
|---|---|---|---|
| 增量 ROI | 增量收益/增量成本 | 渠道间排序依据 | 领先 |
| 预算执行率 | 实际/计划 | 95%–105% | 护栏 |
| 护栏击穿数 | 四护栏合计 | 0 | 护栏 |
| 台账差异 | 漏项/错项 | 0 | 合规 |

## 失败模式（症状 → 检测器 → 处置）
| 症状 | 检测器 | 处置 |
|---|---|---|
| 平均 ROI 掩盖差异 | 分配依据审计 | 驳回重算增量口径 |
| 自然增长记功 | 对照缺失检测 | 补对照实验后重估 |
| 敞口失控 | 在跑实验敞口监控 | 停止新增 + 收紧档位 |
