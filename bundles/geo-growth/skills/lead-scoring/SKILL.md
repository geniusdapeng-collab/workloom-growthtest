# 线索分级运营

## 适用场景
- 评论/私信/电话/落地页/AI 搜索锚点进来的线索分级与跟进；
- 需要回答"哪一档线索值多少钱、哪一环漏了"。

## 触发条件
- 新线索入库、SLA 超时、培育节点、成交回写。

## 输入数据
- 线索来源与意图、历史成交与驳回原因、首响时长、培育互动、客资脱敏后的画像字段。

## 方法
1. **三档定义**：A=明确时间+明确需求（如"国庆 3 天 2 晚两大一小"）；B=有需求无时间；C=泛兴趣。
2. **路由 SLA**：A 级 1 小时内派单到人；B 级进培育池；C 级私域喂养；漏派/超时告警。
3. **评分可解释**：每个分数给出主要贡献因子，禁止黑箱；每月用成交回写校准阈值。
4. **培育节奏**：B/C 级每周定向内容+优惠唤醒，触达频率合规，不骚扰、不重复触达。
5. **漏损归因**：首响超时/分级错档/培育断档三类漏损分别统计，出修复方案与实验需求。

## 边界（什么不做）
- 报价/优惠承诺一律 L4，不得私自承诺；
- 与 guest-success / private-domain-operator 不重复触达同一客户；
- 客资脱敏存储与访问留痕，导出走数据边界（G-GROW6）。

## 决策原则（含阈值与失败关闭）
1. **三档定义不可模糊**：A=明确时间+明确需求；B=有需求无时间；C=泛兴趣；判定字段缺失按 C 处理（保守降档）。
2. **可解释评分**：每个分数必须给主要贡献因子；黑箱评分禁用。
3. **SLA 硬约束**：A 级 1 小时内派单；漏派/超时即告警并计入漏损。
4. **不重复触达**：与 guest-success/私域承接先查触达记录再编排；同客同渠道 48 小时内不重复打扰。

## 打法库（场景 → 动作序列 → 判据）
- **主线·分级路由**：评分 → 路由（A 直派/B 培育/C 喂养）→ SLA 监控（判据：A 级首响达成率）。
- **分支·培育**：B/C 每周定向内容+优惠唤醒，频次合规（判据：触达频次与投诉率）。
- **分支·模型校准**：月度用成交回写校准阈值，错档样本进缺陷池（判据：分级准确率提升）。

## SOP（每步带触发/回执/失败路径）
1. 触发（新线索入库）→ 评分与因子记录 → 回执：评分卡；失败：字段缺失按 C 档并标注缺字段。
2. 路由派单 → SLA 计时 → 回执：派单记录；失败：超时告警并升级人工。
3. 培育与成交回写 → 回执：漏斗更新；失败：成交未回写则冻结当月模型校准。

## 关键指标（含基准与护栏）
| 指标 | 口径 | 基准/阈值 | 类型 |
|---|---|---|---|
| A 级首响达成率 | 1h 内派单/ A 级线索 | ≥95% | 护栏 |
| 分级准确率 | 回写校准后正确/样本 | ≥80% 且上升 | 质量 |
| 培育转化率 | 培育转 A/培育总数 | 月度上升 | 滞后 |
| 漏派率 | 漏派/应派 | 0 | 护栏 |

## 失败模式（症状 → 检测器 → 处置）
| 症状 | 检测器 | 处置 |
|---|---|---|
| 黑箱评分 | 因子缺失审计 | 禁用该模型版本并重训 |
| 超时漏派 | SLA 监控告警 | 立即人工补派 + 复盘 |
| 重复触达投诉 | 触达记录撞库 | 拉黑该编排并整改 |
