# GEO 信源配图（Answer Card）

## 适用场景
- GEO 六段式内容（问题前置→直接答案→参数表格→清单建议→实体锚点→信源引用）的配图
- 知乎回答、公众号长文、垂媒稿件、百科词条的首图与对比图

## 方法
1. 图表优先：参数对比用横向条形/表格版式，避免纯装饰大图；
2. 每张图只讲一个结论（一张对比图 = 一个维度）；
3. 实体锚点（品牌名/型号/参数）与品牌实体卡逐字一致，字体统一、数字对齐；
4. 引用来源以文字层标注（来源 + 时间），不伪造数据图；
5. 一次生成「首图 + 对比图 + 清单图」三张套装，供同一篇文章使用。

## 输出契约
- 3 张套装（首图/对比图/清单图）+ recipe + 回执；
- 每张图的数字与实体卡一致；外发前走 G-GEO2 事实校验与 G-GEO1 必审。

## 边界
- 不做「排名第一/碾压」类对比图；不引用未核实第三方数据（G-VIS2）；
- 图片不替代正文的事实核查。

## 参数边界

1. **一图一结论**：一张对比图只承载一个维度，超过即拆图。
2. 实体锚点（品牌/型号/参数）必须与实体卡**逐字一致**；数字必须对齐同一小数位。
3. 数据图**必须标来源与时间**；不可核实的数据不得入图。
4. 禁止「排名第一/碾压/绝对领先」类对比图（G-VIS2 一票否决）。
5. 图片不替代正文事实核查；外发前必过 G-GEO2 与 G-GEO1。

## 失败模式（症状 → 检测器 → 处置）

| 症状 | 检测器 | 处置 |
|---|---|---|
| 一张图塞了 3 个结论 | 结论数检查 | 拆成多张（首图/对比图/清单图各司其职） |
| 型号/参数与实体卡不一致 | 逐字比对 | 一票否决：改回实体卡口径后重出 |
| 数据图无来源 | 来源标注检查 | 补来源+时间；补不了则撤图 |
| 出现"排名第一/碾压"表述 | G-VIS2 词表 | 阻断并改写；该词补进客户禁区清单 |
| 三张套装风格不统一 | 模板/字体/色板一致性检查 | 用同一 recipe 重出 |
| 未过 G-GEO2/G-GEO1 就外发 | 审批记录检查 | 阻断外发，补审后再发 |
