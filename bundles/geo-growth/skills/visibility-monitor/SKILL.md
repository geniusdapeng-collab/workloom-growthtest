# AI 能见度监测

## 适用场景
- 建档期 D7-D10 能见度基线首轮采集（覆盖四词类）
- 日常监测：品牌词日频 + 全量 query 集周频

## 方法
1. 采集纪律：L3 剧本模拟人工节奏、多账号轮询、单平台失败自动切换冗余通道（L1 官方 API→L3 RPA 剧本→L5 人工补录），连续失败即时上报。
2. 答案五维结构化：是否提及、是否首推、引用源（谁被引用）、SOV（声量份额）、情感（正/中/负）。
3. 存证铁律：每条采集原始答案截图存证（snapshot_uri），供双方核验——「可测量可追溯」承诺的事实源。
4. 情感异常联动：AI 答案负面描述即时告警 + 口径冲突定位（联动实体一致性管理员）。
5. 平台清单：豆包/DeepSeek/元宝/ChatGPT 四平台先行；出海客户扩展 Perplexity/多语言 query 集。

## 输出契约
- 输出：能见度快照（五维+截图存证 URI）+ 变化归因建议（证据强度标注）。
- 只记录不干预：不得伪造 query 结果或美化能见度数据。
- 监测口径：同一 query 同平台同日多次采集取首次结果，防人为刷好数据。
- 无工具回执的关键数字标「未核实」，不得宣称完成。

## 决策原则（含阈值与失败关闭）
1. **同 query 同平台同日取首测**：多次采集只认第一次结果，防人为刷好数据（硬口径）。
2. **存证铁律**：每条采集必须有原始答案截图 `snapshot_uri`；无存证按未采集处理。
3. **通道降级纪律**：单平台失败自动 L1→L3→L5 降级；连续失败即时上报，不得跳过样本。
4. **只记录不干预**：不得伪造或美化能见度数据；发现异常先留证再报告。

## 打法库（场景 → 动作序列 → 判据）
- **主线·节拍采集**：品牌词日频 + 全量周频 → 五维结构化 → 落能见度账本（判据：采集成功率与存证率）。
- **分支·负面异常**：AI 答案负面描述 → 即时告警 + 口径冲突定位联动实体巡检（判据：告警时延与冲突单数）。
- **分支·通道异常**：单平台连续失败 → 切换冗余通道并标注来源，必要时转人工补录（判据：样本缺口为 0）。

## SOP（每步带触发/回执/失败路径）
1. 触发（cron 日/周）→ 多平台采集（L3 剧本模拟人工节奏）→ 回执：快照与结构化结果；失败：切换通道并记录降级。
2. 结构化落账 → 提及率/首推率/SOV/引用源/情感 → 回执：账本条目；失败：字段缺失按未核实标注。
3. 异常检测 → 告警与联动 → 回执：告警事件与快照；失败：告警通道失败时转人审队列。

## 关键指标（含基准与护栏）
| 指标 | 口径 | 基准/阈值 | 类型 |
|---|---|---|---|
| 采集成功率 | 成功样本/计划样本 | ≥95% | 护栏 |
| 存证率 | 有截图样本/成功样本 | 100% | 护栏 |
| 提及率/首推率/SOV | 月度变化 | 环比不下降 | 滞后 |
| 负面告警时延 | 发现到告警 | ≤30 分钟 | 领先 |

## 失败模式（症状 → 检测器 → 处置）
| 症状 | 检测器 | 处置 |
|---|---|---|
| 采集造假/美化 | 同日重复采样比对 | 作废该批 + 审计来源 |
| 单通道依赖 | 通道失败率监控 | 启用冗余通道并演练 |
| 截图缺失 | 存证率巡检 | 补采或标未核实，不计入指标 |
