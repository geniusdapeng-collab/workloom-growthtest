# query 集建设（四词类 × 双语）

## 适用场景
- 建档期 D5-D7 query 集 v1 建设（GEO 班组+客户确认）
- 日常 query 集扩充与优先级调整

## 方法
1. 四词类模板（附录 A）：
   - 品牌词：「XX 机械怎么样」「XX 机械 vs YY」——口碑监测
   - 品类词：「CNC 加工厂家哪家好」「激光切割机怎么选」——首推率争夺主战场
   - 场景词：「小批量定制零件找什么供应商」「出口欧洲的机械认证要求」——长尾覆盖
   - 竞品对比词：「XX 和 YY 哪个好」「替代 YY 的中国供应商」——截流
2. 每词六字段：语言、目标市场、优先级、当前能见度状态、关联 GEO 内容、关联短视频选题。
3. 中英双语 50-100 条起步；客户确认优先级后落一客一档 GEO 资产。
4. 与情报站联动：AI 问答高频新问题持续补入 query 集。

## 输出契约
- 输出：query 集（四词类分栏 + 六字段全填），客户确认版标 confirmed。
- 词类覆盖率检查：四类词缺一不可；优先级字段必须经客户确认。
- 无工具回执的词频数据标「未核实」，不得宣称完成。

## 决策原则（含阈值与失败关闭）
1. **四词类缺一即拒**：品牌/品类/场景/竞对对比四类不全不进入确认版；缺类先补采再提交。
2. **客户确认才叫 confirmed**：优先级字段未经客户逐项确认一律标 reported；混入 confirmed 即判缺陷。
3. **量级门槛**：起步 50–100 条（中英双语按目标市场拆分）；有效词（有热度或意图证据）占比 <60% 时驳回重采。
4. **无源不入库**：缺来源与采集时间的词条不得写入 query 集（失败关闭）。

## 打法库（场景 → 动作序列 → 判据）
- **主线·建档**：意图雷达取词 → 四词类归并 → 双语扩写 → 客户确认优先级 → 落一客一档（判据：四类齐 + confirmed 全填）。
- **分支·新品/新市场**：先用场景词与竞对词探路 2 周，出现稳定高意图词再升级为品类词争夺（判据：竞对词首推率变化）。
- **分支·异常**：同类词突然全无热度 → 先核采样通道与平台口径，再决定是否降级该词类优先级（判据：跨平台交叉验证）。

## SOP（每步带触发/回执/失败路径）
1. 触发（建档 D5–D7 / 月度扩充）→ 采集四路词源 → 回执：词源清单与时间戳；失败：单源失败转人工补录并标注。
2. 归并去重 → 六字段填充（语言/市场/优先级/能见度状态/关联内容/关联选题）→ 回执：query 集版本号；失败：字段缺失即整批驳回。
3. 客户确认 → 标 confirmed 并落档 → 回执：确认记录；失败：超时未确认保持 reported，不得推定。

## 关键指标（含基准与护栏）
| 指标 | 口径 | 基准/阈值 | 类型 |
|---|---|---|---|
| 四词类覆盖率 | 已建词类/4 | 100% | 护栏 |
| 有效词占比 | 有热度或意图证据/总词数 | ≥60% | 领先 |
| 品类词首推率 | 首推次数/有效问法次数 | 月度环比上升 | 滞后 |
| 无源词条数 | 缺来源与时间的条目 | 0 | 护栏 |

## 失败模式（症状 → 检测器 → 处置）
| 症状 | 检测器 | 处置 |
|---|---|---|
| query 漂移（答非所问） | 驳回码 `geo.keyword_drift` 计数 | 冻结该词优先事项，重对齐词类 |
| 词量不足硬凑 | 有效词占比 <60% | 整批驳回重采，不进客户确认 |
| 未确认混入 confirmed | 字段审计与逐字比对 | 回滚状态并审计来源，补确认 |
