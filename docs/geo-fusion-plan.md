# 社媒短视频营销 × GEO 融合经营系统 · 完整落地执行方案

> 版本：v1.0（2026-08-23）
> 方案定位：这不是概念方案，是排产文档——每个模块有对象、有员工、有围栏、有 SOP、有验收指标、有 90 天逐周计划。
> 代码落点：`bundles/geo-growth/`（底座零改动，一切新能力经 Bundle 注入）。

## 第〇章 方案总览（一页纸）

**一句话**：以 WorkLoom 经营底座为发动机、以易飞轮出海 B2B 闭环与渠道为车身，交付「全网存在感经营系统」——社媒短视频与 GEO 两个经营域共享一个情报站、一条内容生产线、一套分发基建、一张战报、一条私域转化链路。

**90 天三个硬目标**：
1. 跑通 3 家试点客户（亚凯型 1 家 + 佛山中小 2 家）的双域经营全流程；
2. 产出可验证的效果证据：能见度提升回测命中率 ≥60%、试点客户询盘入口从 1 变 2；
3. 形成可复制的交付包：一客一档模板 + query 集模板 + 双域 SOP + 套餐报价单，支撑新签 25→50/月 的爬坡。

## 第一章 商业逻辑：为什么这门融合生意成立

### 1.1 需求侧三重证据
- **证据一**：社媒经营性劳动是真痛点，且付费方已存在。报告类工作占运营工时 18-22%；代运营 1 人服务 20-50 个账号；75% 从业者任务过多、46% 倦怠、72% 已用 AI 但未减负——单点工具已卷，经营系统空白。
- **证据二**：出海 B2B 的闭环已被易飞轮验证。社媒引流→私域转化闭环已建成；新签 25 家/月、佛山渠道五角色交付团队、亚凯约 300 账号高强度样本均为存量资产。增长瓶颈：新签卡在「系统下限水平」，续约卡在「流量效果+系统使用程度」。
- **证据三**：GEO 是 2026 年确定性新增预算，但行业交付能力拉胯。AI 搜索月活破 8.2 亿、AI 问答流量占比 52% 首超传统搜索；超 70% 中大型企业已把 GEO 纳入年度预算；但行业口径混乱、灰帽泛滥、效果不可验证是第一大痛点。

### 1.2 供给侧判断：三方各司其职

| 角色 | 拥有什么 | 缺什么 | 在融合方案中的位置 |
|---|---|---|---|
| WorkLoom | 经营机制底座：围栏/审批/事件链/夜班/数字CEO/班组/技能沉淀 | 行业入口、客户渠道、出海 know-how | 发动机：决策层+审批层+留痕层+值守层 |
| 易飞轮 | 出海 B2B 闭环 SaaS、一客一档、佛山交付渠道、25 家/月新签、私域转化链路 | 「数据→行动」的决策层、审批与留痕机制、GEO 能力 | 车身与渠道：业务闭环+客户关系+交付网络 |
| 短视频/GEO 工具市场 | 单点生成、单点监测工具 | 经营闭环、责任承接 | 被整合对象：Seedance 等模型 API 与发布/监测通道 |

### 1.3 融合的经济学：为什么是 1+1>2

单独做社媒，客户把你和蚁小二/新榜比；单独做 GEO，客户把你和数百家混战的 GEO 服务商比；组合之后，比价对象消失——**「全网存在感经营 + 效果可验证账本」这个品类位当前无人占据**。

## 第二章 产品架构：一个底座、两个经营域、四层结构

### 2.1 分层纪律（防膨胀的第一原则）
- **底座零改动**：一切新能力经 Bundle 注入；GEO 域与社媒域的所有对象、员工、围栏、技能都在 Bundle 层（`bundles/geo-growth/`）；
- **通道可替换**：模型 API、发布渠道、AI 平台监测通道全部走五级分层（L1 官方 API → L3 RPA 剧本 → L5 人工），任一通道失效不塌架构；
- **数据归属红线**：客户业务数据（客资、WhatsApp 聊天、线索）留在客户系统；WorkLoom 事件链只记录经营动作留痕，不碰内容数据。

### 3.3 账号成长六阶段机（系统内置）

1. 产品与市场 → 2. 账号搭建 → 3. 规模测试 → 4. 流量跑通 → 5. 转化验证（GEO 引用源建设启动）→ 6. 批量放大（扩编提案 L4 逐单批）

## 第四章 端到端 SOP：从签约到续费

### 4.1 启动建档期 SOP（D1-D10）

| 日 | 动作 | 产出 | 验收标准 |
|---|---|---|---|
| D1 | 启动会：学产品、定市场、定目标 | 启动会纪要、目标确认书 | 客户签字确认目标与禁用表达 |
| D1-D3 | 产品理解 Agent 提炼产品档案与实体卡 | 品牌实体卡 v1 | 参数/资质/卖点经客户逐项确认 |
| D3-D5 | 市场分析：国家/竞品/账号矩阵方案；对标拆解 3-5 个同行账号 | 市场分析报告、对标拆解报告 | 含竞品 GEO 能见度对比 |
| D5-D7 | query 集建设：品牌/品类/场景/竞品对比词，中英双语 50-100 条 | query 集 v1 | 覆盖四词类；客户确认优先级 |

> **信任设计**：建档期同步启动 shadow 影子模式（3-7 天）——AI 的全部决策 dry_run 不执行，每日出对照报告。这是对被「承诺-落空」伤害过的客户唯一有效的信任建立方式：先让它试，每个预测都记在账上。

| 卡审/限流 | 预检规则更新+驳回原因归档学习 | 复审内容方向 |
| AI 答案负面描述 | 即时告警+口径冲突定位（哪个信源出错） | 确认事实→信源修复计划（L2 执行） |
| 询盘投诉/纠纷 | 敏感 block+升级通道 | 人接管沟通，全程留痕 |
| 平台政策变更 | 政策信号上 L4+围栏 patch 快速收紧 | 裁决是否调整分发策略 |

## 第五章 五大协同机制（1+1>2 的执行层）

1. **选题情报双向流动**：情报站每日统一情报卡（来源域：热榜/评论/AI问答），双用选题优先排产——一条「XX 设备怎么选」的 AI 高频问题，同时产出短视频与 GEO 问答图文；
2. **内容一次生产、两处变现**：脚本成套包固定字段「AI 答案适配版」——人审通过后 GEO 改写自动触发，零边际成本，但必须双审（社媒审传播力，GEO 审事实与结构）；
3. **分发渠道统一编排**：publish-rpa 渠道分两组——社媒组（抖音/TikTok/小红书/YouTube/Meta）与信源组（知乎/头条号/百家号/公众号/新闻稿/垂媒/百科），同一套模拟人工纪律；
4. **全网存在感战报**：固定三栏【社媒侧】播放/涨粉/互动/询盘；【GEO 侧】提及率/首推率/SOV/引用源变化；【交叉侧】双入口询盘对比、双用选题命中率——这份战报本身就是续约工具；
5. **询盘双入口进同一私域**：来源打标（社媒私信/表单 vs AI 搜索→官网/落地页→WhatsApp），月度战报单独呈现两入口询盘量/质量/成交率对比——GEO 价值最硬的去伪存真证据。

## 第六章 服务交付模式（SaaS + 渠道服务双层交付）

| 交付线 | 适用客户 | 内容 | 定价形态 |
|---|---|---|---|
| 全托管线 | A 类 0 基础工厂 | 渠道团队+系统全权代运营，客户只做 L4 裁决 | 月度服务费 + 询盘效果奖励 |
| 人机协作线 | B 类成长型企业 | 系统为主、客户团队配合，逐步接管部分裁决权 | SaaS 订阅 + 增购包 |
| 平台嵌入线 | C 类亚凯型 | 系统能力嵌入客户自运营流程，集团CEO 聚合 300 账号 | 平台年费 + 账号矩阵规模阶梯价 |

> 佛山五角色减负：运营（1 人服务客户数 8-15→30+）、拍摄剪辑（保留实拍，剪辑工时降 50%+）、AI 内容人（由系统替代，人只做审美抽检）、广告投手（管理盘子扩大 2-3 倍）、售后客户成功（报告工时 18-22%→5% 以内）。

## 第九章 90 天落地执行计划（逐双周排产）

- **W1-W2（对接与建档基建）**：一客一档 v2 字段对齐；query 集模板；能见度监测通道 MVP（豆包/DeepSeek/元宝/ChatGPT 四平台先行）。验收：监测通道连续 7 天零失败；
- **W3-W4（试点签约与影子期）**：3 家试点签约；一客一档 v1 建档；宪章配置；shadow 影子模式启动。验收：深度授权六步完成率 100%；基线报告产出。关键动作：给客户老板做第一次「AI 能见度体检」——最锋利的签约钩子；
- **W5-W6（双域生产线上线）**：GEO 改写（AI 答案版）上线；信源分发适配器（知乎/公众号/百家号先行）；试点客户进入日频经营节奏。验收：首批「双用选题」内容上线；双域发布成功率 ≥95%；
- **W7-W8（节奏固化）**：周经营会跑 2 轮；夜班值守接管跨时区；首轮高表现结构固化写回档案。验收：周活跃裁决率 ≥70%；报告工时降幅 ≥50%；
- **W9-W10（首份回测报告）**：决策日记首轮回测；双入口询盘对比；能见度变化归因。验收：回测命中率 ≥60%；3 份客户案例素材；
- **W11-W12（商业化验证）**：GEO 增购包向试点客户报价；「AI 能见度体检报告」投放新签渠道。验收：至少 1 家购买 GEO 增购包；体检报告带来 ≥10 个新签线索；
- **W13（复盘与决策）**：90 天经营报告（效果提升/交付人效/续约意向三指标）；Go/No-Go 决策。

**90 天成功指标总表**：试点客户 3 家全留存（续约意向 ≥2 家）/ 周活跃裁决率 ≥70% / 回测命中率 ≥60% / AI 搜索入口询盘 >0 且可追溯 / 报告工时降幅 ≥50% / GEO 增购转化 ≥1 家 / 围栏零误放（block 级误放行 0 起）。
