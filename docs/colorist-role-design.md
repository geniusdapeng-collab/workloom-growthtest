# 调色师岗位设计（ai-video 行业包）

> 建档：2026-09-21 ｜ 岗位 preset：`bundles/ai-video/presets/colorist.yml` ｜ 任务：`[T-2026-0921-0040]`
> 定位：把"成片调色"从一句要求，变成**有技能、有配方、有工具、有围栏、有证据**的岗位职责。

## 1. 为什么调色值得单设岗位

三件事决定了调色不能"顺手做"：

1. **它是内容意图的翻译**：同一个镜头，暖调=亲密、冷调=疏离、高饱和=冲动、低饱和=克制。调错方向等于讲错话。
2. **它有硬技术面**：白平衡、曝光、裁切、色彩空间、肤色保护、多镜一致性——每一项都有客观标准，失手就是废片。
3. **它跨所有内容类型**：产品、访谈、美食、科技、旅拍、夜景、美妆、亲子、汽车、房产、促销、纪录、高端品牌，**每类的内容逻辑不同，色调取向也不同**。

所以本仓给调色师配的是"**岗位 + 技能矩阵 + 配方库 + 工位工具 + 围栏**"五件套，而不是一个滤镜按钮。

## 2. 岗位卡

| 项 | 内容 |
|---|---|
| 官衔 | 调色师（`preset_key: colorist`） |
| 定位 | 成片后期的色彩负责人：定调 → 校正 → 统一 → 交付证据 |
| 上级/协作 | 上游：渲染师（交付镜次）、剪辑师（交付定稿母版）；下游：发布运营（消费已调色母版） |
| 工作时段 | 支持夜班（批量片子在夜间跑） |
| 风险级别 | 本地非破坏动作，不烧生成额度；但**品牌 appearance 变更**属对外观感变更，须人审 |
| 产物 | 成片（新文件）+ `color_report`（色彩报告）+ scope/对比帧/哈希证据 |

## 3. 能力矩阵（4 技能 × 7 工具 × 5 围栏）

### 3.1 技能（随 Bundle 分发，安装即生效、卸载即撤销）

| 技能 | 回答什么问题 |
|---|---|
| `color-grade` | **怎么做**：五步法（probe→analyze→correct→look→match&verify）、目标值表、强度纪律、输出契约 |
| `color-look-design` | **调成什么样**：题材×场景→色调的选型方法、13 个配方的适用边界、情绪→色彩映射、平台适配、禁忌清单 |
| `color-shot-matching` | **怎么统一**：参考镜选择三准则、逐镜派生、残差验收线（ΔYAVG≤5 / ΔU≤3 / ΔV≤3）、批次与断点纪律 |
| `color-delivery-spec` | **怎么交付**：Rec.709/8-bit 口径、平台变体派生纪律、证据包六件、版本回滚、返工归因表、不可修复情形 |

### 3.2 工具（调色工位 bridge，7 个）

| 工具 | 类型 | 用途 |
|---|---|---|
| `colorread.health` | 读 | 工位与 ffmpeg 健康（含可用 look 与白名单目录） |
| `colorread.probe` | 读 | 素材规格（是否 log、色彩空间、时长、帧率） |
| `colorread.analyze` | 读 | 抽帧量化诊断（曝光/裁切/偏色/饱和/肤色）＋修复建议 |
| `colorread.recipes` | 读 | **题材×场景配方检索**（profile/LUT/强度/目标区间/禁忌/平台） |
| `colorread.scope` | 读 | 波形/矢量/直方图 + 前后对比帧 |
| `colorwrite.grade` | 写 | 应用 look/LUT 与滤镜链出片（校正 100% 生效、look 按强度混合、永不覆盖原片） |
| `colorwrite.match` | 写 | 多镜匹配到参考镜并回报残差 |

### 3.3 围栏（`fences/ai-video-color.yml`）

| 门 | 名称 | 级别 | 意义 |
|---|---|---|---|
| G-COL0 | 常规调色直通 | auto | 本地可逆、非破坏动作，不打扰人审 |
| G-COL1 | 品牌 look / 新 LUT 首次启用 | review | 外观变更须人审 |
| G-COL2 | 覆盖原片禁止 | block | 原片只读是硬红线 |
| G-COL3 | 调色必须可核验 | block | 禁止关闭指标复检与哈希 |
| G-COL4 | 单租户日调色配额 | block | 30 次/日熔断，防成本与产能失控 |

## 4. 题材×场景 → 色调决策表（配方库摘要）

完整配方（含目标区间覆盖与禁忌）在 `bundles/ai-video/library/color-recipes/recipes.json`，
由 `colorread.recipes` 检索；下表是给人与岗位看的速查版。

| 题材 | 代表场景 | 情绪目标 | look | 强度 | 不可越的线 |
|---|---|---|---|---|---|
| 产品广告 | 棚拍白底、桌面特写 | 干净可信 | clean-bright | 0.7 | 白底真白、商品本色不变 |
| 人物访谈/口播 | 室内半身 | 可信亲和 | warm-film | 0.6 | 肤色 hue 20–40°，背景可去饱和 |
| 美食/餐饮 | 菜品特写、出锅 | 诱人温暖 | warm-film | 0.85 | 白瓷盘仍须中性白 |
| 科技/SaaS | 暗场棚拍、屏幕演示 | 冷静精密 | cool-technical | 0.65 | 界面白不能变蓝 |
| 户外/旅拍 | 山海、街拍 | 开阔通透 | teal-orange | 0.6 | 天空不变塑料蓝 |
| 夜景/都市 | 霓虹、车流 | 戏剧现代 | teal-orange | 0.75 | 暗部裁切 <3%，先降噪再提饱和 |
| 美妆/护肤 | 面部特写 | 通透可信 | clean-bright | 0.5 | 强度≤0.5，禁美白式提亮 |
| 亲子/家庭 | 日常、出游 | 明亮有温度 | clean-bright | 0.6 | 禁压黑 |
| 汽车/出行 | 外观、内饰 | 强劲精密 | cool-technical | 0.7 | 车漆色相不许偏 |
| 房产/空间 | 样板间、户型讲解 | 明亮通透 | clean-bright | 0.55 | 饱和≤55，窗景保层次 |
| 节日促销 | 促销切片、红包信息 | 热烈紧迫 | high-contrast-social | 0.8 | 高饱和只给画面不给文字 |
| 纪录片/科普 | 实拍纪事 | 真实克制 | natural | 0.4 | 只做还原 |
| 高端品牌 | 形象片、材质特写 | 克制质感 | moody-dark | 0.6 | 黑位深而不死（裁切<1%） |

**选型纪律**：一个项目只用一套 look；平台差异只做微调（+5~10% 对比之类），**不重新调色**。

## 5. 调色师的一天（标准工作流）

```
接收母版（剪辑师交付）
  ↓ 定调四问：题材？场景/主体？情绪目标？发哪个平台？
  ↓ colorread.recipes 取配方（说明选型理由，含被否掉的候选）
  ↓ probe 读规格 → log 素材先套 slog3-to-rec709
  ↓ analyze 抽 4 帧诊断（有人脸必查肤色；有灰卡用 neutral_patch）
  ↓ correct：白平衡 → 曝光 → 裁切 → 饱和（100% 生效，一次只改一个变量）
  ↓ look：按配方叠 profile/LUT（0.5–0.85 强度）
  ↓ match：多镜以合格参考镜为基准统一（残差达标）
  ↓ verify：scope + 目标值表 + 可见性度量（≥4/255）
  ↓ 交付：新成片 + color_report（含证据包六件）
```

## 6. 交付标准（不达标不算完成）

1. 成片哈希 + 滤镜链 + profile/LUT + 强度；
2. 前后指标（YMIN/YAVG/YMAX/UAVG/VAVG/SATAVG）与差值；
3. scope 三图 + 前后对比帧；
4. **可见性度量**：平均像素差 ≥4/255（`<2` 由工具直接拒绝出片）；
5. 选型说明（题材/场景/情绪/配方 id）；
6. 多镜残差表（如有多镜）。

## 7. 与上下游的接口

| 对手方 | 调色师接收/交付什么 | 冲突时的裁决 |
|---|---|---|
| 渲染师 | 接收镜次；发现素材裁切/噪点/压缩伪影 → 退回上游并标注不可修复 | 上游素材质量优先于后期补救 |
| 剪辑师 | 接收定稿母版；**在母版上调一次**，不参与剪辑决策 | 剪辑决定节奏，调色决定观感 |
| 发布运营 | 交付已调色母版 + 平台微调建议；变体由母版派生 | 变体不重新调色 |
| 品牌合规 | 品牌色/商品本色不可偏移；对外观感变更走 G-COL1 人审 | 合规优先 |

## 8. 质量指标（用于绩效与考试院）

| 指标 | 目标 | 数据来源 |
|---|---|---|
| 一次通过率 | ≥85% 首次人审通过 | G-COL1/审批记录 |
| 可见性 | 交付全部 ≥4/255 | 可见性度量（回执） |
| 多镜残差达标率 | ≥95% 镜头 ΔYAVG≤5、ΔU/ΔV≤3 | match 回执 |
| 肤色合格率 | 100%（有人脸镜头） | analyze 肤色复检 |
| 返工归因准确率 | 100% 标注"选型错/参数错/上游素材" | 返工表 |
| 平台一致性 | 同片各平台色差 ΔE ≤ 阈值（派生不改色） | 平台变体抽检 |

**考试院题目方向（建议）**：① 夜景素材 YAVG=68 是否可交付、依据是什么；② 美妆镜头饱和推到 1.4 的后果；③ 三个镜头 ΔV=9 时的处置顺序；④ 品牌 look 变更该走哪个门；⑤ 素材高光裁切 6% 时能否用风格化掩饰。

## 9. 边界（本岗位不做什么）

- ❌ 不做剪辑决策、不改叙事结构、不改字幕文案；
- ❌ 不做 HDR/10-bit/ACES（第一版口径，遇到按"超出交付口径"上报）；
- ❌ 不重新生成 AI 视频（只处理已成片像素）；
- ❌ 不负责对外发布（发布是发布运营的职责，走 G9）；
- ❌ 不用后期掩盖上游缺陷（裁切/噪点/压缩伪影/失焦 → 如实上报）。
