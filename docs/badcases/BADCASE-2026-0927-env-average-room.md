# BADCASE · 2026-09-27 · 「平均样板间」（8 镜全过监制，产品所有者一眼判"不像实拍"）

> 触发：销售口播片（VID-GROWTH-SALES01，8 镜 / 89s）交付后，产品所有者复检的第一句话是"空间布景不像实拍、像随意口播"。
> 数据源：`work/video/env-realism-report.json`（8 镜逐条规则命中）、CF-04（原版）与 CF-04E（实指化重渲）的关键帧与视频对照。
> 结论一句话：**不是模型不行，是管线里从来没有"环境真实性"这一类判据**——8 镜监制全放行，因为它们"符合镜头卡"，
> 而镜头卡本身写的就是空词。

## 一、事实：8 镜逐条命中（改造前）

审计工具：`scripts/tools/environment-realism-audit.mts --shots work/video/shotlist.json`（原始卡，不展开圣经）

| 规则 | 命中 | 说明 |
|---|---|---|
| `generic-wording` | 4/8 | 场景里出现「现代、简约、商务空间、简洁、通透、干净留白」这类空词 |
| `material-depth` | 8/8 | 材质与工艺项 <3（多数只剩「玻璃」一项，且无工艺/状态） |
| `practical-light` | 8/8 | 灯光只有柔光箱 + 反光板 + 白板补光（**棚具语言**），没有一处场景内实用光源 |
| `usage-traces` | 8/8 | 没有任何使用痕迹（指纹/水渍/卷边/划痕/薄灰）——不存在"无痕"的真实办公室 |
| `space-specificity` | 7/8 | 镜头卡没带空间实指（年代/地段/尺度/朝向/时段/空间类型 ≥3 项） |
| `optic-signature` | 8/8（软） | 缺光学签名（等效焦段/光圈口径） |
| `prop-interaction` | 2/8 | 含手机/支架却不声明物理关系（见 BADCASE-2026-0927-phone-screen-toward-audience） |

合计：**硬缺陷 37 · 软提示 8**。同一份卡在管线里连过 G5/G6/G7 与关键帧/视频两道监制门。

## 二、根因（按证据强度排序）

### 根因 1（主因）· 评审清单里没有"环境真实性"这一类目

- 旧 `keyframe` rubric 只有"场景与镜头卡一致"——而**卡里写的就是空词**，于是"一致"与"真实"之间没有任何判据，
  监制永远只能判"对得上卡"，判不出"不像实拍"。
- 证据：8 镜监制裁决全部放行（`stages.jsonl`），而 8/8 在环境审计里判红。
- 置信度：高（同一批产物、两个判据体系的直接对立结论）。

### 根因 2 · 空词只能生成"平均空间"

模型拿到「现代明亮的商务空间」时，只能落回训练分布里出现频次最高的那间办公室：无痕迹、匀光、材质一级名词。
**平均化正是"AI 感"的定义**。8 镜各自独立出图 → 每镜一个样板间（同一场戏的会议室换了三次装修）。
- 证据：8 镜空间实指缺失 7/8；同一支片子里同一空间出现多种材质描述。
- 置信度：高。

### 根因 3 · 提示词侧没有约束，只有棚具语言

8 镜的 `lighting` 字段是同一句话的复制：「柔光箱主光从镜头左前方 45°…右侧一块白板补出柔和过渡」。
这不是布景的光，是**影棚的光**：真实办公室不会有人举着白板。
- 证据：7/8 镜 `practical-light` 判红；灯光字段逐字重复。
- 置信度：高。

### 根因 4 · 没有"空间圣经"这个片级事实源

每镜的 `scene` 各写各的，没有一处声明"整片发生在哪间真实空间、什么材质、什么光源、有什么使用痕迹"，
于是"同一支片子"这件事在生成侧根本不存在。跨镜连续性只能靠人眼事后发现。
- 置信度：高（工具实测：补上圣经后 18 镜模板一次性 0 硬缺陷）。

## 三、修复（已落地，全部机制化）

| # | 修复 | 落点 |
|---|---|---|
| 1 | **场景圣经**（片级事实源）：`space`（城市/建筑/年代/面积/层高/朝向/时段）+ `otherSpaces`（总部外的门店/现场）+ `materials`（材质+工艺+使用状态）+ `practicalLights`（场景内实用光源+色温）+ `traces`（使用痕迹）+ `colorDiscipline` | `packages/video-studio/src/scene-bible.ts`、`shotlist.json#sceneBible` |
| 2 | **圣经展开**：`expandShotWithBible` 把圣经展开进每镜既有字段（`scene`/`sceneDescription`/`lighting`/`props`/`color_palette`），关键帧提示词与视频提示词因此都吃到；**不改表演/台词/时长/构图** | 同上 + `full-chain-film.mts` 装载期 |
| 3 | **渲染前确定性审计**：8 条规则（空词/材质深度/实用光源/使用痕迹/空间实指/空间连续性/道具交互/光学签名），硬缺陷 **fail-closed**，报告落盘 | `environmentDefects` + `scripts/tools/environment-realism-audit.mts` |

| 5 | **评审侧两个类目**：`keyframe`/`shot`/`master` 增「环境真实性（必判）」与「道具-人体交互逻辑（必判）」 | `producer-gate.ts#PRODUCER_RUBRICS` |

## 五、可复用规则（分镜与制片 Playbook）

1. **先写圣经，再写镜头**：一支片子只允许一组空间事实（材质/光源/痕迹），每镜从圣经里取，不各自发挥。
2. **空词换实指**：不许出现「简约/现代/商务空间/干净留白」；空间至少给 3 项实指（年代/地段/尺度/朝向/时段/空间类型）。
3. **材质必须带工艺或使用状态**："原木"不算，"哑光打蜡 + 中央咖啡杯痕"才算。
4. **灯光必须有场景内实用光源**：窗光/筒灯/台灯/屏幕光…带方向与色温；柔光箱只能作补充，不能作主光。
5. **画面里留使用痕迹**：指纹、水渍、卷边、划痕、薄灰、杯痕、旧钉眼——"无痕"= 假。
6. **换空间要显式登记**：进 `sceneBible.otherSpaces` 并用 `shot.sceneId` 指认，否则空间连续性判红。
7. **光学签名**：每个镜头的景深档要带等效焦段（等效 35mm 视角、大光圈浅景深…）。

## 六、残留风险与后续

- 本轮的"真实感"判据是**可校验的必要条件**，不是充分条件：它拦得住"平均样板间"，拦不住"材质写对了但生成得不对"
  （后者仍靠关键帧监制的视觉评审与重渲）。
- 素材镜（`photo` 首帧）目前同样走审计；素材来源真实时若被判红，属**提示词侧**需要补齐，不是审计误判。
- 未做量化对照（"有圣经 vs 无圣经"各渲 N 镜的人评打分）；当前 A/B 是单镜证据（n=1），后续建议按题材各做 3 镜。
