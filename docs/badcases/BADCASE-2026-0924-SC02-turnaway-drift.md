# BADCASE · 2026-09-24 · SC-02「石桥指船」反复打回（转身/换脸/手部）

> 触发：产品所有者点名"SC-02 反复失败，是个很好的 badcase，仔细分析原因"
> 数据源：`stages.jsonl` 中 SC-02 的全部 25 条裁决记录（VID-PJL01 无知识库版 + VID-PJL02 带知识库版）
> 结论一句话：**这不是"提示词写得不够狠"，而是三件事叠在一起——场景语义先验、镜内大幅转向、以及评审证据不足**。

### 1.2 关键观察

- **同一句台词、同一套服化、同一台机位**，模型每次只满足一部分约束：这一版动作对（指船）但背身，下一版正面但静止，再下一版动作对但换脸。
- 失败**不随提示词加长而减少**：带知识库版（1974–1952 字）与无知识库版（约 2400 字）失败模式完全一样。
- 关键帧阶段就已经露出苗头：**4 次关键帧尝试里 3 次被判"侧身/侧转"**——即视频阶段的失败是从关键帧继承的。

## 二、根因分析（按证据强度排序）

### 根因 1（主因）· 场景语义先验：模型把「桥+栏杆+船+河+指物」默认演成侧身倚栏指船

- 证据：分镜明确写"面向镜头、眼神交流"，但关键帧与视频仍输出侧身姿态（12:31:48、12:55:47、12:59:49、13:01:37）。
- 机理：这组语义在训练数据里与"游客倚栏指船/远眺"的构图强绑定，**文本层面的"面向镜头"压不住画面先验**。
- 置信度：高（跨两个项目、两个版本、10 次生成一致复现）。

### 根因 2 · 镜内大幅转向 → 同一镜换脸

- 证据：4 次"同镜换脸"，全部出现在包含"侧脸→正脸/回头"的版本（18:04:13、18:17:57、12:46:14、13:10:13）。
- 机理：镜内旋转超过约 45° 时，模型需要重新合成面部；在 5 秒、1080p、单次生成的约束下，人脸身份会在帧间漂移。
- 置信度：高（失败与"是否有大幅转向"高度相关）。

### 根因 3 · 手部动作 + 浅景深 = 手部崩坏

- 证据：4 次手部畸变（指节粘连、手指畸变、左手消失、单手悬空），且都发生在"指/搭栏"这类手部承担叙事的镜头。
- 机理：手在画面里占比小、运动快，而知识库给该镜的光圈档是 f/2.8–f/4（环境人像）——浅景深进一步把手指细节交给模糊，模型更容易糊成一团。
- 置信度：中高（相关性明确；单变量对照未做）。

### 根因 4 · 5 秒动作预算超支

- 证据：该镜同时要求「正面 + 走来 + 说话 + 摆手 + 表情弧 + 视线锁定」6 类约束，多版结果都是"满足其中 3–4 条"。
- 机理：扩散视频模型对单镜的"动作容量"有限，约束互相挤占，表现为版本间抖动而非稳定收敛。
- 置信度：中（经验规律，缺少逐条消融实验）。

### 根因 5（闸门设计问题）· 审稿证据不足 → 误判与多花额度

- 证据：13:06:17 的裁决写明"手部摆动与步态证据不足"——当时只给监制 3 张静帧（0.6s / 中段 / 末段）。
- 机理：**静帧无法证明"有没有动"**，监制按 fail-closed 打回；于是同一镜反复重渲。
- 附带发现（负面结果，值得记录）：我们随后实现的"运动能量"（相邻帧中心区平均绝对差）**也不能跨景别直接比较**——
  实测同一批片段：正面走近镜 5.79/255，而静物特写 12.48/255（近景的像素级微动天然更高）。
  因此它只能作为**软证据**（低到 <0.8 才升级硬失败），不能作为"动作是否完成"的通用判据。
- 置信度：高（直接来自裁决原文 + 自测数据）。

## 三、修复（已落地）

| # | 修复 | 落点 | 效果 |
|---|---|---|---|
| 1 | **构图先验风险闸**：场景含「桥/栏杆/船/河」+ 动作含「指物/递物」+ 要求「正面看镜头」→ 在**花钱之前**打回，并给出"改正面走近或删指物"的建议 | `full-chain-film.mts` spec 阶段（软检查，但监制会据实打回） | 用原始 SC-02 文本复测：**打回 58 分**，附可执行建议；修正后文本 **放行 87 分** |
| 2 | **朝向互斥硬闸**：「面向镜头/眼神交流」与「转身/侧身/背身」同镜互斥（注意：只算身体转向，"转头看镜头"不算） | 同上（硬闸） | 拦截设计层面的自相矛盾 |
| 3 | **手部动作光圈纠偏**：动作含「指/挥/搭/捧/舀」且推荐档 ≤ f/2.0 时，自动收到环境人像档 f/2.8–f/4，理由留痕 | `cine-kb-bridge/core.mjs` `recommendAperture()` | 依据 OPTICS-001 §3.1/§3.4，避免浅景深糊手 |
| 4 | **动作节拍预算改为 advisory**：只报数进 context，不进 PASS/FAIL（原先会把"9 个节拍 vs 8"当成缺陷打回） | `full-chain-film.mts` spec 阶段 | 修正后 SC-02 在"仅节拍偏多"情况下可放行 |
| 5 | **审稿证据升级**：抽帧 3 → 4 张（0.5/1.8/3.2/4.5s），并附运动能量数字（soft） | `full-chain-film.mts` shot 阶段 | 让监制有"动没动"的数字参照，减少"证据不足"式打回 |

## 四、可复用规则（分镜设计 Playbook）

1. **一镜只做一件事**：5 秒内动作节拍 ≤4（起势/主动作/收势），避免"走来+说话+摆手+表情弧"全塞一镜。
2. **不要在镜内做大幅转向**：需要"侧面→正面"就拆成两镜；单人镜优先"正面站定/正面走近"。
3. **警惕构图先验**：`桥/栏杆 + 船/河 + 指物 + 正面看镜头` 是高危组合；要么删指物，要么把桥/船降级为纯背景（人物提示词不写"倚栏/望向船"）。
4. **手部承担叙事时收小光圈**（f/2.8–f/5.6），并避免手部贴画幅边缘。
5. **失败重试纪律**：第 1 次按建议微调；**第 2 次必须改分镜**（换机位/换动作/拆镜）；第 3 次改为"带瑕疵放行 + badcase 归档"，不再原样重烧额度。

## 五、残留风险与后续

- 本次未做单变量消融（例如"同一镜头分别去掉指物/收小光圈"各跑一次），因此根因 3/4 的权重仍是经验判断；
  建议在额度允许时做 2×2 对照（指物 有/无 × 光圈 f/2.0/f/5.6），把"哪个变量最关键"量化。
- 运动能量指标需要**景别归一化**（或改为身体区域光流）才能当硬闸用；当前只作软证据。
- 关键帧阶段的"朝向"判定目前依赖监制的视觉评审；若要前置成确定性闸，需要引入姿态估计（粗粒度 head/body yaw）——
  属下一阶段能力，不在本次范围。

## 附录 · 第二个 badcase：从"没有桥头的水中桥"走过来（2026-09-24，产品所有者截图指出）

### A. 现象

带知识库版（VID-PJL02）SC-02 的入片画面：人物沿一条**平直的石桥面**从画面深处走向镜头，
但**看不到桥头、看不到桥与两岸的连接**，视觉上像"悬在水面上的一条无头栈道"。

### B. 为什么会被设计成这样（根因）

1. **改机位时只盯人物，漏了场景几何**：前一版"侧身指船"反复被判背身/换脸，我的修法是把机位改成
   「人物从画面深处正面走近」。改的是**人物朝向与动作**，而"她脚下这座桥长什么样"我一个字没写。
2. **我给出的构图词反而鼓励了这个错误**：分镜里写了「石桥栏杆与桥面形成向画面中心的引导线」——
   "桥面直插画面中心"正是"看不到桥头"的构图成因。
3. **知识库没有"场景物理常识"这一层**：19 篇覆盖光学/景别/运镜/光线/色彩/材质/天气/人群/风格/情绪，
   但**没有人造物与地形的合理性规则**（桥/路/台阶/门/船的落点与透视）。我的自动注入因此只补了
   影像语言（光圈/光比/色调），补不到"桥必须有头"。
4. **监制门没有空间自洽检查项**：当时 shot/keyframe 的 rubric 关注人物一致性、肢体、表情、口型、遮挡，
   **没有"建筑与地形是否物理自洽"**，所以这种画面能连过关键帧与视频两道门。
5. **错误在关键帧阶段就固化**：视频用 `first_frame = 关键帧`，空间错误一旦进关键帧，
   后续每一帧都继承它——**在关键帧阶段不拦，等于用最贵的方式返工**。

### C. 已落地修复

| # | 修复 | 落点 |
|---|---|---|
| 1 | 关键帧提示词自动追加**空间自洽约束**：场景含 桥/栈道/廊桥/石阶/埠头 时，强制写入"必须连到两岸（桥头、石阶或对岸可见），不得出现悬空、无桥头、看不出通往何处的桥面；水面与桥底关系清晰，栏杆与桥面透视线一致" | `full-chain-film.mts` `platePrompt()` |
| 2 | 禁忌清单补「悬空无落点的建筑结构」 | 同上 |
| 3 | 节拍预算改 advisory、朝向互斥硬闸（同前文），避免"改机位"变成新的自由发挥 | spec 阶段 |

### D. 建议的下一层修复（未做，需产品所有者确认）

1. **知识库增补一篇 `SCENE-003 · 人造物与地形合理性`**：桥（拱桥/平桥、桥头与两岸）、台阶与河埠、
   门与院墙、船与水线、廊与柱的落点与透视规则。属于产品资产扩充，**不擅自代写**，请确认后我再补。
2. **监制 rubric 增加"空间物理自洽"检查项**（关键帧与视频两处都要），与人物一致性同级。
3. **分镜规范**：只要人物处于人造物之上/之中（桥、台阶、船舱、廊下），必须同时写清该人造物的
   **类型与落点**（例："石拱桥，桥面通向镜头，桥头石阶清晰可见，两端连着两岸"）。
