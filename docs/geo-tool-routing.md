# GEO 工具路由与模拟回执

部署执行器按规格或模块声明逐工具接管。运行时只在档案 `profiles.archive.dataMode` 明确为 `simulated`，且部署执行器明确声明当前工具未覆盖时，使用当前岗位白名单内的本地模拟器。未配置部署桥的明确模拟档案也使用该模拟器。真实档案缺连接器保持 `connector-required`、`mode=real`、`synced=false`。

已配置且声明覆盖当前工具的桥，调用失败、工厂拒绝装配、导入失败都保留失败或未核实状态。失败桥保留其已声明工具范围；无法获取范围时保守接管所有工具。非空配置无法解析出任何模块时也保守接管全部工具并保持未核实。其它声明范围的健康桥仍可独立执行。工厂缺失时，已经读取到的模块工具声明仍用于保留失败范围。没有模式但提供 `supportsTool(name)` 的旧模块，其声明参与逐工具路由。

一份规格表中同时存在健康桥和缺模块路径的坏声明时，坏声明不能被解析器丢弃。例如 `::createToolExecutor::metrics.read` 仍保留 `metrics.read` 的失败范围，明确模拟档案也不能把它当成未覆盖工具并签发成功回执。坏声明未提供工具范围时，未被健康桥明确接管的工具保守保持装配失败；健康桥自己的明确范围仍可工作。该行为与声明顺序无关，新规格表和旧单桥变量都适用。

本地模拟结果只说明运行了受控的本地结构模拟。账本 `receipt` 保留 `mode=simulated`，不表示平台发布、扣费或任何外部动作已经生效。模拟执行证据存放在 `decision.tool_execution` 扩展槽，冻结的五元回执结构保持原契约。

证据包含租户、工作区、线程、步骤、工具、步骤指纹、参数摘要、结果摘要、模拟快照 URI 和时间。模拟结果保存参数摘要，避免再次复制原始工具参数。运行时执行与 replay 都核对这些绑定；缺绑定、跨作用域、换步骤或工具、改参数或结果、换快照或时间都不能推进步骤。网关已脱敏的历史参数，由同指纹的持久计划核对原始参数摘要。未核实步骤保持停线，replay 不自动重发。

真实档案不能复用模拟回执。已模拟完成后把档案改为真实数据，原模拟回执仍留在账本，任务会保持未核实，直到取得与真实动作相符的回执。已核实真实连接器沿用既有回执契约；本改动没有实现真实平台连接器，也不把模拟结果计入真实经营交付。

## 独立验证

干净提交安装现有依赖后，从仓库根目录执行：

```sh
node scripts/verify-geo-tool-routing.mjs
```

它运行 runtime 全目录、部署执行器注册表的现有及 MC-006 回归，以及原发布任务门禁对零进度、失败状态、线程不一致、未核实回执等反例的回归。旧酒店种子库的数据库测试保留自身启用条件；单元命令的通过不代表数据库验证完成。

真实数据库验证需要已执行迁移的专用测试库，并提供 `DATABASE_APP_URL`、`DATABASE_GATEWAY_URL`。随后执行：

```sh
node scripts/verify-geo-tool-routing.mjs --db
```

`--db` 缺连接配置或数据库断言失败时返回非零，不会跳过后报告通过。断言通过应用/网关角色创建唯一命名的测试租户、工作区、档案、线程和事件，不使用迁移 owner，也不删除或改写事件。测试资料保留供复核。桥只使用临时本地模块，不发网络请求，不调用模型、图像或视频 API。

PG 断言覆盖部分桥配置下的模拟执行、特殊字符和事件脱敏、跨租户/工作区并发隔离、RLS、同线程 replay 幂等、跨租户模拟证据与篡改结果的 replay 停线、真实档案缺桥、已覆盖桥的运行及装配失败、非空畸形配置停线、混合健康与畸形声明的前后顺序和未知失败范围、六步骤边界、空参数、档案从模拟改真实、事件链一致性。健康桥断言使用临时本地模块返回的测试回执，不表示真实外部平台已交付。发布门禁另外在实际 GEO 工作区运行 `scripts/release-gate.ts`；其任务执行断言保持原强度，必须有已执行步骤和可核对的步骤回执。
