# 空间与物理自洽的**机制化**审核（2026-09-24）

> 起因：带知识库版 SC-02 出现"从没有桥头的水中桥上走来"的错误镜头（产品所有者截图指出）。
> 第一版修复是"场景含 桥/栈道/廊桥/石阶/埠头 时追加空间自洽约束"——**这是关键词补丁，穷举必然漏**。
> 本文回答："整个视频管线里到底有没有这类审核机制？应该怎么在机制上完善？"

## 一、现状（代码事实）

管线只有**一个统一评审层**：`packages/video-studio/src/producer-gate.ts`

```
producer-gate
├── PRODUCER_RUBRICS   逐环节评审要点（script / prompt / keyframe / shot / compose / color / subtitle / danmaku / bgm / cover / master）
├── reviewStage()      统一裁决：确定性硬闸 + LLM 评审（可带图）→ approved / rerun
└── 调用方：full-chain-film.mts（逐阶段）、apps/server studio-worker（G1–G7 门）
```

**当时的缺口**：11 个环节的 rubric 里**没有任何"空间/物理自洽"类目**——
`keyframe` 只查"人物一致性 / 写实度 / 构图 / 无文字水印 / 场景与镜头卡一致"。
所以"无头之桥"能通过关键帧与视频两道门，直到人眼发现。**问题不在模型，在评审清单里没有这一类。**

## 二、机制化修复（本次落地）

### 1. 把"物理不变量"写进评审层（与场景无关，不枚举）

在 `keyframe` / `shot` / `master` 三个环节的 rubric 增加**通用**类目：

| 不变量 | 判据（任何画面都必须成立） |
|---|---|
| 结构完整性 | 建筑/地形/器物都是有来由、有落点、有支撑的完整结构；无悬空构件、无断裂结构、无来由的延伸 |
| 尺度关系 | 人物与环境元素尺度比合理（门高于人、栏杆到腰、路宽于步幅、器物可被手持） |
| 透视一致 | 同一场景共享地平线与消失点，不出现两套透视 |
| 光影一致 | 光向/色温/阴影方向与时段相符，物体与地面有接触阴影 |
| 接触与承重 | 脚踩地、手有支撑、道具被真实承重，无穿模与漂浮 |

**为什么这样就不需要枚举**：任何新场景（未来出现"悬在崖边的玻璃栈道""漂在海上的木屋"）都落在同一组不变量里，
评审层不需要知道"桥"这个关键词；它只问"这个结构成立吗"。

### 2. 提示词侧改为**通用约束**（不再是桥专属）

`full-chain-film.mts#platePrompt()` 现在对**每一个镜头**输出：

> 场景结构与物理自洽（通用）：画面中每一个建筑、地形与器物都应是有来由、有落点、有支撑的完整结构
> （桥有桥头并连着两岸、路通向某端、台阶连着地面与水面、门窗嵌在墙体内、器物可被真实手持或承重）；
> 同一场景共享一条地平线与一套透视；光向、色温、阴影方向与时段一致，物体与地面有接触阴影；
> 不出现悬空构件、断裂结构、无来由的延伸、漂浮物体或与人物尺度冲突的元素。

括号里的"桥/路/台阶/门窗/器物"是**举例**，不是触发条件——约束本身对所有场景生效。

### 3. 两侧同时兜（提示词 + 评审）

- **提示词侧**：让模型有约束可用（生成阶段减少发生率）；
- **评审侧**：让监制有类目可判（即使提示词没拦住，也会在关键帧阶段被打回）。
- 关键帧是"一次定生死"（视频用 `first_frame=关键帧`），因此**必须在关键帧阶段拦住结构错误**——
  这也是把该不变量放进 `keyframe` rubric 的原因（1 张图 vs 1 条视频的代价差）。

## 三、怎么继续扩展（不改代码就能加要求）

1. **加不变量**：直接在 `PRODUCER_RUBRICS` 对应环节追加一条（评审层自动对所有镜头生效）；
2. **加确定性硬闸**：若某类错误可被脚本量测（如检测地平线倾斜、检测人物脚部是否接触地面），
   在 `reviewStage` 的 `deterministic` 里加一条 `hard: true` 即可（示例：`motion-evidence`）；
3. **加场景包**：若某题材有专门的物理规则（例如水下、失重），建议进知识库作为**新篇**，
   再由 `cine-kb` 的"意图→知识行"映射注入——但要遵守"知识库只增不改"与"措辞取原文"两条纪律。

## 四、边界（这套机制仍不覆盖什么）

- **不能替代几何一致性算法**：目前是"提示词约束 + 视觉评审"，属概率性防线；
  要做到确定性，需要引入场景图/深度估计（如单目深度 + 平面检测）做自动化结构校验，属下一阶段能力。
- **不覆盖跨镜空间连续性**：相邻镜头之间"同一地点是否长得一样"目前只由 `master` 的抽检类目覆盖，
  未做逐镜对齐。
- **评审仍可能漏判**：LLM 评审不是形式化验证；高频错误的兜底仍是"badcase → 回填一条规则/闸门"。
