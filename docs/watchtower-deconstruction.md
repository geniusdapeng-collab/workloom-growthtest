## 二、叙事结构（无对白的地理叙事）

它不讲故事，讲**一次穿越**：

1. **地理线**：Pamukkale 的冷蓝 → Cappadocia 的暖金 → 以弗所/伊斯坦布尔/科尼亚的市井与历史；
2. **时间线**：清晨 → 白天 → 黄昏 → 夜晚（灯光与烟火）；
3. **情绪线**：好奇（开场）→ 加速（中段）→ 澎湃（高潮，音乐主题爆发）→ 收束（回落留白）；
4. **人物线**：不塑造角色，而是让**陌生人的脸与手**反复出现，作为"人味"的节拍点——
   全程没有台词，人只做动作（喝茶、揉面、招手、看镜头一笑）。

**对模板的启示**：城市片不需要主角讲故事；主角是**城市本身**，人是"标点符号"。

## 三、音乐与声音（节奏的骨架）

- **一首曲子撑全片**：Einaudi《Experience》——钢琴主题 + 弦乐渐强，天然三段：
  ① 前段稀疏（弱起、留白）② 中段加速（主题重复、层次叠加）③ 后段爆发再收（情绪峰值后回落）。
- **人声（Voice off）不承担叙事**：Meryem Aboulouafa 的声音是**音色元素**（更像吟唱/气息），不是解说；
  它出现在音乐缝隙里，把"异域感"与"人的温度"钉住。
- **音效层（推断，C）**：镜头切换处有**气流/呼啸（whoosh）与冲击（impact）**做掩体，
  与画面里的甩镜/速度坡道同步；环境声（集市、礼拜、厨房、街道）在段落转换处短暂浮出。

**对我们的启示**：声音不是"配个 BGM"，而是**三层**：音乐床 + 人声层（可选短句/吟唱）+ 转场音效层；
转场音效必须**对齐剪辑点**（我们有 `--bgm-track/--bgm-level/--bgm-ducking` 与卡点实测，
但没有专门的 SFX 层——见第十二节缺口）。

## 四、剪辑结构（估算，C）

- 3:33 的片子里，**绝大多数镜头 1–3 秒**，密集段落可到 0.5–1 秒，留白段落 3–5 秒；
- **前 20%**：镜头较长（建立地理与色彩），剪辑点稀疏；
- **中段 50%**：镜长缩短、剪辑点落在音乐重音/切分上（"鼓点卡点"）；
- **高潮 15%**：极短镜 + 连续 match cut，画面变化率最高；
- **收尾 15%**：镜长回升，留 1–2 个长镜收情绪。

**对模板的启示**：镜长必须**分段曲线化**，不是"每镜都 5 秒"；我们的模板给的是
`建立(3–4s) → 加速(2–3s) → 高潮(1–1.5s) → 收束(3–4s)` 的镜长表 + 卡点参数。

## 五、运镜词汇（它为什么"一直在动"）

| 词汇 | 画面表现 | 我们的落地 |
|---|---|---|
| **Hyperlapse（大范围延时）** | 时间压缩下的行走/市集/道路 | 生成式场景 + 环境运动 + 速度坡道（`--material-speed-ramp`） |
| **Whip pan（甩镜）** | 高速横摇，带运动模糊 | 模型端：场景构建提示词要求"真实镜头位移"；剪辑端：`hblur` 转场 |
| **Speed ramp（速度坡道）** | 快起稳收 / 慢起快收 | `applySpeedRamp`（快起→稳行→快收，归一化回原时长） |
| **Dolly in/out（推近/拉开）** | 主体变大/环境展开 | 场景构建提示词要求"自选机位 + 至少一次真实镜头位移" |
| **Crane/Tilt（升降/俯仰）** | 视线抬升、楼层揭示 | 同上（镜头意图写进镜头卡 `motion`） |
| **Orbit（环绕）** | 主体旋转视角 | 同上（环绕半圈/一圈） |
| **Handheld（手持呼吸感）** | 轻微不规则抖动 | 生成端天然具备；后期**不加**（加了像贴纸） |
| **Air-to-ground（空中下压）** | 航拍到地面 | 生成端"低空俯冲推近"（航拍实拍不可复刻，见第十二节） |

**关键认知**：它的"动"来自**拍摄时真实的机位运动**，不是后期把一张图推来推去。
这正是产品所有者三次纠偏的核心：**素材只作实景依据，场景与运镜必须由模型构建**。

## 六、转场语法（它没有"转场特效"，只有"运动掩体"）

1. **Match cut · 形状**：圆形（盘子/穹顶/眼睛）接圆形；
2. **Match cut · 运动**：甩镜方向一致（右甩接右甩），接力形成连续运动；
3. **Match cut · 颜色**：暖金接暖金、蓝调接蓝调，剪点几乎看不见；
4. **Match cut · 主体位置**：主体固定在画面同一位置完成跳切（人物在左下角切到另一场景左下角）；
5. **Cut on action（动作峰值下刀）**：挥手/转身/倒茶的动作峰值处切，运动模糊掩护接缝；
6. **速度坡道连接**：前一镜尾速加快 → 后一镜头速放慢，两镜像同一段连续运动。

**对模板的启示**：转场库里应该以**运动/颜色/形状匹配 + 甩镜拖影**为主，
`hblur`（横向拖影）与 `smoothleft`（横向擦除）已经可在 compose 里逐刀指定（`--transition*`）。

## 七、构图与镜头语言

- **前景遮挡**（门洞、窗棂、茶烟、人群手臂）制造纵深与"偷看感"；
- **门框式/框景**（拱门、窗、桥洞）反复出现，形成视觉母题；
- **地面反射**（湿石路、水面、镜面地板）把同一景物复制成上下两份；
- **对称与打破对称**：穹顶对称构图后立刻切一个手持掠过；
- **焦段跳变**：大广角（空间关系夸张）接长焦细节（压缩感），产生"换眼睛看"的节奏。

## 八、色彩与光线

- 全片**一以贯之的胶片感**（低饱和、暖高光、青暗部），保证不同城市剪在一起不跳；
- **色温叙事**：冷蓝（清晨/帕穆卡莱）→ 暖金（卡帕多奇亚/黄昏）→ 暖橙+青（夜）；
- 天气是资产：雾、雪、雨、逆光都被当作"质感层"而不是事故。

## 九、人物策略（人味节点，不是角色）

- 人物**从不对镜头说话**（无台词、无口型叙事），只做**动作**与**表情**：
  喝茶、揉面、招手、点烟、看镜头一笑、孩子奔跑、老人静坐；
- 人物出现**短**（0.4–1.5 秒），是节奏里的"重音"而不是主体；
- 面孔多样（年龄/职业/性别），构成"这个国家的人"的群像；
- 不重复同一张脸太久——避免变成"人物专题"。

## 十、为什么好看（三条可量化的直觉）

1. **信息密度**：每 1–3 秒换一次"看的东西"（景别/地点/时间/主体至少变一项）；
2. **变化率曲线**：从慢到快再到慢，观众的快感来自**变化率的变化**，不是"一直快"；
3. **连续感**：运动与颜色被剪点接力，观众感觉"一镜到底"，实际是几十次跳跃。

## 十一、它的"反常识"（值得抄的纪律）

- **没有特写大脸对镜头说话**（我们的口播片反而依赖这个）；
- **没有字幕解释地点**（信息藏在画面里）；
- **没有炫技转场**（所有花活都在"运动"里，剪点本身干净）；
- **音乐不换**（一首曲子吃满全片，情绪靠镜头密度控制）。

## 十二、可复刻矩阵（结合本仓管线能力）

| 维度 | 复刻方式 | 现状 |
|---|---|---|
| 参考素材 → 构建场景镜头 | `material-scene/v1`：素材作 `reference_image`（不作首帧）+ 场景构建提示词 + `scene-constructed` 硬闸 | ✅ 已实现（本仓 `material-policy.ts` + 管线 `material-gen`） |
| 真实运镜（推拉/摇/升降/环绕/甩） | 镜头卡 `motion` 写镜头意图，模型端构建；机检运动能量 + 速度坡道比 | ✅ 已实现（`assessMotionRichness`） |
| 速度坡道 | `applySpeedRamp`（快起→稳行→快收，归一化回原时长） | ✅ 已实现（默认开） |
| 剪辑卡点（BPM） | bgm-bridge 真实剪辑网格反推 BPM + 卡点实测 | ✅ 已实现（真机 5/5 卡点 0ms） |
| 逐刀转场（甩镜拖影/擦除） | compose `--transition hblur|smoothleft --transition-at` | ✅ 已实现 |
| 镜长曲线（建立/加速/高潮/收束） | 模板给出分段镜长表；镜头卡逐镜 duration | ✅ 模板层（本文件 + template.yml） |
| 色彩统一（胶片感、冷暖叙事） | color-bridge 配方（`grade`/`best`）+ 模板给 profile/intensity | ✅ 已实现 |
| 人声层（吟唱/短句，无解说） | voice-bridge TTS（同一音色档案，短句 + 混音让位） | ✅ 具备（用于"气息式"短句 narration） |
| **转场音效层（whoosh/impact）** | 需要在 bgm 之后加一层 SFX：按剪辑点贴 whoosh/impact，并做 BGM 让位与响度对齐 | ⚠️ **缺口**（当前没有 SFX 工位；模板标为 P0 待补） |
| 真实航拍 / 真实群众 / 现场抓拍 | 需要真实拍摄 + 版权/肖像授权 | ❌ 不可复刻（用生成式场景 + 授权素材替代） |
| 8 城 20 天素材量 | 需要现场采集 | ❌ 不可复刻（改用"参考素材 + 生成场景"，素材来源需授权） |

## 十三、它还告诉我们怎么用我们的管线（落地清单）

1. **素材是"实景依据"不是"画面"**：`reference_image` + 场景构建提示词 + `scene-constructed` 硬闸（已落地）；
2. **镜头运动写在镜头卡里**：`motion` 必须是真实三维运镜意图（推拉摇移升降环绕甩），由模型构建；
3. **节奏靠镜长曲线 + 卡点**：不同段落用不同镜长，剪辑点落 BPM；
4. **转场只用"运动掩体"**：`hblur` 甩镜拖影 / match cut 方向一致；
5. **声音三层**：音乐床 + 人声层 + 转场音效（第三层待补）；
6. **人物是标点**：主讲人（如陈卓）只在开场/收尾短出镜；中间用**临时角色**（摊主、骑手、老人、学生…）
   做 0.6–1.5 秒的"人味节点"，一律类型化、无台词、不经久停留；
7. **不做字幕解释**：地点与信息交给画面与文案（小红书版本可按平台习惯保留一句钩子）。
