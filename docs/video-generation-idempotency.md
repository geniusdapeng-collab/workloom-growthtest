# 生成提交与失败接续

图片与视频的生成 POST 会产生费用。网络错误、5xx、下载失败或轮询失败不代表供应商没有受理，不能据此重发生成请求。

`packages/video-studio/src/generation-submission.mjs` 提供本地持久化提交日志。请求发出前，先以完整 endpoint 和实际请求正文的摘要记录 `submission-unknown`；只有这一步持久化成功，才允许 POST。收到成功响应后，先保存第一次响应，再解析图片 URL 或视频任务 ID。重启读取该响应，只重新下载图片或查询已受理任务，不再提交生成。

未知结果保持未知。改变正文、切换模型或改走另一个付费入口不会解除同一提交日志的未知状态。只有结构化、明确且不含已受理任务或产物的供应商拒绝，才允许修正输入后提交；普通 HTTP 状态码本身不能证明未受理。并发调用使用排他锁；进程异常留下的锁不会自动抢占，已保存的成功响应仍可只读恢复。

定妆照运行时与定妆照 Agent 按实际请求复用成功响应。输出被删除、缓存收据被改或下载失败时，重新下载第一次生成的图片；不同角色、造型、模型或真实参考图字节构成不同请求。已就绪的肖像版本不原地改写，恢复出的图片写入新候选后再按原有规则激活。背景诊断默认关闭；显式诊断也不会自动付费重渲染。历史不完整候选没有可核实的提交记录时，必须先对账，不能猜测它没有收费。

接续日志以 `0600` 写入 `.submissions/`，包含恢复下载所需的短期媒体地址，属于私有本机执行状态，禁止提交、上传或作为公开交付物。日志不保存请求参考图字节、请求头或 API key。`.gitignore` 排除这类目录；已有秘密扫描与来源收据继续适用。

生产实测 CLI 同一输出目录使用 `budget-run.json` 绑定原累计预算；每次观察仍有独立证据运行 ID，但重启不创建新的资金和张数额度。已结算任务只读停止，写入独立的重复运行说明，不覆盖原回执或再次结算。未结算预占只能恢复既有响应/视频任务，不能发送新的生成 POST。旧目录只有一个可核实预算身份时接续它；混有多个历史预算或身份缺失时先对账，禁止以空预算重跑。报告分别记录 adapter 调用与实际新增提交次数，恢复不冒充新收费。

本机制不能推导供应商的账单，也不承诺平台侧完全幂等。若请求结果未知且没有任务 ID，需要使用供应商记录对账后再恢复；删除私有接续目录、更换工作目录或另建不相关任务会丢失本地防重依据。调用方必须保留同一业务任务的日志目录与请求身份。

验证覆盖成功响应接续、网络中断/5xx/未明确拒绝、下载失败、输出丢失或篡改、并发、进程重启、正文变化、坏响应与日志篡改。测试使用明确的本地或合成接口，不调用真实付费生成服务。
