# 生成提交与失败接续

图片与视频的生成 POST 会产生费用。网络错误、5xx、下载失败或轮询失败不代表供应商没有受理，不能据此重发生成请求。

`packages/video-studio/src/generation-submission.mjs` 提供本地持久化提交日志。请求发出前，先以完整 endpoint 和实际请求正文的摘要记录 `submission-unknown`；只有这一步持久化成功，才允许 POST。收到成功响应后，先保存第一次响应，再解析图片 URL 或视频任务 ID。重启读取该响应，只重新下载图片或查询已受理任务，不再提交生成。

未知结果保持未知。改变正文、切换模型或改走另一个付费入口不会解除同一提交日志的未知状态。只有结构化、明确且不含已受理任务或产物的供应商拒绝，才允许修正输入后提交；普通 HTTP 状态码本身不能证明未受理。并发调用使用排他锁；进程异常留下的锁不会自动抢占。提交 helper 可以只读复用已保存的成功响应；若调用方的外层肖像缓存/档案锁残留，仍会停止并要求对账，不能据此承诺任意崩溃自动恢复。

认证素材派生 CLI 将同一逻辑角度的图片/视频作为一次准入事务：先读取两种引擎的日志，auto 优先恢复已受理引擎；未知结果、两种引擎同时有受理/未知记录或显式切换到另一引擎时停止。准入锁持续覆盖图片明确拒绝到视频回退，防止并发进程趁回退间隙提交；已受理任务仅按完整 endpoint 与当前请求摘要（视频允许原参考的有序子集）只读接续，可绕过残留准入锁读取，不删除或抢占该锁。身份母版 `master-front` 与最终角度 `front` 保持不同业务角色。

派生 CLI 的旧 `.tmp-<taskId>.mp4/png` 必须由经过结构与响应摘要校验的 accepted 视频日志中的合法 taskId 逐项对应。孤立临时文件不因存在另一份无关日志而获准新 POST；在新增提交前停止并保留旧文件，要求对账。合法母版临时文件允许后续不同角度生产，原任务下载/取帧失败后仍沿原 GET 恢复。

定妆照运行时与定妆照 Agent 按实际请求复用成功响应。输出被删除、缓存收据被改或下载失败时，沿第一次受理响应中的原 URL 重新下载；这表示复用同一次受理，不保证远端 URL 返回的图片字节永久不变。不同角色、造型、模型或真实参考图字节构成不同请求。已就绪的肖像版本不原地改写，恢复出的图片写入新候选后再按原有规则激活。背景诊断默认关闭；显式诊断也不会自动付费重渲染。历史不完整候选没有可核实的提交记录时，必须先对账，不能猜测它没有收费。

接续日志以 `0600` 写入 `.submissions/`，包含恢复下载所需的短期媒体地址，属于私有本机执行状态，禁止提交、上传或作为公开交付物。日志不保存请求参考图字节、请求头或 API key。`.gitignore` 排除这类目录；已有秘密扫描与来源收据继续适用。

生产实测 CLI 同一输出目录使用 `budget-run.json` 绑定原累计预算；每次观察仍有独立证据运行 ID，但重启不创建新的资金和张数额度。已结算图片/视频任务只读停止，不再次结算。原任务回执或 transcript 任一存在时，所有重跑结果（包括缺凭据或任务不可用的早退）均写入新的独立文件，当前报告指向本次结果，保留首次文件字节。未结算预占只能恢复既有响应/视频任务，不能发送新的生成 POST。旧目录只有一个可核实预算身份时接续它；混有多个历史预算或身份缺失时先对账，禁止以空预算重跑。报告分别记录 adapter 调用与实际新增提交次数，恢复不冒充新收费。

预算账本由逐条带换行的事件组成。非空账本末行缺少换行时，即使最后一段仍是可解析 JSON，也视为不完整写入：累计身份装载、预算重新打开和预占均在追加事件或调用供应商前停止，保留原账本字节，要求先对账；不会猜补换行或以空预算重跑。

认证素材肖像派生 CLI 也按角度/引擎持久化第一次受理响应。两段式身份母版默认接续原视频任务，不再依赖 `--reuse-masters` 开关，不盲信没有受理证据的旧文件。图片网络/5xx/坏响应或受理后的下载失败均不得自动重发或转去付费视频；`auto` 只有在无受理产物的结构化明确400拒绝且说明不支持 asset 参考时，才可尝试视频入口。视频移除失效参考同样只接受明确400未受理证据；重启以原参考集合能推导的准确请求摘要恢复已受理任务，正文/模型变化停止。

本机制不能推导供应商的账单，也不承诺平台侧完全幂等。若请求结果未知且没有任务 ID，需要使用供应商记录对账后再恢复；删除私有接续目录、更换工作目录或另建不相关任务会丢失本地防重依据。调用方必须保留同一业务任务的日志目录与请求身份。

验证覆盖成功响应接续、网络中断/5xx/未明确拒绝、下载失败、输出丢失或篡改、并发、正常退出后的进程重启、正文变化、坏响应与日志篡改；派生入口补测 auto 跨引擎受理/未知重启、拒绝到回退之间的并发、两日志冲突、残留锁只读接续、旧临时文件阻断及真实合成视频取帧接续；实际实测 CLI 的可解码合成图片/视频成功后，移除凭据重跑仍保留首次回执、transcript 和结算。未认证硬断电或所有进程崩溃注入的耐久性。测试使用明确的本地或合成接口，不调用真实付费生成服务。
