# 开场钩子：前 3 秒的机制化（2026-09-27）

> 产品所有者口径：抖音类平台上，**完播率的分水岭在前 3 秒**；需要新增岗位/机制（数字员工 + 音效 + 首镜模板）。
> 本文回答：钩子是什么产物、谁产出、管线怎么判、与既有岗位的边界、以及怎么验收。

## 一、改造前缺什么

| 环节 | 当时状态 | 后果 |
|---|---|---|
| 岗位 | 有「片头设计师」（30 字段片头镜头卡 + 标题） | 管的是**片头这一段画面**，不管"第 1 秒用什么把人钉住" |
| 音效 | 有转场音效层（whoosh/impact/riser） | 只铺在**剪辑点**上，0–0.6s 是空白；而短平台的钩子音恰好在这一窗口 |
| 评审 | 监制 rubric 无"钩子"类目 | "开头三秒平平"没有任何机制能发现 |
| 产物 | 没有任何东西能回答"钩子是什么类型、承诺了什么、在哪一镜兑现" | 钩子只能靠人嘴描述，无法评审、无法回归 |

## 二、机制（四件）

### 1. 钩子卡（产物）

写在 `shotlist.json` 顶层 `hook`：

```jsonc
{
  "type": "question",                 // 8 类之一：question/conflict/counterintuitive/benefit/result-first/suspense/number/scene-shock
  "promise": "还在给平台打工吗",        // 一句话说清许了什么（≤18 字的量级）
  "payoffShotId": "GR-06",            // 承诺在正片哪一镜兑现
  "firstShotTemplate": {              // 0–3s 首镜模板（画面线 + 台词线）
    "visual": "她坐在长桌一侧正对镜头，右手抬起做「停一下」手势，窗外城市灯火刚开始亮",
    "line": "还在给平台打工吗？",
    "lineSec": 2.4
  },
  "sfx": { "kind": "impact", "atSec": 0.08, "gainDb": -11 },   // 声音线（0–0.6s 窗口）
  "rationale": "疑问开场把观众心里的话先说出口；正片在 GR-06 用「别再买工具，你缺的是一支班组」回应"
}
```

### 2. 数字员工（谁产出）

新岗位 **开场钩子设计师**（`bundles/ai-video/presets/hook-designer.yml`）+ 技能
**开场钩子套件**（`bundles/ai-video/skills/opening-hook-craft/SKILL.md`：8 类钩子类型库与判据、首镜模板、
钩子音效清单、反标题党纪律、平台窗口口径）。围栏绑定 G6/G7（提示词审核、预生产最终确认）。

**与片头设计师的边界**（两岗不重叠）：

| 岗位 | 负责 | 不负责 |
|---|---|---|
| 片头设计师 `opening-designer` | 片头一段的 30 字段镜头卡 + 标题优化 | 钩子类型、承诺兑现、钩子音 |
| 开场钩子设计师 `hook-designer` | 前 3 秒注意力机制：类型/承诺/兑现镜/首镜 0–3s 模板/钩子音 | 剧本结构、台词内容、渲染与后期 |

### 3. 确定性判据（`openingHookChecks`）

| 判据 id | 级别 | 内容 |
|---|---|---|
| `hook-card` | 短平台硬 / 长视频软 | 短平台（抖音/快手/视频号/小红书/TikTok/Reels/Shorts）必须有钩子卡：前 3 秒不许靠运气 |
| `hook-card-complete` | 硬 | 类型在库内、承诺与兑现镜齐备、首句 ≤18 字、钩子音在 0–0.6s |
| `hook-payoff-shot` | 硬 | 兑现镜必须真实存在——**没有兑现镜头的钩子即标题党** |
| `hook-window` | 软 | 首镜时长 ≥ 窗口（短平台 3s）− 0.5s，别把钩子切在两镜之间 |
| `hook-promise-stated` | 软 | 承诺与首镜文本重叠度 ≥0.2（首镜要真的把承诺说出口/演出来） |
| `hook-promise-paid` | 软 | 疑问/悬念型以"另一镜用台词回应"为兑现判据；其余类型看字面重叠 |
| `hook-sfx-window` | 硬 | 钩子音起点必须落在 0–0.6s |

平台窗口：`hookWindowFor(platform)` —— 短平台 3s，长视频 5s。

### 4. 钩子音效（声音线）

`sfx-synth.ts#planHookSfx`：0–0.6s 窗口内摆**一记**（短平台默认 `impact` −11dB，长视频默认 `whoosh` −13dB），
越窗直接抛错；与剪辑点音效冲突时**钩子音优先**，被挤掉的记进 `hookConflicts` 证据（不静默丢）。
音效全部 ffmpeg 合成，无第三方采样（版权干净、确定性可复现）。

## 三、管线接线

| 位置 | 行为 |
|---|---|
| 装载期 | 读 `shotlist.hook` → `openingHookChecks` → 落 `hook-audit` 阶段记录；短平台硬失败即 `exit 8`（可用 `--accept-rejected hook` 留痕放行） |
| G7 门 | 判据清单增加 `hook-first-3s`（硬）：结论在花钱前的门账本里可见 |
| sfx 阶段 | 摆放钩子音（`--no-hook-sfx` 关、`--hook-sfx` 强制开、有钩子卡默认开）；rubric 增加"开场音不盖首句台词" |

## 四、验收口径

1. **单测**：`packages/video-studio/src/opening-hook.test.ts`（13 例：卡片自检、类型库、平台窗口、缺卡硬/软、兑现镜缺失、首镜过短、疑问型回应兑现）；
   `sfx-synth.test.ts` 钩子音窗口（越窗抛错）；
2. **模板示例**：销售讲解型 18 镜模板带完整钩子卡（`type=question`，兑现镜 GR-06），7 项判据全绿（`full-chain-film` 日志可见）；
3. **真机**：钩子音落在 0.08s、整片响度漂移 ≤1.5 LUFS（sfx 阶段机检），首句台词清晰可辨（监制）。

## 五、边界（本方案不解决什么）

- 不判断"钩子文案好不好"（那是监制与钩子设计师的判断）；机制只保证**类型在库内、承诺能兑现、声音在窗口内、首镜装得下**；
- 不自动改写台词：只决定"先说什么、画面怎么给、声音何时起"；
- 音效不做人声分离式的响度自适应 ducking（现有 ducking 在母版层，钩子音只保证不抬总响度）。
