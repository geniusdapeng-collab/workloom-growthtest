## 一、修复清单（现象 → 根因 → 修复 → 回归 → 证据）

### F1【严重 · 已修】关键帧提示词根本没有 `depth_of_field` 行，且「规格」硬编码"浅景深"

- **现象**：光圈顾问把"全画面锐利、细节丰富（较深景深）"写进 `depth_of_field`，
  但关键帧提示词（`buildPlatePrompt`）的字段清单里**没有这一行**，反而在「规格」行无条件写着"浅景深，纪实风格"。
  真机复现（36 场景中 10 个深景深档）：航拍梯田 / 雾中湖面 / 夜晚车轨 / 玻璃幕墙 / 海雾晨光
  的关键帧提示词里，KB 的深景深裁决被"浅景深"覆盖。关键帧是图生视频的首帧，首帧没有的东西后面不会长出来。
- **根因**：`packages/video-studio/src/plate-prompt.ts` 的 `lines[]` 只覆盖 12 个字段，
  KB 注入的 `depth_of_field` / `props` 不在其中；「规格」行把"浅景深"当通用质量词写死。
- **修复**：新增 `景深：` 与 `道具与质感：` 两行（空值不出行，避免占位噪音）；
  「规格」行改为**只在卡片未声明景深时**才补"浅景深"。
- **回归**：`plate-prompt.test.ts` › "注入的 depth_of_field 出现在提示词，且【规格】行不再硬编码浅景深"
  + "卡片没有声明景深时，规格行仍给通用安全值浅景深" + "空字符串字段不得变成空行"。
- **真机证据**：`work/kb-ab-real-shots.txt`（6/6 镜发生变化：`景深：` 行从无到有，`规格` 行不再断言浅景深）。

### F2【严重 · 已修】注入的 `props`（镜面倒影 / 湖面微澜 / 烛火 / 雨丝 / 玻璃反射）同样不进关键帧

- **现象**：`props` 只出现在视频提示词（`prepareShotPrompt` → 【道具】行），关键帧提示词里没有；
  而评审侧 keyframe rubric 明确要查"场景与镜头卡一致（地点 / 时段 / **道具**）"——提示词侧缺项，评审项无从满足。
- **根因**：同 F1（字段清单缺项）。
- **修复**：同 F1（新增 `道具与质感：` 行）。
- **回归**：`plate-prompt.test.ts` › "注入的 props 出现在提示词；无 props 时不产生空的占位行"。

### F3【严重 · 已修】夜景人像档位效果词带出真机翻车词"主体悬浮感"

- **现象**：`⑤ 雨天夜景霓虹` / `⑧ 烛光晚餐` 等夜景人像镜的 `depth_of_field` 注入成
  "奶油般虚化、梦幻光斑、**主体悬浮感**（极浅景深）"。
- **根因**：OPTICS-001 §三「夜景人像 = f/1.4–f/1.8」与 §二 档位表**每一档都零重叠**（只在下界擦边），
  `apertureStopFor()` 的两段逻辑（正重叠取最大 / 兜底取第一个有交集的档）都会落到 f/1.2–f/1.4，
  而该档的效果词里含"主体悬浮感"。三轮审计的注释里已把"N 夜景人物漂浮"记为翻车信号，
  但当时的修法只覆盖了 f/1.4–f/2.8 这一个区间，夜景人像档漏在网外。
- **修复**：新增 `sanitizeApertureEffect()` + 禁用短句表，写进提示词前剔除该短句（其余措辞仍取 KB 原文）；
  同时把这条口径写进注释，说明"为什么不能整档替换"。
- **回归**：`audit-round4.test.ts` › "夜景人像档不再拿到主体悬浮感" + "sanitizeApertureEffect 只剔除禁用短句"
  + "正常档位效果词不受影响"。
- **真机证据**：36 场景矩阵修复后 ⑤ / ⑧ 的 `depth_of_field` = "奶油般虚化、梦幻光斑（极浅景深）"。

### F4【一般 · 已修】室内兜底规则抢掉卡片已明写的光源（时段自相矛盾）

- **现象**（三条都是真实卡片）：
  - ㉒「室内，窗边柔光」的老年肖像 → 注入"暖黄钨丝灯下的温馨室内"（卡片明写窗光）；
  - ㉖「阴天的茶室，木格窗外是青瓦白墙」→ 注入钨丝灯，阴天散射光反而没进去；
  - ㉗「正午的室内，强光从窗户斜射」→ 注入"室内暖黄灯光，窗外**蓝调天光**"（正午不可能是蓝调）。
- **根因**：`INJECTION_RULES` 里 `indoor-warm-mix` / `indoor-tungsten` 排在窗光 / 正午 / 阴天 / 黄金时刻之前，
  而 `usedFields` 保证"每字段一条"→ 先到先得；`interior` 只要出现"室内 / 店内"就成立。
- **修复**：新增 `hasExplicitDaylight()`（窗光 / 正午 / 阴天散射 / 黄金时刻 / 雪景 / 蓝调），
  两条室内兜底规则在它成立时让位。
- **回归**：`audit-round4.test.ts` › "显式光源优先于室内兜底" 4 条（含"真·室内夜景仍走钨丝灯"防误伤）。
