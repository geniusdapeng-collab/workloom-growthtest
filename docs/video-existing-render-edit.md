# 自由剪辑入口已撤除

`--existing-render-edit`、`workloom.existing-render-edit/v1` 计划及其分段准备实现已在 `T-2026-1006-0002` 撤除。该入口曾允许调用者删换镜头、独立映射图声和裁切片段，违背本仓本次生产要求，不能继续用于标准交付。

CLI 遇到该旧参数会在工位、密钥和生成初始化之前报 `FREE_EDIT_REMOVED`。原素材、历史回执与失败交付仍作为历史证据保存，旧通过报告不认证新标准影片。

现行入口、冻结提交和原始渲染清单、允许的四种后期设置及失败路径见 [完整原片的标准后期](video-standard-post.md)。正常生产和标准后期均保留原稿中的全部镜头、原顺序、完整时长及各自同文件原声。
