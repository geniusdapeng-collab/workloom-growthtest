## 本批范围与行为（A：实现精读）

- 文本核验采用 NFKC + Unicode 码点 LCS / 较长文本长度，保留顺序及重复次数；非相同长文本最多计算 1600 万 DP 单元，超限显式拒绝。
- `result.status=passed|failed|unverified`；只有 passed 同时返回 `ok=true`、`receipt.synced=true`。`checked.text_match_status` 独立为 passed / failed / unverified / not_applicable。
- 有效原稿要求有效 ASR 回读；缺稿、关闭回读、不支持 ASR、空回读、网络/HTTP/超时/无效 JSON 均不得放行。仅明确 `speech_expected=false` 才将台词项设为 not_applicable；它不能与非空原稿同时使用。
- `strict=false` 保留失败/缺测报告，不改变放行结果；ASR 异常保留 `{code,message,retryable}`，物理测量缺失也不得通过。削波失败与台词匹配状态分开，避免调用方把混音问题当成缺人声补配音。
- 转写临时 WAV 在所有退出路径 finally 清理，测试二进制沿调用链注入；卸载调用保持同一注入通道。
- `voicewrite.verify` 每次重测，跳过 HTTP 桥的结果缓存，避免 ASR 恢复或同路径文件返修仍读取旧证据；其他动作的幂等策略保持现有行为。
- CLI、岗位、交付技能与自检使用相同合同；CLI 无效数值阈值不再静默回落默认值。
