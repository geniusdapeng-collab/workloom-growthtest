## 实现与取舍

**A · 原因与行为**：旧增强器把注入后的词继续当成新事实，并用人物专用知识或固定五路微动作补齐所有卡片。结果包括商品推近变成面部、保持蹲姿变成起身、右窗变左窗、烛光变成室内钨丝灯。现在先恢复本系统可证明的原字段，再生成同一份原始镜头意图；知识与微动作只追加适用完整句，不截断作者原文。

候选一是在 TypeScript 微动作和 Node 摄影连接器中各维持一套解析器，改动少，但否定、主体和恢复规则会继续漂移。采用候选二：`cine-kb-bridge/shot-intent.mjs` 单一 ESM 实现，邻接类型声明和 TypeScript facade 复用它。独立 CLI 无需 TypeScript loader，包内类型仍可检查。解析器为有限文本规则，不能替代监制或实片质量判定。

三个用户场景及验证结果：

1. 商品/动物/空镜：摄影只用相容主体知识，人物微动作为 `not_applicable`，不补面部、肤质或身体动作。
2. 人物蹲姿、睡眠、背影、远景或手部特写：按原姿态和可见部位决定表演通道；原卡要求起身时保留动作，不被起始坐姿锁死。无真实台词不写台词节拍。
3. 白天右侧窗光、烛光或显式景深：明确光源优先于泛时段规则；不更换左右、时段和色温，不因雾天制造逆光，不因空舞台制造追光。原景深逐字保留。

本批 P0 是上述意图守恒、来源恢复和真实写入记录；P1 是结构化失败、CLI 状态和资产摘要；本批不新增 P2 视觉功能。没有这些修复时，重复返工可能持续强化已偏离的镜头文本。新增材质/运镜知识、模型端画面效果、实际请求和门回执绑定由后续独立批次承担。

**A · 调用方联动**：CI 的真实 CLI 回归暴露旧 full-chain 仍要求至少四路微动作，合法两路也被拒绝；摄影阶段逐镜固定记录成功，末镜成功会掩盖前镜未验证；G7 只检查标记或历史任一成功。现改为逐镜消费当前四态、来源与输出摘要、完整应用句和真实写入字段，汇总优先级为 `failed > unverified > passed > not_applicable`。全空镜/商品可合法不适用，任何未验证/失败停止下游。G7 再次核验同一当前卡片，微动作复评显式使用适用性标准，不要求凑齐五路。

## 接口、失败与边界

- **A** `normalizeShotIntent(card)` / `resolveShotIntent(card, supplied?)`：归一原始主体、可见部位、姿态、相机动作、台词、时段、光源方向、色温和景深。返回 `sourceHash` 与版本；旧显式意图不匹配当前源卡时返回 `SHOT_INTENT_STALE` 错误。
- **A** `applyMicromotion(card, { intent? })`：返回卡片与四态 `passed / failed / unverified / not_applicable` trace；每个通道各判适用性。增量上限 200 个 UTF-16 码元，完整句加入；实际增量、应用句、源/输出摘要可核对。
- **A** `enrichShotCard(kb, card, options)`：保留原字段，字段上限 320 个 UTF-16 码元；超限整条不写，trace 记 `writtenChars: 0` 与 `field-over-budget`，状态 `unverified`。`actualWrittenFields` 只含真正落字段的贡献。
- **A** `_workloomEnhancements` 保存本系统每个字段的 before/after/suffix/afterHash 及来源；只删除可证明为自有的末尾贡献。用户改写原文但保留已知后缀时保留改写；不可证明的旧标记、被修改的贡献、非 JSON 数值与不适合字符串拼接的结构化字段均保留输入并标未验证。此来源结构不是身份认证或发布审批凭证。
- **A** KB 哈希覆盖主题版本、映射行、章节和光圈顾问数据。重复同输入及 JSON 保存后卡片保持一致；微动作与知识交替执行也恢复到同一源卡。函数无跨镜计数和共享运行状态。
- **A** CLI `enrich` 输出每镜状态和实际写入字段；未验证/失败返回 3，文件/JSON 等输入操作失败返回 2；trace 文件名由序号与清洗后的镜头 ID 组成，镜头 ID 不能越出 trace 目录。
- **A** full-chain 每次都消费增强函数返回的卡片，包括复用与不适用；摄影和微动作 dry-run 保存实际文本证据。请求的知识库缺失/加载失败为 `unverified` 并停止；逐镜任一未验证不能被最后一镜成功覆盖。`--micromotion-review` 读取当前 trace 和镜头快照，G7 使用当前卡片的微动作证据并作为硬检查，不接受孤立旧标记或历史成功。
- **D** `passed` 仅表示文本规则和写入证据通过，不等于视频看起来真实。未运行真实模型、没有实片质量结论。本批未改 vendor、模型供应商或生产账户。
