## 此批结果契约

普通文件重叠改为提醒；显式 `MODULE_EXCLUSIVE` 在 PR 阶段仍保持互斥。排除自身只依赖完整 PR 身份，其他 PR 的同 SHA、同分支或祖先关系不能当作自身。分页、删除、重命名、权威空 diff、实际 source 与预合并 checkout 分别处理；远端不可读不伪造成功。

桌面 release 初始仍要求精确 main/SHA/tag 和当前同 SHA 三门 CI，保存观察。之后允许受保护 main 真正前进到该 SHA 的后代；tag、签名、平台制品、字节摘要和最新相应 CI 仍核验。已公开或状态未知的副作用有真实回执，后验失败不能被写成“从未发布”。这不等于此次已经签名、构建或发布了原生安装器。

官方影片 CLI 新增显式 `--existing-render-edit <plan.json>`。它在 worker/镜头/密钥初始化之前运行，禁止混入生成选项。已有原片、声音、音乐的哈希与范围先冻结；按实际图声配对裁切并继承正式后期工位。原生对白搬到商品画面时记录呈现变化，错误人物画面按源 SHA 禁入，包括封面和别名。

选择独立本地入口优于复制一条临时 FFmpeg 管线：新增取段与来源适配，其余直接复用正式 compose/color/subtitle/bgm/cover。正常生成的登记人物、真实提交回执和专用视觉评审条件保持。

确定性封面取已有商品帧，字体摘要、真实字形与 alpha 墨迹逐项核对，不调用 LLM。首帧装配保留原始时长、音频与字幕时间轴。主版可明确保留源画面，三个风格变体仍通过真实调色与混音复检。新目录交付母版、软字幕、三变体、封面和来源/后期报告，原有媒体和失败历史只读保存。

## 需求和非功能条件

服务对象是拥有既有生成材料的制作方和负责本仓合并发布的开发者。目标是消除已知原声、人物画面及发布对象错误，用可复核结果结束原任务。

本地单任务画幅上限 4096、整数 1–60fps、0.25–600 秒，源最多 100 文件、100 段。生产实例是 1080×1920、24fps、30 秒、七段、全 1x。任务独占输出锁，中途源/字体/二进制/代码变化失败；没有新增数据库表、跨仓服务或网络素材获取。

候选门禁方案为修正全部身份/API缺陷但仍互斥普通文件，或修正事实读取并将普通重叠降为提醒、显式模块保持硬约束。选后者：普通 Git 合并与真实 CI 已承担集成验证，不能把任一同文件修改等同于危险冲突；确需互斥的模块仍由协议声明。

候选发布绑定为整个构建期间固定 main tip，或首检精确绑定并允许后续有证据的后代推进。选后者：不接受分叉、旧 CI 或 tag 改写，同时避免正常开发造成长构建失效。
