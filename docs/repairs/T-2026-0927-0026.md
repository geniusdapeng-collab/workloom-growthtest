## 问题与修复后行为

**A：** 原交付读选路径和媒资补录依赖可由调用者编辑的清单检查标志，不能证明当前媒体经过生产终审；工作区、项目、版本和实际文件指纹也未形成同一条绑定链。现在清单只登记候选产物。正式选择和生成件补录必须同时满足服务端封签、完整固定检查集合、证据文件、当前清单、当前产物实际字节及作用域匹配。

**A：** 普通 CLI、旧包和缺少封签的产物状态为 `draft`；签名、证据或当前媒体不一致为 `invalid`。两者可在正确作用域内预览已登记且实际哈希匹配的素材，不能正式选择，也不能经交付补录伪装成 `generated`。签名器和真实终审生产接线由后续权威资格批实现，本卡不包含可供调用者自签的 API。

## 方案选择与合同

比较过两条路径：一是建立数据库权威交付注册表并把全部文件引用收口到新服务；隔离更集中，但需要迁移现有 CLI、离线工程和多个生产器。二是在现有目录协议上增加仅服务端认可的封签、固定证据集合和字节核验，保留离线草稿能力。本卡选择第二条，避免扩大基座表结构；正式资格仍只能来自后续服务端生产权威。封签密钥必须独立于媒体 URL 密钥，并且只注入服务端。

文件模型没有数据库迁移。包保存到 `<deliveryRoot>/scopes/<sha256(tenantId + NUL + workspaceId)>/<package>`，封签 `workloom.delivery-seal/v1` 的 HMAC SHA256 覆盖 canonical JSON payload：租户、工作区、项目、正整数 revision、清单 SHA256、recipe/toolchain SHA256、时效、包 realpath、产物 ref/hash/role/variantId/bytes/realpath、每项检查及证据 ref/hash。生产环境使用 `WORKLOOM_DELIVERY_SIGNING_SECRET`；不足 32 字节或未配置时验签失败关闭。本卡只检查 recipe/toolchain 摘要合同，实际冻结内容由 P4b 及权威签发器提供。

固定检查集合 `workloom.delivery-required/v1`：母版、视频变体、软字幕版和烧录版要求 visual/audio/subtitle/provenance/final_review；封面要求 visual/provenance；独立字幕要求 subtitle/provenance；包要求 variant_axes/variant_distinctness。每项证据必须是 `workloom.delivery-evidence/v1`，具有同 scope/project/revision/artifactHash、明确 passed、非空 receiptId/method/observations。还必须具备母版、至少三支视频变体及各自封面，清单已有检查必须显式为 true。

## 实施结果与出处

- **A，`delivery-trust.ts`：** 只允许清单登记的产品产物引用。拒绝绝对路径、穿越、反斜线、空分段、符号链接包及任意中间目录符号链接。通过 `O_NOFOLLOW` 打开同一 FD，流式计算实际哈希，读取前后核对文件身份、大小和时间；预览返回的就是本次哈希过的字节，限制最大读取量。清单和证据限 4 MiB。
- **A，`delivery.ts`：** 列表、详情、取件、选择、返修分诊、返修作业及查询都要求 scope。正式选择绑定 project/revision/manifestSha256/sealSha256/variantSha256；封签更换使旧选择失效。选择时清单快照必须等于验签快照。作业完成标记只记录进度，只有真实进程 close(0) 才成功并触发补录，非零退出如实失败。
- **A，`router.ts`、`media/index.ts`：** 八个 delivery 入口与一个补录入口均从已认证上下文取 scope，不信任输入伪造的租户/工作区；越权路径返回 FORBIDDEN，缺件 NOT_FOUND，未核实交付 PRECONDITION_FAILED。读写守卫保留，返修作业 ID 不能跨租户/工作区查询。
- **A，`ingest-delivery.ts`、`register-local.ts`：** 首次写入前核验整包，每个产物拷贝前再次验证封签；使用 EXCL 临时文件、拷贝后真实哈希和原子 rename，再核对仓库目标哈希。失败即停止后续登记并保留真实部分进度。已有相同 SHA 的资产若属于其他项目或来源为 uploaded，则拒绝借补录改写为 generated。合法同项目重复补录维持幂等。
- **A，`Delivery.tsx`：** 展示草稿/失效原因，禁用未核实选择按钮，下载显示草稿身份；切包清空产物缓存、绑定当前包目录、拒绝旧异步详情覆盖新页面。文案统一三支变体，去掉会误导成已核验成功的旧提示。
- **A，`deliver.ts`：** 空集合、单支、重复 ID、空采样帧、畸形 RGB、NaN、非法响度和非法阈值不再被差异判断误报通过。两支有效实测仍可用于差异分析，产品三支门槛另行维持。
