# 出镜人物 成片反馈与制作契约修复

任务卡：[T-2026-1005-0001 / #103](https://cnb.cool/workloom-ai/workloom-growthtest/-/issues/103)。

本批属于 Growthtest 隔离副本。产品所有者已授权修复成片反馈、发布上一轮本地生产修复，并分析制作耗时与 Codex 接入阻力；不向其他仓分发，不增加付费视频生成。

已落盘的真实素材证明：第 1、3 镜原生台词识别通过，但统一后配参数替换了它们。封面未进入主片由关闭参数与旁路副本两者共同造成；字幕烧录在没有封面时自动添加了取自镜头清单的开场标题。第 3 镜的人物和服饰连续性缺陷保留为失败样本，不用再次生成掩盖。

本批将把这些要求落实为生产契约：出镜对白保留原生音轨；后配仅用于明确画外音；最终发布片首帧嵌入干净封面且保持时间轴；额外标题须显式声明；授权角色、统一参考素材、服饰与身份检查分别留证，缺证据保留内部候选；交付检查验真实摘要与元数据。

候选方案已确定：封面前置若干秒会改变片长与字幕偏移；首帧替换保留声音、时长和字幕时间轴，作为默认正式交付方式。人物颜色检查只作服饰信号，身份需要带授权参考图的独立视觉回执，技术分数不能代替。

验证包括失败断言、已落盘原生媒体负例、首帧与音轨守恒测试、能力入口和恢复回归、独立验收、发布门禁及平台真实评审。此文件后续只记录最终实现与实际结果。发布通过受保护 PR；回滚使用合并提交的 revert。

路径声明：官方 `scripts/tools/full-chain-film.mts`、任务接续与音频策略辅助组件、`packages/video-studio/src/` 封面与人物契约、BGM 工位、`bundles/geo-growth/capabilities/video.mjs`、相关测试和制作文档、派生能力清单及本任务排雷台账。

在途 PR #102 与制作入口和视频能力文件重叠。本批保持 WIP，按当前 main、路径锁和实际平台评审顺序发布，不覆盖在途修改或强制合并。
