# 完整原片原声标准后期与生产规则纠正

任务卡：[T-2026-1006-0002 / #107](https://cnb.cool/workloom-ai/workloom-growthtest/-/issues/107)。仅在 Growthtest 隔离副本实施，不同步其他仓。

产品所有者明确要求先交付六份原始渲染素材的标准五版影片；原顺序、完整原时长、同文件原声不变，只加调色/BGM/封面/字幕，人物问题本批暂忽略。然后撤回错误自由剪辑和自动后配/变速生产规则，经独立验收、精确 CI 和真实平台发表；最后系统复盘 Codex 擅改生成与生产规范。没有新供应商、模型、TTS、ASR 调用。

旧 `--existing-render-edit` 允许改图声映射、删换取段，曾由执行者自行选择七段重剪及旧配音。本次删除该实现与原测试断言，旧参数在生成初始化前明确拒绝。原 CI 测试路径仅保留完整标准套件的兼容 import，不保留自由实现；实际核对两条调用的全部用例相同并通过，不改流水线、不合入其他任务。新标准入口从生成前冻结原稿与生成后实际签发的原片清单重建唯一时间线；公开设置只包含四后期层，不再提供源/segments/取段覆盖。

正常 CLI 和父工位也使用全部原生音轨，提交前拒绝不支持的精确镜长、变化帧率/画幅、自动改速/补配。服务端在预算和工位调度前拒绝 voice.dub 及 normalizeToSeconds。生成后立即绑定实际下载回执；缺失、篡改、错序、旧 voiced、当前媒体与证据不符都失败。事实见证不是签名，不把历史采用或忽略人物问题写成身份通过。

新后期仍调用已有正式 compose/color/BGM/subtitle/local-cover/cover-assembly；不新写临时 FFmpeg 制片管线。首帧封面只替换第一帧，保持片长和音轨；五版交付有完整源和阶段回执。实际第一调用在合成前暴露外部 cwd 的 tsx 解析问题，已修正子进程 cwd，保留真实失败记录。

独立完整钟检验又发现五个初版 AAC 均缺少末尾 256 个真实采样。正式 BGM 合流移除最短流截断，有限完整 master WAV 自然结束；真实 3 秒混音回归先失败再通过。新后期逐个成片核对完整画面钟采样数，旧失败成片如实拒绝，新五版完整原声可用。正常 CLI 的裁尾、归一变速、速度坡和相机运动覆盖函数及分支均删除；子工位 `normalizeVideo` 在 IPC 前明确拒绝，父工位也在预算前拒绝。

只读能力联动移除 ASR/后配前提、限制当前精确镜长，并能实际读取标准后期 `outputs` 的视频及首帧封面摘要。行业清单与文档同步，bundle 使用实际 `bundle.json` 通过原治理工具刷新摘要，不新增签名、模型或依赖。

当前旧自由入口真负例 16 项中 13 项语义失败；原正常 CLI 53 项中 52 项失败；音频政策 16 项中 9 项失败；父工位 33 项中 8 项失败。新代码的合同/原片签发/实际区段/服务端拒绝回归与独立验收须在最终精确提交重跑，旧任务的通过记录不继承。最终 MCD、CI、main 和用户影片检验结果以实际产物及回执为准。

需求、输入数据、候选方案、三个场景、优先级、异常路径及不做范围见 [标准后期](../video-standard-post.md)。只用普通 PR/合并或已明确授权的透明 owner 平台操作，不伪造评审、运行、签名、发布或质量通过。安装器、社交发布和完整人物整改不在本批范围。

产品所有者随后提出多版配乐相同的听感反馈。核对实际五文件发现母版/软字幕/暖色共用音轨，三个风格版实际采用三份不同曲目并进入最终音轨。既有 `deliver.ts` 要求三风格在调色/封面/配乐三轴两两不同，主版不占名额。标准入口原 validator 错误接受主版单独交付、重复调色、同曲别名及部分漏乐；真实七例中六例先失败，再补入已有三轴与实际采样差异闸。当前影片经同一规则实测合格，不因误把便利版本当风格版而重新生成或擅改六镜。

完整普通 CLI 复查还找到旧配乐缺尾的 `apad` 覆盖路径及变体缺实际解码钟检验。修复撤掉静音补救，在主配乐/软字幕/母版/变体记录和发布前复用完整解码钟守卫；真实一秒完整音轨、0.8 秒缺尾及缺原合同三例先失败后通过。普通 CLI 回归更新为 56 项，标准原片/设置/最终三轴回归为 19 项；最终提交与独立 MCD 必须重新运行。
