## 方案与实际行为

候选一保留旧默认 auto 和十秒缓存、仅补网络异常处理，仍会让无规则与撤销后的调用派发，否决。候选二默认拒绝且每次重读，在当前薄适配层只允许明确无条件工具许可，本批采用；成本是每次多一次有界规则请求，暂不对未知业务 DSL 自行推断放行。生产服务继续拥有业务判断与生成资格。

- A：规则源缺失、非安全地址、认证缺失、HTTP/UTF-8/JSON 异常、响应超限、空/非法规则与未命中动作都拒绝；重定向不转发令牌，调用取消返回 cancel。
- A：支持认证 tRPC 投影和原始数组；禁止歧义约束；auto 精确动作/显式点分子树，限制级别保守匹配且 block 优先。没有过去成功许可缓存。
- A：条件/对象范围/未知字段不被当作已求值授权；review 只请求 Harness 审批，不生成生产资格。保留真实下游错误，不把执行失败改成规则获取错误。
- D：完整 Harness 进程端到端仍在后续集成验收；本批实际运行的是插件 hook、真实本机 HTTP 和真实计时/取消，并没有启动完整 Harness。插件不构成同一操作系统用户的 shell 沙箱。
