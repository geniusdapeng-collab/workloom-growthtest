# T-2026-1013-0002 · 视频交付联动修复移植（字幕随转场重映射 / 独立音轨逐刀对齐 / 暖调配方重定标）

> 来源：`workloom-ai/WorkLoom-video-edit` 的全链路审计台账（F1/F8/F2），按产品所有者要求移植到本仓。
> 本仓基线较旧：交付引擎是**整段 mode/fadeSec** 口径（无逐切计划/回执），因此移植按本仓口径适配。

## 1. 字幕随转场重映射（F1）

**问题**：转场（xfade）会交叠缩短成片，而字幕按时间轴写时间 → 尾部字幕超出片尾 → 软字幕轨内嵌把容器时长拉回
时间轴长度 → `duration_kept` 硬闸失败，产物被删（"转场 + 字幕"交付不出去）。

**修复**：
- `subtitle-bridge/core.mjs`：新增 `buildTransitionTimemap` / `retimeCuesForTransitions` / `clampCuesToDuration`；
  `softMux` 在 mux 前把可解析字幕轨（SRT/VTT）的 cue 尾钳到容器时长，钳制事实进回执（`subtitle_within_container`）；
- `post-bridge/core.mjs`：旁挂 SRT 按**母版实际转场**重映射；每个变体按**本变体**的 mode/fadeSec 重映射，
  变体目录另存 `<id>.zh.srt` 供软轨/烧录使用；时间轴口径 SRT（`<id>.timeline.zh.srt`）随包留存，返修可重算。

## 2. 独立音轨节目声（F8）

**问题**：`buildAudioStemTimeline` 只认整段 fadeSec；0 重叠（硬切）会触发 `acrossfade=ns=0` 报错；
画面逐帧量化导致节目声与画面差几十毫秒时被 40ms 同步闸判红。

**修复**：逐刀口径（`cuts`）+ 0 重叠 run 拆分为 concat + 按**画面实测时长**补尾部静音（`padToSeconds`）；
缓存校验与回放同口径。

## 3. 暖调故事版配方重定标（F2）

`warm-film@0.75` → `high-contrast-social` 打底 + `look-warm-film.cube@0.5`：去掉提黑造成的"灰雾压平"，
保留暖调同时把中间调对比/饱和拉回来。
